# 文库版 → web版 字词转换对照表

> 适用范围：本合集 web版第一章～第三章（由文库版第一～六卷转写补全的部分）。
> 目标译名标准：合集中实际存在的 web 原文（第129～264话）的主流拼写，即早期译者（朱雫、落地死的流星等）体系；**不采用** web 第347话后换译者出现的新拼法（玛莉亚/赛拉/雷梵教/芙茨亚茨/拉斯缇亚拉等）。
> 依据：①文库版第二卷卷首译注的官方对照（8组）；②web第129～264话词频统计与上下文比对；③web第135话《温习》等命名回的原文；④同场景文库/web双版本对照（文库七、八卷校对版 ↔ web第131～186话）。
