## 目录结构

- 文字/

  - 01_迷深观前须知/：新人阅读指引

  - 02_文库/第一卷～第九卷/：文库版正文，每卷一个目录一个 .md，卷内按「章（##）／话（###）」分节

  - 03_文库相关/：文库特典（第10～16卷插画见插画大目录）

  - 04_web版/第一章～第十章/：web版正文，每章一个目录一个 .md，章内按「话（###）」分节
    - 第一章～第三章为合集缺失部分的补全：由文库版第一～六卷转写（专有名词/标点已按web版译名转换：维度/连接/冻结/次元魔术/炎之矢体系、──/⋯⋯标点等），第三章末尾附合集中实际存在的web原文第129话Epilogue
    - 第四章～第十章为合集原有web原文

  - 05_外传空间/：外传、IF线守护者路线、诺文系列、闲话

  - 06_笔记解析/：作者设定讲解（部分设定、真正的魔法）与各话笔记

  - 07_后日谈/：后日谈、剧组一览、阿尔缇与缇达的过去篇

- 插画/

  - 02_文库/第一卷～第九卷/：各卷插画 + 图说索引.md

  - 03_文库相关/第十卷～第十六卷/：各卷插画 + 图说索引.md

  - 04_web版/：无随书插画，仅说明文件

5. 05_外传空间 / 06_笔记解析 / 07_后日谈

## 格式约定

- 一级标题（#）：书名+卷/章；二级标题（##）：章或分册；三级标题（###）：话/小节。

- 所有「第N话」小标题均保留，正文内含的HTML已清洗为纯文本+Markdown。

- 文库第七、八卷内容为「流星校对版」，其话标题与web版一致；文库第一卷第五章末尾内嵌第六章（原EPUB即如此）。

- 正文中引用的外部图片（译者交流截图等）以 ![alt](url) 形式保留原始URL。
