## 环境雷区（详见 knowledge/pitfalls.md）
- Windows：`python` 坏，用 `py -X utf8`；.py 被 hook 拦就写 .txt 执行。
- 破折号正则用 `[—─]{2,}`；半角方括号是标记不可删（P-003）。
- Context7 MCP 的 API key 失效（2026-09-03 观察），网络调研用 webReader。
- 网络（2026-09-09 证实）：大文件直连海外 CDN（desktop-assets.comfy.org 等）单连接会被限速到 KB/s 级，多段 Range 并发可达 ~13MB/s；HuggingFace 类资源需 hf-mirror。机器有 RTX 5070 Ti Laptop（驱动 610.47），装 ComfyUI Desktop v1.0.46 做 AI 绘图（实例名「文生图-智谱」）；机器上有 360/搜狗/Nahimic 等注入型软件，排障时勿凭模块表定罪。
