# 两轴模型与演化授权 v1

> **性质**：本库（库调试工作区，L9 + bootstrap_v3.9）的演化治理设计文档。人工维护（references/ 语义归属地；engine install 校验会将其列为未在册——已知外观项，见头部说明）。
> **依据**：混元 26 轮离线推演（125 实验）+ 衔尾蛇真引擎六轮（280+ run）+ DeepSeek 线独立复现，三线交叉验证。
> **状态**：v1（2026-09-09）· 授权清单随实测数据滚动修订

## 一、两轴定义

| 轴 | 含义 | 物理载体 |
|---|---|---|
| **L 能力轴**（L0–L9） | 库**能做什么**：安装期决定的静态能力阶梯（模块构成） | install 时的 level + modules（state.json.modules） |
| **E 信任轴**（E0–E4） | 库**被允许自己改什么**：运行期授予的演化自主权 | 本文件 + state.json.law_params + 锚定/评测资产在位情况 |

**核心命题**：两轴正交。L9 库缺锚定/评测时**不得**开 E4（库调试v3.2 = 反例：L9 但法层带病灶）；L2 库配齐三尺后可安全跑受限参数演化。**档位 ≠ 授权。**
