# 命令速查 v3.9 · 库系列操作手册

> 适用引擎：`library-bootstrap-v3.9/bootstrap_v3.9.py`（sha256 前 16 位见 `--hash`）
> 运行方式：一律 `py -X utf8`（本机 python 命令不可用）；从库目录内跑引擎用相对路径 `../library-bootstrap-v3.9/bootstrap_v3.9.py`，从根级目录出发**一律绝对路径**（P-010 教训）
> 法律：手改渲染件（AGENTS/README/spec/citations/提示词速查）= 违例，重刷走 `build-docs --lib`

## 一、引擎子命令总表

```
py -X utf8 <引擎路径> <子命令> [参数]

install   <L0-L9> --target <目录> --yes --data <bootstrap_data目录>
          全新装库；L8/L9 为慢车道，--yes = 人类令牌（须真人指令）
absorb    <v2.x源树目录> --data <输出目录>          # 从源树抽取内容体 → bodies.json
verify    [--fix] --data <目录>                      # 题录对账（arXiv 官方 vs REGISTRY）
run-tests                                            # 自测（v3.9 起真实计数，不再静默假绿）
build-docs --lib <库目录>                            # 重刷渲染件 + state 版本/锚点/law_params + Merkle 根
engine     <op> --lib <库目录> [更多参数]            # 库的日常操作（见下表）
guard      --diff <候选> --lib <库>                  # 变异守卫：触碰基准黑名单即否决
           --snapshot --lib <库>                     # 导出锚定快照 anchor_snapshot.json（抄录人侧）
           --anchor <快照.json> --lib <库>           # 人侧锚定表对账
absorb-md  --src <v4双库工作区> --lib <v3库> [--dry-run]
          # v4 Markdown 知识库 → v3 条目迁移；v3.9 起 TRAJ ID 含日期不撞号
migrate    --lib <v2.x老库>                          # 老 v2.x 库链续接迁移
--hash                                                # 打印引擎自哈希（公理 E 人侧锚点）
```

## 二、engine 日常操作（--lib 必带）

```
engine append  --lib . --text '<条目JSON>'    # 写入（十字段 schema；缺证据锚/含密钥即拒；同 id 不覆盖）
engine retrieve --lib . --text "<查询>" [-k 5] # 检索（kw×3+content×1+imp×law_w_imp−law_w_age×age）
engine eval    --lib . [--text <查询集.json>]  # 金标评测 → recall@5/MRR 入 evals/baseline.json
                                              #   劣化超 5% 触发宪章警告并 exit 2
engine wrapup  --lib .                        # 收尾：情绪衰减+根重算+反思触发检查（accum≥50 提示）
engine reflect --lib .                        # 反思素材包 → 交 harness 按提示词合成
engine reflect-done --lib .                   # 合成入库后重置累计器（勿手改 state.json）
engine retire  --lib .                        # t_invalid 超 TTL(90天) 条目移 attic（留痕不删）
engine shadow  --lib . --text "<描述>"        # 预演占位：只记审计链不改状态（公理 G）
engine doctor  --lib .                        # 体检：memory/audit/ledger/链/根 五态对账（只报告不修）
```

## 三、law_params（v3.9 法层参数，state.json 快照）

| 参数 | 当前默认 | 说明 |
|---|---|---|
| law_w_kw | 3.0 | 关键词命中权重 |
| law_w_content | 1.0 | 正文命中权重 |
| law_w_imp | **0.5** | 重要度权重（真实库 A/B：1.0 时 PT-005 霸榜、双指标最差；0.5 召回最优） |
| law_w_age | 0.1 | 年龄惩罚（老库注意定时炸弹；本库条目新鲜暂无感） |
| law_filter_zero | **0** | 零命中过滤，默认关！开启后 MRR↑ 但 recall↓（0.485→0.394，真实库实测）——接受召回损失才开 |

改法：改引擎 TUNABLES 后 `build-docs --lib` 重刷（全局生效）；单库微调待 v3.10 per-lib 覆盖机制。
