# exp8-council · 心智议会（society of minds）

## 装什么
council-reflect 技能（reflect 的议会升级版）。依赖 m-reflect。

## install.md 步骤
1. 复制 template/knowledge/skills/council-reflect/SKILL.md。
2. 在 reflect SKILL 的「步骤 2 合成」后追加可选提示：「信息冲突大时升级 council-reflect」。
3. 校验点：SKILL 含四席位与「少数派异议」强制段。

## 席位（默认同体分饰，预算 2 轮封顶）
档案官（证据）/ 批评家（夸大与无据）/ 梦想家（跨域狂想，承接 dream-fusion）/ 用户代言人（读 soul/USER.md 模拟用户反应）。产出 = 综合报告 + **少数派异议节**（异议不可被综合吞掉）。

## 溯源
Multiagent Debate（arXiv:2305.14325）：多实例辩论提升事实性；弱模型/低额度时退回单席 reflect。
