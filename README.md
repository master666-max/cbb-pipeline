# cbb-pipeline

百万字长篇小说 → 设定资料库。每条设定都能翻回原文出处。
思路：不要求 AI 记住整本书——每次只读一章，跨章记忆全部写进结构化账本。成本只看章数。

## 入口

| 路径 | 用途 |
|---|---|
| `SKILL.md` | 主说明书 |
| `scripts/cbb/cbb-anchor/` | 锚点核验（`cbb_anchor.py` + `test_cbb_anchor.py`） |
| `scripts/cbb/cbb-coordinate/` | 坐标/定位环节 |
| `references/` `assets/` | 说明书与素材 |
| `ACKNOWLEDGMENTS.md` | 致谢 |

## 流程

切章编号 → 逐章提取（每次一章 + 前情提要）→ 入库前自动检查（格式·引用·时间·前后一致性）→ 入库 or 待确认清单 → 全书画完自动对账（硬伤扫描 + 抽样核对）。

## 规矩

- 入库分两档：**已核实 / 暂定**。
- 可疑项进**待确认清单**等人裁定，不许直接进正式库。
- 同一个人换称呼必须归并，不许档案分裂。
