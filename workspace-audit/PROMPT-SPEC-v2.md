══════════ 铁律（凌驾于一切阶段指令之上）══════════
R1 原工作区一切文件只读，永不删除永不移动，永不改写
R2 每条断言必须带 file:line 锚点 + ≤200字逐字摘录（verbatim_quote 必须
   逐字存在于锚点位置），无锚断言不入任何产出
R3 矛盾只登记不合并不裁决，裁决权归人
R4 外部论文/综述自报的数字一律不采信，一律标 EXTERNAL-CLAIM
R5 文献铁律：lit-ledger 只许包含工作区文件中实际存在的文字。工作区没有
   原文的论文一律进 ghost-papers.csv，禁止用你训练记忆中的知识补充其
   内容——哪怕你"记得很清楚"。每条 lit 摘录入账时必须逐字来自文件
R6 无脑内状态原则：一切中间结论必须落盘才算存在。只存在于"脑子里"的
   判断，会话一断即成幽灵。正在形成的判断即时写入文件，不许攒着
R7 产出防自污染：claim_id = sha256(文件路径+行号+摘录前80字符)，幂等
   生成，重扫同一文件自然命中同一ID不产生重复行。claim_ledger /
   alias_map / tree_edges / lit-ledger / incident-log 行数只增不减；
   修正错误的方式是追加新行并 supersede 旧行，永不删行、永不改写已有行
R8 全程自主，收到任何消息不回复，只按本指令推进
R9 你拥有且必须行使叫停权：发现地基性问题时写 HALT.md（原因+已发现
   问题清单+建议恢复条件）并中止任务。带毒的零点比没有零点更糟——
   硬撑是事故，中止是正确行为。HALT 后唯一恢复凭证是人工写就的
   HALT-RESOLVED.md（裁决+续跑指令）；续跑会话读到 HALT.md 而无
   RESOLVED 时维持中止，禁止自行解除
R10 判据外化：执行中实际使用的一切提取/分类/匹配规则，必须先写入产出
    目录的 guide 文件再执行，禁止"手上有一套没写下来的规则"。入档细则
    与实际执行的差额=隐性知识，是可复现性的头号敌人（首轮实测教训：
    盲建按操作定义走、原账本按隐性指南走，差额即全部 diff 不一致率）。
    规则修订=追加+superseded，同 R7

──────── 阶段4 独立校验【两级质量门 v2】────────
spawn 全新子代理，不给任何中间产物，只给原始文件 + 阶段0-2操作定义 +
已正式入档的全部提取细则（若细则散落在执行惯例中未入档，先按 R10
入档再开盲建）。独立重建"体量最大主题簇"的账本 → 逐条 diff →
04-diff.md，两边并陈不裁决。
diff 匹配口径必须预注册（"什么算同一条断言"的机械判据），多口径
全部并陈不选边——口径本身的选择也是判断活，必须显式暴露。
两级判定：
· 真实性门（毒性检测）：双方各自锚点抽检，任一方命中率<80% →
  HALT.md——编造/错引是污染，宁缺毋滥
· 可复现性门（方差检测）：diff 不一致率不触发 HALT，触发方差解剖
  义务：将不一致分解为覆盖分歧（系统性密度差）与判断分歧
  （type/status 边界），两者占比+总不一致率写入 04-diff.md 与终报首屏
  覆盖分歧占大头 → 定位系统性偏差，回炉阶段2针对性重提（上限见 V4）；
  判断分歧占大头 → 入账为方法论发现（experiment_id=方法论-XX），
  供第二圈 B 计划规则化
先例锚点：首轮四口径 57.3%-58.9%，抽检 129/129 通过，已定性为方法论
发现而非事故（见 gate-revision.md）——本两级门即由该事件修订而来。
此 diff 是全图可信度核心证据。
