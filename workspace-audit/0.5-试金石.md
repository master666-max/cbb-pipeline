## 试金石抓出的规则 bug 与修订（本阶段核心产出）

1. **手抄摘录引入抄写错误**（试金石#2：2/39 条——粗体星号误加、行号偏移一行）。
   → **修订 R2 执行纪律：verbatim_quote 一律经 `ledger_add_extract()`（起止锚程序化截取）入账，禁止手抄整段**。起止锚不存在/锚重叠/超 200 字均当场抛错。试金石#3 全程按此纪律执行，0 抄写错误。
2. **需要 supersede 而账本不可改写**（R7 只增不减）。
   → 新建 `supersede_log.csv`（old/new claim_id + reason + ts），账本本体保持 append-only 纯净；`ledger_tool count` 与 `ledger_verify` 经此表过滤被取代行。
3. **验证器必须与 supersede 状态联动**：被取代的旧错误行永久留存（诚实记录），但不再计入现行命中率分母。
4. **工具自身也要修**：`load_superseded` 键名写错 / Edit 子串匹配吃掉缩进——工具 bug 由冒烟暴露并当日修复（`tools/ledger_tool.txt` v2）。
