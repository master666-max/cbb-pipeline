## 四、时间线重建规则（本考古采用）

1. **版本号最高者为有效版本**（提示词规则）；
2. 无版本号竞争时：文内日期 > git log > 目录并存事实；**mtime 不可信**（提示词明令）；
3. 嵌套 git（大审查 c31ad39 / zcode e91bdef / 猴子 c53c75a→HEAD ad8b274）的 log 作为各宇宙内部时序依据（快照见 `data/nested-repos-baseline.txt`）；
4. 跨目录副本以 hash 对账（如 5f8199aa 三副本=同一时点快照）。
