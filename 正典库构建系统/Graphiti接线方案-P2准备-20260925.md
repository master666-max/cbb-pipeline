## Spike 实测（`graphiti_spike.py`）

- 输入：真章节切片（ch0003 前 600 字）+ 伪锚点 reference_time（第 3 章 → 2000-01-03，禁墙钟纪律同 neo4j_export）；
- 输出：**Entity 8 / RELATES_TO 6** 落入 graphiti 实例——管道全通；
- **成本：988.7 秒/集**（600 字！graphiti 每集多轮 LLM 调用：实体抽取→消歧→边抽取→摘要，14B CoT 模型慢）。
- 坑记三笔：①cross_encoder 缺省会找 OPENAI_API_KEY（须显式 `OpenAIRerankerClient(config=…)`）；②episode 节点标签是 `Episodic` 不是 `Episode`（清点查询注意）；③neo4j AsyncSession/AsyncResult 全异步（`async with` / `await result.single()`）。

## 架构决定（接线形态）

1. **双图并存**：正典图（neo4j-step0，neo4j_export 派生，检索单真源）不动；Graphiti 图在独立实例积累双时序层——两图不做 MERGE；
2. **episode 摄入挂章收口**（与 lightrag delta sync 同批 aux）：每章一章文本一集；reference_time=伪锚点；
3. **时序语义收益**：graphiti 自动做实体消歧与旧事实 invalidation（t_valid/t_invalid + t'created/t'expired），取代手工维护——这正是"作者吃设定"的终态解；
4. **消费方式**：graphiti 实例只读检索（search/syntax 邻域），结果作为链构造器的第二来源，不直接写正典。
