# 前沿工具调研 · 知识图谱表示学习一路（2026-09-27）

> 深度档：KGE 框架选型/图算法现成件/时序知识图谱/Neo4j GDS/LLM+KGE 混合/冷启动稀疏图。GitHub API+源码+官方文档直查；【待确认】处已标注。

## A. 逐题深度发现

**Q1 KGE 框架与万节点小图选型**
- **PyKEEN**（MIT，2039★，2026-09-26 当天活跃）：30+ 模型，filtered ranking 评估（MRR/Hits@k）；**关键 API=`predict_target`/`predict_all(k)` top-k 缺失三元组建议**，带 `.filter_triples` 与 `.add_membership_columns`。
- **官方警告（决定人审闭环设计）**："KGE 分数没有统计含义、不能跨模型比较、没有先验最低分阈值，预测只能作为排序优先级；分数校准可能很差"——top-k 只能当排队优先级，不能当置信度。
- LibKGE 论文结论（ICLR 2020）：**训练策略与超参的影响大于模型类别**——小图不必纠结 TransE vs RotatE，精力放在打分函数与负采样配置。
- 万节点级实测：RotatE/ComplEx-N3 最优（FB15k-237 MRR≈0.338/0.354）；小图安全首选=低维（32-128）ComplEx/RotatE+KvsAll 训练循环。
- **AnyBURL（BSD，笔记本级）=规则+confidence 可解释输出**——比 KGE 分数更适合"缺口提议"人审场景；PyClause（BSD）做规则排序聚合。

**Q2 共现图→候选关系的算法实践**
- networkx 链接预测六件套（Adamic-Adar/RA/Jaccard/资源分配/共同邻居中心性）；Leiden 社区（GPL；MIT 替代 graspologic 或 networkx louvain_communities）。
- 通行阈值实践：共现边权 ≥2-3 剪噪；Adamic-Adar/RA top-k 且**硬性要求共同邻居数 ≥2**；多分数共识（AA 与 RA 同时进 top-k 才提报）。
- Neo4j GDS Community 覆盖全部所需（LP 基线=Alpha tier；Leiden/Louvain/Node Similarity=Production；LP Pipeline=Beta），万节点毫秒-秒级。

**Q3 时序知识图谱（双时序适配）**
- 离散时间步线（RE-GCN/TiRGN）**错配**：假设等间隔事件流预测 t+1，与 valid_at/invalid_at 区间型双时序不符；且 repo 均无 license、2022-2023 后休眠。
- 区间型 TKBC（TimePlex/Time2Box/NeuSTIP）均为无 license 研究代码——**"失效感知链接预测"无生产级现成件（明说）**。综述：arXiv:2403.04782 等。
- 工程替代三层方案（B-2）：validity 掩码训练 + 过期边当天然负例 + 时间特征（活跃度/共存窗口）。

**Q4 Neo4j GDS**
- Community 版可装 GDS（GPL-3 分发，注意传染边界）；算法全覆盖：LP 基线（Alpha）、Leiden/Louvain/Node Similarity（Production）、LP Pipeline（Beta，可训练 predict_stream）。

**Q5 LLM+KGE 混合**
- OMNIA（2026-03）：语义聚类生成候选→嵌入粗滤→LLM 语义校验；**PERSEUS（2025）实测 generate-then-verify 比直接 LLM 抽取精度 +11%、假阳性 −54.6%**。
- KICGPT（EMNLP 2023，MIT）：检索示例进 in-context 让 LLM 打分；KoPA（ACM MM 2024）：KGE 结构嵌入投影成虚拟知识 token；RoG（ICLR 2024）：约束 LLM 沿 KG 路径推理（grounding 思路可借鉴到提议解释生成）。

**Q6 冷启动/稀疏图**
- 1719 三元组落在经典小数据集区间（Nations/UMLS/Kinships 均为 PyKEEN 内置标准件）——**KGE 在几百~几千三元组上有三十年文献背书，可训**。
- 小图套路：**KvsAll/1-N 打分显著优于负采样**（稀疏图伪负例）；dim 压到 32-64；epoch 加大；负采样开 filtered+提高 num_negs_per_positive+方向性关系用 Bernoulli。**低于 ~500 三元组 KGE 基本不可用**（转 AnyBURL 规则或共现统计）。

## B. 接入建议：链接预测→缺口队列的三通道人审闭环

1. **通道一 共现结构**（最便宜先跑）：人物共现图→networkx Adamic-Adar/RA top-k（共同邻居≥2）+社团同属过滤→候选对。
2. **通道二 KGE/规则排序**：PyKEEN（ComplEx/RotatE，dim=64，KvsAll）对候选对 predict_target 排序；并行 AnyBURL 出**规则+confidence**（"师从(A,B)∧师从(B,C)⇒同门(A,C)"规则文本直接给审阅者看——相对 KGE 的决定性优势）。
3. **通道三 LLM 语义校验**（复用 NLI 分歧管线）：只对 top 候选提问，LLM 给支持/反对/文本证据出处。
4. **队列字段设计**：候选 (h,r,t)+各通道分数（**分开列不融合**——KGE 分数不可跨模型比较）+规则解释或 LLM 证据+与已知边矛盾标记+建议 valid_at。
5. **反馈回流**：人审接受/拒绝记录成表→下轮留出集与校准依据——补上"领域内无公开 top-k 精确率基准"的空白，第二次迭代起有自己的 PR 曲线可定提议阈值。
6. **双时序进特征三层**：①打训练集掩码（已 invalid 的边剔出训练）②**过期边当天然负例**（"曾经真现在假"的免费监督，静态 KG 没有的信号）③时间特征（活跃度/共存窗口）喂 LP pipeline。区间型 TKBC（Time2Box 思路）列二期研究。

## C. 排除项

DGL-KE（2020 停+亿级边设计）、RE-GCN/TiRGN 线（等间隔流假设错配+无 license 休眠）、TimePlex/Time2Box/NeuSTIP 直接集成（无官方可用代码）、GDS ML Pipeline 硬绑定（Beta+GPL 传染，仅内部用）、leidenalg 代码外发（GPL 传染，内用无碍，外发换 graspologic/networkx）、ConvE/TuckER 重模型与 dim>256（小图无优势）、NSCaching/AnyBURL 大图配置（规模不符）、OMNIA 等纯论文无码（借 generate-then-verify 模式）。
