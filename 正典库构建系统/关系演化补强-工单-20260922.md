  ① **路径域校验**：派工前机械断言——本次各并发子代理要写的路径**两两不相交**（现纪律只写在文字里："路径互不相交"，无判据）；
  ② **章号认领登记**：同一章不得被派两次（田论 A19 边界"不防同田并行"在 CBB 的对应物）；
  ③ **资源域分类表**：把 CBB 每个写入面标定四类——**W-A 并行追加**（切片／候选件，各自路径）／**W-B 单写序号**（记录编号与注册表）／**W-C 互斥受控**（本体库／STATE／commit／账本）／**W-D 追加后裁定**（隔离区裁决）；**含无路径的写**（Neo4j 导出、嵌入服务调用、DeepSeek 抽检调用——田论 A20："路径没载体"的那类）。
- **判据**：派工前产出一份"本次域清单"并断言无交集；资源表每一行都有类别与单一写者；**正对照**：故意制造一次路径重叠 → 校验必须报错；故意重复派同一章 → 认领登记必须报错。
- **交付**：派工前校验脚本 + 资源类别表 + 单测（含两个正对照）+ 报告。

### U-D18 报告体例（可机械自检）
- **内容**：本单所有报告与判定采用**态标记体**（照田论第七卷的机械自检）——每条主张起头一行，紧随一行 `态：证实／结构判断／疑`；**每条附否证动作**（别人能执行、若为假会看到什么）与**空判定面一问**（"如果被检查的东西完全不存在，这条命令会说什么？"）；文末必须有**落点自陈**（这份文件有没有强制力、谁读它、删掉会怎样）。
- **自检**：机械计数"主张块数 == 态行数"，比值必须 = 1（复算命令写进报告）。
- **判据**：本单终报与各干跑报告全部合体例；自检可复算；**终报另附双向平衡核验**（照田论卷六）——本单提出的每条判据，必须在 CBB **自己的账面上**找到同构实例，找不到即视为本单**未完成**（例：主张"判定面为空不得读成通过"⇒ 必须指出哨兵件把"裁决滞后"写成 UNKNOWN 却仍作可读报告的那个实例）。
- **交付**：体例说明（追加进报告模板）+ 自检脚本 + 终报。

## §8 借鉴：隔壁「田 · 声明式审计」方法论（专为 U-D10）

> **来源**：research-hub `田-理论研究/`——真源=`论文/田论_写域作为可复算的协作单位.md`；`START-HERE.md` §4 五条证据纪律；`被测件锚.md`。本会话已通读，只借方法、不搬任何文件。

**能借的四条（逐条给 CBB 落点）**

1. **声明面 / 观测面必须分离**。田把"谁有权写哪块地"从运行时共识提升为**静态坐标**，于是"归属"变成可机械查询的东西。CBB 的对应物＝**应覆盖域登记**：**"应该有什么"必须来自独立于抽取链的声明**（语料自身的章标记＝外部真值），**不能由抽取产物自报**——否则就是自己给自己出题。
2. **空判定面必须产生非零状态**（田论 A27）。隔壁的元反模式说得很清楚：**"判定缺席"／"判定为空"／"判定为通过"，三者在输出上同形**。CBB 现在正是它的发作形态：**"这一章没有记录"与"这一章确实该是空的"，在读的时候长得一模一样**。故 U-D10 要求：登记件缺失 ⇒ 必须非零，不许读成"不适用"。
3. **正对照必带**（田论 T5）。判据的价值不在"它拒了什么"，而在**"它拒对了一个、放过了一个"**。故 U-D10 的判据必须是成对的：抽掉一章 → FAIL；补回同一章 → PASS，同一判据、唯一变量。
4. **有界宣称**（田论纪律 4：有限测试只能证相交、不能证不相交）。所以 U-D10 只能说"**相对语料章清单的覆盖完备**"，**不得**升格为"账本完整可证"；且照纪律 1，每次复算绑内容哈希（`clean_full.txt` sha + 库状态 sha），否则矩阵没有指称。
   附：纪律 5（**标签与量必须对账**）正是 CBB 现有的一处病灶——同一个"矛盾积压"出现过 76／183／172／155／32／604 六种读数，本单 U-D05／U-D15 的回放报告必须自带"这个数是怎么数出来的"。

**不宜照搬的一条**：隔壁的门是**拒止**（fail-closed，用吞吐换安全）。CBB 的补强件**不得阻断主线抽取**——故 U-D10 只做"登记 + 复算 + 非零状态"，**不做拒止**；拒止权留给终审判据（U-C09）。同理照 `被测件锚.md` 的 T-E 论证：**不复制语料**，只锚它的哈希。

## §9 理论吸收条款（T-1~T-10 · 跨全单通用纪律）

> 来源：`田-理论研究/`（真源《田论·写域作为可复算的协作单位》+ `START-HERE.md` §4 五条证据纪律 + `被测件锚.md`）。
> 写法：**不看标语，看否证动作**——每条都写"违反时你会看到什么"。条款对本单**全部单位**生效，不止 U-D10。

| # | 理论想法 | CBB 落点 | 违反时你会看到什么（否证动作） |
|---|---------|---------|------------------------------|
| **T-1** | **声明面与观测面分离**：归属必须是静态坐标，不能靠运行时共识 | "应该有什么"只能来自**独立于抽取链**的来源（语料自身的章标记），不能由抽取产物自报（→ U-D10①） | 把声明面换成"抽取产物自报"，覆盖矩阵立刻变成恒真——**任何章都能自证已处理** |
| **T-2** | **元反模式**：判定缺席／判定为空／判定为通过，三者在输出上同形 | **跨全单通用**：门 1、召回探针、校准报告、四触发器哨兵、判分器、DeepSeek 抽检——凡"判定面为空或未执行"，**必须输出非零状态并显式标"不适用（非通过）"** | 现状实例：哨兵件把"裁决滞后"写成 `UNKNOWN`，整件仍是一份**可读的报告**；门 1 零拦截时的输出与"没跑"同形 |
| **T-3** | **正对照必带**：判据的价值在"拒对了一个、放过了一个" | 本单每个自动化判据（U-D04／D05／D06／D10／D13／D15／D16／D17）提交时**必须附正负成对样例** | 只有负例 ⇒ 检查器可能"对什么都报错"，你无法区分它是否正确 |
| **T-4** | **有界宣称**：有限测试只能证相交，不能证不相交；且实测对象以**内容哈希**标识 | ①一切结论绑 sha（语料+库状态）；②宣称写明口径上界——只能说"相对章清单的覆盖完备"，**不得**说"账本完整可证" | 不绑哈希 ⇒ 换一份语料/改一次库，"上次那份矩阵"没有指称；口径越界 ⇒ 一句话把"没漏"和"没被篡改"混成同一件事 |
| **T-5** | **标签与量必须对账** | 每个数字必须能复算：报告须给"这个数是怎么数出来的" | 现状实例：同一个"矛盾积压"出现过 **76／183／172／155／32／604** 六种读数，无一时点口径可复算 |
| **T-6** | **判据侧的错与被测对象的错，在输出上同形** | 本单每个新脚本先跑"空输入／坏输入"自证**它能报错**，而不是静默通过（P-018 姊妹条） | 检查器自己坏了，报告与你看到的是同一个"没问题" |
| **T-7** | **单向稀缺分配**：全局唯一且不可回退的东西，必须有独占分配者 | 不可回退的分配＝记录编号／状态晋升／裁决终态／章号认领：一律**单一写者 + 不可重排 + 撞号即占位**（→ U-D02、U-D17②） | 两个写者同时分配 ⇒ 撞号或双份终态，且**事后无法判谁有效** |
| **T-8** | **副本多义律（T-E）**：k≥2 个副本时，被执行的是并集、被报告的是最宽的那个、**差集是静默的** | 同一物多副本（skill 四处副本、工单／发车件双份、影子件）**必须锚哈希 + 机械比对**，禁止靠"我记得同步了" | 现状实例：发车件的并发档（4）与工单（6~8）互斥而**无任何信号报警**——差集静默 |
| **T-9** | **落点自陈**：先把自己落在哪一级写清楚，再谈别人 | 每份 CBB 文书（工单／判定书／报告）必须写：**这份文件有没有强制力？谁读它？删了会怎样？** | 不写 ⇒ 文书被当成了机制；"写了"被读成"做了" |
| **T-10** | **双向平衡核验**：每条弱项必须在撰写者自己的账面上找到同构实例 | **本单终报的硬要求**（→ U-D18）：本单每条判据在 CBB 自己的账面上找同构实例，找不到即视为本单未完成 | 只给别人定标准、不在自己账上举例 ⇒ 该条判据不可判，属"没有对手的陈述" |

**主题（三条落点已在案）**：T-1／T-2／T-3／T-4 是 U-D10 的理论骨架；T-2／T-6／T-9／T-10 是对**全单文书**的约束；T-7／T-8 分别对着"不可回退分配"与"影子件漂移"两个已现形的病灶。
