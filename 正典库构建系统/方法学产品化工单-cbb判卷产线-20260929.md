# 方法学产品化工单 · cbb 判卷产线通用化（v1.0 · 2026-09-29）

> **动机**：迷深实战（517 章大书）独自扛下了判卷产线的全部踩坑成本——契约刻度、三票编制、植株元门、审计通道、隔离纪律全部已在真库验证。本工单把这些组件从"迷深专用脚本"蒸馏成 **cbb 技能族的可复用产线**，达成用户目标：下一本书从两周压到两三天，不再死磕任何一本书。
> **范围冻结（第一批）**：只做"判卷产线通用化"。抽取线（章节切分/实体抽取）适配、发布链模板化列后续批次，本批不碰。
> **执行方式**：串行、逐单位 scoped commit、dry-run 先行、换一本书实测为最终判据。

## 一、批次划分

### 批次 1（本批）：判卷产线 config 化 → `scripts/judging/`
- **U1 判卷配置文件**：`judging.config.json`——库根/工作目录/考官编制（base/model/key-env 名）/契约文本路径/掺株数与种子/批大小。全部路径与编制外置，脚本零迷深字面量。
- **U2 五件套改造**：组装/DS 腿/合票/上岗考试/中途修复 读 config 运行；契约文本走文件（`contracts/judge-v2.2.txt`），不进代码。
- **U3 契约刻度 A/B 件**：`ab_contract.py` 泛化（任意两契约文本×任意分层样本）。
- **U4 随包测试**：小样本夹具（合成 20 件+4 株）离线跑通组装→双票→植株门，进 cbb2-tests。
- **U5 试点实测**：换一本小书（或迷深切片副本）50 件验证轮，零代码改动仅改 config。
- **判据**：U5 零代码改动跑通 = 批次 1 过门；随包测试全绿 = 可发布。

## 二、纪律（不变）

- 真库写只动 sidecar；判卷面永不携带 expected；植株穿插全卷；第三方不过考试不上岗；第三方不进主链（抽检/审计）；每单位 scoped commit。
- **不做全量**的裁决延续：任何新书先 50 件验证轮。
