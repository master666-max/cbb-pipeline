## 五、DeepSeek 为什么耐用（2026-09 口径）

1. **牌价本身就是最低档**：V4-Flash 输出 ¥2/M vs Kimi 24、MiniMax 6.8——不是促销，是常态定价。
2. **缓存命中 ¥0.02/M ≈ 输入价的 1/50**：DS 把用户上下文前缀落盘缓存，命中几乎白送。判卷负载（固定系统提示+格式头 × 数千条）正是命中率最高的负载形态，账单大头（输入）被砍 98%。
3. **架构省**：极稀疏 MoE（总参大、激活小）+ MLA/稀疏注意力把 KV cache 压缩一个量级 → 单 token 真实服务成本就低。
4. **商业模式**：幻方（量化基金）自费养，API 不背盈利 KPI，定价≈边际成本；开源权重倒逼全行业降价（GLM-Flash 0.8、step-flash 0.7、MiMo-Flash 1 的价签都是被 DS 卷出来的）。别家 API 是收入线，DS 的 API 是广告位。
5. **峰谷分时**：空闲时段再对折——串行夜间跑正好吃满。
