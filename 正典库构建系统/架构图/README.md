## 〇·五、植株与捕获门算术（消歧：8 vs 5/6）

- **8 株全数计门，没有金丝雀、没有备用株**：4 正（已晋升件复判，期望 promote）+ 4 负（张冠李戴合成件，期望 hold/human），seed=20260928 同源同构可复现（g16c_rejudge.build_plants）。
- 门是**两条取交**：`correct ≥ 5`（小样本下限）**且** `capture = correct/株数 ≥ 5/6`（比率门限，设计容忍至多 1/6 错判）。
- **8 株下的实效门 = correct ≥ 7（至多错 1 株）**——"5/6"不是"8 选 6"；株数 <6 时下限条才先起作用（两条件并存的原因）。
- FAIL ⇒ 本轮全部判词降级「仅参考」：判词留档不采信，但不追溯重烧钱。

## 二、分层维护频率（C4 思路，本项目落地）

- **容器图/部署图** = 架构层：只在仪器变更登记（考官编制·仪器变更登记.md）出新版本时更新——半年量级。
- **状态机/ER/流水线** = 规则层：票门规则（B5/B13/TWD）、台账契约字段变更时更新——月量级。
- **模块依赖图** = 代码层：**永远自动生成，禁止手画**。生成器 `tools/gen_module_graph.py`（stdlib ast，零依赖）。
- 每张图头部标「数据锚」：图里的数字/编制来自哪个在案文件，三个月后可回查。
