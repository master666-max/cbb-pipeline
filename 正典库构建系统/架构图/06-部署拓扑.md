## 读图三问

1. **令牌放在哪？** 只在用户级环境变量（黄色节点=涉密面）：`DEEPSEEK_API_KEY` / `MODELSCOPE_SDK_TOKEN`；setx 后必须重启 ZCode 子进程才可见（P-027）。任何 key 不落文件（D-004），工作流脚本里只有 env 名不含值。
2. **哪条链路最脆？** GitHub 推送链——反代进程死→伪装成 token 失效（P-025）；REST 树 POST 502→需要 blob 幂等+耐心的重试（升级中的 rest_push_phasea.py）。
3. **扩容往哪加？** 考官=env 三元组即插即用（候选池见 白嫖调研工单）；并发=工作流 GUI 旋钮（用户手调，当前 4）。
