## 二、七路预调研关键发现（浓缩）

### 路1 增量图谱与同步
- GraphRAG 增量=批式 delta+标题碰撞合并，官方 bug #2540（2026-09 仍 open）证明 delta 间互不知晓——**CBB 的稳定业务键 MERGE 天然免疫，此优势要显式文档化**。
- LightRAG 官方主打增量插入；块级部分更新 PR #4054 2026-09 仍未合并 → 整批重喂是对齐其能力的正确姿势；官方已不依赖 community reports。
- Graphiti 三雷：edge invalidation 全图误杀（#1728，生产图 41% 边带 invalid_at，抽检 3/4 误杀）、CJK MinHash 去重失败（#1357 open）、摄入静默丢失（#1707）。`add_triplet` 官方定位"bypassing extraction"。
- "单一事实源→派生投影+对账"与 AWS CQRS/event-sourcing 指引完全同构；增量索引标准做法=内容哈希+投影检查点；**单机文件源轮询无反对证据**。
- 颠覆候选：Narrative World Model（叙事学接地记忆，多跳故事状态 QA 击败 Zep/Graphiti，OpenReview 在审）；HyperGraphRAG 超边（n 元事实）；LazyGraphRAG 按需物化（冷热分层思想）。

### 路2 抽取侧与动态提示
- **Schema 键名/词表措辞是指令通道**：仅改措辞可移动精度数十点（PARSE：SWDE 最高 +64.7%；Schema-Key Wording）——词表升级必须做"措辞偏置审计"。
- 格式税来自提示层而非解码器："先自由推理→再格式化"可收回；约束解码只保语法不保语义——**证据门仍不可省**。
- GEPA（ICLR 2026 Oral）反思式提示进化胜 GRPO 6%/rollout 少 35 倍；逐例自适应提示在 IE 有直接正证据（+13.6 点）；动态 few-shot 有反例（临床域不稳定）→ 上线须配回归闸。
- **闭环抽取无成熟范式**——最接近 DIAL-KG"双轨抽取→验证→schema induction"三阶段；"知识缺口驱动抽取"是真实空白，**CBB 的 gate1 reward 条件是全世界少有的适配资格**。
- 上下文工程共识：混合三层（实体卡内容寻址+递归状态滚动摘要+近期窗口）省一半 token 保效果；**跨管线指代必须显式化**（漂移实证）；≥100 章 KG 辅助增益无显著证据——别指望上下文包解决全书级一致性。
- 小模型跑量+校准路由实测 -31% 成本 F1 持平（UCCI，7.5 万查询生产负载）；gate 失败/降级事件就是免费置信信号。

### 路3 一致性与判定
- 中文 NLI 小模型现成：Erlangshen-RoBERTa-110M-NLI（CMNLI ~79-80%）；MiniCheck-FT5（770M）grounding 核验 GPT-4 级、成本 1/400。
- per-claim 验证显著优于整段；长文档自主定位矛盾不可靠（ContraDoc）→ 拆小再验；LLM 判矛盾本身不可靠（RAG 矛盾检测评估）→ **"只分流不裁决"设计被侧证**。
- **Finch-Zk（EMNLP 2025 Industry）：异构模型细粒度一致性检测幻觉，F1 +6~39%、GPQA +9pp——"外部异构 API 独立考官"路线获最强正面实证**。
- 多智能体辩论一致性≠正确性（KDD Eval Workshop）→ 考官必须隔离评审后聚合；位置偏见用答案对调取均值（IJCNLP-AACL 2025）；口头置信系统性过自信。
- 生产范式=失效而非覆盖：Zep 双时间线 edge invalidation；Mem0 写入路径 ADD/UPDATE/DELETE/NOOP 四分（注意 ER-MIA 注入攻击警告——语义相似度驱动的 UPDATE/DELETE 可被利用）。
- 0.97 单门限无文献同构物；"trust decay+evidence accrual+自动晋升"无统一标准模型——**票数累积制是自行组装项，非抄作业**。

### 路4 审计抽样与覆盖率（漏项机制补调研）
- 审计抽样共识：**发现与估计两轨分开**——可疑优先排序只用于发现（Northcutt 模式），其通过率不可外推；估计须分层随机或 LQAS（每层 n=19 只出合格/不合格）。
- **我们 20 条对样/30 条终判在统计上只支持极粗判定**（30 全过 → 95% 置信下真实通过率下限仅约 82-86%）→ 双轨记账+区间宣称。
- Chapman 的独立性坑：同模型相似提示两次抽取正相关 → 重叠高估 → 覆盖率高估；链接错误（假并/假分）直接污染计数（arXiv 2403.11438）→ **去相关双捕获器+Chao1/ACE 发现曲线**；2026 已有 LLM 抽取用生态丰富度估计器先例（arXiv 2602.24262）。
- 植物捕获（plant capture）：向语料注入 30-50 条已知金标测捕获率——绕开独立性假设、可自动化，比 Chapman 交叉验证更硬。
- CUSUM 直接用于 LLM 质量监控：无公开案例（新领地）；上线前必须 bootstrap 控制限+已知变更打标记重置基线+优先监控相对指标。
- 仪器治理：指纹四元组 → 升级"语义版本+冻结归档+桥接样本（新旧仪器同跑 50-100 条）+误差条"三件套（HF Leaderboard v1/v2 与 lm-eval-harness 治理惯例）。
- 颠覆候选：人机分歧率当质量信号源（分歧簇=判据模糊处，回流修 criterion）；终审从"毕业考"改"仪表盘+再校准触发器"（Netflix 评审生命周期）。

### 路5 实体解析与别名（漏项机制补调研）
- ER 共识=两阶段（blocking 召回+判决）；LLM 未全面取代微调小模型（COLING 2025 三范式对比）；简单 TF/IDF blocking 出奇地强。
- **悬挂端点两分法获正面印证**：变体→归一/别名表，缺失→NIL 两步法（detection+clustering）+隔离区人审晋升（Lost and Found，SWJ 2026：无法链接的历史人物提及作为新节点进 KG 而非舍弃）；"禁自动删除"无字面先例但获强间接支撑。
- 43 变体归一机械化三段：确定性归一（NFKC 全半角/括注剥离/零宽字符）→ blocking 召回 → LLM 判残余（输出四分类+置信）。**别名表只增不改、规范名永不改写、合并必须可撤销（union-find+合并日志）**。
- 0.85~0.95 相似带：废弃绝对阈值 → **margin（best 与 second-best 差）+分歧信号（属性冲突/关系兼容）+人工判例回流自校**。
- 65 例已人工分好 43/22 → 直接当 ER 评估金标；SHACL"关系对象必须在实体表"固化为写入前常态校验。

### 路6 混合检索与归因拒答（漏项机制补调研）
- RRF 是稳健基线，重排后融合方式差距趋平；**更高杠杆旋钮是每路窗口深度**（比融合公式值得调）。
- 图路增益条件清晰：多跳/关系中心/全局综合问题胜，事实型局部查询向量路足够（RAG vs GraphRAG 系统评估，被引 140+）。
- **颠覆警示：Graphiti #1924 实测朴素三路（BM25+余弦+浅层 BFS 遍历）RRF mean 0.90，LightRAG 式结构化管线反而 0.60** ——五路中 LightRAG 路是最该被对照替换的一路。
- 拒答闸：CBB"逐字落回"是构造性判据、比 MiniCheck 蕴含式更严，方向正确；**RAG 悖论**（有材料在手模型更倾向强行作答）→ 按"上下文充分性"分桶校准阈值；归因指标跨语料会反转——**不抄外部数字，自画误拒/漏放曲线**。
- Lorebook 触发机制三条可移植进上下文包：时间性激活（sticky/cooldown/delay）、NOT ANY/NOT ALL 负向过滤、Inclusion Group 同组单选；**整词匹配伤中文**（隐性漏召回点，须核查）。
- 图链加深照 Graphiti #1924 结论：逐层判定（勿一次展开两层全选打分）+beam 2-4+P(已答)早停；judge 可复用 qwen3-reranker——无 LLM 多跳。

### 路7 动态切分与块分配（★用户补充机制）
- **语义切分全面替代：负证据**（NAACL 2025 Findings，被引 141：无抵偿成本的一致增益；Vectara 独立复述固定大小常反超）。
- **但抽取方向正证据**：GraphRAG 官方——块越大实体抽取保真度越低（默认 1200 token vs 2400 显著掉召回）；"长上下文时代整章最优"无证据（Lost in the Middle+RULER：有效上下文不足标称一半）。
- 场景边界检测精度远未解决（KONVENS 2021 冠军只找回 ~51% 边界；2025 仍 work-in-progress；中文叙事无现成模型）→ **场景标签用"廉价机械信号+一次轻量 LLM 扫描"获得软标签，别追高精度切分器**。
- **公式出处**：用户记忆的"公式"最可能是 LlamaIndex `SemanticChunker` 默认断点公式——相邻句余弦距离 >95 分位处切分（breakpoint_percentile_threshold=95）；次候选 Meta-Chunking 句间 PPL 突变法（零嵌入成本）。本地未定位到更早出处【待确认】；speed-quality-cost 三角的显式形式化公开缺位——门控判据即工程替代。
- 边界损失：重叠 10-20% 只是部分解；**最强缓解=章间状态传递层**（承接摘要+伏笔/时间线/角色状态文件，oh-story tracking 模式）+全局归并 pass。
- 网文工具事实标准：**章单元+首章特判+逐章状态传递**，场景是派生标签不是抽取单元——与建议 1 的"默认整章"互证。
- 动态分配公式雏形（可直接实现）：`升级抽取 = (新实体率>θ_e) ∨ (场景边界数>θ_s) ∨ (字数>θ_len)`；θ 本地 A/B 定标（三档：整章/章内 600-1200 token 逻辑分段/整章+二次扫描，20-30 章，指标=每章新实体数+关键事件数+幻觉率）。

## 三、第一性原理推导

**公理：正典库 = 可复算的证据链**（每条结论能从原文+判定过程机械重建）。

1. **唯一写模型定理** → 一切派生视图（Neo4j/LightRAG/嵌入）必须是可再生的投影 → 三视图三节律是伪分权，投影检查点+崩溃重放是应然形态（改判 6）。
2. **证据锚定定理** → 抽取输出的原子单位天然是命题（引文回落即命题级验证）→ 切分粒度问题最终被命题化降维（远期方向）；近期，门控切分只服务召回率。
3. **判定与陈述分离定理** → 判定器判定"断言位"，不判定"陈述位" → D-23 的根；同理**状态变化不是矛盾**（时间维度的更新），矛盾只属于"不可同真的断言位冲突"（改判 2）。
4. **独立性=证据强度定理** → 单模型自报置信不构成证据；异构独立评审的一致才是（Finch-Zk）→ 晋升制与终审判卷同源（改判 4）。
5. **成本花在信息密度处定理** → 均匀处理是浪费：门控二次切分、按章路由模型档位、margin 触发人审、按需物化社区（LazyGraphRAG 思想）共享同一原理（改判 7 及各"调整"项）。
6. **仪器可比性定理** → 尺子可以换，但换尺子必须留桥（指纹+版本+桥接样本+误差条）。

## 四、逐机制判定表

| 机制 | 判定 | 要点（SOTA 锚） |
|---|---|---|
| gate1 九码证据门 | **保留（核心资产）** | 引文回落=构造性 grounding 判据，严于 MiniCheck 蕴含式；条件独有 reward 资格 |
| 哈希链账本+幂等 | **保留** | CQRS 教科书同构 |
| 三方对账哨 | **保留+升级** | 加投影检查点（ledger offset），崩溃重放 |
