# 前沿工具调研 · 形式化与测试一路（2026-09-27）

> 深度档：property-based testing/变异测试/契约式设计/模糊测试/轻量状态机检查/数据管线测试思想。GitHub API+PyPI JSON+官方文档直查为准；Python 3.14 兼容性逐项实测。

## A. 逐题深度发现

**Q1 Property-based testing（Hypothesis）**
- v6.168.1（2026-09-23），9k★，周级发版，**Python 3.14 官宣支持**（changelog 实读：3.10-3.14t+PyPy）。
- 最强一手证据：**CPython 自身 CI 已有 Hypothesis tests job**+meta-issue #107862（公开征集属性测试点）。
- `RuleBasedStateMachine`（@rule/@invariant/@precondition）官方示例即**模型对照测试**——比手写单测强一个量级：invariant 在**每一步后**检查；失败自动 shrinking 给最简复现例。预算：max_examples=50 默认，状态机建议 step 50-100。

**Q2 变异测试**
- mutmut v3.8.0（2026-09-12，BSD-3，3.14 就绪）：按调用栈映射测试、增量缓存、`mutmut browse` TUI 幸存者审阅、变异分数 badge。**硬限制：POSIX only（fork），Windows 需 WSL/Linux CI**。cosmic-ray（MIT）classifiers 仅到 3.13。
- **变异分数定位**：arXiv:2606.10417（2026-06）实证 coverage/kill score 是"实现中心"度量——10 库 8,922 方法中 **17.5% 预期行为完全无测试覆盖**（行为盲区）；趋势型审计指标 ≠ per-commit 硬 KPI（Google ICSE-SEIP 2021 同结论：定向审计）。

**Q3 契约式设计**
- icontract v2.7.3（MIT）：CI 矩阵仅 3.8-3.13，**字节码反解对 3.14 兼容风险中高**；开销 1.5-4.5μs/次（对毫秒级写路径可忽略）；被 CrossHair 官方集成。deal（MIT）：CI 到 3.12。
- 落点：**测试期用或以 Hypothesis invariant 表达同一契约；生产路径不挂装饰器**（省开销+兼容风险）。

**Q4 模糊测试**
- Atheris v3.1.0（cp314 wheel 实测存在）：**仅 Linux/macOS**——win 本机不可用，放 Linux CI。
- 无 schema 时的零依赖打法：`st.recursive` 生成任意 JSON 形状（NaN/深度嵌套/非法代理对），断言"gate 不抛未分类异常"；hypothesis-jsonschema（发版停 2024-02）3.14 未声明——可选。

**Q5 轻量状态机检查**
- python-statemachine（MIT，v3.2.1，3.14 就绪，cond/unless 守卫+StateChart）；transitions（6.6k★，docs 站 404）；**CrossHair**（1333★，v0.0.110 **2026-09-26 push**，3.8-3.15）：符号执行离线检查契约+diff_behavior 找两实现行为差异+从契约生成单测——**Python 生态内最接近轻量模型检查的件**。
- 成本收益判断：cbb2 状态机 ≤10 规则，**换运行时框架收益不抵改造风险**；用测试端建模（Hypothesis stateful + CrossHair 对 2-3 条核心不变式）。

**Q6 数据管线测试思想（dbt/GX/pandera）**
- dbt 核心思想可移植（不引工具）：**测试=返回"失败行"的 select，0 行即通过**；generic 四件套=unique/not_null/accepted_values/relationships（跨档引用完整性）；失败行落盘审计（store_failures）。
- great-expectations：**requires_python <3.14，工具排除**（取思想）。pandera v0.33.1（MIT，3.14 就绪，`strategies` 反向生成 property 数据——与 Q1 闭环）。

## B. 对 cbb2 的接入建议（property 形状）

**B1 决策树五分支（@given 判定性与完备性）**：①总性：任意输入必落五轨之一且不崩；②身份幂等：同身份重复写不产生新件不改字节；③位谓词对应：落位与断言/陈述位谓词一一对应（property 遍历 2^k 位组合，元变性质）；④失效字节不动性：快照逐字节相等+只追加登记；⑤真矛盾三分不可被前两支吞掉。

**B2 三态迁移（RuleBasedStateMachine 模型对照）**：real Store vs 10 行 dict 模型双记账；@precondition 编码迁移守卫（省预算）；@invariant 每步检查"晋升单向（无 confirmed→provisional 回边）+双记账一致"；settings(max_examples=200, stateful_step_count=50)。

**B3 哈希链账本**：①verify==从创世重算（委托独立第二实现防同源 bug）；②幂等键：同键二次 append 至多追加一次且跳过时链尾不动；③**篡改检测：翻转任意一环任意一字节 → verify 必失败**；④首尾连接：每环 prev_hash==前环 hash。

**B4 gate 对抗性（json_ish 递归生成）**：gate 不抛未分类异常，输出要么 None 要么合法记录档。

**B5 金丝雀升级**：mutmut 在 WSL/Linux CI 对 store 模块定向跑（mutate_only_covered_lines+pragma 排除样板），产出**幸存变异体清单**——每个幸存者翻译成一条新断言；badge 只当趋势指标。

**B6 jsonl 数据面 dbt 式审计（不引工具）**：CHECKS 字典=返回失败行的纯函数（unique/not_null/accepted_values/relationships 跨档引用）；audit(rows, plan) 空列表=通过；pandera（3.14 就绪）可作可选封装。

## C. 排除项

great-expectations（<3.14）、icontract 上生产路径（3.14 未官宣+开销）、deal（CI 到 3.12）、Atheris 本机（仅 Linux/macOS）、cosmic-ray（3.13）、python-statemachine/transitions 作运行时（状态机太小+docs 404）、TLA+/Alloy（超轻量范畴，三不变式用 CrossHair+stateful 同等置信）、hypothesis-jsonschema 默认依赖（停 2024-02）、dpcontracts/PyContracts（死/难维护）、**"变异分数=硬 KPI"**（行为盲区实证 17.5%）。

**一句话路线**：Hypothesis（@given 五分支+StoreMachine）→ WSL/Linux CI mutmut 定向审计 → jsonl 面 dbt 式审计函数 → 可选 CrossHair 符号双保险。默认新依赖只有 hypothesis 一个（3.14 官宣支持）。
