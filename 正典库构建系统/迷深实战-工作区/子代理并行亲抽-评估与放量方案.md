## 0. 结论摘要

**精度层不受影响，判断层部分受影响且可用四层机制补回，净收益为正。** 决定性质量门（引文逐字性/行号/契约/元文本/墙钟/重复与分类学）全部是确定性机器校验，与抽取者无关；子代理改变的是首次判断的锐度（候选筛选深度/伏笔分级/分类学直觉），这层用"固化指南+强制查库+主线握持+十查抽检"补齐。放量前必须过 3 章 A/B 对照门（§4）。

## 2. 质量影响分层分析

### 2.1 确定性质量门（不受抽取者影响）——本窗口实证

| 质量门 | 机制 | 本窗口实证（抽取者=主线代理本人） |
|---|---|---|
| 引文逐字性 | precheck 全块扫描比对 + 门1 G1-EVIDENCE 悬空拦截 | **"老手"本人被拦 15 处**（问号/逗号、间隔号、括号、长句截断——ch39×1/ch40×2/ch42×3/ch43×1/ch49×2/ch50×6），全部修正后过门，零漏网 |
| 行号精度 | 引文自动定位脚本（语料命中行重写） | 自动修正 39 处（ch40 一章 29 处——人工行号在长章系统性漂移，脚本化后归零） |
| 契约/元文本/墙钟 | gate1 三域（R6 全文内嵌/reference_time=伪锚点） | 全程有效：noise 章零抽取、译注排除 8 处、tick 0-40 无缺口 |
| 重复与分类学漂移 | 双轨 ON MATCH（一致合并/矛盾隔离+Verdict）+ 嵌入扫描 | 本人触发分类学矛盾 2 处（ch41 舞斗大会/圣人缇娅拉）被自动隔离→对齐重抽+裁决；嵌入提示 19 项全部只提示不静默 |

**要点**：这套门对"写了 40 章的本人"都不留情面（15 处引文拦截），对子代理同样有效——精度层是机器均质的。

### 2.2 判断层（子代理冷启动的真实风险）

| 风险 | 表现 | 代价 |
|---|---|---|
| 剧情弧缺失 | 不知基督线/改篡线/手环机制等 40 个位置攒下的弧 → 漏抽伏笔、tier 判轻、事件 entities_involved 挂错 | 主线级事实遗漏（最重的风险） |
| 分类学/别名惯例漂移 | 不查库直接写 → entity_type 不对齐/新造同义实体 | 双轨矛盾项与 R4 审计负担增加（不污染库，隔离区兜底） |
| cross_chapter_notes 变浅 | 冷启动写不出跨章对证 | 批 STATE 主线摘要质量下降 |

## 3. 架构方案（三层分工 + 四层监督）

### 3.1 并行层：子代理亲抽（每章一个独立代理，前台）

**任务包规格**（每个子代理）：
- 输入：单章切片（boundary-table 行区间）＋《抽取指南》固化件＋库内既有名录（名称+entity_type 清单，含别名表）＋剧情大锚档（记忆索引载明在档，路径下窗口验证后接入）
- 输出：`candidates/extraction-chNNNN.json`（照 Record v2.0 契约，与现行格式逐字段一致）＋ 300 字章节摘要（供主线写 _meta 与批摘要）
- 禁令：不碰本体库（只读名录）、不跑管线、引文必须为语料逐字子串（禁转写禁间隔号发明）、置信度照校准表

### 3.2 串行层：入库（主线代理独占，防竞态）

- `precheck`（自动行号修正+悬空检测）→ `run_chapter.py --no-aux` 逐章串行——jsonl 本体库/aliases/appearances 是共享追加写，**单写者硬约束**
- 批收口统一跑嵌入扫描+Neo4j 导出（结果等价，省串行时间）
- 修正循环：悬空引文由调度层回炉对应子代理或主线代改（机械操作）

### 3.3 主线握持层（不变的部分）

- `_meta` 跨章注记、批 STATE 更新、十查留痕、隔离裁决、commit——全部留主线
- 剧情大锚档每批由主线增量更新（喂给下一批子代理）

### 3.4 质量监督四层（对 2.2 风险的覆盖）

1. **固化《抽取指南》**：R6 全文 + 分类学表（库内现行 entity_type 枚举）+ 置信校准 + 别名纪律 + 引文规则 + 候选类型判定样例（从批 1-5 沉淀）——一次性成本 ~1 窗口，复用至终单
2. **强制查库**：任务包含名录，新实体必须先比对（对齐分类学与再提名判断）
3. **主线复核**：章节摘要+门1结果+候选清单抽样（每章 ≥3 条对原文），替代全读
4. **十查不变**：批收口十查照旧，⑧抽检照旧

## 4. A/B 对照验证门（放量前置，数字说话）

- **样本**：ch0051-0053 中取 2 章双盲（主线与子代理各自独立抽同章，互不见对方产物）
- **对照指标与通过阈值**：

| 指标 | 基线（本人，本窗口） | 子代理通过线 |
|---|---|---|
| 引文一次通过率 | ~93%（15/221 悬空率≈7%） | 悬空率 ≤10%，修正循环 ≤2 轮收敛 |
| 分类学首过矛盾 | 0.2/章 | ≤1/章 |
| 关键事实覆盖（vs 主线版） | — | 主线事件/伏笔命中 ≥90% |
| 候选数量偏差 | — | ±25% 以内 |
| 抽检 2 条证据对原文 | 全过 | 全过 |

- **放量阶梯**：2 章 A/B → 单批 8 章试运行（子代理抽+主线复核，十查照旧）→ 全量。**任一阶梯不达标即回退串行模式**，已入库部分因确定性门兜底不受影响。

## 6. 收益与残余风险

**收益**：主线每章上下文成本从 15-45k 降至 ~2k（调度+摘要+复核）→ 单窗口 25-40 位置；全单 40-50 窗口 → **12-18 窗口**（约 6-7 周 → 2-3 周）。

**残余风险（接受声明）**：
- 判断层精度损失无法归零——靠 A/B 门量化后决定接受与否，而非假设无害
- R4 别名合并审计负担上升（矛盾/嵌入提示项增多）——U-C09 R4 本就是预留审计位
- 子代理失败/超时章由主线兜底亲抽（不阻塞批次）
