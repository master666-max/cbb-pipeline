## 一、设计公理（六条，全部来自第一性原理推导）

1. **唯一写模型**：账本+本体库是唯一事实；一切图/向量/索引是可再生的投影（改判6）。
2. **证据锚定**：每条 canonical 断言必须逐字落回原文；抽取输出的原子单位是命题。
3. **判定与陈述分离**：判定器只判"断言位"；时间维度的状态变化是**失效事件**不是矛盾（改判2）。
4. **独立性=证据强度**：晋升与终审只认"异构考官隔离评审的一致"，不认单模型自报置信（改判4）。
5. **成本花在信息密度处**：切分/模型档位/人审/索引全部门控化，均匀处理是浪费（改判7）。
6. **仪器可比性**：尺子可换但必须留桥（指纹+版本+桥接样本+误差条）。

**工程分工律**（承接插件/技能裁决）：会话必须永远遵守的约束→插件 hook（防违）；按需执行的流程知识→技能；多步流程的执行→runner 工具（可被特征测试锁）；hook 不做指挥。

## 二、总图：三闭环 × 八阶段

```
┌────────────────────────────────────────────────────────────────┐
│  治理闭环（P5/P6 产出 → 回灌 P1/P2）：缺口队列→词表差量/提示差量/判例  │
└────────────────────────────────────────────────────────────────┘
语料 ─→ P1 消化 ─→ P2 抽取 ─→ P3 门禁写入 ─→ P4 收口投影 ─→ 检索面交付(P7)
            ▲        ▲            │                │
            │        │            ▼                ▼
            │        └── 进化闭环：上下文包/承接摘要 ←── P5 区段治理（对样/NLI巡检/缺口队列/ER）
            │                         │
            └── 库喂先验 ─────────────┘
                                       P6 终审（票数晋升）→ confirmed
```

- **主闭环**：P1→P4，每章一转，章收口=事务边界。
- **进化闭环**：P5 产缺口队列 → 词表差量+提示差量+判例 → 回灌 P1/P2（库喂养抽取，抽取喂养库演化——"图文互相照应"的完全体）。
- **治理闭环**：P5 对样/NLI 巡检 + P6 票数晋升 → confirmed/判例修订/仪器版本 bump。

## 四、贯穿机制

1. **配置单源**：cbb2/config.py 收编全部端点/容器/taken 集/凭据引用；env-first；缺配置报错不猜（路径惯例判据升格）。
2. **仪器治理**：每份报告/评分/抽样带 `仪器指纹+语义版本+误差条`；版本 bump 必附桥接样本对照表。
3. **旗标纪律**：全部【新·旗标】机制（动态切分/模型路由/输出两段式/共进化闭环）默认 off、独立预注册实验定标后逐个开——**实验永不阻塞主线**。
4. **数据兼容承诺**：`libraries/{lib}/{status}/{rid}.json`+`quarantine-zone/items.jsonl`+哈希链账本布局不变；6,172+1,373 件真库零迁移。

## 五、契约 v3 数据设计（要点）

```jsonc
record {
  // 现制 10 必填保留
  + "t_valid": "<pseudo-date>",        // 叙事时间起点（源自锚点树 tick）
  + "t_invalid": "<pseudo-date>|null", // 失效记账制：被后继断言取代的时刻（历史保留）
  + "at": "<pseudo-date>",             // 摄入时间（t'），全写路径强制
  "canonical": { /* profile 声明：assertion_fields / statement_fields / mutable / immutable */ },
  "profile": { "identity_key": "…", "compare_fields": "assertion_only", "library": "…" }
}
```
profile 示例：character.mutable=`{status, location, affiliation}`；character.immutable=`{entity_type, origin}`；relation.statement=`{claim}`。

## 七、与现制的差异总表
