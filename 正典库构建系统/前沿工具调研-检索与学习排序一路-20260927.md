# 前沿工具调研 · 检索内部与学习排序一路（2026-09-27）

> 深度档：金标构造（LLM-as-judge）/LTR 小数据/查询扩展/混合检索权重科学/中文 tokenizer/拒答校准。arXiv API+GitHub API+官方文档直查；【待确认】处已标注。

## A. 逐题深度发现

**Q1 金标构造（LLM-as-judge 可靠性）**
- **UMBRELA**（SIGIR 2025，GPT-4o 复现 Bing 判官，TREC DL 全量重判）：**判档位不可靠**（Cohen κ 四级 0.308-0.373、二值化 0.418-0.499；"highly relevant"判准仅 ~30%）但**排系统高度可靠**（nDCG@10 Kendall τ 0.87-0.94/Spearman 0.97-0.99）。代码 castorini/umbrela（Apache-2.0）。
- Thomas/Bing（arXiv:2309.10621）：选最优系统一致 0.86-0.97，**识别最难 query 弱**（RBO 0.40-0.48）；prompt 特征对 κ 影响 0.20-0.64 极大。
- **合成 query 循环的关键负面结果**（SIGIR 2024，arXiv:2405.07767）：合成 query+人工判断 τ=0.82 可用；**合成 query+稀疏判断（只把生成来源段当正例）τ=0.157 完全不可用**；合成 query+LLM 判断相关性接近人工；评测对"与生成器同源的检索系统"有偏需混源审计。
- RAGElo（arXiv:2406.14783，Infineon 量产）：合成 query→LLM judge→Elo 比较各 RAG 变体=工业样板闭环。
- Ragas（Apache-2.0，15.9k★）testset 生成开箱即用（生成侧指标，检索金标仍需自建）。

**Q2 LTR 小数据**
- **LambdaMART 最低标注量：无公开系统对照研究（明说）**；传统基准量级=MSLR-WEB30K 31.5k queries/Yahoo 29.9k——"数千 queries"来自大基准时代。
- **最硬小数据实证=融合函数本身**：Bruch et al.（arXiv:2210.11934，CIKM 2023）：单参数凸组合（CC）用**一小撮标注 query 即收敛**，α∈[0.6,0.8] 跨域稳定，**理论上与实证均优于 RRF**（RRF 对参数敏感、尾部权重失真）；归一化方式不敏感（z-score 即可）。
- 零人工替代：RankVicuna/RankZephyr——LLM listwise 判序当教师蒸馏重排器（无需人工标签）。
- LightGBM（MIT，18.8k★，已迁 lightgbm-org，日活）lambdarank 需按 query 传 group；过拟合靠 min_data_in_leaf/树数/学习率；query 多样性比每 query 行数重要。

**Q3 查询扩展与改写**
- query2doc（arXiv:2303.07678，Microsoft）：few-shot 伪文档拼 query——BM25 MS MARCO MRR@10 18.4→21.4（+3.0）、DL19 nDCG@10 51.2→66.2（+15.0）；稠密同效。
- HyDE（arXiv:2212.10496）：零标注可比微调稠密；**翻车模式=LLM 对领域不熟时伪文档与真实切片分布脱节**。
- **multi-query 收益边界**：DMQR-RAG（arXiv:2411.13154）四策略各自有益但**"全开"引噪——必须按 query 自适应选择策略/数量**；稳定超越原生 RAG-Fusion。Rewrite-Retrieve-Read（arXiv:2305.14283）=可训练改写模块路线。
- PRF（RM3）中文先例：NeuCLIR 技术报告（arXiv:2602.05334）把 RM3（top10 文档各扩 10 词）作为中文 BM25 标准配套（k1=0.9/b=0.4）。
- CoT 式 LLM-QE（arXiv:2305.03653，Google）：不像 PRF 被第一阶段拖累——五路召回不稳场景更安全的扩展。

**Q4 混合检索权重科学**
- RRF 原始出处（Cormack SIGIR 2009）：**k=60 是当年手工设定，无系统调参依据**。
- Bruch（arXiv:2210.11934）：RRF 对参数敏感；归一化凸组合（CC/TM2C2）理论+实证优于 RRF；α∈[0.6,0.8] 一致偏语义侧；窗口截断是 RRF 尾部权重失真来源之一。
- Elasticsearch 官方：rank_constant 默认 60、rank_window_size 独立控制每路窗口——**窗口深度与 k 是两个独立旋钮**。
- "互伤边界"：NeuCLIR 中文科学摘要实测——BM25=0.290 > MILCO（学习稀疏）0.253 > e5-large 0.233；BGE-M3 sparse=0.307 最强——**弱神经路拖融合，强稀疏反而第一**；互伤边界由"该路是否真的强"决定，先做每路金标 recall 再谈融合。

**Q5 中文 tokenizer 对 BM25/索引**
- Lucene CJKAnalyzer 官方默认=**字 bigram**（javadoc 实测；生造词免疫）；NeuCLIR 中文用 spaCy 细粒度切分（近字级）BM25=0.290 强基线（k1=0.9/b=0.4）。
- jieba（MIT，35.2k★，2024-08 后冻结）：自定义用户词典对小说人名/别名为刚需；HanLP（Apache-2.0，2026-09 活跃）N-最短路/bigram 多档。
- **字级 vs 词级中文 BM25 的现代公开系统对照：arXiv 未找到直接可引实验（明说）**——实践帖仅支持"细/粗粒度影响召回"方向性判断。

**Q6 拒答/abstention 阈值校准**
- Sufficient Context（ICLR 2025，Google）：充分性分类器 1-shot F1=0.935；**RAG 悖论**（有材料在手模型更倾向强行作答）；Selective RAG 用充分性信号+自评训线性模型，正确率 +2-10%。
- **"标准答案字符串出现在 context"平凡基线 F1=0.810**——我们的逐字核验门正是其强化版（构造性判据，比蕴含式更严）。
- 归一化指标跨语料会反转（Do LLM Attribution Metrics Transfer，arXiv:2606.23915）——**不抄外部阈值，自画误拒/漏放曲线**；归因评测 RGB 中文切分（2023）可用作内部回归。
- 反例：2000 条 LoRA 微调 Mistral-7B **没有**可靠提升拒答率——别指望微调小模型解决 abstention。
- TREC 2024 RAG Track：支持性评测人工 vs LLM judge 系统对比（arXiv:2504.15205）——与逐字核验门直接同题。

**Q6b 中文对照**：NeuCLIR 中文科学摘要单语实测——细粒度切分 BM25=0.290 强基线；BGE-M3 sparse=0.307 最强（弱神经路拖融合的先例）。

## B. 对本管线的接入建议

**B-1 金标零成本起步**：6172 记录本地 LLM 生成合成 query 每条 3-5 个，模板显式分层覆盖五路（别名/关键词 paraphrase/双跳关系问句/语义描述/情节细节）；**相关性判定用二值或粗三档**+judge 提示词配逐字证据引用要求（与核验门同构）；**正例池必须池化**（含同记录其他切片+相邻章节，τ=0.157 教训）；人工只做锚点抽检 10%（200-300 判定算 κ，二值≥0.4 放心用），重点审计"相关/高度相关"档；固化 50-100 query 看家金标集+500-1000 大集（小集每次改动必跑，大集周批）。零 GPU 成本、人工≤半天。

**B-2 LTR 值得投入的标注量**：**<100 人工锚定 query：不上 LambdaMART**——改用单参数学习融合（Bruch CC/TM2C2），少量 query 即收敛，α 先验 [0.6,0.8] 再金标微调（几乎免费，已证稳定优于 RRF）；≥500 锚定 query（每 query top20≈1 万对）才上 LightGBM lambdarank，特征=每路归一化分数/排名/命中数/别名命中类型/骨架距离/reranker 分；训练集 query 数是瓶颈不是行数。

**B-3 融合参数科学化**：金标上网格 RRF k∈{10,20,60,100}×rank_window∈{10,20,50,100}（两旋钮独立，预期显著敏感——k=60 默认不可继承）；并行试 z-score 归一+CC 加权路线；每路先单独报 recall@窗口（分层），砍掉或降权"金标上始终拖后腿的路"（NeuCLIR 弱神经路先例）。

**B-4 查询扩展**：短/含别名/代词 query 加 multi-query 改写，**上限 3-4 个**按类型自适应开关；HyDE 式伪文档只喂向量路且世界观外 query 关掉；关键词路可试 RM3（词级索引下）；中文 LLM-QE 以自家金标裁决。

**B-5 中文索引对照（预期收益高）**：双索引对照——字 bigram（Lucene CJKBigramFilter 谱系，生造专名免疫）vs jieba 词级+自定义人名/别名词典；金标上分 query 类型比 recall。生造专名占比高的小说语料，bigram 路很可能在别名类 query 上反超。

**B-6 拒答校准**：保留逐字门（文献证实字符串包含基线 F1 已 0.81，我们的门更强）；叠加充分性二判（本地 LLM 1-shot prompt"此上下文是否足以回答"）与 reranker 分数、自评 P(True) 进**逻辑回归**（不进 LLM）；人工标 300-500 条做校准（Google 自身门槛即 500），按"正典严格/检索宽松"设两个运行点。
