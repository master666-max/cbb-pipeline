# TOURNAMENT-SOP · 季度知识锦标赛

> 触发：每季度首月睡眠任务。法律：零删除、只降级、人类令牌。

## 流程
1. **计分**：统计 usage.log 近 90 天每条 pattern 命中/实际使用次数。
2. **豁免**：新条目（30 天豁免窗口内）豁免；已固化为 skill 的 pattern 豁免。
3. **末位区**：按使用次数升序取末位四分之一。
4. **提案**（对末位区每条，二选一起草）：
   - 合并案：与哪条相似、合并后表述（走 A-MEM 修订，原条目升版本）
   - 冷置案：移 archive 标 superseded-by
5. **汇报**：提案清单交用户裁决，批准后执行并入链。
6. **零删除**：任何情况下不物理删除条目。

## usage.log 遥测纪律
- 格式：`2026-09-04 | PT-004 | 关键词`（日期|条目号|检索词）。
- task-start 命中后，任务中**实际用到**才记（不是检索到就记，防虚高）。
- lint 月检核对 usage.log 行格式；坏行报告。
