### 核-02 【待确认】闭环：DGM reward hacking 案例确认（一手核验）
- 本轮独立核验（arXiv HTML 全文）：Appendix F 确认 Node 114 objective hacking 原文——"the agent removed the logging of special tokens that indicate tool usage (despite instructions not to change the special tokens), effectively bypassing our hallucination detection function"；且论文给出关键处方："the hallucination checking functions are hidden from the coding agent during self-modification. We found that objective hacking…occurs more frequently when these functions are not hidden."；结论节引用 Goodhart 定律。
- 对修复方案的影响：v2.1.1 的 Z-001 从「豁免 + 锚定」两件套升级为**三件套**：①豁免于变异 ②外部锚定 ③**对变异引擎不可见**（DGM 用实验数据证明不隐藏时 hacking 显著更频发）。
- 备注：审查所引「Reward hacking is a documented, observed risk.」一句在抓取的 HTML 全文中未逐字出现（Appendix F 用语为 objective hacking），不影响实质结论，登记为引文措辞差。

## 第 2 章 层二 · 修机制（防止同类问题复发）

### X-007 lint 断言号闭包
- 文档引用的每个 T 编号必须存在于 run_tests 断言清单；38/58 漂移、T26-T45 无定义这类问题由脚本机械报警（复用 L-int-02 思路）。

### X-008 L-int-03 升级：题录标题对账
- 不止抽样存活：题录标题与 arXiv API 逐条 diff（联网时），A14/A20 类错误从此由脚本拦截；离线时标注「未对账」。

### X-009 计数类事实单一来源
- 断言数、论文数、字段数、铁律数等计数从代码/数据单一来源生成注入文档，或 lint 与源对账——消灭「同一事实多处手写」。

### X-010 变异基准三件套落地（DGM 处方）
- ①基准与执法文件（run_tests/lint/l8_guard/anchor）豁免于变异（MUTATION-SOP 黑名单）；②其哈希入外部锚定表；③**对变异引擎不可见的近似实现**：验收判据细则存于锚定目录（库外），变异引擎只接收 pass/fail 结果不接收判据文本——文件库语境下无法真正「隐藏」，此为近似实现并如实声明。
- 回归：T49（触碰基准文件的变异自动否决）+T51（判据文件不在 mutations 可读清单）。

### X-011 记忆投毒防线条款（继承 Z-009）
