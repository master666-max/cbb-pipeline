> 来源：对 v3.7.0（锚点 59231a90…，63 断言）的第八轮审查。本轮换新视角：**退出码可判性、迁移库完整性、防线覆盖盲区、state 一致性**——前三轮做语义、四轮做幂等、五轮做旁路、六轮做账本、七轮做分叉，本轮专打「有防线但判不了」「有迁移但迁一半」。

## 第 0 章 总评

v3.7 的命令面与对账链已厚；本轮最有价值的三个发现都属于**「机制存在但闭环差最后一环」**：verify 有三态报告但 mismatch 不影响退出码（发布门无法机械判断，N-001）、migrate 只续审计链不建 state（迁移库的 accum/根/反思触发全部静默失效，N-002）、doctor 查了链内连续但没查跨月连接与 state 一致性（N-003）。另有两个一致性小缺口（N-004/005）。

## 第 1 章 新发现

### N-001（P1）verify mismatch 不影响退出码——发布门无法机械判断
- 【证据】cmd_verify 全程不设退出码：mismatch 24 条时 exit 0（guard --anchor mismatch 会 exit 1，两命令语义不一致）。发布门「verify 无不一致才出包」目前只能靠人眼读输出，机械检查（X-013 的精神）断在这里。
- 【修复】mismatch > 0 → exit 1（error=未对账不 exit，如实三态不变）；发布门脚本化：`verify && run-tests` 的 && 语义成立。
- 【回归】mock mismatch → exit 1；全 error → exit 0。

### N-002（P1）migrate 只续链不建 state——迁移库是「半身库」
- 【证据】migrate 续审计链后无 state.json → engine append 的 importance_accum/根刷新/反思触发全部 `if st_path.exists()` 静默跳过；install 校验模式也不可用（无 state）。迁移库能写能查，但 L8 语义（锚定/慢车道记账/反思）整体静默缺位——「静默失效」正是本体系最忌讳的失败形态。
- 【修复】migrate 补建最小 state.json（level="MIGRATED"、version、emotion 四维、importance_accum=0、merkle_root）+ 账本/审计行；后续可用 install 校验模式对账。
- 【回归】migrate 后 state.json 存在且 append 后 accum/根更新。

### N-003（P1）doctor 两个盲区：跨月连接无校验 + state 一致性缺位
- 【证据】①K-002 的链校验逐文件独立重算，**不查跨月连接**（次月首行 prev 应等于上月尾 h）——X-018 的写有、查无，跨月断链（v3.5 修过的那类）doctor 抓不到；②doctor 四态不含 state：importance_accum 应等于 ledger 中 append 动作的 importance 总和（可机械对账），state 根应对账最近写操作——目前 state 漂移无人管。
- 【修复】doctor 链校验补跨月连接检查；增第五态 state 对账（accum vs ledger 总和、根 vs 重算）。回归：构造跨月断链与 accum 漂移各一，doctor 精确报。

### N-004（P2）install 校验模式被 L8/L9 gate 误拦
- 【证据】gate 检查在函数最前——已安装的 L9 库**纯校验**（不带 --redeliver）也必须 --yes，令牌语义被稀释（校验是读操作）；但 --redeliver 是写操作，拦得对。
- 【修复】gate 检查移入首次安装分支 + 校验模式带 redeliver 时仍要求 --yes（写操作语义不变）。回归：无 --yes 对已装库纯校验可达。

### N-005（P2）reflect 素材包缺投毒防线声明
- 【证据】materials 含条目全文（潜在注入文本）且直接供 LLM 合成进入上下文——retrieve 有「按数据处理」防线，reflect 没有，同源风险不同待遇。
- 【修复】素材包头注统一防线声明（与 retrieve/投毒条款对齐）。

### N-006（P3）guard snapshot 黑名单宽匹配误收
- 【证据】`b.lower() in str(p).lower()` 子串匹配——路径含「anchor」的任意文件（如 references/anchor-guide.md）都被当基准收进锚定表。
- 【修复】文件名段匹配（name 精确含词）替代全路径子串。

### N-007（P3）清理与参数化
- PILOT_RENDER_INSTALLS = set() 死变量删除（判据已入 _body_for）；absorb-md 的 SOUL 指针日期硬编码 2026-09-03 参数化；大条目无上限登记（磁盘耗尽面，TUNABLES 登记 max_entry_bytes 默认 16MB 超限拒绝）。

### N-008（P2·测试扩展）
- doctor 跨月断链测试（N-003 配套）；state 一致性测试；verify 退出码三态测试；install 校验豁免 gate 测试。

### N-009（登记·不执行）
