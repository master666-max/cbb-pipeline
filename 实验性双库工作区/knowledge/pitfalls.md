### P-001 / 2026-09-03 / 大 PDF 不能用 Read 工具直接读，Windows 下用 py 启动器 + pypdf 提取
- 场景：需要读取 3 份几百 KB 的中文 PDF（任务输入源），Read 工具直接报错，随后多条常规提取命令接连失败。
- 教训：Read 工具对二进制/大文件有约 256KB 上限，直接读必失败；根因是 PDF 为二进制编码且超限。Windows 环境下最短可行路径是 `py -c "import pypdf..."`（系统 Python 3.14 自带 pypdf，docx2pdf/pymupdf 可按需 pip 装）；注意 `python`、`pdftotext` 这类命令在某些受限会话（如计划模式 hook）下会被拦截，`py` 启动器此前已验证可用，优先用它。
- 实例：archive/2026/09/dual-library-docs/README.md（「数据流」节记录了提取路径；HANDOFF.md 记录源 PDF 位置）
