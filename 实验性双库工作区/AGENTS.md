# AGENTS.md — 会话入口

- **每次会话开始，先读 `knowledge/_index.md`**（知识库总索引，<200 行常驻），再开始任务。
- 开始任何新任务前调用技能 `knowledge/skills/task-start/SKILL.md`（三步启动）。
- 任何任务完成后调用技能 `knowledge/skills/wrap-up/SKILL.md`（五步收尾闭环）。
- 铁律：永不删除/覆盖已有文件；写入知识库的每条经验必须有工作区内真实依据，禁止编造；拿不准标【待确认】；移动文件前先出清单。
- 体系设计与模板详见 `双库自进化体系·建库提示词.md`；设计理念阅读版见 `双库体系建设方法论·阅读版.docx`。
