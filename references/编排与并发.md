# 编排与并发（v2.0 · 执行者运行手册 · 通用术语）

> 术语：**单元**=切分单位（章/节/页/文档）；**执行批次**=一次连续执行会话（缺陷聚集单位＝抽样分层依据）；**区段**=重检查点。并发数值随平台画像配置在 project.yaml，本件不写死。

## 一、调度员-执行者编排（长语料唯一可扩展架构）

- **主代理=调度员，不亲自抽单元**（单上下文不可扩展；亲抽仅为引擎故障兜底）。
- 每单元派**全新上下文执行者**，提示词=四行指针：
  ①读《抽取规范》（连同《判例》）②读**上下文包**+本单元切片 ③按 Record 契约产出候选 JSON 自行写入工作区 candidates/ ④回传一行回执 ≤200 tokens（路径+计数+引文预检结果）。
- **候选全文走磁盘不过主代理上下文**；调度员收执后核文件存在与行数 → gate → 隔离 → store → commit。

### 派工前两道机械断言（并发安全＝分路径＋分资源，只做前者只完成一半）

1. **路径域互不相交**：本次各执行者要写的路径两两无交集（脚本断言，禁口头保证）
2. **单元认领登记**：同一单元不得被派两次（认领表撞号即拒）

## 二、上下文包（库喂抽取的闭环）

派工前由**确定性脚本**（禁执行者裁量）从库生成，≤2K 封顶，四件套：
1. 主要实体册（canonical+别名，出场频次排序；**图启用时附"一跳关系邻域＋最近出场"——从图查询生成，深融条款③**）
2. 活跃伏笔/开环清单（status=open）
3. 滚动摘要（最近 N 单元，每个执行者追加"本单元新增要点/新实体/新设定"）
4. 判例指针（封顶 30 条，淘汰最旧留痕）

**先验非事实源**：与原文冲突以原文为准＋存疑分开建（防先验污染）。种子期可并入项目既有语料作深度先验。

**预算内重排（本地重排器，深融条款①）**：包生成后，以本章切片为 query 对"候选人物/活跃伏笔/判例"重排——2K 预算留给最相关的条目；本地模型不烧 token；重排器不可用→退回机械排序（频次/时间/urgency），产出同形。

**裁剪留痕**：预算耗尽被裁掉的条目必须记入包尾一行（"因预算裁掉 N 条＋名单"）——静默裁剪=审计黑洞。

## 三、并发与限流

- 两段式数值（起步档/巡航档/切换时机）**写入 project.yaml**，依据平台画像数据驱动；限流→全批等待 60~120s 重试一次→仍失败降档并**记录稳定并发数**（入 STATE，后续批次直用起步）。
- **唯一合法停止=服务端掐停**；禁止自我停止/滑行收尾/时间表降档（调度降档不是停止）。
- **挂死诊断**：执行者疑似挂死查 metadata（status/更新秒数/工具计数全空=首次请求即挂死）→ 等 1~3 分钟无动静放弃重拉（幂等零污染）。
- **并行前置四条件**：路径互不重叠＋单元认领不撞／断言式幂等／失败零写入／提示词固化＋验收脚本独立。

## 四、收口与断点

- **每 N 单元轻收口**（秒级）：游标＋scoped commit（只 add 本批路径/STATE/日志，禁 `add -A`）——commit 频率=断点密度，批界不是停止点。
- **区段收口**：跑**批次机械自检**（十条失效模式断言，见 [审查与收口.md](审查与收口.md) §二）＋重项（嵌入扫描/召回探针/评分/图导出/校准报告）。
- **STATE=缓存，磁盘+git=事实**：done 单位证据不在即改回 todo 记勘误；开工程序=读 STATE→对账→从游标续跑。
- **规范版本入账**：每条候选带抽取规范版本（防口径漂移；历史记录填 unknown，不得回填假值）。

## 五、NLI 矛盾预筛（矛盾积压超阈值时上岗）

- 矛盾对生成器导出（新候选 claim vs 既有记录 claim，含双方证据）→ 三分判定（entails/neutral/contradicts，temp=0）。
- **只分流不裁决**：contradicts→人工队列置顶；neutral→挂起；entails→转双轨 confidence 流程；全程留痕。
- **上岗小考**：已裁案件 ≥10 对＋注入伪矛盾 ≥10 对，分离度 ≥0.70 才启用；不达标继续人工。
- **分类口径**：矛盾四分——粒度差异／直接冲突／随时间变化／知识库不完整；只有"直接冲突"进人工，粒度类走对齐重抽（机械可修）。

## 六、本地模型调度（常驻双模型 · 2026-09-23 改判）

- **常驻双模型**：嵌入档用 **q4_k_m**（≈4.7GB），与重排器（≈2.5GB）**同驻一张 12G 卡、免换装**；只在引入大模型（判分器等）时按**批边界**抽换（每批封顶 2 次，禁逐章逐条）。
- **档位固定纪律**：一个项目内嵌入档位不许混用（q8 与 q4 向量不可比）；**换档＝重算全部嵌入**；换档前先跑一次"同批文本 q8↔q4 距离对照"，确认 0.85/0.95 阈值未漂。
- **重排器四岗位**（深融条款）：①上下文包预算内重排 ②审查抽样前"证据最弱"排序 ③候选匹配建议（仅建议位）④检索层重排。铁律：**只影响"先看谁"，不影响"算不算对"**。
- **不可用即降级**：重排器缺席（端点不支持/模型未装）→ 退回机械排序（频次/时间/urgency）或文件扫描兜底——**规则一份、产出同形**，不因载体缺席改判据。
- **红线**：模型缺席不影响主链；一切"分数"只作内部排序，不外报、不作裁决依据（判定权在人）。
