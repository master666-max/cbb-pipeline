# 考官契约（cbb-pipeline · G5 票数晋升 · v1.0 · 2026-09-28）

> 本文件是正典库考官编制的**对外契约**：任何消费晋升结论的一方（外部验收/重放/下游系统）据此知道"confirmed 这个字背后是什么"。实现=`cbb-v2/cbb2/promote.py`；编制变更史=`考官编制·仪器变更登记.md`。

## 一、判断纪律（纠偏三件，SOTA 锚）

1. **考官隔离**：考官互不可见，各自独立评审——禁止互相喂答案。
2. **答案对调**：每件证据先行、结论先行**各判一次**，两次一致才采纳，不一致=unsure（位置偏见纠偏，IJCNLP-AACL 2025）。
3. **不信口头置信**：LLM 自报置信系统性过自信——采信票数，不采信自报分数。

## 二、票门（B13）

- confirmed := 证据锚定 ✓ ∧ gate1 零违例 ∧ **≥⌈2/3⌉ 考官 support 且 against=0** ∧ 考官数 ≥2 ∧ 存续巡检（G17）。
- 任何一票 **against ⇒ 转人工**（异构反对=真分歧信号）。
- **需票按满编制算**：编制缩员不得自动降门槛（单考官无异构性，不得单独晋升）。
- 判卷质控：**判卷掺植物**——卷内混入已知答案植株，捕获率 <5/6 ⇒ 全卷结果降级"仅参考"（2026-09-28 B5 实战触发，门有效）。
- 宣称纪律：一切通过率宣称**必须带 Wilson 95% 区间**，点宣称禁用。

## 三、考官输入契约

- **只喂原文**：canonical JSON + 逐字原文引文（含机械回填补充引文），**图谱/派生数据构造性不可见**（载荷白名单审计，C4 测试化）。
- **先验非事实源**：上下文包类信息永不进考官输入。

## 五、消费方须知

1. confirmed 不是真理宣判，是**三票质控下的当前最优信念**——G17 巡检持续再验证，改判走失效记账。
2. hold/human 不是废料：hold=证据不足的诚实弃权（真诠释型断言的宿命），human=异构分歧或 NLI 矛盾的必看件。
3. 每张票面可回溯：`G16*-台账.jsonl` 逐考官记录，配合重放指引（G19）可独立复核。
