# 架构与 profile（v2.0 · 项目无关层）

> 本件回答两个问题：①这套流水线的六层不变式是什么（换语料不变的部分）；②新项目要填哪些参数（换语料要换的部分）。

## 一、术语映射（旧小说实例 → 通用）

| 实例用语 | 通用用语 | 说明 |
|---|---|---|
| 章 | **单元 unit** | 切分单位：章/节/页/文档/条目，由语料适配器定义 |
| 班车 | **执行批次 run** | 一次连续执行会话＝抽样的"层"（缺陷聚集单位） |
| 段 | **区段 segment** | 区段收口＝重检查点 |
| 六库 | **本体 profile** | 项目声明的库类型集合（小说六库=样例 #1） |
| 金标 | **基准样例** | 试车对照物 |

## 二、六层不变式（换语料不变）

```
L0 语料层   外部真值＋单元边界表＋锚点（单元伪锚点，禁墙钟）
            不变式：边界表来自语料自身标记，不来自抽取产物（声明面≠观测面）
L1 抽取层   单元 → 全新上下文执行者 → 候选（写盘不过主上下文，回执≤200tok）
            不变式：四件套输入＝规范＋判例(≤30)＋上下文包(≤2K)＋本单元切片
                    并发只写互不相交路径＋单元认领登记（防重复派工）
L2 校验层   门（结构/引用/连续性/词表域）→ 隔离分流 → 双轨入库
            不变式：能机械判定的必须机器判定；判定面为空≠通过
L3 存储层   账本（append-only 哈希链）＋记录库（三态）＋取代链＋出场/别名＋隔离区
            不变式：旧件字节不动；矛盾不静默合并；不可回退分配单一写者
L4 派生层   图/索引/摘要视图（可随时重建）；真源↔派生对账必须全量
L5 结论层   报告/判定：数字可复算；宣称有口径上界；落点自陈
```

**事实演化**：记录带 `version＋supersedes`；证据带 `valid_at/invalid_at`；裁决判定"推翻"时**写失效章＝新说法最早证据章，旧事实永久保留**；修订传播＝依赖闭包（改一个单元只重跑下游）。历史是资产。

## 三、八项参数（新项目初始化）

| # | 参数 | 说明 | 小说样例取值 |
|---|---|---|---|
| 1 | 语料适配器 | 单元切分规则＋边界真值来源＋编码/繁简归一化（NFKC＋OpenCC） | `<<<CHAPTER nnnn>>>` |
| 2 | **本体 profile** | 库类型集合＋每库必填字段＋类型/关系**受控词表** | 六库＋entity_type/rel_type 枚举 |
| 3 | 抽取引擎 | 代理亲抽／付费 API／本地模型 | 代理亲抽（¥0） |
| 4 | 编排 | 单元大小、并发档、上下文包预算（≤2K）、滚动摘要长度 | 1 章；两段式；30 单元 |
| 5 | 审查强度档位 | A 保命／B 治理／C 演化 | 先 A 后 B |
| 6 | 基准样例 | 单单元试车对照物＋评分器 | 金标 v5 |
| 7 | 判例来源 | 跨单元裁决沉淀（≤30 条滚动） | 分类学案等 |
| 8 | 交付目标 | jsonl／图库／世界书／问答 | jsonl＋图视图 |

## 四、本体 profile 怎么写（假矛盾的疫苗）

1. **库类型集合**：项目要分几类记录（样例：character/event/relation/foreshadow/setting/timeline）。判据：一类记录=一种必填字段集＋一种收纳规则。
2. **每库必填字段**：写到能机械校验（缺→门拦，理由码"缺必填"）。
3. **受控词表**：entity_type 与 rel_type 用**枚举**，不用自由文本。建表法：
   - 有存量→**词表自举**：统计现有取值频次，逐值四选一——保留／归并到 X／降级／新增提案，不许漏值
   - 无存量→从基准样例试车归纳初版＋"词表外→隔离＋理由码"兜底，跑 50 单元后回补
4. **粒度纪律**：枚举值之间不得存在"包含关系"（"人物"与"人物(迷宫生物)"并存=事故源——实例 604 件假矛盾的根因）。要么拆成独立值＋附加字段，要么归并。

## 五、语料类型适配速查

| 语料 | 单元切分 | 特有防御 |
|---|---|---|
| 长篇小说 | 章标记/卷章层级 | R6 元文本防御（作者杂谈/更新公告）；称谓随关系变化→别名增量 |
| 多卷文档/手册 | 节/页 | 版本日期防御（旧版声明作废→失效宣告） |
| 维基集群 | 条目 | 编辑战/来源分级（正典 tier 字段）；重定向→别名 |
| 法规汇编 | 条/款 | 废止/修订条款→失效宣告；引用网→G4 对账 |
| 剧本/对话 | 场/集 | 说话人归属；舞台指示≠事实 |
| 代码库历史 | 提交区间 | 提交信息元文本；后续提交推翻早期事实→失效宣告 |

## 六、四类病（实例实证，开新项目前自检）

| 病 | 实测证据 | 预防 |
|---|---|---|
| 假矛盾淹没真矛盾 | 604 件"矛盾待裁决"多为粒度差异；人工 128/129 是返工 | 受控词表＋词表域门 |
| 失效宣告空转 | 326 条图边 invalid_at 全空 | 失效写入路径＋允许/禁止情形判据 |
| 裁决不回写 | 129 件已裁，status 全 pending；无日期致滞后不可算 | 终态可读回＋日期位强制 |
| 读数不可复现 | 同一积压指标六种读数 | 每个数字自带口径（怎么数/何时数/绑什么哈希） |
