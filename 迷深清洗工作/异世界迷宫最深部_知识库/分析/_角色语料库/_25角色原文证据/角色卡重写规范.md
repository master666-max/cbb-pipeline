# 丰卡角色卡重写规范（子代理用 · 权威版）

> 用途：重写《异世界迷宫最深部为目标》(迷深) web版 25 张贫瘠角色卡。
> 执行者：子代理。本文件是唯一规范；与规范冲突的旧卡内容一律作废。
> 依据：web版 全十二章节清洗标注版原文 + 整理过的原文资料（画像报告/关系网/咏唱库/关系映射）。
> 禁止：任何形式的编造台词、改写咏唱/独白、张冠李戴、把他人台词安到本角色头上。

## 一、任务定义

把 丰卡 目录下指定角色的旧卡完全重写为「超丰富」质量角色卡，与已重建的 9 张（涡波/拉丝缇娅拉/缇娅拉/缇亚/玛利亚/斯诺/诺斯菲/阳滝/拉古涅/缇缇）同级。
输出：覆盖写入 `丰卡/<角色>_角色卡.md`。

## 二、必须基于的证据来源（按优先级）

1. **清洗标注版原文**（唯一可引用台词/独白/咏唱的底本）：

   行格式：`[对白] 「…」` / `[内心独白] …` / `[咏唱] …` / `[闪回/记忆] …` / 无标签叙事行。
   说话者判定：看台词行前后的叙事行（如「XX说道/问道/答道/笑道/低声道」或「XX看着…说」），
   以及是否有 block 头 `## block_id: … episode: 第X话 …`。
2. **证据包**（已整理好，含画像报告/关系映射/关系网）：

4. **叙述证据**（无标签叙事行，外貌/性格/身份/剧情线索，**需核验上下文**）：
   `<KB>/分析/_角色语料库/_25角色原文证据/叙述证据/<角色>_叙述证据.md`
5. **关系网权威视图**：`<KB>/分析/关系网/关系网_千年羁绊.yaml`
6. **画像报告**（提及量/峰值章/言语风格量化）：`<KB>/分析/基础资料/异世界迷宫最深部_主要角色画像报告_全文提取.md`
7. **咏唱库**（角色相关咏唱/开场白，红线原文）：`<KB>/…/咏唱库/…`（如咏唱库_main.yaml）

只写你有把握的。叙事描述（外貌/性格/剧情）也要基于原文事实，不得编造设定。

## 四、红线（不可逾越）

1. **咏唱/独白/原文逐字引用**：任何以「」引出的台词、以【内心独白】标记的话、咏唱正句，
   必须**逐字**来自原文，一字不改（含「……」省略号、『』、・、——）。不得改写、不得编造、不得补全。
2. **易混名严格分离**（全书最重要的五向/多向区分）：
   - 缇娅拉（千年前圣人·始祖，常称「缇娅拉小姐/圣人缇娅拉」）≠ 拉丝缇娅拉（現人神·女主角，全名 拉丝缇娅拉・弗茨亚茨）≠ 缇亚（使徒西斯·迪亚布罗·西斯）≠ 缇缇（风之理·涡涡）≠ 缇达（暗之理·兰斯家）。
   - 芙兰琉莱（赫勒比勒夏因家女性，莱纳义姐）≠ 法芙纳/法夫纳（血之理盗窃者，男性龙族）。
   - 勒伽希（使徒·西娅・勒迦希相关）≠ 帕林库洛（近卫骑士）。
   - 艾尔（艾尔米拉德·短称）≠ 艾尔米丽（魔石人类少女）。
   - 海因 ≠ 海莉。格连・沃克 与 沃克家 区分。
   - 诺文（地之理·阿雷亚斯家）≠ 诺伊（次元之理上代·我主）≠ 诺瓦露。
   写卡时必须确认台词说话者确实是本角色；若原文该句实为他人所说，禁止挪用。
3. **不编造设定**：外貌/身份/年龄/关系/剧情一律以原文或整理资料为据；资料中没有的不写或标注「（原文未明）」。
4. **精选台词是二次创作**：可以口语化改写原台词（聊天体），但必须基于真实原文台词，并在段首标注原句出处；
   咏唱红线句（如代价咏唱）改写时不得改动原句结构/关键词。
