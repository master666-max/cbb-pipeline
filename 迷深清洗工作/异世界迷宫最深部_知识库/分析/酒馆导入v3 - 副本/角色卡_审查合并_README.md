## 用途与规格
《异世界迷宫最深部为目标》37 张 A-v3 角色卡（`酒馆导入v3\角色卡\*_card.json`，含相川涡波 BOM 修复后状态）的审查用合并文件，规格与「T8后_角色专属世界书_审查合并」一致：
- **排序**：映射至世界书 B10后 权威序列（卡文件名含全名/旧形，按卡↔角色一一映射排序，映射表见 `角色卡_审查合并_清单.json`）
- **分份**：9 份，按字数线性划分均衡（各份 99,982～126,481 B，139～173 行）
- **分组**：第1组 4 份／第2组 5 份（按累计字数差最小切分）
- **结构**：每张卡前插独立成行的 `===== <卡文件名> =====` 标题行，字节原样拼接，UTF-8 无 BOM
- **质量**：逐份 SHA256 回验通过；拆解 37/37 张独立解析通过且 spec=chara_card_v2
