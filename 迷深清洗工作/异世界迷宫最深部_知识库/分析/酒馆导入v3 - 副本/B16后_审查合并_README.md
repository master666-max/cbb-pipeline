## 用途与规格
《异世界迷宫最深部为目标》37 本角色专属世界书（B16+B17 补丁后最新态）的审查用合并文件。
- **排序**：与 B10后 合并文件完全一致（权威序列）
- **分份**：9 份，按字数线性划分均衡切分（各份 67,731～84,672 B，1,193～1,824 行），任何一份都能被阅读工具单次完整读入，尾部书不再被截断

- **结构**：每本书前插独立成行的 `===== 角色专属世界书_X.json =====` 标题行（已根治旧版"标题粘连在前一本书末尾"的缺陷），书与书之间强制换行分隔
- **质量**：逐份 SHA256 回验通过；9 份共拆出 37 本逐本独立 JSON 解析全部通过
