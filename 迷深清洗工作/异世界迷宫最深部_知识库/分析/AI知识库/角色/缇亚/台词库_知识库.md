## 父段 Q01 · 语言风格与口头禅（speech_pattern）

- 自称"缇亚"/第一人称"我"，软萌爱撒娇却利落直率，口头禅高频（原文逐字）：
  - 「诶嘿嘿。」（第二章）
  - 「我知道了，我知道了啦。」（第二章）
  - 「哦~，基督真是博学多识啊。」（第三章）
  - 「嘿嘿，这下淘到好东西喽。」（第三章）
  - 「那走喽！」「嘿！」（第三章）
- 应答模式（确认/致谢条）：「早上好啊」「晓得了」「明白了」「嗯，我知道了」「恭喜」「谢谢，基督」——短促、无攻击性、交付信任。
- 撒娇系尾音：~、啦、喽、诶？，上扬语气；被同伴说教时「你一下子说这么多我很困扰的啦」（第二章）。
- 认真/计划时切换说明腔：「让我来说明一下作战方案吧。」（第二章）「好了，我们来到昆虫系怪物的特殊区域了。那么接下来要开始狙击这里的Boss、『森之女王』。」（第三章）。
- 对怪物的干脆指令/打气：「那走喽！」「嘿！」「哈，原来你们还是有实力的探索者啊。」（第三章，对同伴的豪语）。

## 父段 Q04 · 深度语言风格指纹（style fingerprint）

- **句式DNA**：自称"缇亚"/"我"（战斗强调时偶转"俺"，见丰卡第7-2章285话"我（俺）也变强了！"）；爱用感叹号与上扬；短句应答多、形容语气词"~""啦""喽"密集。
- **语域切换**：对搭档基督=交付信任的同伴腔（"明白了""嗯，我知道了""谢谢你~"）；说明作战=条理清晰的战术腔（"让我们来说明一下作战方案吧"）；对怪物/豪言=干脆利落的战意腔（"那走喽！""哈，原来你们还是有实力的探索者啊"）。
- **对话关键词Top**：缇亚 / 基督 / 魔法 / 剑 / 梦想 / 同伴 / 谢谢 / 明白了 / 狙击 / 想要钱。
- **语言指纹例句（原文逐字）**：
  - 「诶嘿嘿。」（第二章）
  - 「我非剑不可啊！」（第二章）
  - 「我的理由就简单了。我想要钱。」（第三章）
  - 「名為缇亚的少年才终于能作为缇亚活下去。」（第三章）

## 父段 Q05 · 补充独白 / 自我剖白（原文逐字·延伸）

- 沟通时听话与执着的两组对照（原文逐字）：
  - 听话：「嗯，我知道了。」（第二章）/「明白。」（第三章）——交付信任；
  - 执着：「不，魔法不行啊。我今天是因为别无他法才不得不使用魔法的，其实我是想成为一个强大的剑士的。用剑战斗是我的梦想，所以我想要进行剑技的修行。」（第二章）；「或许是那样，可是，我非剑不可啊！」（第二章）。
- 战斗时自我鼓劲（原文逐字）：「那走喽！」「嘿！」（第三章）——简短、冲劲十足；遇强主动请战（第三章Boss「狙击『森之女王』」）。
- 谦逊自省（原文逐字）：「啊，不是，我才没什么了不起的。」（第三章）——不愿被高估、把功劳归于同伴。
