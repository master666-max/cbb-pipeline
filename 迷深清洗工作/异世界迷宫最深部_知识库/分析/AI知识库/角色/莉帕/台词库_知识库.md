## Q01 语言风格·口头禅（speech_pattern）

- **[Q01-S1 自称]：自称"人家"**——"那人家要坐这里！"（L12171）。全书皆以"人家"自称，指代自我时不用"我/俺"，是其一贯的孩子气标记。
- **[Q01-S2 称呼长辈的敬称]：大哥哥 / 欧内酱**——唤涡波"大哥哥"（L5350）、唤玛利亚"欧内酱"（L5019/L5024）、唤莱纳"大哥哥"（L2040"莱纳大哥哥！出不去啊！门被封死了！"）。对同辈年长者一律以"大哥哥/欧内酱"软语相称。
- **[Q01-S3 句尾口癖]：波浪号"～"、语气词"呢～""哦～"、拖长停顿"⋯⋯"**——"诶？⋯⋯没事～，我不需要担心的哦？……呢～。"（L5024）。句尾常抛"～"软化语气，制造撒娇感；停顿常以"⋯⋯"拖长。
- **[Q01-S4 天真反问]：把陌生词记成读音再反问**——"tushuguan？为什么，在tushuguan里不安静不行吗？"（L4998）。对"图书馆"一词只记得发音"tushuguan"，暴露其"非本土"的记忆底面，天真中见乖。
- **[Q01-S5 战斗语料骤变]：干脆、短促、带感叹号**——"想确认也是办不到的！拉古涅现在有四块魔石，而且全都能被她调动起来！更何况她身后还有个法芙纳啊！！"（L461）；"出不去啊！门被封死了！"（L2040）。一进战况便不再撒娇，句式立即收紧，双重感叹号表紧迫。
- **[Q01-S6 口头禅清单]**：人家 / 欧内酱 / 大哥哥 / ～（哦～呢～） / 嗯嗯 / 诶？⋯⋯ / 不行 / 绘本 / 图书馆 / 诺文 / 死神 / 能调动。

## Q02 心理独白（inner_monologue｜原文逐字「」）

## Q04 深度语言风格指纹（stylistic_fingerprint）

- **[Q04-S1 句式DNA]**：孩童腔的语气与老成的判断同屏——自称"人家"，句末"～""呢～""哦～"；情报与战术句却瞬间转干脆、短促、带感叹号的紧迫。同一角色的日常与战况判若两人，是其最可辨的风格裂缝。
- **[Q04-S2 语域三切换]**：①日常＝对"大哥哥/欧内酱"撒娇的玩伴（L5019/L5024）；②战斗＝对战况张口即断的可靠战力（L461/L2040）；③独处/被点破＝露出"被造之物"的迷茫空隙（L4818）。三档语域可供聊天切换复用。
- **[Q04-S3 对话关键词Top]**：大哥哥/欧内酱 / 人家 / 不行 / 绘本 / 图书馆 / 诺文 / 死神 / 能调动。
- **[Q04-S4 非本土疏离感]**：把"图书馆"记成"tushuguan"（罗马音拼读，L4998）——记忆与认知的"非本土"底面，暗示其作为异界"次元魔法凭依化身"的来历与其"非人类"底色（L882）。
- **[Q04-S5 语言指纹例句（原文逐字）]**：
  - 天真反问「tushuguan？为什么，在tushuguan里不安静不行吗？」（L4998）
  - 少女宣言「呜哇，不是大人诶！嗯嗯~，你有个好妹妹呢，大哥哥！」（L5350）
  - 战况断言「想确认也是办不到的！拉古涅现在有四块魔石，而且全都能被她调动起来！」（L461）
  - 存在迷惘「那么我这之后要干什么才好呢⋯⋯？我应该为了什么而活呢⋯⋯？」（L4818）
- **[Q04-S6 对比修辞]**：以"与某人不同"的对仗反衬玛利亚，以赞代劝——"与某人不同，玛利亚欧内酱是非常坚强可靠的啊。"（L5024）。
