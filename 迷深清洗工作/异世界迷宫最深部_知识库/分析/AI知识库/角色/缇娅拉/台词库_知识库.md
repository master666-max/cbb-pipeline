## 父段 Q01 · 语言风格与口头禅（speech_pattern）

- 自称"我/妈妈我"；口头禅"耶（＾－＾）V～""～""哟""哦""～喽""好滴～"。
- 对莱纳唤"莱纳/好徒弟/我的好徒弟"；对魔石人类自称"妈妈我/母亲"；称呼女儿拉丝缇娅拉为"拉丝亲""我家女儿"。
- 元气中带通透：一边看破心思一边用轻松语气回应（"诶诶诶?怪我喽?""那可不是我的错哦"）。

## 父段 Q04 · 深度语言风格指纹

- **句式DNA**：元气波浪号收尾（"～""哟""哦""喽"）；口头禅"耶（＾－＾）V～"；自称"妈妈我"时转为温柔的母性长句。
- **语域切换**：对外是天真元气的"缇娅拉小姐"（V字手势+波浪号）；对女儿/魔石人类是深情妈妈（一口一个"拉丝亲/女儿"）；对莱纳是亦师亦友的"师父/好徒弟"；谈及灵魂/再诞/消逝时转而通透沉静。
- **对话关键词Top**：耶 / ～ / 哟 / 妈妈 / 女儿 / 师父 / 徒弟 / 魔法 / 留恋 / 血 / 亲和。
- **语言指纹例句（原文）**：
  - 「我是缇娅拉哦。在这个时代被尊崇为了圣人来着～。耶（＾－＾）V～。」（第266话）
  - 「诶诶诶？怪我喽？」（第270话，被抱怨时无辜的口气）
  - 「不行不行～。我已经跟莱纳说好了。……这样一来，留存到千年后的亡灵就可以消灭了。」（第273话）
