# AI 知识库 · 父子分段 Schema 说明

> 用途：为 AI 检索/上下文提供结构化的知识库（事实档案库 / 台词库 / 世界观库 / 共通世界书）。
> 模式：RAG 父子分段（parent-child chunking）。

## 术语
- **父段 Parent**：一个较大的主题语境块（几百~上千字），供 LLM 注入上下文。
  标识：`## 父段 P<编号> · <主题名>`
- **子段 Child**：父段内部更细的可检索小块，向量检索时命中；带 `parent: P<编号>` 引用 + 来源。
  标识：`### 子段 C<P>-<序号> · <条目名>`，下方一行 `parent: P<编号>` `source: <章节/话号>`

## 目录结构
```
分析/AI知识库/
├── 角色/<角色名>/
│   ├── 事实档案_知识库.md     # 外貌/性格/语言/战斗/关系/身份分层/剧情锚点/时间线
│   └── 台词库_知识库.md       # 心理独白原文 / 精选台词(聊天体) / 口头禅指纹 / 咏唱红线
├── 世界观/
│   ├── 世界观_知识库.md       # 全体角色共享：理之盗窃者/魔法/阵营/地理/时间线（父子分段）
│   └── 世界书.md             # 共通世界书（SillyTavern 世界书/World Info 风格，keyword→entry）
└── README.md                 # 索引
```

## 字段规范
- 每条子段必须含：`parent:`、`source:`（来源话号/章节）、正文。
- 咏唱/独白/间隔点 = 红线原文，逐字保留，不得改写（改写仅限"聊天体台词"且注明原句出处）。
- 事实条目标注：外观/性格/关系/伏笔/身份分层 等标签。
