## 使用建议

- **事实档案库**：先取父段（主题语境）注入，命中子段（细粒度事实）可再扩到父段（retrieval→context expansion）。
- **台词库**：子段=单条台词（红线原文逐字），用于对话生成时挑选角色口吻；聊天体条目注明原句出处。
- **世界观库**：全体角色共享，问答/世界观一致性检索用。
- **世界书**：导入世界书/World Info 系统，关键词触发自动注入对应设定。

> 统计：37 角色 × 2 库 = 74 个角色库文件 + 世界观库 + 共通世界书 + Schema 说明。
