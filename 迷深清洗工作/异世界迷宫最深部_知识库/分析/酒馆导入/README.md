## 🎴 角色卡（34 张）

酒馆 PNG 卡片格式**一张 PNG 存一个角色**（chara chunk 内嵌 chara_card_v2 JSON）。全 34 张独立 PNG，每张都用 **第一卷文库封面（插画/02_文库/第一卷/1-1.jpg）** 做底图，导入后自动展开为完整角色卡。

同时提供同名 JSON（角色卡/），两种任选：
- PNG：拖进酒馆即用，带封面缩略图
- JSON：文本导入，体积更小

## 🚀 导入步骤

1. **世界书**：World Info → 导入 World Info → 选 世界书/ 下 4 个 json（全勾）。
2. **角色卡**：角色管理 → 导入 → 拖入 PNG卡/ 下想要的 PNG（或用 角色卡/ json）。
3. 开聊即用。触发了世界书关键词（如"六十六层""诺斯菲"）会自动注入对应设定。

## 通用世界书（不能丢）

- 共通世界书.json（32 entries）原样保留，与角色专属世界书并存。
- 通用 = 全体角色共享设定（理之盗窃者/魔法/阵营/地理/时间线）；角色专属 = 单个角色知识。两者同时挂载即可。

## ⚠️ 关于"打包成一个 PNG"

酒馆 PNG 卡片格式硬性限制：**一个 PNG 只能存一个角色的 chara 数据**（若塞多个，酒馆只会读取第一个 chunk）。所以无法把 34 张卡塞进 1 个 PNG。
等价交付：34 个独立 PNG（同封面）+ 4 个世界书 json。要"一次性全导"，直接把 PNG卡/ 文件夹和世界书/ 文件夹整体拖进酒馆对应的导入区域即可（酒馆支持整文件夹多选）。
