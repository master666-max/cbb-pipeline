## 一、核心闭环（千年羁绊循环）

全书「千年羁绊网」主轴 = **涡波 — 诺斯菲 — 阳滝** 镜像三角（计划书 §六.1）：`涡波 → 相川阳滝 → 诺斯菲 → 涡波` 闭合循环。涡波对妹妹的病态依存、阳滝作为水之理镜像宿主的身份、诺斯菲对涡波的名义婚姻与千年求爱，三者互为因果。

**① 涡波 → 相川阳滝（妹妹依存 → 病态依存）**（yaml note: 妹妹就是我的一切）

- 证据（妹妹·唯一依存）：「妹妹就是我的一切」（第7-2章 287话）；"她是我在这世上唯一无二的妹妹"；结局"终于能与我『亲和』了呢"
- 镜像侧：兄妹镜像／次元对阵——阳滝亦能演算先谭且更精练（mirror_pairs）。

**② 相川阳滝 → 诺斯菲（千年镜像 → 镜像宿主体）**（yaml note: 水之理的盗窃者／可模仿次元决战演算）

- 证据（千年镜像）：镜像三角主轴：涡波→阳滝→诺斯菲→涡波（画像网框架）；丰卡：镜像三角主轴
- 画像网层面即「镜像三角主轴」（丰卡）。

**③ 诺斯菲 → 涡波（名义婚姻 → 千年求爱）**（yaml note: 名义女儿／妻子——千年前与涡波为夫妻）

- 证据（名义婚）：共现 3,180；千年前夫妻；第200话「承认我们之间的夫妻关系的国家早已不在」；第199话「⋯⋯涡波大人，请务必让我与罗德相见」；第201话「我的一切都是为了涡波大人」
