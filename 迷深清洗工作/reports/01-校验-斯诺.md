## 概要

卡的整体质感较高：早期（文库二~四卷=web第二章~第三章前段）的慵懒人设、口癖、13+4+6+7=30 条台词库绝大多数逐字命中语料；Ice・锁／振动／封焰入瓶／魔石扩音／双持超大型武器等能力设定全部有原文依据；「舞斗大会／舞闘大会」双触发词设计正确（实测两译区正文均以「舞斗大会」为主）。

但存在 1 条 P0 级台词张冠李戴（「格连·沃克！！」实为斐勒卢托所喊，斯诺的真实行动是劝格连「静观其变」）、以及两组结构性方向性错误：①涡波与斯诺的关系被写成「兄长般的存在」，正史实为**被举荐的婚约者／恋慕对象**（242 话当众「他是我老公」）；②缇亚被标为「龙人族」（缇亚非龙人）。此外卡的剧情覆盖止步于「文库四卷+第 7-3 章」两截，中段（第五卷舞斗大会**公开龙化**、第六卷退出公会）与 239 话代理总司令、242 话、第九章次任代行人、后日谈实质会长、外传其一的身世核心（故乡毁灭／威尔·沃克之死／二十层缇达惨剧／恐飞）全部缺失——而「龙化红线=第 7-3 章前绝不使用」的设定与第五卷当众龙化参赛的正史直接冲突。

### V-08 ★P0 「危急时喊『格连·沃克！！』」——台词归属错误＋场景重构失实
【角色卡原文】scenario／uid2／uid7：「守护义兄格连：为『那个人并不是坏人』辩护、危急时喊『格连·沃克！！』」；uid7 台词库末条：「〔第四章-玛利亚・玛利亚篇〕『格连·沃克！！』」
【语料出处】02_文库/第三卷 6240-6248 行（web 第二章 15694 行同位）：斐勒卢托请格连出手抓人→格连回绝「不好意思、这事儿我不干！」→**「格连·沃克！！」（斐勒卢托因被拒绝而愤怒的呼喊）**。该场景中斯诺的实际行动：拉住格连衣角耳语「……哥哥，我们还是静观其变吧」。
【判定】不通过（P0）。
【差异说明】「格连·沃克！！」的说话人是**斐勒卢托**（代理宰相），不是斯诺；且场景并非「危急」，而是宴会清算现场的口角。卡把它写成斯诺「危急时为义兄呼喊」，既错归属又错场景，还直接违反卡自己在 system_prompt 里立的红线「严禁以他人台词冒充自己的发言」。
【建议改为】从 uid7 台词库删除该条；scenario/uid2 的「危急时喊」改为「在清算现场劝格连静观其变」（若需保留紧张感场景，可引斯诺真台词「……哥哥，我们还是静观其变吧。」）。
【置信度】高

### V-09 ★P1 「为『那个人并不是坏人』辩护」——辩护对象搞反
【角色卡原文】scenario／uid2／uid7：「守护义兄格连：为『那个人并不是坏人』辩护」
【语料出处】02_文库/第三卷 6234-6238 行：斯诺对格连耳语「……处理的不好的话，也会影响到以后的事。……而且，那个人并不是坏人。」格连回「诶—、就算你跟我说他不是坏人……」——「那个人」指斐勒卢托要格连逮捕的**基督（涡波）**一方。斯诺是在劝格连不要对涡波动手、替**涡波**作保，不是为格连辩护。
【判定】不通过（P1）。
【差异说明】台词本身逐字正确，但语义方向反了：不是「斯诺护格连」而是「斯诺拦格连、护涡波」。此句同时是「斯诺暗中保涡波」的早期伏笔（呼应第二卷组队经历）。
【建议改为】uid2/uid7 注明「『那个人』指基督（涡波）：斯诺劝格连勿对其出手」；scenario 改为「清算现场劝格连静观其变、暗中为涡波作保」。
【置信度】高

## 三、web 版 vs 文库版差异专列

1. **章节体系**：卡内早期章节名（第一章-再掀挑战……第三章-再会）= web 第三章内部章节 = 文库第二~四卷各第一章；「第四章-玛利亚・玛利亚篇」= 文库第三卷第四章「玛利亚・■■■■■」= web 第二章后半。两套体系在卡内混用且时序错置（玛利亚篇实为最早）——见 V-10。
2. **「舞斗大会／舞闘大会」**：web 第三章正文以「舞斗大会」为主（194:27，舞闘集中于『一之月联合国综合骑士团舞闘大会』标题）；文库四~六卷全为「舞斗大会」；外传空间用「舞闘大会」。卡双触发词设计正确（V-27）。
3. **Ice・锁／维度**：web『Ice・锁』『维度』vs 文库『Ice·锁』『Dimension』。卡采 web 式拼写并自标 tags「web版」，内部一致，判定为译名体系差异不算矛盾；但 uid3 若在文库语境使用需知道文库用词不同。
4. **真双版本区（web 第四章 131-185 vs 文库七/八卷）**：斯诺相关内容（船旅「稚拙的恋慕」、沃克家诀别后的随心所欲、「夫君」称呼请求、不擅长恋爱）两版本情节一致，文库版有删节（如文库八卷删第 163 话）但无设定冲突，无需用户选基准；卡内未收录此区间，无影响。
5. **web 独有区间**：第 239-242 话（代理总司令/老公宣言）所在的 web 第六章（229-264）在语料库中无文库对应卷——引用时应标注「web 版独有」；卡完全未引用，故不产生基准问题。
6. **第 7-3 章（320-346）**：语料库仅存 web 版（第七卷对应文库第五~六卷区间、第九卷对应 314-346 部分书卷化，但 7-3 章文件为 web 原文），卡的「第7-3章」引用均落在此文件，无版本歧义。
