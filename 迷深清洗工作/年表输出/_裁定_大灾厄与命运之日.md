## 二、关键矛盾/疑点(需你裁定)

### 疑点1:初代七骑士中「已逝去的海因、拉古涅、帕林库洛」的时间位置?
第388话 13874:拉斯缇亚拉诞生后第一年(新历1011年)身边围绕初代七骑士,其中海因、拉古涅、帕林库洛**已逝**。
但第331话(拉古涅追忆,发生于主线中后期)拉古涅本人还活着、还在写信给妈妈,海因帕林库洛也都活着在七骑士活动。
→ 疑问:新历1011 是不是比主线后期更晚?还是 13874 的「已逝去」是拉斯缇亚拉**后来**(写自传时)的回溯注脚?(13869-13870 明说这是过去视「新历1011年的景象」,而 13875 在同句中称三人已逝 → 若为当时实况,则新历1011 拉古涅已死;但第7-3章主线中拉古涅活跃——**除非拉古涅线追忆发生在新历1011 之前?**)

### 疑点2:大灾厄 vs 命运之日,是同一件事的两次转述,还是两件不同的事?
- 第331话(拉古涅视角,主线中):帕林库洛与涡波**同归于尽** → 『大灾厄』(本土,死伤十万)。此时拉古涅尚未死,涡波也还没到芙茨亚茨城顶点(她后来才与涡波同行 Living Legend 号)。
- 第393话(命运之日):涡波被切断四肢身亡(在芙茨亚茨城45楼,疑似拉古涅所杀——见第323话诺斯菲「拉古涅杀死了父亲大人」「他为了保护我,从一开始就落了下风」),同日拉斯缇亚拉察觉自己仍活着三理由。
- 第404/405话:『一年前』帕林库洛在**本土**发动世界奉还阵 → 交换身体。

### 疑点3:若大灾厄=世界奉还阵(一年前,本土),它发生在第331话之前还是之后?
- 第331话拉古涅追忆时序:入七骑士 → 大圣都成长 → 邂逅涡波三战三败 → 涡波获称号 → 准备杀涡波 → **听闻大灾厄(帕林库洛×涡波同归)** → 五年后归乡寻母 → 成为七骑士总长 → 与涡波再会(涡波从迷宫逃出?) → 同行赴弗茨亚茨(第332~333话:顶点战)。
- 若大灾厄=命运之日之前的事件(第393话在第八章),而第331话在第7-3章(320~346话)——**第7-3章话号早于第八章**,则拉古涅在第331话已听闻大灾厄 → 大灾厄发生在第331话之前 → 早于第393话?那第393话的「涡波被切四肢」又是另一次死亡?
