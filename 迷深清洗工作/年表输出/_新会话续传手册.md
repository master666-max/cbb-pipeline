## 五、单发分页子代理模板（铁律！避免上下文耗尽）
失败的根因是：子代理一次 read 整个包（~150KB）导致上下文耗尽、且 >2 并行会全灭。**皇成功模式 = 每波1个子代理 + 明确分页读取**：
- prompt 中写：分 3 次读该文件（read offset=1 limit=600 / offset=600 limit=600 / offset=1200 limit=800），每页随手记要点，读完一次性写 JSON。
- quotes 内半角引号一律用『』避免 JSON 错误。
- 块头 timeline 标签可能混乱，**以内容实质判定 layering**。
- 每个事件必带 event_id / event_time / story_anchor「话X / block_id md-YY」/ title(≤20字) / description(100-300字引原句) / characters(含化名"相川涡波(化名:基督·欧亚)") / location / event_type / timeline_layer / confidence / 可选 foreshadow/callback/reversal/incantation_refs/quotes。
