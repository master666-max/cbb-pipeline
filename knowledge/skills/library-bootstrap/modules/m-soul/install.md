# m-soul · 灵魂层

## 装什么
soul/SOUL.md + soul/USER.md 模板 + 会话入口追加三级加载条款。

## install.md 步骤
1. 复制 template/soul/ 两文件，填 {{SLOT:OWNER_NAME}} 与 {{SLOT:DATE}}；SOUL 价值观/风格段留给用户对话后 agent 补写（标注【待填充：与用户磨合后写】）。
2. 入口文件（m-index 装的）追加一行：「会话开始按 SOUL → USER → knowledge/_index.md 三级加载」。
3. 校验点：soul/ 两文件存在；入口含三级加载。

## 纪律
- 灵魂层修订只能依据真实互动史（A-MEM 演化），修订注明日期。
- 常驻层预算：SOUL+USER+_index 合计 ≤150 行（context rot 对策）。

## 溯源
Letta memory blocks（persona/human）+ OpenClaw SOUL 生态；本工作区 v3 实装，用户裁决含轻松层双模式。
