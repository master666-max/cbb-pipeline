# EXP-dream-fusion · 梦境融合（实验·最激进）

> ⚠⚠ L7 旗舰实验模块。稳定性 ☆：完全未经验证，属于「因为很 cool 所以做」档（miza 2026-09-04 授权）。

## 做什么
把「睡眠整理」从「列建议」升级为「做梦」：定时任务（或 reflect 触发）时，agent 不只整理条目，而是**自由联想式重读全库**——随机抽 3 条互不相关的条目（跨库跨类型），强行寻找深层关联，写一条「梦境笔记」进 knowledge/dreams.md。关联若真有价值，升格为正式 R- 反思条目；无价值就留着当墓志铭（不删）。

## 安装步骤
1. 复制 template/dreams.md → knowledge/dreams.md。
2. 在 m-cron 的 SLEEP.md 流程追加第 5 步：跑一次 dream-fusion（抽 3 条 → 联想 → 记笔记）。
3. reflect 技能取材范围加入 dreams.md（梦境笔记是反思的高质量候选素材）。

## 已知风险
- 产出大概率无意义（这本来就是设计的一部分：发散记忆融合的低信噪比探索）。
- 消耗额外 token；建议仅在额度充裕时启用（正好符合本用户画像）。

## 理论依据（三派杂交）
- Generative Agents 反思的极端化：从「归纳同主题」到「跨主题强行联想」。
- Sleep-time compute 的梦境版：空闲期做与直接任务无关的重组。
- MemoryOS 热温冷调度的浪漫主义翻译：让冷记忆偶尔被「梦见」。

## dreams.md 条目格式
```
### D-001 / {日期} / {一句话梦境}
- 抽中：[[PT-xxx]] [[P-xxx]] [[W-xxx]]（三个不相关条目）
- 联想：{强行找到的深层关联，写得越离谱越诚实}
- 判定：treasure（升格为 R- 条目）/ junk（留档不删）
```
