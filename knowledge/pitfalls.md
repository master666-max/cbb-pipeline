### P-001 / 2026-09-03 / Windows 会话里别用 `python` 命令跑脚本：用 `py` 启动器；被 hook 拦截就写成 .txt 再执行
- 场景：多次任务需要执行 Python（提取 PDF/EPUB、生成后处理、程序化验收），直接调 `python` 失败或被会话 hook 拦截。

### P-002 / 2026-09-03 / EPUB 解包文件名乱码：ZIP 非 UTF-8 标志位条目要按 cp437→utf-8 修复
- 场景：按文件名定位 EPUB 内章节时内容错乱/找不到文件。

### P-007 / 2026-09-08 / 沙盒实验的度量缓存必须随库状态递增版本号（pre≡post 假象）
- 场景：自演化沙盒 X2d 实验中，对同一库「批量写入前后」各测一次检索指标，两次读数完全相同——不是库没变，是度量函数的全局缓存 key 为 `(lib路径, rev)`，两次调用都传 rev=0，post 读到的是缓存的 pre 条目集。
- 教训：实验脚本里任何「读库→度量」的缓存，key 必须包含库内容版本（写操作后 rev+1），否则写后测量静默读旧数据，产出「干预无效」假象。根因：缓存设计时只考虑了「同状态重复度量要快」，没把「库已被自己写入」纳入失效条件——与报告失败 #7（id() 缓存串味）同族，都是缓存键不完整。识别信号：两次本应不同的测量**完全相等**。

### P-008 / 2026-09-09 / ComfyUI Desktop 秒崩双重根因：残缺安装记录触发下载器在国内网络的未处理异常，勿信「重新装一遍」

### P-009 / 2026-09-09 / Python subprocess 调 MSYS 工具链（Git 自带 gpg）：路径要走 /c/ 原生格式 + 读输出必须 errors="replace"
- 场景：验证脚本里用 python subprocess 调 Git Bash 自带的 gpg.exe（MSYS 构建）做 GPG 签名实验，GNUPGHOME 传 Windows 反斜杠路径或 C:/ 正斜杠路径均被改写成 `/tmp/<cwd>/C:/...` 混合路径而 Fatal；另一处 subprocess 读 git 中文输出时 UnicodeDecodeError 崩在 reader 线程。
- 教训：MSYS 运行时会对类路径的环境变量/参数做 POSIX↔Windows 自动转换，Windows 形态路径喂给它反而错——要转成 MSYS 原生 `/c/Users/...` 格式再传（`"/"+盘符小写+去掉冒号`）；同时 subprocess `text=True, encoding="utf-8"` 必须配 `errors="replace"`，Windows 中文环境下子进程输出可能是 GBK。根因：混用两套路径世界观 + 假设子进程输出编码与己方一致。

- 关联：[[P-001]]（同为 Windows 混合环境执行纪律）、[[PT-011]]（本次验证流水线全程踩此坑后修复）
- 版本：v1（2026-09-09 建立）
- schema_version：3
- 来源：knowledge/trajectories/2026-09-09/task-022-bootstrap对抗验证.md
- 置信度：高（三种路径形态对照实测：反斜杠 Fatal / C:/ 正斜杠 Fatal / /c/... 通过；errors=replace 前后对照）

### P-010 / 2026-09-09 / 长会话运营三事故：相对路径三路不同源 + 输出管道截断留存 + 异常归因先想别人
- 场景：多轮长会话（自演化沙盒 v3.9 应用）连续发生——①从**根级目录**出发用 `../../` 做 cp，落到 D 盘根误建目录（D:\library-bootstrap-v3.9\），同链哈希检查却读 `../` 正本位置，造成「先新后旧」假象，进而**误判为「他方智能体覆盖」并对无辜方提出指控**（后经用户纠正、绝对路径取证更正）；②长跑输出经 `| head`/`| tail` 查看或截断，三次丢失完整数据（并发探针 stdout、test_compare 精确计数）；③已删除的任务（库调试v3.2 改名）被重新列进挂起项，账本不同步，用户两次纠正。
- 教训：①**cp 目标、哈希核验、文档记录必须是同一个（绝对）路径**——核对了 A 路径却复制到 B 路径等于没核验；根级目录下 `../../` = 盘根，高危写操作一律绝对路径；②`> file` 留存、管道只用于即时查看；③异常现象的归因顺序必须是「先绝对路径取证自己的操作链，再考虑外部因素」——本次在零证据下先指控他方。共同根因：多轮长会话里每一步运营操作「当时觉得没问题」，没有纪律约束。
