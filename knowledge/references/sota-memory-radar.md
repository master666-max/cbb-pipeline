## 触发器（何时重新轰击调研）
1. 条目总数 > 100：重评向量检索（B 派管线 + C 派图索引）
2. 出现多 Agent 协作：重评 G-Memory、MemOS 调度
3. 需要超长文档/百万 token 任务：重评 MemAgent、MemoryOS 页调度
4. 新范式出现且三个信源以上提及：随时追加本图
5. 每季度例行：Bing 搜索页探测一次最新综述
