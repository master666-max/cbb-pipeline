# exp8-tournament · 知识锦标赛（达尔文选择压）

## 装什么
usage.log 遥测纪律 + 季度锦标赛流程。依赖 m-tools。

## install.md 步骤
1. 建 tools/usage.log（空，格式：日期|条目号|检索词）。
2. task-start SKILL 追加：「search_knowledge 命中的条目，任务中实际用到时追加一行 usage.log」。
3. 在 SLEEP.md 追加季度任务：「锦标赛（TOURNAMENT-SOP）——末位四分之一的 pattern 生成合并/冷置提案，仅提案，等人类令牌」。
4. 校验点：usage.log 存在；SOP 含「新条目 30 天豁免」与「零删除」。

## 溯源
MemoryBank 遗忘曲线的主动版 + DGM 选择压；防库腐化的自动机制（替代纯人工清理）。
