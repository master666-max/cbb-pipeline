# library-bootstrap · 建库分类与提示词速查（超绝统合版 v2.0）

> 用法：拷包到任何 harness 工作区后，把下面任一提示词原样发给 agent（把「库名」换成你的意图）。拿不准就发第一条「起手式」，agent 会走交互向导。
> 档位全链：L0 最稳 → L9 最激进；特色包可叠加在任意 L≥2 上；模块可自由点菜。
> **本统合版含 L0-L9 全档 + L8/L9 add-on 模块，无需另装分包**：L8/L9 档位提示词可直接使用（仍会先要求宪章/公理确认）。

---

## 一、起手式（不知道怎么选就用它）

```
按 library-bootstrap 建库
```
→ agent 走交互向导（支持交互的 harness）或默认 L2 标准版。

## 二、档位提示词（L0-L9，从最稳到最前沿）

| 档 | 一句话定位 | 提示词（原样发送） |
|---|---|---|
| L0 | 裸奔骨架，零依赖 | `按 library-bootstrap 建 L0 裸奔库，只要目录骨架和铁律` |
| L1 | 基础闭环：入口+索引+task-start/wrap-up | `按 library-bootstrap 建 L1 基础库` |
| L2 | 标准版（特色包默认基座）：+lint+检索 | `按 library-bootstrap 建 L2 标准库` |
| L3 | 演化版（A-MEM）：条目元数据+六步收尾 | `按 library-bootstrap 建 L3 演化库` |
| L4 | 灵魂版：soul/SOUL+USER 三级加载 | `按 library-bootstrap 建 L4 灵魂库` |
| L5 | 反思版：reflect+定时体检+睡眠整理 | `按 library-bootstrap 建 L5 反思库` |
| L6 | 前沿全家桶（本工作区同构） | `按 library-bootstrap 建 L6 全家桶` |
| L7 | 实验档：梦境融合/自动批评家/向量检索 | `按 library-bootstrap 建 L7 实验库，三个实验模块全上` |
| L8 | 超绝激进：自指演化（库改自己的机器） | 先装 L8 add-on 包，再：`按 L8 档加装：先展示 L8-CONSTITUTION 宪章全文，我确认后再装全部七模块` |
| L9 | 内省仿生（BCA）：情绪式调制器/GWT/睡眠闸门 | 先装 L8 再装 L9 add-on，再：`按 L9 档加装：先展示 BCA 公理与验收三件（消融/干预/谄媚），确认后按序装八模块` |

> 说明：L3+ 的档位提示词说「建 L{n}」即可，嵌套自动包含其下全部模块；L8/L9 需要对应的 add-on 包已拷入工作区（见第七节）。

## 三、特色包提示词（叠加在任何 L≥2 上）

| 特色包 | 干什么 | 提示词（原样发送） |
|---|---|---|
| 角色扮演 | 人格卡+世界观/角色/剧情/名场面四库 | `建 L2+角色扮演库，角色人格卡先留空模板`（可加：`用我提供的世界观初始化`） |
| 写作 | 文风画像+设定集/时间线/伏笔账本 | `建 L2+写作库，我要连载小说，伏笔账本必须带 planted/recovered 状态` |
| 语料分析 | 清洗规则库+统计范式库+三层数据流 | `建 L2+语料库，我会喂整本小说 txt，先铺好 raw/interim/processed` |
| 代码工程 | bug 模式库+ADR 决策记录 | `建 L2+代码库，我在维护一个 X 项目，ADR 放架构决策` |
| 研究综述 | 文献卡+演化综述+信源 S/A/B/C 分级 | `建 L2+研究库，方向是 X，信源分级表建好` |
| 多 Agent | 协作契约+agent 分区 | `建 L3+多agent库，先逐条确认 CONTRACT 分工再继续` |

组合示例：`建 L4+角色扮演库，人格卡用米莎人设，加梦境融合实验模块`、`建 L5+研究库，季度锦标赛也要`。

## 四、自由组合（点菜语法）

```
按 library-bootstrap 建自定义库：要 m-core、m-index、m-soul、m-tools；不要 m-loop 闭环
```
- 语法规则：模块名 m-* 与特色包 x-* 直接列出；「不要 X」即排除。
- agent 会先跑依赖校验（如 m-evolve 缺 m-schema3 会被拒绝并告诉你补什么）。

## 五、升级与加装提示词（库建好后继续长大）

| 想干什么 | 提示词 |
|---|---|
| 档位升级 | `把本库从 L4 升到 L6，装完后跑 manifest 校验` |
| 加单个模块 | `加装 m-radar 模块（升级流程：diff 现有 manifest，只装新增）` |
| 加特色包 | `给本库加装 语料分析 特色包` |
| 体检 | `跑库体检（lint_library）并汇报` |
| 检索 | `检索知识库：XXX 关键词`（内部自动走 search/broadcast） |
| 收尾/反思 | `执行 wrap-up` / `跑一次反思`（L8 可加：`开心智议会`） |
| 定时 | `给我配每月 1 号自动体检`（harness 有 cron 则自动建，否则写手动流程） |

## 七、add-on 安装提示词（三轨发布链）

```
主包：先按第二节提示词建 L0-L7 任意档。
L8：  把 library-bootstrap-l8-addon/ 拷进工作区 → 「按 L8 档加装…」（第二节）→ 装完跑 run_tests
L9：  把 library-bootstrap-l9-addon/ 拷进工作区 → 「按 L9 档加装…」（第二节）→ 装完跑 A1 消融初测
```
> 任何一步都有逃生舱（见第六节），主库永不推倒重来。

## 八、环境与故障对照

| 现象 | 该发什么提示词 |
|---|---|
| 安装时 python 报错/被拦 | `先跑 harness-detect 环境探测，按结果选择脚本形态再继续` |
| 重装/校验 | `重跑一遍安装（幂等），跑完 bootstrap_verify 对账` |
| 怀疑文件被改 | `跑 bootstrap_verify + l8_guard --check-templates` |
| 想试装不想动主库 | `在 _l8_lab/（或新沙盒目录）试装 L8/L9，主库不动` |
