# exp8-twin · 用户数字孪生（预演 oracle）

## 装什么
soul/TWIN.md（决策偏好模型）+ 预演纪律。依赖 m-soul。

## install.md 步骤
1. 用 soul/USER.md + 相处记录初始化 TWIN.md（用户裁决：以既有语料起步），填槽 {{SLOT:OWNER_NAME}}。
2. 纪律写入 task-start：「提交计划书前，先按 TWIN 预演用户三个最可能反应，写入计划书【孪生预演】节」。
3. 校验点：TWIN 存在且含「预演记录」节；本模块首验 = 下一份计划书自带【孪生预演】。

## 红线
- 仅咨询不代行：TWIN 预演不能替代真实用户确认（宪章第三条）。
- 预演必须显式标注【孪生预演】，不许冒充用户意见。
- 每次真实反馈回来后校准：命中/落空记入 TWIN「预演记录」。
