# X-Writer · 写作库特色包

## 定位
小说/剧本长期创作：设定集、时间线、伏笔账本、文风样本四库 + 废稿 attic。机制层复用双库。

## 装什么（叠加在 L≥2 上，推荐 L4：文风画像=soul 形态）
| 模板 | 目标 | 编号系 |
|---|---|---|
| template/soul/STYLE.md | soul/STYLE.md | 作者文风画像（替代 SOUL 的写作人格） |
| template/knowledge/设定集.md | knowledge/设定集.md | SET-001 |
| template/knowledge/时间线.md | knowledge/时间线.md | T-001 |
| template/knowledge/伏笔账本.md | knowledge/伏笔账本.md | F-001 |
| template/knowledge/文风样本.md | knowledge/文风样本.md | FS-001 |

## install.md 步骤
1. 复制五模板填槽。
2. wrap-up 复盘特化：本章埋的伏笔记账了吗？设定有无前后矛盾？文风漂移了吗（对照 FS 样本）？
3. 检索特化：伏笔检索「状态：未回收」；设定冲突检查 = 新 SET 条目 grep 旧条目同关键词。
4. 校验点：五文件齐；伏笔账本含「状态」字段（planted/advanced/recovered/dropped）。

## 溯源
本工作区 mepub 深加工计划书（伏笔/设定/文风维度）的泛化。
