# X-Research · 研究/文献综述库特色包

## 定位
长期研究项目：文献笔记 + 综述演化 + 来源可信度分级。核心特色是「综述不是快照而是演化文档」+ 信源分级。

## 装什么（叠加在 L≥2 上，推荐 L5：反思层对综述演化很有用）
| 模板 | 目标 | 说明 |
|---|---|---|
| template/knowledge/文献笔记库.md | knowledge/文献笔记库.md | LIT-001 起：一文献一卡 |
| template/knowledge/综述.md | knowledge/综述.md | EVOLVING 文档：版本化综述正文 |
| template/knowledge/信源分级表.md | knowledge/信源分级表.md | 来源可信度分级规范 |

## install.md 步骤
1. 复制三模板。
2. 综述.md 标注当前版本号与「上次依据变更」；文献新证据与综述冲突时，综述升版本并写「变更依据」。
3. wrap-up 复盘特化：新文献入卡了吗？综述版本号该升吗？信源分级有变化吗？
4. 校验点：三文件齐；信源分级表含 S/A/B/C 定义。

## 溯源
综述演化 = A-MEM 记忆演化在文档层的应用；信源分级源自本工作区调研实践（arXiv 直接抓 vs 搜索页二手信息分级）。
