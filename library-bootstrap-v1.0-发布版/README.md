# library-bootstrap v1.0 · Agent Harness 通用建库 Skill

> 把本目录整个拷到任何 agent harness（ZCode / Claude Code / Cursor / Codex CLI / Trae…）的工作区，
> 对 agent 说：「按 library-bootstrap 建库」——一句话一键建出可复现、可校验的双库自进化体系。

## 快速开始
```
拷贝本目录 → 目标工作区
对 agent 说：
  「按 library-bootstrap 建库」              （交互选择/默认 L2）
  「建 L4 库」                               （灵魂版）
  「建 L7 库，实验模块全上」                  （尝鲜档，风险自担）
  「建 L2+角色扮演库」                        （特色包）
  「只要 m-core 和 m-soul，不要 loop」        （自由组合）
```
