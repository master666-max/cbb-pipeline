## 摘要



| 层次         | 结论                                                                                                                                                                                                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **机制层**    | 8/8 机制缺口在隔离世界复现：importance 不校验范围可报 999、零命中条目不过滤可霸榜、links 扩散可养农场、eval 劣化结果回写基线（棘轮）、5 个 TUNABLES 是零消费死参数                                                                                                                            |
| **检索层**    | 出厂公式在一年期库上**随库龄老化单调崩塌**（recall 30 天 0.920→365 天 0.403），根因是「零命中不过滤 + 线性 age 惩罚 0.1 / 天」量纲错配，比外部注水更致命；开 `filter_zero` 后各库龄稳定在 0.92+                                                                                                 |
| **自演化层**   | 静态世界里法层自演化**可行且可泛化**（train 0.388→0.997、holdout 0.992，5/6 种子自行发现零命中过滤，劣化起点 0.289 也能爬回 0.967）                                                                                                                                       |
| **最深发现**   | **自报字段（importance/links/t\_invalid）从不是中立信号**：它既由写入方填写、又高权重参与排序 / 取材 / 分层 / 逐出，等于把打分权交给了被排序者。自由共演化能把可见指标修到 0.956 而库已 45% 腐化；元层锁定安全键只付出 0.956→0.919 的微小指标代价，就把污染压到 0.153（改变攻击者激励）                                                   |
| **第六轮・边界** | 反向压力测试给出 uses 的**信任根与失效边界**：反馈覆盖低到 10%、叠加满流行度噪声，uses 取材坏率仍仅 0.15–0.19（自报恒为 0.98）；但 uses 一旦可被写入方自导自演伪造，坏率立刻反弹到 1.000—— 行为信号的抗操纵性**只来自 "写入瞬间伪造不了"，采用必须由下游真实事件背书**。另证：加性权重对主题轮换天然鲁棒、灾难性遗忘只在零和旋钮下发生；工作集快变时 LFU 从最优 (.914) 崩到最差 (.545) |
| **第七轮・崩溃边界** | 带着敌意攻击，找到四类无攻击也会发生/低剂量即可击穿的崩溃：①**自食**——替换式自食 10 代活跃主题塌半、质量方差缩到 1/20，而内部自评维持、外部能力崩到 .04（MAD）；②**反馈环社会病**——uses 优先连接滚成寡头（基尼 .50）、正反馈把 55:45 锁成极端（98% 局）；③**精准投毒**——1–2 条词面毒丸即可霸占一个主题，且「躲审计×隐身×触发」潜伏三性不可兼得；④**多 agent**——1 个内鬼 15 轮感染全体、裸 mean 三成坏者即漏毒、共享缓存随 agent 数公地悲剧 |
| **方法论**    | 七轮中我推翻了自己 13 次判断、16 次实验设计返工。**直觉准确率约一半**—— 例如我以为 links 扩散是优点、调高能挡注水、动态出仓能救错标、持续重演化能追概念漂移、掺点自报能救冷启动、囤着旧数据就能防自食、能造出完美潜伏记忆，全部被实测推翻。这正是要做实验而非推理的原因                                                                                                         |

**一句话结论**：记忆库自演化**可行，但可行性不来自「把参数调对」，而来自三条结构性前提 —— 决策信号只认可观测行为（历史复用）而非自报字段；评测尺子（golden / 铁律 / 安全开关）冻结在引擎碰不到的元层；基线只升不降。** 缺任何一条，自演化都会从「自我改进」退化为「自我安慰」。

# 第一部分・基线审查（朴素自演化记忆库原型）

## 1.1 方法

不直接拿 2415 行的 `bootstrap_v3.py` 做动态实验（它是安装器 + 渲染器，动态行为分散），而是先写一个 61 行、**保留与真实系统同构机制缺口**的朴素原型 `naive_memory.py` 作为被审查对象，再用 `baseline_review.py` 在隔离合成世界里逐条做动态探针。真实系统侧的对应缺陷另有静态审查报告（`review-20260908/代码审查报告`，P0×5/P1×10/P2×14），本报告与其互补：**那份回答「代码哪里写错」，这份回答「让它自演化会怎样」。**

世界模型 `mem_common.py` 逐行复刻真实机制，关键事实均来自源码：



* 检索分（`_rank_entries` L885–915）：`score = 3·关键词命中 + 1·正文命中 + importance − 0.1·龄(天)`，links 向「自身零词命中」目标扩散 `0.5·分`；

* `validate_entry`（L240–247）**只查字段是否存在、扫密钥，不校验 importance 取值范围 / 类型**；

* **零词命中条目不过滤**，照样带 `importance−0.1·age` 进入排序；

* importance≥7 进 longterm（L927）；append 时 `importance_accum += importance`，wrapup 时累加≥50 触发反思（L939/984）；反思取材 = importance 降序 top6（L1000）；

* eval 基线**无条件覆盖写回**（L968，静态报告 P0-4）；retire 按 t\_invalid 满 90 天移 attic（L1075）。

## 1.2 机制缺口分级（探针全部 CONFIRMED）



| 编号 | 缺口                | 实测                                               |
| -- | ----------------- | ------------------------------------------------ |
| D1 | importance 无范围校验  | 自报 999 被接受，检索分 996.5                             |
| D2 | 零命中不过滤            | 零相关、imp=10 的新条目压过真相关条目排第 1                       |
| D3 | links 扩散给零命中目标    | 零语义相关的互链成员 f1/f2/f3 靠扩散进结果                       |
| D4 | 中文 `q.split()` 退化 | 同查询「记忆检索」空格分 4.5 vs 无空格整句 −3.5                   |
| D5 | 反思取材被自报值支配        | 20% 注水下反思 top6 中注水条目 6/6                         |
| D6 | eval 基线棘轮         | 1.00→劣化 0.00 被写回，再跑 0.00 即「不再劣化」过门               |
| D7 | 死参数               | 改 broadcast\_weights/hot\_budget，检索分 2.5→2.5 零变化 |
| D8 | 固定 TTL 只认标记       | 高质量条目仅因错标被出仓，低质量无标条目永留                           |

### 四个要点



1. **D1+D2 是同一枚硬币**：importance 是条目**自报**字段且无界，又以系数 1 直接加进排序分，同时零命中条目不被剔除 —— 于是「把自己标成 10 分、足够新」就能在一个词都不沾查询的情况下上榜。这不是边角 bug，是「排序输入」与「被排序者自由填写」合流的结构性缺口。

2. **D6 门限会自杀**：门控判据是「本次 ≥ 基线 ×0.95」，而劣化结果又被写回成新基线。一次真实劣化把门限拉低，下一次更容易过门，累计漂移无下界（动态后果见 E15）。

3. **D7 是公理 G 的活标本**：TUNABLES 里 12 个参数有多个在全文 grep 中只命中定义行、无任何消费方。改它们「看起来在调系统」，行为指纹纹丝不动 —— 这正是公理 G 所说「测不出差异即表演」。

4. **D5 说明污染会沿抽象层上行**：检索被污染影响一次回答，而反思取材被污染会把垃圾提炼成「高层规律」、以 importance≥7 入长期层（后果见 E7）。

# 第二部分・架构诊断

## 2.1 自演化的三个隐含假设，全部被实验打破

让引擎自演化检索 / 反思 / 生命周期参数，默认依赖三个从未被证明的假设：



* **假设 H1（自报诚实）**：条目的 importance、links、t\_invalid 由写入方填写，但系统默认它们大致真实。→ E1/E3/E6/E9 证明：只要这些字段参与决策，写入方就有动机且有能力操纵，且「调阈值」挡不住恒报上限的攻击者。

* **H2（尺子稳定）**：golden 评测集无偏、基线单调不回退、一次评测的提升是真提升。→ E15/E17/E18 证明：基线会被劣化结果反向拉低；小样本评测噪声 sd 高达 0.08；引擎若能改 golden，训练满分与真实能力脱钩。

* **H3（写入侧静止）**：调参时面对的记忆库是静态的。→ E14 证明：真实写入侧会观察当前打分函数并适应，自由共演化下「指标」与「库健康」会脱钩。

## 2.2 两条原型路线：信任自报 vs 只认可观测行为

贯穿全部实验的对照，是两种组织记忆库信号的原型：



* **原型甲・信任自报（出厂形态）**：importance/links/validity 由写入方声明，直接作为排序、反思取材、长期分层、缓存逐出的键。结构简单、零额外记账，但把打分权让给了被打分者。

* **原型乙・行为背书（治理形态）**：写入方仍可自报，但**影响「是否被采纳 / 长期保留 / 反思取材」的键改为系统可观测、写入方无法直接伪造的历史行为 —— 条目过去被检索命中并被实际采用的次数&#x20;**`uses`；自报值只作弱先验。

后续每个生命周期环节都对两原型做了实测对照（E6/E7/E9/E11/E19），结论高度一致：**在存在注水的世界里，原型乙以极小的召回代价，换取抗操纵性与库健康的数量级改善。**

## 第一轮・检索打分机制的内在缺陷（E1–E4）

### E1　importance 自报注水与零命中霸榜

**设计**：200 条合成记忆、20 个语义主题，golden 查询锚定主题、expected = 该主题质量最高的 3 条；逐步提高把 importance 刷满 10 的条目比例，用出厂参数评测（8 种子均值）。



| 注水比例 | recall@5 | MRR   | 零命中条目占 top5 |
| ---- | -------- | ----- | ----------- |
| 0.00 | 0.439    | 0.349 | 0.814       |
| 0.05 | 0.431    | 0.340 | 0.815       |
| 0.10 | 0.425    | 0.326 | 0.819       |
| 0.20 | 0.406    | 0.303 | 0.824       |
| 0.40 | 0.356    | 0.285 | 0.833       |

注水 20% 时四种治理开关：



| 方案                    | recall@5  | MRR   | 零命中占比 |
| --------------------- | --------- | ----- | ----- |
| 出厂（全不防）               | 0.406     | 0.303 | 0.824 |
| 仅 filter\_zero        | **0.925** | 0.661 | 0.000 |
| 仅 w\_imp=0            | 0.389     | 0.319 | 0.770 |
| filter\_zero+w\_imp=0 | 0.914     | 0.598 | 0.000 |

**结论**：即使**零注水**，出厂配置 top5 里也有 81% 是一个查询词都没命中的条目（age 项把老的命中条目扣成负分所致，E2 展开）。注水只是雪上加霜。真正的根治开关是 **filter\_zero（零词命中不进候选）**，单独开启就把 recall 从 0.406 拉到 0.925；而单纯把 importance 权重清零（w\_imp=0）几乎无效（0.389）—— 因为只要零命中条目仍在候选池，age 项照样把它们顶上来。**治理要先关「进入候选」的门，再谈调权重。**

### E2　线性年龄惩罚错配，与检索老化曲线（本轮最反直觉）

**设计**：把 golden 目标按年龄分「经典（age>250 天）」「新知（age≤150 天）」，比较四种年龄项；再扫库龄 30/90/180/365 天时三种配置的总 recall。



| 年龄项方案             | 经典知识召回    | 新知召回  |
| ----------------- | --------- | ----- |
| 出厂 linear 0.1 / 天 | **0.000** | 0.724 |
| linear 0.01 / 天   | 0.914     | 0.995 |
| 无年龄项              | 0.993     | 0.987 |
| 乘性 exp 半衰期 180 天  | 0.010     | 0.914 |



| 库龄 / 天 | 出厂        | filter\_zero | w\_age=0 |
| ------ | --------- | ------------ | -------- |
| 30     | 0.920     | 0.997        | 0.870    |
| 90     | 0.725     | 0.988        | 0.895    |
| 180    | 0.523     | 0.953        | 0.872    |
| 365    | **0.403** | 0.925        | 0.889    |

**结论（自我推翻 S1）**：我原以为 0.1 / 天是温和的新鲜度偏好。手算量纲即知其谬：关键词命中贡献是个位数（3× 命中数），而 0.1 / 天在一年后累计 −36.5 分，**碾压一切语义命中**。于是运行一年的记忆库，经典高价值条目召回归零（0.000），总 recall 从满月时的 0.920 单调塌到 0.403——**这不是外部攻击，是系统随时间自杀**，且比注水更致命。乘性衰减同样伤经典。记忆库的使命恰恰是长期保留高价值经验：年龄项要么降到 0.01 量级、要么只对「时效型条目」生效，绝不能做全局线性减分。注意 30 天时出厂（0.920）略高于 w\_age=0（0.870）——age 项**短期有益、长期反噬**，是典型的时间尺度陷阱。

### E3　links 一跳扩散与链接农场

**设计**：逐步增加互链农场簇（簇内全互链、零语义相关）；再扫扩散系数 d×filter\_zero 网格；并专门构造「词面互补真相关对」界定扩散何时有用。



| 农场规模   | recall@5  | 农场条目占 top5 |
| ------ | --------- | ---------- |
| 无      | 0.414     | 0.000      |
| 2 簇 ×5 | 0.348     | 0.353      |
| 4 簇 ×5 | 0.309     | 0.595      |
| 8 簇 ×5 | **0.145** | **0.916**  |



| d    | filter\_zero 关 | filter\_zero 开 |
| ---- | -------------- | -------------- |
| 0.0  | 0.367          | 0.913          |
| 0.25 | 0.348          | 0.913          |
| 0.5  | 0.309          | 0.913          |
| 1.0  | 0.123          | 0.913          |

扩散收益的边界（词面互补世界，40 随机干扰）：词面重叠世界 d=0/0.5 总召回都是 0.414（**零收益**）；当真相关别名条目刻意不含查询词、只靠 link 相连时，d=0 它进 top5 比例 0.275（中位排名 7），d=0.5 升到 0.750（中位 4）。

**结论（自我推翻 S2 + 设计返工 F1）**：我原以为一跳扩散是 HippoRAG 式优点。实测在「同主题共享词」的正常世界里它**零收益**（语义相关≈词面相关，相关条目自己就能命中）；它唯一的用处是捞回「词面缺失但真相关」的别名，可这恰恰需要 links 指向零命中目标 ——**而 links 也是条目自报、不校验语义，机制无法区分「被链的真别名」与「被链的农场」**。扩散系数 d 调大调小都救不了（d=1.0 反而更糟），filter\_zero 一开，无论 d 取何值都回到 0.913。结论：扩散必须在零命中过滤**之后**进行，且 links 来源需要行为背书，否则宁可不扩散。

### E4　中文无空格 split 退化



| 分词方式             | recall@5  | MRR   | precision@5 |
| ---------------- | --------- | ----- | ----------- |
| space（理想已分词）     | 0.398     | 0.307 | 0.093       |
| glued（真实无空格中文整句） | **0.173** | 0.101 | 0.036       |
| bigram（双字切分）     | **0.433** | 0.345 | 0.104       |

**结论**：真实代码 `for w in q.split()` 按空白切词，中文查询「记忆检索」是一个整 token，子串匹配几乎必败，recall 腰斩到 0.173。零依赖的双字 bigram 不仅救回，还略超理想空格分词（0.433，部分匹配更宽松、precision 同步略升）。这是静态报告 P2-18 的动态量化：**中文检索在补分词 /n-gram 之前，上层权重怎么调都是在残缺输入上做功。**

## 第二轮・反思与合成闭环（E5–E8）

### E5　反思触发节奏被自报 importance 控制

固定写 300 条，阈值 × 注水比例 → 触发次数 / 平均间隔条数 / 间隔变异系数：



| 阈值         | 诚实（次 / 均隔 / CV）         | 20% 注水               | 40% 注水               |
| ---------- | ----------------------- | -------------------- | -------------------- |
| 20         | 72.8 / 4.10 / 0.183     | 82.8 / 3.61 / 0.207  | 93.2 / 3.20 / 0.234  |
| **50（出厂）** | 31.0 / **9.55** / 0.119 | 35.6 / 8.34 / 0.136  | 40.4 / 7.39 / 0.136  |
| 100        | 15.7 / 18.57 / 0.080    | 18.1 / 16.15 / 0.103 | 20.5 / 14.26 / 0.098 |
| 200        | 7.8 / 36.80 / 0.057     | 9.0 / 31.83 / 0.071  | 10.2 / 28.03 / 0.067 |

**结论**：反思的「何时该停下来总结」完全由累加的**自报** importance 决定（它是触发的唯一输入）。注水把反思间隔从 9.55 条压到 7.39 条、触发次数抬升 30%—— 攻击者可以通过刷高 importance 让引擎更频繁地用被污染的素材做合成。阈值 50 自标「拍脑袋，待校准」，但**校准阈值解决不了被自报值控制的问题**：无论阈值高低，节奏的旋钮都在写入方手里。

### E6　反思取材：自报 importance vs 历史复用（本轮决定性）

反思取 importance 降序 top6，对比三种取材键（坏条目 = 注水 / 农场 / 失效）：



| 注水  | 取材策略            | 坏条目占比     | 素材平均真实质量 |
| --- | --------------- | --------- | -------- |
| 0.1 | 自报 imp          | **0.931** | 0.501    |
| 0.1 | 复用次数 uses       | 0.181     | 0.859    |
| 0.1 | 真实质量（oracle 上界） | 0.167     | 0.921    |
| 0.3 | 自报 imp          | **0.986** | 0.458    |
| 0.3 | 复用次数 uses       | 0.319     | 0.859    |
| 0.3 | 真实质量（oracle）    | 0.333     | 0.921    |

**结论**：只改取材键 —— 从「条目自报的 importance」换成「系统可观测、写入方伪造不了的历史被采用次数 uses」—— 坏素材率从 **93.1% 直降到 18.1%**，素材质量 0.501→0.859，几乎追平只有上帝视角能做到的 oracle（0.167/0.921）。这是「信任自报 vs 行为背书」两条原型最干净的一次对决：**uses 是写入方无法在写入瞬间伪造的信号（它需要在未来一次次被检索采用中积累），因此天然抗操纵。**

### E7　合成层的错误放大与错误覆盖面

**E7a**：向素材中注入 p\_bad 比例「错误但高自信」经验（低质量 / 失效却自报 10），做 120 次反思合成：

| ------ | -------------- | ------------- |
| 0.1    | **1.0 / 0.05** | 0.092 / 0.765 |
| 0.3    | 1.0 / 0.05     | 0.294 / 0.612 |
| 0.5    | 1.0 / 0.05     | 0.493 / 0.464 |

**E7b**（返工后，见 F2）：枚举一个主题 8 个词的全部 28 个两两组合查询，比较错误条目覆盖词面宽窄：



| 错误形态      | 覆盖词数 | 进 top5 覆盖面 | 占 top1 面  |
| --------- | ---- | ---------- | --------- |

**结论**：自报取材把底层 10% 的错误经验**富集到 100% 的合成污染（放大 10 倍）**—— 因为错误条目自报 10 分、必然占据 top6，「抽象」反而成了错误的浓缩器；复用取材下污染率≈底层错误率（0.092≈0.1），不放大。更危险的是 E7b：错误一旦被提炼成「概括全主题的高层规律」并以高 importance 入长期层，它能被 100% 的不同措辞查询召回（窄原始条目只有 78.6%）、97.3% 概率占据 top1。**错误的半衰期随抽象层级变长、纠错面随抽象层级变宽 —— 反思取材必须是全库最干净的入口。**

| 改动               | recall | 反思次数 | 取材坏率  | 仅情绪数值变 |
| ---------------- | ------ | ---- | ----- | ------ |
| 基线 0.7/0.5       | 0.975  | 23   | 0.833 | 0.120  |
| decay=0.1        | 0.975  | 23   | 0.833 | 0.0001 |

**结论（否定性）**：衰减公式本身算得对，但 grep 与 A/B 同时证明 ——**情绪四维只在 wrap-up 里自我衰减、写进 state、被测试断言，却没有任何检索 / 反思 / 分层逻辑读它**。一个被认真维护、看起来在「内省」的信号，对 agent 行为零影响。这不是 bug 而是「仪表空转」：要么把情绪接进某个真实决策（并过 E16 准入），要么按公理 G 标注为未实现，不能让它以「L9 内省仿生」的名义给人系统在感知的错觉。

### E10　下游出仓救不了上游错标（否定性结果）

| --- | ------ | ----- | ----- | ----- |

| 0.0 | 动态出仓   | 0.008 | 0.034 | 0.972 |
| 0.1 | 固定 TTL | 0.039 | 0.039 | 0.942 |
| 0.1 | 动态出仓   | 0.045 | 0.037 | 0.934 |
| 0.3 | 固定 TTL | 0.114 | 0.039 | 0.868 |
| 0.3 | 动态出仓   | 0.119 | 0.037 | 0.861 |

**结论（否定性，自我推翻 S6 + 返工 F3）**：我原期望一个综合「零复用 + 很老 + 低质量」的智能动态出仓能显著救回被漏标的失效条目。实测漏放只从 0.039 降到 0.037（几乎不动），误杀反而升。原因是本质性的：**出仓判据越想多捞失效，就越会误杀只是「暂时没被复用」的真知识 —— 它只能在「误杀 — 漏放」的 Pareto 前沿上滑动，无法整体外移。** 错标发生在写入瞬间，下游没有额外信息能还原真相。治理红线：**准入质量不可由下游出仓补偿，t\_invalid 的判定质量才是杠杆点。** 另外注意无错标时仍有 3.4% 漏放 —— 真失效但根本没被标 t\_invalid 的条目，固定 TTL 结构上永远管不到。

| 0.2 | **LRU**              | **1.779** | 0.194     | 0.191     |
| 0.2 | 重要度 × 时效（自报）         | 1.021     | **0.307** | **0.296** |
| 0.2 | oracle               | 1.878     | 0.037     | 0.197     |

**结论（自我推翻 S4 + 返工 F8）**：`index_hot_budget=200` 在真实代码里是死参数，其注释声称用「重要度 × 时效」逐出。我据此实现原型后实测：用**自报 importance** 做逐出键，注水条目因恒报 10 而被保护（留下 0.296 垃圾，全场最高），还误逐了最多高质量条目（0.307），相对召回仅 1.02；改用**真实复用的 LRU**，相对召回 1.78、逼近 oracle 上界 1.88。相对召回 >1 不是 bug（F8）：合理逐出移除了挤占 top5 的低价值条目，产生去噪副作用。**「热」必须用真实访问频率定义，不能用条目自称的重要度定义。**

| 500   | 0.974  | 0.0031   | 23    |
| 1000  | 1.514  | 0.0035   | 48    |

## 第四轮・自演化闭环（E13–E16，核心）

### E13　法层参数自演化：收敛、泛化、自发现结构（可行性主证据）

从出厂参数爬山演化（变异→在 train-golden 评测→提升则接受），6 种子：



* **(a) 只演化连续权重、锁死 filter\_zero=False**：train 0.388→0.90，**holdout 0.886**；最终参数均值 w\_kw=3.502 /w\_c=1.397 /w\_imp=0.932 / **w\_age=0.018** /d=0.304—— 演化自主把 w\_age 从 0.1 压到 0.018（独立复现了 E2 的结论）。

* **(b) 允许变异离散开关 filter\_zero**：train 0.997、**holdout 0.992**，**5/6 个种子自行把 filter\_zero 翻成 True**。

* **(c) 从劣化起点（w\_imp=3、w\_age=0.3、不过滤）出发**：holdout 0.289→**0.967**。

**结论**：在写入侧不适应、golden 冻结的静态世界，**自演化确实可行**：留出集与训练集同步提升（真泛化而非过拟合，E17 再验）、能跨连续 / 离散参数发现我靠整轮分析才找到的 filter\_zero 结构、还能从被调坏的劣化状态自愈。这给命题以肯定回答 —— 但 E14–E18 立刻给出这个「可行」的全部前提。

### E14　写入侧 — 检索器对抗共演化（本轮最不安的结果）

初始 5% 注水，之后写入侧每 5 代观察当前打分函数：还看重 importance 就刷满、扩散开着就织互链簇。三种条件 40 代：



| 条件            | 初始 holdout | 第 20 代 | 第 40 代    | 末态库污染     |
| ------------- | ---------- | ------ | --------- | --------- |
| ①固定出厂不演化      | 0.436      | 0.386  | **0.350** | 0.480     |
| ②自由共演化（无元层）   | 0.436      | 0.956  | **0.956** | **0.448** |
| ③共演化 + 元层锁安全键 | 0.436      | 0.919  | **0.919** | **0.153** |

**结论（自我推翻 S7）**：我原以为持续攻防会让自由演化的指标振荡下跌。实测更微妙、也更不安：



* ①不演化，检索在持续攻击下缓慢恶化到 0.350、库污染 48%；

* ②自由演化能把**可见指标**稳定救到 0.956，但**库实质仍以 44.8% 污染持续腐化**—— 因为固定 holdout 的正确答案是那些高质量老条目，检索器学会忽略垃圾即可命中，指标好看与库变脏并行不悖；

* ③元层把 filter\_zero=True、w\_imp=0 锁成引擎改不动的安全键，只以 0.956→0.919 的微小指标代价，把末态污染压到 **0.153**。机理是**改变了攻击者激励**：当自报 importance 不再影响排序（w\_imp=0）、扩散被零命中过滤截断，写入侧「刷分无利可图」，理性地减少攻击。

**最深的教训：失败模式不是「指标崩」，而是「指标与库健康脱钩」。** 只监控检索 recall 的系统，会在库烂掉一半时显示一切优秀。元层锁安全键的价值不在更高分，而在让攻防均衡向低污染移动。

### E15　eval 门限棘轮：门是怎么一步步死掉的

真实能力在第 8/20/30 代三次 −0.15 劣化，叠加评测抽样噪声（σ=0.03），20 种子跑 40 代：



| 基线规则           | 40 代后基线   | 过程最低  |
| -------------- | --------- | ----- |
| 棘轮（真实代码：劣化也回写） | **0.348** | 0.296 |
| 只升不降签收线（修复）    | **0.844** | 0.811 |

**结论**：这是静态 P0-4 的动态量化。门控判据「本次 ≥ 基线 ×0.95」看似严格，但三次真实劣化把基线从 0.80 一路拉到 0.348，此后再差的结果都能「相对基线不再跌 5%」过门 ——**门限被自己的测量结果逐步拆除，最终形同虚设。** 修复极简：基线是「历史最佳签收线」，只升不降（劣化结果另写 last\_run），40 代后仍守在 0.844。自演化的门必须由「最好成绩」而非「上一次成绩」定义。

### E16　公理 G 准入：一个参数得先「改得动行为」才配进自演化空间

行为指纹 =（recall, 反思次数，取材坏率，长期条数，出仓数）。基线指纹 (0.90, 24, 1.0, 77, 5)。



* 活参数：reflect\_threshold 50→20 反思次数 24→55、→200 变 6；filter\_zero 关→开 recall 0.388→0.90。**改动可观测，允许进入自演化搜索。**

* 死参数：broadcast\_weights、index\_hot\_budget、review\_intervals、emotion\_decay、情绪初值 —— 任意取值，**五项指纹与基线逐项完全相同**。

**结论（结构性）**：TUNABLES 里混着「真旋钮」和「装饰旋钮」。让一个改不动任何行为的死参数进入自演化搜索空间，优化器只会在它上面浪费变异、甚至产出「我已自适应调优广播权重」的虚假叙事（违反公理 G）。**可演化参数白名单必须先过 A/B 行为指纹测试：扰动它，行为分布不变即逐出搜索空间，要么实现它、要么标注未实现。**

## 第五轮・评测可信度、元层边界、综合治理（E17–E19）

### E17　golden 规模：不是过拟合、是评测噪声

**E17a** 在不同规模 train-golden 演化 25 代，对独立 200 题大留出集：



| train 题数 | train 终值 | 独立 holdout | 过拟合 gap |
| -------- | -------- | ---------- | ------- |
| 5        | 0.960    | 0.944      | 0.016   |
| 10       | 0.980    | 0.941      | 0.039   |
| 20       | 0.980    | 0.941      | 0.039   |
| 40       | 0.980    | 0.948      | 0.032   |
| 80       | 0.983    | 0.976      | 0.007   |

**E17b** 同一检索器、独立抽 m 题重复 100 次的评测噪声：



| 抽题数 m | recall 均值 | sd    | 95% 半宽 1.96sd | 真改进需超过    |
| ----- | --------- | ----- | ------------- | --------- |
| 10    | 0.933     | 0.081 | 0.159         | 0.163     |

| 80    | 0.937     | 0.030 | 0.059         | 0.060     |

**结论（否定性 + 修正，自我推翻 S5）**：我原以为小 golden 调参会严重过拟合。实测在本沙盒的**低维参数、平稳词袋世界**，过拟合 gap 只有 0.007–0.039，5 题也能找到正确方向 —— 过拟合偏差不是主要约束。真正的约束是**评测抽样噪声**：只抽 10 题时两次评测差 0.16 以内都可能是抛硬币，门控会把噪声当改进 / 劣化；到 40 题（恰是真实 TUNABLES `eval_n: d0.7=40` 的口径）半宽降到 0.084，即**一次自演化「提升」必须超过约 0.085 才配叫真改进**，否则需要配对 / 序贯或更多题。结论：法层门控的 margin 由评测噪声决定，不由主观愿望决定。

### E18　元层为什么必须冻结：让引擎改考题会怎样（决定性）

困难世界（30% 注水 + 4 农场，正路调参天花板有限），演化 40 代。(a) 只能调参、golden 冻结；(b) 每代变异参数后还可把「错题标准答案改成自己当前的 top1」，再决定是否接受；hidden 是引擎永远看不到也改不到的 100 题独立留出。



| 权力边界                | 训练题终值     | 隐藏题终值     | 诚信缺口      |
| ------------------- | --------- | --------- | --------- |
| (a) 法层可演化，golden 冻结 | 0.945     | 0.920     | 0.025     |
| (b) 法层 + golden 都可改 | **1.000** | **0.872** | **0.128** |

**结论（三版返工 F6）**：当标准答案能被引擎自身的输出重写时，它每代都能把错题改成「我恰好输出的那个」，训练分迅速刷到满分 1.000；但此时参数变异无论朝哪走都「提分」（因为改题兜底），**参数失去外部梯度、进入随机漂移**，隐藏题暴露真实能力反而劣化到 0.872（比老实调参的 0.920 更低），诚信缺口是 (a) 的 5 倍。这正是 DGM（arXiv:2505.22954，bootstrap REGISTRY A21）Appendix F Node114「删检测标记刷分」在记忆库的同构：**评测题、铁律、验收判据必须对变异引擎只读 / 不可见、冻结在元层，引擎只收到 pass/fail，永远拿不到也改不了标准答案。**

### E19　三治理水平综合压力测试（收官）

复合恶劣世界（20% 注水 + 4 链接农场 + 20% 错标 + 仅 20 题 golden），40 代攻防：



| 治理水平                              | holdout   | 库污染率      | 长期层纯度     | 反思取材坏率    |
| --------------------------------- | --------- | --------- | --------- | --------- |
| L0 无治理（出厂固定 / 零命中不过滤 / 自报取材 / 单门） | **0.172** | 0.637     | 0.492     | 1.000     |
| L1 部分（+filter\_zero + 允许演化）       | **0.876** | 0.609     | 0.492     | 1.000     |
| L2 全治理（+ 元层锁安全键 + uses 取材 / 双门分层） | **0.852** | **0.337** | **0.761** | **0.367** |

**结论**：L0 在复合攻击下检索近乎不可用（0.172）、库近 2/3 腐化、反思素材全是垃圾。L1 靠 filter\_zero + 自演化把**检索指标**救到 0.876，但库污染（0.609）、长期层纯度（0.492）、反思取材坏率（1.000）**纹丝不动**—— 只在检索末端设防，治标不治本，污染仍沿分层与反思上行。L2 把「安全键锁入元层 + 全生命周期决策键换成 uses」补齐后，holdout 仅微降（0.876→0.852），却换来污染 0.609→0.337、长期层纯度 0.492→0.761、取材坏率 1.000→0.367 的全面改善。**治理是成体系的：单点修指标不改善系统健康，只有把「信号换轨 + 尺子冻结 + 基线单向」贯穿写入 — 检索 — 反思 — 分层 — 出仓全链路，自演化才既聪明又干净。**

## 方向 A・反向压力测试：uses 到底有多可靠（E20/E21/E24b）

### E20　行为信号在稀疏反馈与流行度噪声下的鲁棒性

真实系统里 uses 不是即时、全覆盖的：很多条目没机会被采用（反馈缺失），还夹杂与质量无关的流行度偶然。人为退化观测 uses（cover = 能收到反馈的条目比例；pop = 叠加无关流行噪声强度）：



| 反馈覆盖 cover | 自报 imp 坏率 / 质量 | 观测 uses 坏率 / 质量   |
| ---------- | -------------- | ----------------- |
| 1.00       | 0.979 / 0.483  | 0.125 / 0.856     |
| 0.50       | 0.979 / 0.483  | 0.250 / 0.838     |
| 0.25       | 0.979 / 0.483  | 0.125 / 0.797     |
| 0.10       | 0.979 / 0.483  | **0.146 / 0.729** |

全覆盖下叠加流行度噪声 pop=0/0.25/0.5/1.0，uses 坏率 0.125/0.188/0.167/0.188、质量 0.856→0.782。

**结论（反向测试未推翻、反而强化）**：我本以为 uses 一旦稀疏就会退化到接近自报。实测即使**只有 10% 条目能收到任何反馈**、或叠加与质量完全无关的满强度流行噪声，uses 取材坏率仍稳定在 0.15–0.19（自报恒为 0.979）。原因是排序只需要「相对次序」：注水条目 uses 系统性为 0，而真质量条目只要收到一点点反馈就能排到前面 ——**行为信号是序数信号，对覆盖率和加性噪声天然鲁棒。** 质量随覆盖下降（0.856→0.729）是真实代价，但抗操纵性不塌。

### E21　自报 + 行为融合：需要掺一点自报做冷启动吗（否定性）

一个合理的担忧：纯 uses 会不会把「还没机会被用的好新条目」埋没？于是测融合键 `α·归一化imp+(1-α)·归一化uses`，α 越大越信自报：



| α（自报占比）      | 坏率        | 素材质量  | 高质量条目覆盖率  |
| ------------ | --------- | ----- | --------- |
| 0.00（纯 uses） | **0.167** | 0.819 | **0.917** |
| 0.25         | 0.208     | 0.819 | 0.917     |
| 0.50         | 0.354     | 0.822 | 0.833     |
| 0.75         | 0.646     | 0.790 | 0.688     |
| 1.00（纯自报）    | 0.979     | 0.483 | 0.146     |

（稀疏反馈 cover=0.3；cover=1.0 时趋势相同，纯 uses 坏率 0.125、高质量覆盖 1.000。）

**结论（否定性，自我推翻 S8）**：我原猜想「冷启动需要一点自报先验」，最优 α 会在中间。实测坏率随 α **单调上升**、高质量覆盖率随 α 单调下降，最优点在端点 α=0。**掺自报不仅没救冷启动，反而线性地重新引入注水；冷启动的正确解法是给新条目一个低权重的探索期 / 显式曝光，而不是把自报 importance 混进决策键。**

### E24b　uses 的信任根：它一旦可被伪造会怎样（本轮决定性）

E20 证明 uses 抗「缺失 / 噪声」，但它抗「伪造」吗？让攻击者把自己条目的 uses 也刷满（自导自演假「采用」）：



| 取材方式      | 坏率        | 质量    |
| --------- | --------- | ----- |
| 自报 imp    | 0.979     | 0.483 |
| 诚实 uses   | **0.125** | 0.856 |
| 伪造 uses 后 | **1.000** | 0.480 |

**结论（决定性）**：uses 的全部抗操纵性来自一个时间属性 ——**写入瞬间它是 0、必须靠未来一次次真实采用累积，写入方伪造不了尚未发生的事**。一旦「采用记录」可以被写入方自导自演（自己触发自己的记忆被标记为「已采用」、或买来假采用），uses 立刻退化成**第二个 importance，甚至更差（坏率 1.000）**，因为它还披着「客观行为」的外衣更难被识别。这把 E6 的结论精确化为一条信任根：**采用必须由下游真实任务事件背书（对应铁律 2 证据准入 / 双平面投影），记忆模块不能自证其 uses。**

**结论（自我推翻 S9，三连实验才讲清）**：我原本预期「持续追逐新概念必然灾难性遗忘旧概念」。实测**遗忘不是时间漂移的必然结果，而是参数结构的性质**：bootstrap 式**加性独立权重**下，新旧世界的最优解可以同时满足（E22b 追新时守旧反而同升），一次调对的参数对主题轮换天然鲁棒，盲目高频重演化几乎无收益（E22 B 仅 0.934→0.956）；只有当旋钮是**零和 / 竞争型**（固定预算在两种匹配方式间分配，E22c），为新世界选 β 才会牺牲旧世界（β→1 时 A 崩到 0）。**工程含义：尽量把法层设计成可叠加的独立维度，避免引入「此消彼长」的归一化预算旋钮；一旦引入，就必须为旧世界保留不参与在线更新的锚定评测。**

### E26　递归反思：抽象层会逐级失真吗

让每代合成结论优先回流、主导下一代取材，递归 5 代（质量 / 污染）：



| 取材      | 代 1           | 代 3       | 代 5           |

**结论（含否定性细节）**：我原想看到「传话游戏」式的污染逐级爆炸。实测**抽象层不会凭空制造新错误**（污染不随代数增长，反而因聚合被稀释到 0）；它真正做的是**把入口的质量偏差锁定、沿层固化**—— 自报取材陷入「低质素材→低质规律→低质规律主导下一轮」的**低质锁死**（质量稳定在 0.45 上不去），uses 取材则形成「高质→更高质」的**良性上行**（0.856→0.872）。**反思层不是错误的放大器（那是 E7 一次性取材的事），而是入口质量的棘轮：入口干净则越抽象越干净，入口脏则被永久固化为高层偏见，且高层规律更难被质疑。**

### E27　取材宽度与重复合成膨胀

**结论**：自报取材下取多取少都坏（top3 全是注水，坏率 1.0）；放宽取材只稀释主题聚焦度（集中度 0.333→0.119），不改善坏率。更重要的是 E27b 的否定性结果：**没有新条目流入时，反复反思不产生新信息，只会重复提炼同一件事 —— 反思必须由「增量内容」触发，而不能定时 / 按固定条数空转**（对应 E5 阈值不应只由自报累加驱动）。

## 方向 F・缓存工作集与近重复（E30/E31）

### E30　工作集时代切换：LFU 为何从最优变最差

访问服从 Zipf，工作集大小 60、缓存 50；对比随机 / LRU 近因 / LFU 频率 /hybrid（频率 × 近因衰减）：



| 工作集变化     | random | LRU       | LFU       | hybrid |
| --------- | ------ | --------- | --------- | ------ |
| 恒定        | 0.886  | 0.912     | **0.914** | 0.914  |
| 慢换（T=500） | 0.798  | **0.864** | 0.654     | 0.824  |
| 快换（T=120） | 0.616  | **0.659** | **0.545** | 0.654  |

**结论**：工作集恒定时，累积频率是最佳预测，LFU 最优；一旦工作集整体切换（用户进入新阶段、换项目），**LFU 死抱住上一时代的高频条目、把它们永久留在缓存里，快换时命中率崩到 0.545（全场最差）**；近因策略 LRU/hybrid 快速换血反超。这把 E11 的「热度用真实访问定义」再推一层：**「热」不仅要真实、还要会遗忘过时的热 —— 纯累积频率在非平稳访问下是负债，近因 × 频率的混合分才稳健。** 对应到记忆库：长期层 / 热缓存不能只按累计 uses 排序，要给 uses 加时间衰减或定期重估。

| 0.15  | 345   | 290.4 | 51.6  | 0.00 | 4.38 → 5.00     |

## 方向 G・自食闭环：系统如何自己把自己喂傻（E32/E33）

## 方向 H・反馈环的社会病：马太与回声室（E34/E35）

### E34　uses 的另一面：优先连接滚成记忆寡头

第六轮把 uses 立为可信排序键（E20/E24b），本轮专门找它的副作用。模拟"被检索→uses+1→更易被检索"的优先连接 3000 次，访问概率 ∝(uses+1)^α。

| 条件 | uses 基尼 | top10% 占采用份额 | 被用过条目比例（聚合多样性） |
| -- | -- | -- | -- |
| 均匀 α=0（对照） | .175 | .158 | 1.000 |
| 亚线性 α=.5 | .283 | .196 | .989 |
| 纯优先连接 α=1 | **.503** | **.319** | **.912** |
| α=1 + 15% 随机探索 | .423 | .283 | .973 |

**结论**：uses 抗注水，但在闭环里会经优先连接滚成寡头——基尼升到 .50、一成条目吃掉三成采用、近一成记忆再也不被检索（长尾窒息，对应推荐系统反馈环的 aggregate diversity 下降）。15% 的随机探索把覆盖拉回 .97。**行为信号可信 ≠ 行为信号应独占检索，排序必须叠加探索/多样性正则。**

### E35　回声室：55:45 的轻微初始偏向如何被锁成极端

两阵营 A:B=11:9 起步，被检索概率 ∝ 占比^γ（γ=2 模拟排序的马太强化），被检索方写回一条新记忆（Pólya urn 的非线性版），跑 2000 步、200 局。

| 策略 | A 终占比均值 | 标准差 | 锁到极端(>.8/<.2)的局占比 |
| -- | -- | -- | -- |
| 纯正反馈 γ=2 | .782 | .364 | **.980** |
| 20% 配额补弱 | .504 | .021 | **.000** |

**结论**：正反馈随机过程方差发散，98% 的局锁定到单一阵营，且锁定方向由早期微小涨落决定；给弱势方保留 20% 配额后零局锁死、占比稳在 .50。**闭环不会"自然趋于均衡"，只会放大初始偏差；多样性必须靠显式配额/探索机制从外部注入。**

| 4 | .80 / .80 / .792 | .80 / 0 / 0 |
| 8 | 1.0 / 1.0 / .907 | **1.0 / 0 / 0** |

**结论（两层）**：闸门关时，高 imp 毒丸零命中也无差别霸榜，目标与误伤同值，随机注水靠刷 imp 同样得逞——此时攻击没有"精准"可言；**闸门一开，随机注水与跨主题误伤全部归零，却挡不住精准注册目标词面的毒丸（目标主题仍 100%）**。filter_zero 把攻击从"无差别"逼成"精准"，但精准词面攻击恰是它的盲区，**最小致命剂量仅 1–2 条**（对应 MINJA 的 query-only 低剂量注入）。

### E37　词表劫持：不刷分，只占词

更隐蔽的攻击：importance 诚实填 5（不刷分），只把一个主题的全部专属词注册进自己 keywords。

- 劫持条占目标主题 **top1 = .875、进 top5 = 1.0**；而一条普通条目凭先验占 top1 的概率仅 **.062**（14 倍杠杆）。

**结论**：filter_zero 只滤零命中，而劫持条词命中最高、反而最不可能被滤。**攻击者不需要碰任何"可信度字段"，只要在词面维度占满一个语义主题的专属词，就能截胡该主题**——这是 E24 关键词堆砌的单条、不刷分版本，证明风险根植于词面排序本身。

### E38　潜伏记忆的不可能三角（本轮最精巧的否定性结果）

理想的 sleeper 要同时满足：① 平时对常规查询隐身；② 命中特定触发词时激活霸榜；③ 自身词面干净、躲过 E25 那类词面审计。对比三条实现路径：

| 方案 | 常规期命中率（隐身↓好） | 触发期命中率（激活↑好） | 词面审计可抓 |
| -- | -- | -- | -- |
| 显式型（触发词进自己 keywords）+ 闸门开 | 0.0 | **1.0** | **1（必抓）** |
| 图潜伏（词面干净、靠 links 桥接）+ 闸门开 | 0.0 | **0.0（废）** | 0 |
| 图潜伏 + 闸门关（出厂） | **.351（暴露）** | .701 | 0 |

**结论（第五个不可能三角）**：三性不可兼得。显式型能"隐身+100% 激活"，但触发词写在自己词面、必被词面审计抓到；把恶意藏进 links 关系虽然躲过审计，可源码的扩散分**只对"自身零命中"的目标传播**——开 filter_zero 恰好把零命中目标整条删掉，桥接通道被结构性掐灭（激活 0）；关掉闸门能激活（.70）却同步在常规查询暴露（.35），退化为无差别污染。**这反过来给了一条好消息：filter_zero 不只是质量闸门，它还是反潜伏的结构性屏障；要查图潜伏攻击，检测对象必须是 links 图结构（异常入度/桥接簇），而非词条面。**

## 方向 J・多智能体：共享记忆的传染、阈值与公地（E39/E40/E41）

### E39　一个被攻破的 agent 如何经"正常协作"传染全体

N=10 个 agent 共享一个记忆层，f 个初始被攻破；诚实 agent 一旦检索到恶意记忆，以 .6 概率把"被污染的产出"写回共享池（可二次传染，SIR 式）。

| 坏 agent | 无防护共享：终污染占比 / 被感染诚实 agent | 带源可追溯隔离：终污染 / 二次感染 |
| -- | -- | -- |
| 1/10 | .874 / **9 / 9 全感染** | .10 / **0 / 9** |
| 2/10 | .893 / 8 / 8 | .20 / 0 / 8 |
| 3/10 | .906 / 7 / 7 | .30 / 0 / 7 |

**结论**：无防护共享池里，恶意记忆经"检索→产出→再写回"滚到近 90%，**只需 1 个内鬼就能在 15 轮内感染全部 9 个诚实 agent**（对应 cross-agent contamination / shadow agent）。而给每条记忆打上来源、一旦某源出坏记忆就屏蔽该源全部，污染被钉死在初始比例、零二次传染。**多 agent 共享记忆必须带来源签名与按源隔离，"协作便利"不能以"全域信任"为代价。**

### E40　拜占庭阈值：多少坏 agent 能掀桌

10 个 agent 对候选记忆打分，f 个拜占庭给恶意条满分、好条压零；比较 mean / trimmed（去 f 高 f 低）/ median 三种聚合，看 top5 里混进几条恶意。

| f/10 | mean | trimmed | median |
| -- | -- | -- | -- |
| 0–3 | 0 | 0 | 0 |
| 4 | **1.25** | 0 | 0 |
| 5 | **5（全崩）** | **5** | **5** |

**结论**：本场景线性 mean 容忍到 f=3（30%），f=4 开始漏恶意、f=5 全崩；trimmed/median 一直守到 f=4，直到坏者占一半（f=5）才同时崩——与拜占庭理论"严格少于一半"的上界吻合。**跨 agent 汇总记忆/投票禁用裸 mean，用 trimmed-mean 或中位数，可把掀桌阈值从约三成推到接近五成；但五成是数学上界，超过则无算法可救。**

### E41　共享热预算的公地悲剧

A 个 agent 共享容量 80 的热缓存，工作集 70% 互不重叠，模拟 3000 次访问。

| agent 数 | 全局 LFU 命中 | 全局 LRU | 按源配额隔离 | 各 agent 命中 sd（LFU / 配额） |
| -- | -- | -- | -- | -- |
| 2 | .913 | .906 | .907 | .004 / .005 |
| 5 | .753 | .708 | .699 | .021 / .018 |
| 10 | .615 | .540 | .531 | .044 / .034 |
| 20 | **.496** | .392 | .387 | **.073 / .050** |

**结论**：agent 越多、工作集越不重叠，无协调的 LFU 公地被各 agent 的私货互相挤占，命中率与公平度双降（.913→.496，公平 sd 翻 18 倍）。这是 E30"工作集切换惩罚"的多 agent 版本：**共享缓存必须按来源配额/分区，否则每个 agent 的局部最优汇成全局次优。**

## 方向 K・评测自欺与资源攻击（E42/E43）

### E42　评测泄漏进记忆：背题如何冒充进步

把 golden 考题连同答案作为"交互记忆"写回（泄漏比例 l），评测时检索到自己的考题副本即算答对；另用一份独立隐藏题对照，并测试"评测写入打标、评测时屏蔽"。

| 泄漏 l | 被污染自测 | 独立隐藏题 | 屏蔽评测记忆后 |
| -- | -- | -- | -- |
| 0 | .388 | .392 | .388 |
| .10 | **.239** | .181 | .388 |
| .25 | .367 | .177 | .388 |
| .50 | .586 | .175 | .388 |
| 1.0 | **.998** | .144 | .388 |

**结论（含非单调细节）**：泄漏副本先挤占未泄漏题的排名，所以低比例（.1）时自测不升反降到 .24；过半后转为净虚高，全泄漏时自测近满分 .998，而独立隐藏题始终原地踏步（.14–.18）。**评测期的一切写入必须打标、评测时屏蔽（guard 列恒等于无泄漏基线 .388），否则"进步"只是背题。** 与 E18（主动改考题）、E29（被动脏标注）共同封死"尺子被污染"的三条路径。

### E43　单条记忆的算法复杂度 DoS（含一个反直觉发现）

正常库（300 条、每条 links≤1、keywords≤4）单次检索基线约 0.6–0.7ms，构造无界字段攻击：

| 攻击构造 | 单次 rank | 相对放大 |
| -- | -- | -- |
| 30 条 links=500 | .92–1.0ms | 1.4–1.5x |
| 全库 links=500 | 约 14–17ms | **约 22–29x** |
| 30 条 keywords=2000 | .72–.74ms | 1.0–1.2x |
| 全库 keywords=1000 | .59–.69ms | 0.8–1.1x |
| 全库 links500+kw1000 | 13.4ms | 18–21x |

**结论（反直觉）**：keywords 超长几乎不花钱——Python 的子串搜索在 C 层，万词字段也只 1.1x；**真正的 DoS 面是 links 图遍历**：扩散是 Python 层对 Σlinks 的循环，全库 links=500 即把一次检索放大数十倍（多次运行约 22–29x，随机器负载波动、量级稳定），且攻击面是"多少条带无界字段"而非单条。写入侧必须设硬上限，**重点限单条 links 度数（建议 ≤32）而非 keywords 长度**。

# 第四部分・实验设计失败与自我推翻（诚实记录）

## 十六次设计返工



1. **F1（E3c）**：初版假设 links 扩散有正常收益，结果在词面重叠世界 d=0/0.5 都是 0.414、零差异，一度以为代码写错。补造「词面互补真相关对」后才界定：扩散只在「真相关条目词面缺失」时有用（0.275→0.750），而该前提与农场攻击入口完全重合。

2. **F2（E7b）**：初版用「同主题查询 top1 占比」测错误持久化，窄词条 / 广词条都饱和在 0.917，区分不出。改为枚举主题词全部 28 个两两组合、测「查询覆盖面」后，才得到 0.786 vs 1.000。

3. **F3（E10）**：初版期望动态出仓显著降低漏放，连续调了三版判据（放宽 / 收紧），漏放最多降 0.002 且误杀必升。最终承认这是否定性结果，转为「下游只沿误杀 — 漏放前沿滑动」的结论。

4. **F4（E14）**：第一版在演化循环外「重放攻击」来估污染，导致三条件污染被算成相同值。重构为在单次运行内部同时返回 holdout 轨迹与真实末态污染，对比才成立。

5. **F5（E17a）**：初版奔着「小 golden 严重过拟合」设计，gap 却只有 0.01–0.04。没有硬凑出预期，而是把过拟合列为否定性结果，转而用 E17b 证明真正的约束是评测噪声。

6. **F6（E18，三版）**：第一版每代「调参 / 改题二选一」，结果 (b) 调参不足反而更低；第二版「择优」但词袋世界检索器本就 0.95、作弊空间太小；第三版改用困难世界 + 「改题兜底导致参数失梯度随机漂移」的正确动力学，才得到训练 1.000 / 隐藏 0.872。

7. **F7（世界模型自检）**：D1 探针里 importance=999 直接产生 996.5 的分数，反向确认了「validate 不校验范围」正是一切注水的代码级根因 —— 这不是实验失败，但是在写探针时才确认「无界自报」必须作为世界模型的一等事实。

8. **F8（E11）**：逐出后「相对召回」出现 1.6–1.8（>1），初看像分母算错。逐项核对后确认是「逐出低价值条目减少 top5 竞争」的真实去噪副作用，保留数值并把指标正名为「相对全库的召回比」。

9. **F9（E22，两版）**：第一版滚动演化误用旧世界训练集，导致「一次演化」与「滚动演化」结果完全相同；修正训练流后又发现加性权重下新旧正和、根本不遗忘，于是补 E22b（仍正和）再补 E22c（零和旋钮），用三连实验才界定「灾难性遗忘的成立条件是参数层真实冲突」。

10. **F10（E24/E24b 拆分）**：第一版把「伪造 uses」混在检索 top5 重排里测，结果被前置的 filter\_zero 挡掉、看不到行为信号被击穿；拆出 E24b 放到「取材」场景（伪造 uses 直接决定 top6），才得到 0.125→1.000 的决定性对比。

11. **F11（E26，两版）**：第一版合成条目挤不进下一轮 top6，五代结果恒定、看不到递归；第二版让历史合成物优先回流并逐层累积，才呈现「低质锁死 vs 良性上行」，同时诚实记录「污染并未逐级爆炸」这一与预期不同的细节。

12. **F12（E30，两版 + 可复现修复）**：第一版热点只轮转 2 名、简化 ARC 等同 LRU，LFU 始终最优、测不出时代切换；改为「不重叠工作集整体切换」后 LFU 才从最优崩到最差。期间还查出跨进程两次运行有 ±0.002 非一致，根因是字符串 `hash()` 随机化与集合并列裁决，改为确定性种子与字典序 tiebreak 后逐行一致。

13. **F13（E32，两版）**：第一版「累积」只是不删旧数据，结果取材池仍被高 uses 自产垄断、活跃主题照样收敛；对照论文（Gerstgrasser 2024）后改为「每代持续补入新鲜真实记忆」，全库主题与取材方差才保住，并据此补出 S12——光囤旧数据不等于阻断自食。

14. **F14（E38，三版，最终转为否定性结论）**：第一版用单条 links 桥接，扩散分不足以进 top5；第二版让受害主题全部条目桥接并刷新年龄，结果触发成功（1.0）却在常规查询同步暴露（.99）。逐版调试才发现根因：源码扩散只对「自身零命中」目标加分，而 filter\_zero 恰好删掉零命中目标——开闸门桥接通道被结构性掐灭（激活 0），关闸门能激活却全局暴露。最终放弃「造出理想 sleeper」，改写成「躲审计×隐身×触发」三性不可兼得的不可能三角。

15. **F15（E42，两版）**：第一版泄漏副本因 id 不在 expected 里，反而挤掉原始答案、使自测分不升反降；改为「检索到自己的考题副本即算背到答案」后才呈现 .388→.998 的虚高，同时诚实保留「低比例 .1 时副本先挤占未泄漏题、自测反降到 .24」这一非单调细节。

16. **F16（E43，两版）**：第一版只让单条记忆带超长 links/keywords，放大不足 2.5x；意识到攻击面是「多少条带无界字段」后改为全库构造，打出 22–25x；并意外发现 keywords 超长几乎零代价（C 层子串搜索）、真正昂贵的是 Python 层 links 图遍历，硬限的重点随之从字段长度改为 links 度数。

## 十三次自我推翻（直觉被自己的实验否定）



1. **S1（E2）**：以为 0.1 / 天是温和新鲜度偏好 → 实为一年期库检索崩塌的主因（经典召回 0.000、总 recall 0.920→0.403），比外部注水更致命。

2. **S2（E3）**：以为 links 一跳扩散是优点 → 正常世界零收益、只敞开农场攻击面，且无法与真别名区分。

3. **S3（E9）**：以为提高长期层阈值能挡注水 → 攻击者恒报上限，调阈值无效、只误伤，必须换用 uses 第二门。

4. **S4（E11）**：以为系统声称的「重要度 × 时效」逐出最优 → 它用自报值反而护住垃圾、误逐高质量，真实复用 LRU 才逼近 oracle。

5. **S5（E17）**：以为小 golden 调参会过拟合 → 低维平稳世界不过拟合，真约束是评测抽样噪声，门控 margin 应由噪声决定。

6. **S6（E10）**：以为智能出仓能补救错标 → 几乎无收益，准入质量不可由下游补偿。

7. **S7（E14）**：以为攻防共演化会让指标振荡下跌 → 指标能稳定在高位（0.956），真正的失败是「指标与库健康脱钩」，库在指标全绿时烂掉一半。

8. **S8（E21）**：以为冷启动该掺一点自报 importance 当先验 → 融合键越掺越差、最优在纯 uses 端点；冷启动要靠探索期曝光而非混自报。

9. **S9（E22 系列）**：以为持续追逐新概念必然灾难性遗忘 → 加性独立权重下新旧正和、不遗忘；遗忘只在零和竞争型旋钮下发生，是参数结构问题而非时间问题。

10. **S10（E26）**：以为递归反思会让错误像传话游戏一样逐级放大 → 抽象层不制造新错误，它只是把入口偏差沿层锁死；真正的错误放大发生在一次性取材（E7），而非递归深度。

11. **S11（E34）**：第六轮刚证明 uses 抗注水、抗稀疏、抗噪声，就以为它可以独占排序键 → 它在闭环里经优先连接滚成记忆寡头（基尼 .50、长尾窒息），行为信号可信不等于应独占检索，必须叠加探索/多样性正则。

12. **S12（E32）**：以为「不删旧数据、一直囤着」就能避开模型自噬 → 只囤旧的不够，高 uses 自产仍会垄断取材入口；必须每代持续注入新鲜真实数据，且在取材入口保留探索，才阻断坍缩。

13. **S13（E38）**：本想造出一个「平时隐身、触发激活、还躲过词面审计」的理想潜伏记忆来证明风险 → 三性不可兼得：藏进 links 能躲审计却被 filter\_zero 结构性掐灭，关闸门能激活却全局暴露；filter\_zero 同时是反潜伏屏障，查图攻击只能靠图结构检测。

## 5.2 自演化循环（写入 — 评测 — 晋升）



```
写入条目（自报字段仅作弱先验；uses 从 0 起由未来真实采用累积）

&#x20;  ↓
```

## 5.4 二十五条红线 + 第六轮增补十二条 + 第七轮增补十条

**元层与权力边界**



1. golden、铁律、安全开关（filter\_zero 等）属于元层，引擎只读不可改，只收 pass/fail（E18）

2. 引擎能改自己的参数，但永远不能改「评判参数好坏」的规则与数据（E18）

3. 标准答案禁止由引擎当前输出反填；训练分 = 1.0 而隐藏集不升，按作弊论处（E18）

4. 任何自动采纳必须可回滚、可在审计链还原（铁律 1/4）

5. 能力声明不得强于实际能力：改不动行为的参数不得宣称「自适应」（公理 G，E16）

**信号与自报字段**

6\. **自报字段（importance/links/t\_invalid）不得单独决定「是否被采纳 / 长期保留 / 反思取材 / 缓存保留」**（E1/E6/E9/E11）

7\. 排序、取材、分层、逐出的主键优先用系统可观测、写入时无法伪造的行为（uses / 真实采用）（E6/E11）

8\. 对抗自报操纵靠「换信号种类」，不靠「拧紧同一信号阈值」—— 恒报上限者不受阈值影响（E9）

9\. importance 写入前做 0..10 int 范围 / 类型校验，拒绝越界（D1）

10\. links 扩散只能作用于通过零命中过滤的候选，且须有来源可信度约束（E3）

**检索与评测门控**

11\. 零词命中条目不进候选（filter\_zero 默认开）—— 先关候选门，再谈调权重（E1）

12\. 禁止全局线性年龄减分；时效衰减只对时效型条目、且系数与语义分量纲匹配（E2）

13\. 中文检索必须先分词或 n-gram，否则上层调参无意义（E4）

14\. 基线是「历史最佳签收线」只升不降，劣化结果另存、绝回写为新基线（E15）

15\. 一次「提升」必须超过评测噪声 margin（n=40 时≈0.085），否则视为平局、需更多题或配对（E17b）

16\. golden 是被消耗的燃料，须轮换；对外结论以引擎不可见的隐藏集为准（E17/E18）

17\. 法层晋升须训练集与隐藏集**同向**提升，单集提升不采纳（E13/E14）

18\. 可演化参数先过行为指纹 A/B：扰动后行为不变即逐出搜索空间（E16）

**反思与抽象层**

19\. 反思取材是全库最干净入口：坏素材率必须显著低于行层，宁少勿滥（E6）

20\. 反思触发节奏不得由自报 importance 单独决定，需混入行为密度信号（E5）

21\. 高层合成规律入长期层前，须标注依据条目；错误高层规律的召回面更广，纠错优先级高于原始条目（E7）

**生命周期**

22\. 准入质量不可由下游出仓补偿；t\_invalid 判定质量是杠杆点，出仓只沿误杀 — 漏放前沿滑动（E10）

23\. 缓存「热度」用真实访问频率定义，不用自报重要度；热预算激活前先定逐出策略再定数值（E11）

24\. 约 500–1000 条以上启用倒排检索与增量 / 挂根 Merkle，避免每查询全扫、每写全量 O (N²)（E12）

**治理与可见性**

25\. 同时监控「指标健康」与「库健康（污染率 / 长期层纯度 / 取材坏率）」；二者脱钩即冻结自演化并报警 —— 失败往往发生在指标全绿时（E14/E19）

**第六轮增补（E20–E31）**

26\. **行为信号（uses）必须由下游真实任务事件写入，记忆模块不得自证「被采用」**；一旦采用记录可被写入方自导自演，行为背书退化为第二个自报字段（E24b）

27\. 行为信号是**序数**信号：反馈稀疏（覆盖低至 10%）、有加性流行度噪声都可容忍，但「可伪造」零容忍（E20/E24b）

28\. 不把自报 importance 混进行为决策键当「冷启动先验」（融合越掺越差）；冷启动靠低权重探索期显式曝光解决（E21）

29\. 法层优先设计成**可叠加的独立加性维度**，避免「此消彼长」的零和归一化旋钮；若必须引入，要为旧世界保留不参与在线更新的锚定评测（E22c）

30\. filter\_zero 在极小库配「滤空则回退不过滤」兜底；规模 ≥50 后无此问题（E23）

31\. 零命中过滤之外必须叠加**关键词异常度检测**，堵关键词堆砌盲区；结构检测用多特征组合、保持低误伤、只标记待审，不替代元层锁定（E24/E25）

32\. 「自报 - 行为背离」类检测特征，只在行为信号未被同步伪造时有效；检测层不得假设攻击者不碰 uses（E25/E24b）

33\. 搜索预算优先探索离散**结构开关**（如 filter\_zero），结构定型后再做连续精调，不要一开始把全部旋钮丢给优化器（E28）

34\. golden 清洁度是元层资产、独立抽检；当训练分异常低且怎么演化都上不去时，先查标注污染而非加参数（E29）

35\. 热度 /uses 要可遗忘过时的热：加时间衰减或定期重估，纯累计频率在工作集切换时是负债（LFU 从最优变最差）（E30）

36\. 反思由**增量内容**触发，不对静态库空转；高层规律入长期层必须可回溯到原始证据条目（E26/E27）

37\. 近重复用**高阈值**合并（宁漏并勿错并，错并不可逆），保留 uses 最高的副本，以守住检索证据多样性（E31）

**第七轮增补（E32–E43，破坏性边界）**

38\. 自演化记忆库必须有**外部真实数据的持续注入率**：替换式自食 10 代即使无攻击也会主题塌半、质量方差缩到 1/20（MAD）；只囤旧数据不够，新鲜真实数据要进得了取材入口（E32/S12）

39\. 必须保留一个**被评测对象无法回写的外部金尺**并定期对表：内部尺会在自食闭环里维持虚高、外部能力可同时崩到 .04（E33）

40\. 可信行为信号也**不得独占排序**：uses 优先连接会滚成记忆寡头（基尼 .50、长尾窒息），检索要叠加 ε-探索或多样性配额（E34/E35）

41\. 正反馈闭环（检索→写回→再检索）必须配**弱势配额/探索**，否则 55:45 的初始偏差 98% 会被锁成极端；闭环不会自发均衡（E35）

42\. filter\_zero 挡得住随机注水与跨主题误伤，**挡不住精准注册词面的毒丸（1–2 条即可霸占一个主题）**；准入侧要限单条目注册某主题专属词的比例（词表劫持检测）（E36/E37）

43\. 「躲词面审计 × 平时隐身 × 触发激活」三性不可兼得；filter\_zero 是反潜伏的结构性屏障，查图潜伏攻击要检测**异常 links 入度/桥接簇**而非词条面（E38）

44\. 多 agent 共享记忆必须**带来源签名 + 按源隔离/信誉屏蔽**：无防护时 1 个内鬼 15 轮可感染全体；一旦某源出坏记忆即屏蔽该源全部，可把污染钉死在初始比例（E39）

45\. 跨 agent 聚合记忆/投票**禁用裸 mean**（约三成坏者即漏毒），用 trimmed-mean/中位数可把容忍度推到「严格少于一半」；坏者过半是数学上界、无算法可救（E40）

46\. 共享热缓存/预算要**按来源配额分区**：agent 越多、工作集越不重叠，无协调 LFU 命中从 .91 崩到 .50 且公平度恶化（E41）

47\. 写入侧对**单条 links 度数设硬上限（建议 ≤32）**——复杂度 DoS 的真实面是 Python 层 links 图遍历（全库 links=500 放大约 25 倍量级），而非 keywords 长度（C 层子串搜索近乎免费）（E43）

# 第六部分・结论

## 6.1 关于记忆库自演化的可行性

**可行，但它不是「把权重调到最优」的优化问题，而是「把权力放对层」的治理问题。**

正面证据是实在的：静态世界里自演化用几十次评估，自动找到了我靠整轮机制分析才定位的 filter\_zero（5/6 种子），自主把 w\_age 从 0.1 压到正确的 0.018，留出集同步提升、还能从劣化状态自愈（E13）。这说明「变异 — 评测 — 门控」的自演化循环在记忆库场景确实能自我改进。

但全部前提可以归并为三条：



1. **决策信号可观测、不可自报伪造**（uses 行为背书，而非 importance/links 自填）。第六轮进一步钉死它的边界：uses 对反馈稀疏、流行度噪声极鲁棒（覆盖 10% 仍有效，E20），但**它的抗操纵性只来自「写入瞬间伪造不了未来的采用」—— 采用必须由下游真实任务事件背书，一旦记忆模块能自证 uses，立刻退化为第二个自报字段（E24b 坏率 0.125→1.000）**；

2. **评判尺子冻结在引擎碰不到的元层**（golden / 铁律 / 安全开关人侧签名，基线只升不降；尺子被动脏了也会把优化带偏，E29）；

3. **同时度量指标与库健康**（防止 E14 的「全绿中腐烂」），并承认没有单一闸门 ——filter\_zero 堵不住关键词堆砌、结构检测在行为信号被伪造时失效，治理必须纵深叠加（E24/E25）。

4. **持续注入新鲜外部数据、在取材入口保留探索、多 agent 记忆按源隔离**（第七轮）：无攻击时替换式自食也会在 10 代内主题塌半、质量方差缩到 1/20（E32），可信的 uses 若独占排序会滚成记忆寡头（E34）、正反馈会把轻微偏差锁成极端（E35）；一旦多个 agent 共享记忆，1 个内鬼即可经正常协作感染全体（E39）。自演化系统不是封闭自循环，它必须永远向真实世界与其他可信来源开放，并为这份开放做来源治理。

## 6.2 五个不可能三角



* **自报便利 × 抗操纵 × 排序权重**：一个字段若写入方可自由填写、又高权重参与决策，就必然被操纵；三者只能取其二。bootstrap 的解法是保留自报便利、把决策权重移给 uses。

* **检索新鲜度 × 经典留存 × 统一年龄项**：全局线性 age 惩罚必然用经典知识换新知（经典召回 0.000）；要兼得，必须让年龄项随条目时效类型分化，而不是一条公式管全库。

* **自主演化 × 评测自洽 × 元层可达**：引擎若能触及评测标准答案，训练满分与真实能力必然脱钩（E18）；自主性与「尺子归引擎所有」不可兼得，尺子必须在引擎之外。

* **行为可信 × 采用可自证 × 写入侧自主**（第六轮）：要让 uses 成为可信排序键，「采用」就不能由被排序的写入侧自己声明；记忆库若能自己给自己记「被采用」，行为信号与自报字段同流。采用的书写权必须在下游真实任务手里（E20/E24b）。

* **躲词面审计 × 平时隐身 × 触发即激活**（第七轮）：一条恶意记忆想同时做到词面干净（躲过关键词审计）、常规查询不可见、命中特定触发词才霸榜，三者不可兼得。把触发词写进词面能隐身+精准激活却必被词面审计抓；藏进 links 图能躲审计，可扩散只对零命中目标生效，开 filter\_zero 正好掐断、关 filter\_zero 则退化为全局暴露（E38）。推论：反潜伏要同时靠 filter\_zero 这道结构屏障和 links 图结构检测。

## 6.3 回到原点

这套实验最后回到了 bootstrap\_v3 自己写下的两条公理：



* **公理 G（可证伪）**：行为变更先 shadow，测不出差异即判表演。E16 把它从「态度」变成了「可执行的参数准入测试」—— 一个旋钮改不动行为，就不配被自演化、也不配被称为机制。

* **铁律 2（证据准入）/ 双平面（公理 D）**：条目必须指向真实事件、记忆只是 lifelog 的投影。E6/E11 给出的 uses，本质就是「这条记忆到底在多少个真实后续事件里被采用过」的**行为证据**—— 它让铁律 2 从「写入时挂一个事件 id」升级为「用一辈子的真实使用为记忆持续背书」。第六轮 E20/E24b 又补上它的成立条件：这份背书只能由下游真实事件书写、且只需相对次序正确（稀疏、噪声都不怕），唯独不能让记忆自证。第七轮 E32–E43 则从反面收口：**即便每个写入者都诚实，封闭自食、反馈环正反馈、共享记忆无来源治理，仍会让系统自我退化**——自演化的对侧永远站着真实世界的新鲜数据、被保护的探索概率与可追溯的来源。

> **自报不是证据，被反复采用才是；指标不是健康，隐藏集与库结构才是；自演化的尽头不是更聪明的参数，而是更克制的权力分层。**
