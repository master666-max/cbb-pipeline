## 一、操作化（NG 臂 seeds 1–24，真语义，同流键 "PL"，逐代记录 audit_U——只测不选）

- **L1**：早斜率符号 = sign(audit_U@G5 − audit_U@G0)；总收益符号 = sign(audit_U@G25 − audit_U@G0)。一致率 = 符号相等且均非零的 run 占**总收益非零** run 的比例。
  - 一致率 ≥0.80 → **SUPPORTED**（R5 阈值 0.80 沿用）；0.65–0.80 → PARTIAL；<0.65 → NOT SUPPORTED。
- **L2**：首采纳贡献占比 = (audit_U@首采纳后 − audit_U@G0) / (audit_U@终 − audit_U@G0)，仅计总收益 >0 且采纳 ≥1 次的 run。
  - 均值 >0.5 且过半 run >0.5 → SUPPORTED；均值 >0.5 但过半 ≤0.5 → PARTIAL；否则 NOT SUPPORTED。
- 指纹断言：逐种子 final_mainline ≡ x8-NG（s1–8）/ x9-ng（s9–24），不过即 INCONCLUSIVE。
