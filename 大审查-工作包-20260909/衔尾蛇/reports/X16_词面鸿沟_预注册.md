# X16 · 词面鸿沟剂量曲线（豆包 E60 真引擎版）—— 预注册（判据先冻结，执行前文档）

> 日期：2026-09-11 · 地盘：`衔尾蛇/` · 模板：F3 直测（无演化）+ X12 零碰撞世界
> 动机：F8 裁定"filter_zero 风险 = 独立查询专属"，但"独立程度"是连续变量，现有数据只有一个点（豆包 E60 的 p=1：.359→.145）。本实验在**真引擎检索语义**（vendor 快照）下画剂量曲线——真语义词面过滤只有衔尾蛇沙盒能测。

## 一、设计（执行前冻结）

- **世界**：X12 零填充命名世界（无标签碰撞、无语义词族——唯一变量=查询词面断裂）。评测集：24 种子 × 各 8 个 audit 任务。
- **词面断裂操作**：查询词逐一替换为**词表外token**（T→Y 前缀、K→X 前缀，如 "T05 K05"→"Y05 X05"；已验证 X/Y 不出现在任何条目的 content/keywords 中——信息经确定性映射保留，但检索通道不可见，即纯词面鸿沟）。
- **剂量**：p ∈ {0, 0.25, 0.5, 0.75, 1.0}，每种子把前 ⌊p×8⌋ 个 audit 任务（固定序）替换为鸿沟版，其余保持原查询。
- **参数**：真引擎出厂默认 `w_kw=3, w_content=1, w_imp=1.0, w_age=0.1` × filter_zero ∈ {0,1}。选出厂参数的原因：w_imp=1.0 + w_age=0.1 正是 filter_zero 否决事件里"importance 保底通道"的真实配置。
- 直测 recall@5（F3 模板），零演化。

## 二、判据（执行前冻结）

- **R1（清零开关）**：p=1 时 filter_zero=1 的鸿沟任务 recall = **0**（零命中条目全被跳过 → 结果集为空）。
- **R2（保底通道）**：p≥0.5 时 filter_zero=0 的鸿沟任务 recall > filter_zero=1（importance−age 保底排序存在且非零）。
- **R3（单调曲线）**：整体 recall 缺口（fz0 − fz1）随 p 单调非降。
- **判定**：R1∧R2 → **SUPPORTED（清零开关 + 保底通道在真引擎语义下复现，E60 获第二实现）**；R1∧R3 但 R2 失败 → PARTIAL；其余 → NOT SUPPORTED。
- 附加产出：缺口-剂量曲线表（W-8 独立查询风险定价的直接输入）。

## 三、已知简化

- 鸿沟 token 为确定性映射（一一对应），保留"金标可识别性"——只断词面通道，不断信息。真实同义词改写（语义近、词面断）留待扩展。
- 主题词与关键词同时替换（全鸿沟）；部分鸿沟（只换主题词）留扩展。
- 零演化：本实验只测"检索通道的参数级响应"，不涉选择压动力学。
