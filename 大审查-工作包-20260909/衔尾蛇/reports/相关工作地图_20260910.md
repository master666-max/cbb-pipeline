## 二、新颖性登记（2026-09-10 深查后修订；原【待深查】三项已查两项半）

1. **审计效力处方**（X10 超几何表 + X11 实证校验 + 定向审计集）：深查确认落点在**已登记的领域空白**内——[Construct Validity in LLM Benchmarks（NeurIPS 2025 D&B）](https://proceedings.neurips.cc/paper_files/paper/2025/file/1967e0fc3aa6cbbace562f5cb8e3954e-Paper-Datasets_and_Benchmarks_Track.pdf)实测**仅 16% 的基准做过任何统计检验**；最近邻是 [FAQ：Efficient Evaluation of LLM Performance with Statistical Guarantees（arXiv:2601.20251）](https://arxiv.org/html/2601.20251v3)（有效样本量效率）——但它优化抽样效率，不做**通道定向的检出力处 方**。新颖性维持，表述收窄为"通道定向的审计检出力规格"。
2. **评判者腐蚀的"独立性 + 标定 + 效力"三条件**（跨线矩阵 §C-4）：锚定审计必须独立于被审源、必须标定、必须够效力——三条件分别由三线独立发现。
3. **filter_zero 真实库否决史**：合成世界"双世界复现"被真实库一票否决（查询构造假象）——**深查后收窄（2026-09-10 晚）**：现象学有先例（BRIGHT 低词法重叠基准一系、EMNLP 2022 词重叠偏差、合成查询"偏易"问题，见 §三·五）；本线独有＝**程序内定量否决事件**（沙盒 24/24 采纳 → 真库 recall 反向 0.09）+ 审计效力处方，而非现象本身。
4. **伪特征通道自限定定理（候选）**——深查后**表述收窄**：外部已有完整的现象学——[Springer 综述（2026）](https://link.springer.com/article/10.1007/s44163-026-01980-z)的四级分类中 "feature-level exploitation"（冗长/讨好/风格捷径）正是我们伪特征的同级概念；[Goodhart's Law in RL（ICLR 2024, arXiv:2310.09144）](https://arxiv.org/html/2310.09144)区分 reward gaming 与 Goodharting（先益后损）。**本线的增量收窄为**：检索域的结构定理候选（X6a）——词法优势效用 + 训练饱和使 Goodharting 第二阶段（先益后损）**无法启动**，通道自限定；以及 RHB（[arXiv:2605.02964](https://arxiv.org/pdf/2605.02964)）/METR 实证的是"工具型 agent 钻评测机制空子"，与本线"演化优化器在检索效用上的结构性失效"机制不同层。
5. **"测量 > 发明"元法则的六次独立验证 + 校准账本方法论**（R 线 99-FINAL：中间带 +0.29 过度自信、自填账本错误率 17%、心算 12% 错误率）：agent 自实验的元科学，外部未见对应。
6. **伤害归因方法论**：同流配对消融（X7 证伪过期链接叙事）+ 跨轮逐位指纹 + 反事实隔离模板（X11/X12 单行 diff 断言）+ 2×2 反事实矩阵（X12 揭示根因层级）+ 事件级边际分带（X13）——一套可复用的"agent 实验法医学"。

## 三、矛盾与互补（外部主张 vs 本线证据）

| 外部主张 | 本线证据 | 关系 |
|---|---|---|
| AWM/A-Mem 类"记忆自主生长有益" | 收益真实但有前提：检索语义健康（X2d）+ 算子端点非惰性（X7 在本世界惰性） | **互补**：补效益边界 |
| Sleep-time compute"离线整理有益"（5× 节省） | 整理算子有时序/通道前提；过早整理被参数演化作废（X6b 原判）或本就无效（X7 再归因） | **互补**：整理前先验效力 |
| 综述普遍按"能力"分类记忆系统 | 本线证据：四轴（存/更/忘/组）不独立（X2d、X6b），按能力分类的评测会互相污染 | **张力**，值得写进相关工作讨论 |

## 三·五、综述对表（摘要级，2026-09-10 晚）

**综述 1**：[A Survey of Agent Memory in the Second Half（arXiv:2602.06052）](https://arxiv.org/abs/2602.06052)——三维度统一框架（substrate/cognitive mechanism/subject）+ 记忆操作拓扑 + "记忆管理本身正在成为学习问题"；开篇主题=领域进入"第二半场"（从刷分转向严谨真实评测）。**对表**：本线的审计效力处方正落在其"严谨真实评测"主题上；但其框架按能力/对象分类、无统计效力内容——新颖性 §二.1 维持。
**综述 2**：[From Storage to Experience（arXiv:2605.06716）](https://arxiv.org/html/2605.06716v1)——记忆机制演化三阶段：Storage（轨迹保存）→ Reflection（轨迹精炼）→ Experience（轨迹抽象）；前沿=主动探索 + 跨轨迹抽象。**对表**：本程序横跨 Storage→Reflection（X2d 反思合成、X6b 链接≈初级跨轨迹抽象）；本线的护栏/归因结论对 Experience 阶段构成前置约束（整理时序、端点惰性、审计效力）。
