## 二、迁入方案（推荐 A，降级 B）

### 方案 A · git 同源快进（首选）

主区 `大审查\.git` 与包内 `.git` **同一历史**（打包时复制，冻结提交 `6d5cd3d` 为共同末端）。主区仓库把包仓库加为 remote 后可直接快进：

```bat
cd /d D:\zcode专用！！！！危险！！！！！！！！！\大审查
git remote add temp-pkg D:\临时工作区\大审查-工作包-20260909
git fetch temp-pkg
git log --oneline temp-pkg/master -1        & rem 应显示 a84fd6e
git merge --ff-only temp-pkg/master         rem 若主区 HEAD 仍= 6d5cd3d 则纯快进
git remote remove temp-pkg
```

**前提（执行时必须先核）**：①主区 HEAD 仍 = `6d5cd3d`（若解冻后有他人提交 → 走方案 B 或改用 merge 非快进并人工裁决冲突）；②主区 `衔尾蛇/` 无未提交改动。

### 方案 B · 逐文件复制（git 不可用时）
