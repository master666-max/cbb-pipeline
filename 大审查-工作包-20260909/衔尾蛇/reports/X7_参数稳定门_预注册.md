## 二、假设（来源：LIT-REPLICATE + DATA）

- **H-X7**：给链接重组算子加参数稳定门（连续 N 代主线无采纳才允许提议），可消除 X6b 的任务召回伤害（2/8 种子受伤 → 0/8），且不杀死长尾收益面（kw 召回不降）。
- 先验警告在案：本线"发明新启发式 0/3"（X6a/X6b 时序耦合/X6c）。本轮的辩护：稳定门不是新启发式，是 X6b 已测得伤害的**对症闸**，且有跨领域文献同向支撑；若失败，按记录如实登记（那将是"文献类比外推失败"的第四例，同样有信息量）。

## 三、设计（配对流）

| 臂 | 变异流 | 算子 |
|---|---|---|
| P | `seed*31+ord("P")` | 无 |
| PL | `seed*31+ord("PL")` | 每 5 代扫描训练任务，金标在窗口非 #1 → 提议链接（X6b 原样） |
| PLS | **与 PL 同流** | 同 PL，但加稳定门：仅当 `gen − last_mainline_change ≥ N`（N=5，先验定为与提议节奏同拍）才允许提议 |

- **配对理由**：提议扫描不消耗 rng，PL 与 PLS 变异历史逐位相同，唯一差异=链接落地时点/数量 → 结局差异可完全归因于时序。
- 参数 N=5 先验冻结（等于提议周期的 1 个窗口）；GENS=25、KIDS=3、seeds=1–8、margin/tolerance 均沿用冻结元层 `data/meta_layer.json`，零改动。
- 逐 run 记录：`audit_recall5 / audit_U / kw_recall / links_added / gen_first_link / links_log[(gen,src,dst)] / doctor_ok`。
- 输出：`data/x7-{group}-s{seed}.json`、`data/x7_summary.json`（新文件名，只追加纪律不触旧数据）。

## 四、判据（执行前冻结）

1. **复现前提（PL 臂）**：受伤种子（`audit_recall5 < 0.95`）≥2/8 → X6b 基线复现成立；<2/8 → 本轮对 X6b 复现失败，主判定降级 INCONCLUSIVE（只登记不硬判）。
2. **主判定（PLS vs PL，配对）**：PLS 受伤种子 **0/8 → SUPPORTED**（稳定门消除时序耦合伤害）；**1/8 → PARTIAL**；**≥2/8 → NOT SUPPORTED**。
3. **收益保真（副判定）**：`kw_recall 均值(PLS) ≥ kw_recall 均值(PL) − 0.02` → 长尾收益面未被门杀死。
4. **机制保真**：`gen_first_link 均值(PLS) > gen_first_link 均值(PL)`（门确实延迟了提议）；若 PLS `links_total=0` → 登记"门从未打开"边界结果（25 代内主线未现 ≥5 代静默窗，本身即"参数持续漂移"的证据）。
5. **审计面**：三臂 doctor 8/8（链路走真审计面）。
