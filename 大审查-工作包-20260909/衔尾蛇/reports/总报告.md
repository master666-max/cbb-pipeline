## 四、七项超出报告的新发现

1. **`w_age` 病灶（真引擎独有）**：源码打分 `-0.1×age_days` 在真实 age 语义下完全压倒命中分（基线 utility 为负）；报告模拟世界把 age÷100 掩盖了它。全部演化 run 无一例外修复了它——**真引擎适配的价值当场兑现**。
2. **轴间耦合**：源码反思规则强制 `importance>=7`，重组条目在健康参数下无害、在病灶参数下自挤占 top-5——**记忆四轴（存/更/忘/组）不独立，重组以更新为前置**。
3. **检出的代价曲线**：锚定审计 gen2 检出漂移（8/8）并冻结，代价是砍掉 +0.73 的合法收益——检出延迟、误报率之外第三维"误冻结机会成本"首次量化。处方方向：检出后转只读演化，人侧裁决冻结。
4. **伪特征免疫结构**：伪特征要伤到审计集必须先进 top-5，而 default 的年龄惩罚与 evolved 的零命中过滤恰好把它双重堵死——**被演化修复过的检索器对伪特征注入天然免疫**（本世界构造下），E3 红线的适用边界需要注记。
5. **欺骗地形缩水**：真引擎 5 参数地形只有浅谷，strict 爬山 7/8 自愈，宽松准入的价值从 E7 的"决定性"缩水为"兜底险"（在 strict 唯一失败处救场）。
6. **G6 人工维护组画像**：评估最省（38.5 vs 演化组 49–81）、能到达众数最优（6/8）、但会卡死（s2 停在 0.22）且没有任何防御设施——"定期人工维护"是自演化的降级近似而非替代。
7. **`importance_accum` 并发丢 75%**（X1）与事件溯源内核 40/40 精确（X4）——反思触发器在并发下静默失效是 v3 引擎最值得先修的一处，X4 证明换内核即可根治。
