## 1. 一句话：这是什么

一个**可运行的沙盒**，用来论证 agent 记忆库「自演化引擎」的架构设计与可行性。
被测对象是 `bootstrap_v3.py`（v3.8.1）的**真实记忆内核**（不是复制品，是 `importlib` 直调真身），
在它之上外接一个法层自演化引擎，用五种可控地形 + 七个对照臂量化「存储 / 更新 / 遗忘 / 重组」
四项能力与四项成本。

**核心结论（一句话）**：自演化可行且值得（ΔU +0.43，recall 0.603→0.980），
但收益几乎全部来自护栏；而护栏需要标定——未标定的护栏本身是伤害源（零漂移时 11/12 误报、净损失 0.127）。

## 5. 「不要改」清单（改了会让历史数据作废）

1. **`kernel.score_all` 的打分公式**——一旦改动，`equivalence_gate` 可能失配，
   之后所有 ΔU 与历史不可比。改了必须重跑 `selftest`。
2. **等价性门禁本身**——不允许放宽容差来"让它通过"。若失配，是真的跑偏了。
3. **`World` 的随机种子构造**——不得用 `hash(str)`（进程级盐，破坏可复现）。
4. **`_ts()` 上的 `lru_cache`**——去掉会让墙钟涨 7.5 倍。
5. **`Archive` 的 `front` / `pool` 双容器语义**——合并二者会让 E7 从 10/12 掉到 0/12（见 §8 第 4、5 条）。
6. **`ANCHOR_THRESHOLD` 的默认值**——它是**标定产物**，不是常数。换世界必须重新 `calibrate`。
7. **审计集不得参与训练或门控**——对外结论只用冻结审计集（红线 11）。

## 8. 静默失败清单（重做前必读）

这些错误**都不报错**，只会让实验静默地得出"无差异"或"看起来有用"的错误结论。

| # | 失败 | 症状 | 修法 |
|---|---|---|---|
| 1 | 锚定阈值未标定 | α=0 时 **11/12 误报并冻结**，净损失 0.127 | 先 `calibrate` 再 `sweep` |
| 2 | 锚定审计用活库打分 | 测到状态漂移而非权重漂移，α=0 与 0.1 分布重叠 | 在与标注**同一份规范化库状态**上打分 |
| 3 | 锚定判据太粗（绝对阈值） | agreement 恒 1.0，永远检不出漂移 | 改成成对比较 + 过滤分差<0.02 的噪声对 |
| 4 | `Archive` 只留 Pareto 前沿 | 中间态被支配，E7 从 10/12 掉到 **0/12** | 拆 `front`（报告）与 `pool`（取样池） |
| 5 | `Archive` single 模式无条件覆盖 `pool` | "无档案"退化成"末位候选档案" | 只有更优才替换 |
| 6 | 地形塑形项未摊到逐任务分 | 留出集配对比较看不见它，E7 复现失败 | `evaluate(shape_bonus=...)` |
| 7 | `scannable()` 漏排 `t_invalid` | 等价性门禁失败 | 与 `_rank_entries` 对齐 |
| 8 | 热层排序依赖"采纳日志是否为空" | 同基因组不同代数选出不同热层 | 热层只依赖基因组 |
| 9 | `hash(terrain)` 作种子 | 进程级盐破坏可复现 | 改字符序求和 |
| 10 | switch 地形 Δ 跨目标口径 | +0.51 几乎全部来自目标切换本身 | 补同口径 `delta_W1` |
| 11 | `time.strptime` 调 246 万次 | 占 60% 墙钟 | `lru_cache` + 文本块预计算（**7.5×**） |

## 9. 未决项与下一步（建议顺序）

1. **噪声标注下的锚定审计**（最高优先级）
   现在"零误报"是在**无标注噪声**下测的（α=0 一致率恒 1.000）。
   应在 `build_anchor_samples` 的标签上也注入噪声（独立 / 相关两种），重跑 `calibrate` + `sweep`，
   看阈值是否仍能保证零误报。预期：相关噪声下锚定会失效（E57 已证明双门挡不住相关噪声）。
   **这条不做，H7 的结论不能外推到真实系统。**
2. **廉价筛选 / 停摆监控的专项构造**
   二者消融边际 ≈ 0，是因为本沙盒 `cheap_filter` 规则从不触发、margin 从未大到停摆。
   按红线"验证护栏前先构造它所防范的危险"，需要先造出"廉价评估精度不足"与"margin 过大导致饿死"的场景。
3. **世界规模 / 维度扫描**
   当前固定 300 条目、120 查询。报告 E23 的"样本复杂度 ~ 维度"关系未验证。
4. **完整样本量补齐**：漂移、消融、噪声目前是 12–24 种子；预注册口径是 24 种子 × 60 代。
5. **重锚的成本建模**：重锚有效但需周期性付出，注意力成本尚未计入 `attention_budget`。

## 10. 术语表

| 术语 | 含义 |
|---|---|
| ΔU | 冻结审计集上「终局效用 − 起点效用」，对外唯一主指标 |
| 回撤（drawdown） | 峰值审计效用 − 终局审计效用；漂移地形的核心观测量 |
| 自报−真实缺口 | 系统用当前（可能被污染的）尺子自评 − 用初心权重 W0 的真实值 |
| 留一法消融 | 从完整配置逐项拆掉一条护栏，测其边际贡献 |
| 逃出局部最优 | deceptive 地形下冠军到达 `(w_kw≥4 ∧ filter_zero=1)` |
| 锚定集 | 系统启用**前**用 W0 采集的成对判断样本，永不更新、永不衰减 |
| 重锚 | 检出漂移后由人重新采集判断样本并把尺子拉回 W0，然后解冻 |
| 开放式档案 | `front`（Pareto 前沿，用于报告）+ `pool`（全体准入候选，作为变异取样池） |
| 双门 | 主线晋升需同时过：训练集门 + 留出集 bootstrap 门 |
| 五态对账 | v3 `doctor` 的 memory / audit / ledger / 哈希链 / state 根五方对账 |
| 人侧锚点 | 公理 E：Merkle 根（v3）或 chain_tip（v4）抄录至人侧，攻击者拿不到 |

## 11. 故障排查

| 现象 | 排查 |
|---|---|
| `selftest: FAIL` 等价性失配 | 有人改了 `kernel.score_all` 或 `Library.scannable()`。**不要放宽容差**，去查语义 |

| 想重来 | 直接删 `runs/` 下对应目录；代码无状态，重跑即可（种子固定 ⇒ 结果可复现） |
