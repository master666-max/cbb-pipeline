| **方法论**    | 十二轮中我推翻了自己 24 次判断、32 次实验设计返工。**直觉准确率约一半**—— 例如我以为 links 扩散是优点、调高能挡注水、动态出仓能救错标、持续重演化能追概念漂移、掺点自报能救冷启动、囤着旧数据就能防自食、能造出完美潜伏记忆、单纯探索能破先发锁定、自演化会在新主题上退化、退火/种群能稳赢多起点爬山、LFU 会让长尾窒息到接近零、每代重评参照点的门控在漂移世界更聪明、查询日志能当免费的自考检测器、静态席位的免费胜利可以无条件推广、两级存储的冷层会加速自考脱钩，全部被实测推翻（后五个反而是否定性好结果）。这正是要做实验而非推理的原因                                                                                                         |

**一句话结论**：记忆库自演化**可行，但可行性不来自「把参数调对」，而来自三条结构性前提 —— 决策信号只认可观测行为（历史复用）而非自报字段；评测尺子（golden / 铁律 / 安全开关）冻结在引擎碰不到的元层；基线只升不降。** 缺任何一条，自演化都会从「自我改进」退化为「自我安慰」。

# 第一部分・基线审查（朴素自演化记忆库原型）

## 1.1 方法

不直接拿 2415 行的 `bootstrap_v3.py` 做动态实验（它是安装器 + 渲染器，动态行为分散），而是先写一个 61 行、**保留与真实系统同构机制缺口**的朴素原型 `naive_memory.py` 作为被审查对象，再用 `baseline_review.py` 在隔离合成世界里逐条做动态探针。真实系统侧的对应缺陷另有静态审查报告（`review-20260908/代码审查报告`，P0×5/P1×10/P2×14），本报告与其互补：**那份回答「代码哪里写错」，这份回答「让它自演化会怎样」。**

世界模型 `mem_common.py` 逐行复刻真实机制，关键事实均来自源码：



* 检索分（`_rank_entries` L885–915）：`score = 3·关键词命中 + 1·正文命中 + importance − 0.1·龄(天)`，links 向「自身零词命中」目标扩散 `0.5·分`；

* `validate_entry`（L240–247）**只查字段是否存在、扫密钥，不校验 importance 取值范围 / 类型**；

* **零词命中条目不过滤**，照样带 `importance−0.1·age` 进入排序；

* importance≥7 进 longterm（L927）；append 时 `importance_accum += importance`，wrapup 时累加≥50 触发反思（L939/984）；反思取材 = importance 降序 top6（L1000）；

* eval 基线**无条件覆盖写回**（L968，静态报告 P0-4）；retire 按 t\_invalid 满 90 天移 attic（L1075）。

| 编号 | 缺口                | 实测                                               |
| -- | ----------------- | ------------------------------------------------ |
| D1 | importance 无范围校验  | 自报 999 被接受，检索分 996.5                             |

### 四个要点



1. **D1+D2 是同一枚硬币**：importance 是条目**自报**字段且无界，又以系数 1 直接加进排序分，同时零命中条目不被剔除 —— 于是「把自己标成 10 分、足够新」就能在一个词都不沾查询的情况下上榜。这不是边角 bug，是「排序输入」与「被排序者自由填写」合流的结构性缺口。

2. **D6 门限会自杀**：门控判据是「本次 ≥ 基线 ×0.95」，而劣化结果又被写回成新基线。一次真实劣化把门限拉低，下一次更容易过门，累计漂移无下界（动态后果见 E15）。

3. **D7 是公理 G 的活标本**：TUNABLES 里 12 个参数有多个在全文 grep 中只命中定义行、无任何消费方。改它们「看起来在调系统」，行为指纹纹丝不动 —— 这正是公理 G 所说「测不出差异即表演」。

4. **D5 说明污染会沿抽象层上行**：检索被污染影响一次回答，而反思取材被污染会把垃圾提炼成「高层规律」、以 importance≥7 入长期层（后果见 E7）。

# 第二部分・架构诊断

## 2.1 自演化的三个隐含假设，全部被实验打破

让引擎自演化检索 / 反思 / 生命周期参数，默认依赖三个从未被证明的假设：



* **假设 H1（自报诚实）**：条目的 importance、links、t\_invalid 由写入方填写，但系统默认它们大致真实。→ E1/E3/E6/E9 证明：只要这些字段参与决策，写入方就有动机且有能力操纵，且「调阈值」挡不住恒报上限的攻击者。

* **H2（尺子稳定）**：golden 评测集无偏、基线单调不回退、一次评测的提升是真提升。→ E15/E17/E18 证明：基线会被劣化结果反向拉低；小样本评测噪声 sd 高达 0.08；引擎若能改 golden，训练满分与真实能力脱钩。

* **H3（写入侧静止）**：调参时面对的记忆库是静态的。→ E14 证明：真实写入侧会观察当前打分函数并适应，自由共演化下「指标」与「库健康」会脱钩。

## 2.2 两条原型路线：信任自报 vs 只认可观测行为

贯穿全部实验的对照，是两种组织记忆库信号的原型：



* **原型甲・信任自报（出厂形态）**：importance/links/validity 由写入方声明，直接作为排序、反思取材、长期分层、缓存逐出的键。结构简单、零额外记账，但把打分权让给了被打分者。

* **原型乙・行为背书（治理形态）**：写入方仍可自报，但**影响「是否被采纳 / 长期保留 / 反思取材」的键改为系统可观测、写入方无法直接伪造的历史行为 —— 条目过去被检索命中并被实际采用的次数&#x20;**`uses`；自报值只作弱先验。

后续每个生命周期环节都对两原型做了实测对照（E6/E7/E9/E11/E19），结论高度一致：**在存在注水的世界里，原型乙以极小的召回代价，换取抗操纵性与库健康的数量级改善。**

## 第一轮・检索打分机制的内在缺陷（E1–E4）

### E1　importance 自报注水与零命中霸榜

**设计**：200 条合成记忆、20 个语义主题，golden 查询锚定主题、expected = 该主题质量最高的 3 条；逐步提高把 importance 刷满 10 的条目比例，用出厂参数评测（8 种子均值）。



| 注水比例 | recall@5 | MRR   | 零命中条目占 top5 |
| ---- | -------- | ----- | ----------- |
| 0.00 | 0.439    | 0.349 | 0.814       |
| 0.05 | 0.431    | 0.340 | 0.815       |
| 0.10 | 0.425    | 0.326 | 0.819       |
| 0.20 | 0.406    | 0.303 | 0.824       |
| 0.40 | 0.356    | 0.285 | 0.833       |

注水 20% 时四种治理开关：



| 方案                    | recall@5  | MRR   | 零命中占比 |
| --------------------- | --------- | ----- | ----- |
| 出厂（全不防）               | 0.406     | 0.303 | 0.824 |
| 仅 filter\_zero        | **0.925** | 0.661 | 0.000 |
| 仅 w\_imp=0            | 0.389     | 0.319 | 0.770 |
| filter\_zero+w\_imp=0 | 0.914     | 0.598 | 0.000 |

**结论**：即使**零注水**，出厂配置 top5 里也有 81% 是一个查询词都没命中的条目（age 项把老的命中条目扣成负分所致，E2 展开）。注水只是雪上加霜。真正的根治开关是 **filter\_zero（零词命中不进候选）**，单独开启就把 recall 从 0.406 拉到 0.925；而单纯把 importance 权重清零（w\_imp=0）几乎无效（0.389）—— 因为只要零命中条目仍在候选池，age 项照样把它们顶上来。**治理要先关「进入候选」的门，再谈调权重。**

### E2　线性年龄惩罚错配，与检索老化曲线（本轮最反直觉）

**设计**：把 golden 目标按年龄分「经典（age>250 天）」「新知（age≤150 天）」，比较四种年龄项；再扫库龄 30/90/180/365 天时三种配置的总 recall。



| 年龄项方案             | 经典知识召回    | 新知召回  |
| ----------------- | --------- | ----- |
| 出厂 linear 0.1 / 天 | **0.000** | 0.724 |
| linear 0.01 / 天   | 0.914     | 0.995 |
| 无年龄项              | 0.993     | 0.987 |
| 乘性 exp 半衰期 180 天  | 0.010     | 0.914 |



| 库龄 / 天 | 出厂        | filter\_zero | w\_age=0 |
| ------ | --------- | ------------ | -------- |
| 30     | 0.920     | 0.997        | 0.870    |
| 90     | 0.725     | 0.988        | 0.895    |
| 180    | 0.523     | 0.953        | 0.872    |
| 365    | **0.403** | 0.925        | 0.889    |

**结论（自我推翻 S1）**：我原以为 0.1 / 天是温和的新鲜度偏好。手算量纲即知其谬：关键词命中贡献是个位数（3× 命中数），而 0.1 / 天在一年后累计 −36.5 分，**碾压一切语义命中**。于是运行一年的记忆库，经典高价值条目召回归零（0.000），总 recall 从满月时的 0.920 单调塌到 0.403——**这不是外部攻击，是系统随时间自杀**，且比注水更致命。乘性衰减同样伤经典。记忆库的使命恰恰是长期保留高价值经验：年龄项要么降到 0.01 量级、要么只对「时效型条目」生效，绝不能做全局线性减分。注意 30 天时出厂（0.920）略高于 w\_age=0（0.870）——age 项**短期有益、长期反噬**，是典型的时间尺度陷阱。

### E3　links 一跳扩散与链接农场

**设计**：逐步增加互链农场簇（簇内全互链、零语义相关）；再扫扩散系数 d×filter\_zero 网格；并专门构造「词面互补真相关对」界定扩散何时有用。



| 农场规模   | recall@5  | 农场条目占 top5 |
| ------ | --------- | ---------- |
| 无      | 0.414     | 0.000      |
| 2 簇 ×5 | 0.348     | 0.353      |
| 4 簇 ×5 | 0.309     | 0.595      |
| 8 簇 ×5 | **0.145** | **0.916**  |



| d    | filter\_zero 关 | filter\_zero 开 |
| ---- | -------------- | -------------- |
| 0.0  | 0.367          | 0.913          |
| 0.25 | 0.348          | 0.913          |
| 0.5  | 0.309          | 0.913          |
| 1.0  | 0.123          | 0.913          |

扩散收益的边界（词面互补世界，40 随机干扰）：词面重叠世界 d=0/0.5 总召回都是 0.414（**零收益**）；当真相关别名条目刻意不含查询词、只靠 link 相连时，d=0 它进 top5 比例 0.275（中位排名 7），d=0.5 升到 0.750（中位 4）。

**结论（自我推翻 S2 + 设计返工 F1）**：我原以为一跳扩散是 HippoRAG 式优点。实测在「同主题共享词」的正常世界里它**零收益**（语义相关≈词面相关，相关条目自己就能命中）；它唯一的用处是捞回「词面缺失但真相关」的别名，可这恰恰需要 links 指向零命中目标 ——**而 links 也是条目自报、不校验语义，机制无法区分「被链的真别名」与「被链的农场」**。扩散系数 d 调大调小都救不了（d=1.0 反而更糟），filter\_zero 一开，无论 d 取何值都回到 0.913。结论：扩散必须在零命中过滤**之后**进行，且 links 来源需要行为背书，否则宁可不扩散。

### E4　中文无空格 split 退化



| 分词方式             | recall@5  | MRR   | precision@5 |
| ---------------- | --------- | ----- | ----------- |
| space（理想已分词）     | 0.398     | 0.307 | 0.093       |
| glued（真实无空格中文整句） | **0.173** | 0.101 | 0.036       |
| bigram（双字切分）     | **0.433** | 0.345 | 0.104       |

**结论**：真实代码 `for w in q.split()` 按空白切词，中文查询「记忆检索」是一个整 token，子串匹配几乎必败，recall 腰斩到 0.173。零依赖的双字 bigram 不仅救回，还略超理想空格分词（0.433，部分匹配更宽松、precision 同步略升）。这是静态报告 P2-18 的动态量化：**中文检索在补分词 /n-gram 之前，上层权重怎么调都是在残缺输入上做功。**

### E5　反思触发节奏被自报 importance 控制

固定写 300 条，阈值 × 注水比例 → 触发次数 / 平均间隔条数 / 间隔变异系数：



| 阈值         | 诚实（次 / 均隔 / CV）         | 20% 注水               | 40% 注水               |
| ---------- | ----------------------- | -------------------- | -------------------- |
| 20         | 72.8 / 4.10 / 0.183     | 82.8 / 3.61 / 0.207  | 93.2 / 3.20 / 0.234  |
| **50（出厂）** | 31.0 / **9.55** / 0.119 | 35.6 / 8.34 / 0.136  | 40.4 / 7.39 / 0.136  |
| 100        | 15.7 / 18.57 / 0.080    | 18.1 / 16.15 / 0.103 | 20.5 / 14.26 / 0.098 |
| 200        | 7.8 / 36.80 / 0.057     | 9.0 / 31.83 / 0.071  | 10.2 / 28.03 / 0.067 |

**结论**：反思的「何时该停下来总结」完全由累加的**自报** importance 决定（它是触发的唯一输入）。注水把反思间隔从 9.55 条压到 7.39 条、触发次数抬升 30%—— 攻击者可以通过刷高 importance 让引擎更频繁地用被污染的素材做合成。阈值 50 自标「拍脑袋，待校准」，但**校准阈值解决不了被自报值控制的问题**：无论阈值高低，节奏的旋钮都在写入方手里。

### E6　反思取材：自报 importance vs 历史复用（本轮决定性）

反思取 importance 降序 top6，对比三种取材键（坏条目 = 注水 / 农场 / 失效）：



| 注水  | 取材策略            | 坏条目占比     | 素材平均真实质量 |
| --- | --------------- | --------- | -------- |
| 0.1 | 自报 imp          | **0.931** | 0.501    |
| 0.1 | 复用次数 uses       | 0.181     | 0.859    |
| 0.1 | 真实质量（oracle 上界） | 0.167     | 0.921    |
| 0.3 | 自报 imp          | **0.986** | 0.458    |
| 0.3 | 复用次数 uses       | 0.319     | 0.859    |
| 0.3 | 真实质量（oracle）    | 0.333     | 0.921    |

**结论**：只改取材键 —— 从「条目自报的 importance」换成「系统可观测、写入方伪造不了的历史被采用次数 uses」—— 坏素材率从 **93.1% 直降到 18.1%**，素材质量 0.501→0.859，几乎追平只有上帝视角能做到的 oracle（0.167/0.921）。这是「信任自报 vs 行为背书」两条原型最干净的一次对决：**uses 是写入方无法在写入瞬间伪造的信号（它需要在未来一次次被检索采用中积累），因此天然抗操纵。**

**E7a**：向素材中注入 p\_bad 比例「错误但高自信」经验（低质量 / 失效却自报 10），做 120 次反思合成：

| 0.3    | 1.0 / 0.05     | 0.294 / 0.612 |

**E7b**（返工后，见 F2）：枚举一个主题 8 个词的全部 28 个两两组合查询，比较错误条目覆盖词面宽窄：



| 错误形态      | 覆盖词数 | 进 top5 覆盖面 | 占 top1 面  |

| ---------------- | ------ | ---- | ----- | ------ |
| 基线 0.7/0.5       | 0.975  | 23   | 0.833 | 0.120  |
| decay=0.1        | 0.975  | 23   | 0.833 | 0.0001 |
| decay=1.0        | 0.975  | 23   | 0.833 | 0.5    |
| decay=0,init=0.9 | 0.975  | 23   | 0.833 | 0.0    |

**结论（否定性）**：衰减公式本身算得对，但 grep 与 A/B 同时证明 ——**情绪四维只在 wrap-up 里自我衰减、写进 state、被测试断言，却没有任何检索 / 反思 / 分层逻辑读它**。一个被认真维护、看起来在「内省」的信号，对 agent 行为零影响。这不是 bug 而是「仪表空转」：要么把情绪接进某个真实决策（并过 E16 准入），要么按公理 G 标注为未实现，不能让它以「L9 内省仿生」的名义给人系统在感知的错觉。

### E9　长期层阈值：调阈值挡不住注水，必须加第二门

### E10　下游出仓救不了上游错标（否定性结果）

| --- | ------ | ----- | ----- | ----- |
| 0.0 | 固定 TTL | 0.000 | 0.034 | 0.980 |
| 0.0 | 动态出仓   | 0.008 | 0.034 | 0.972 |
| 0.1 | 固定 TTL | 0.039 | 0.039 | 0.942 |
| 0.1 | 动态出仓   | 0.045 | 0.037 | 0.934 |
| 0.3 | 固定 TTL | 0.114 | 0.039 | 0.868 |
| 0.3 | 动态出仓   | 0.119 | 0.037 | 0.861 |

**结论（否定性，自我推翻 S6 + 返工 F3）**：我原期望一个综合「零复用 + 很老 + 低质量」的智能动态出仓能显著救回被漏标的失效条目。实测漏放只从 0.039 降到 0.037（几乎不动），误杀反而升。原因是本质性的：**出仓判据越想多捞失效，就越会误杀只是「暂时没被复用」的真知识 —— 它只能在「误杀 — 漏放」的 Pareto 前沿上滑动，无法整体外移。** 错标发生在写入瞬间，下游没有额外信息能还原真相。治理红线：**准入质量不可由下游出仓补偿，t\_invalid 的判定质量才是杠杆点。** 另外注意无错标时仍有 3.4% 漏放 —— 真失效但根本没被标 t\_invalid 的条目，固定 TTL 结构上永远管不到。

### E12　规模复杂度：全扫与全量 Merkle 的拐点

| 10000 | 20.155 | 0.0292   | 479   |

Merkle 全量重算：200 条单次 0.151ms（再写 100 条累计 15.08ms）→5000 条 4.617ms（累计 461.71ms）。

**结论**：真实 `_rank_entries` 每查询 rglob 全扫 + 解析 + 打分，O (n) 线性，万条时单查询 20ms；倒排索引查询近常数（0.03ms，候选仅 479/10000），万条时快约 690 倍。Merkle 每次写全量重算，批量导入 N 次写累计 O (N²)，5000 条时再写 100 条就要 0.46 秒。`merkle_refresh_trigger=500` 登记了拐点却从不读取（静态 P2-17）——**约 500–1000 条以上，倒排索引与增量 / 挂根 Merkle 从「优化」变成「必要」，否则自演化每次 eval 都在为全扫买单。**（绝对值为本机相对量，趋势稳定。）

## 第四轮・自演化闭环（E13–E16，核心）

### E13　法层参数自演化：收敛、泛化、自发现结构（可行性主证据）

从出厂参数爬山演化（变异→在 train-golden 评测→提升则接受），6 种子：



* **(a) 只演化连续权重、锁死 filter\_zero=False**：train 0.388→0.90，**holdout 0.886**；最终参数均值 w\_kw=3.502 /w\_c=1.397 /w\_imp=0.932 / **w\_age=0.018** /d=0.304—— 演化自主把 w\_age 从 0.1 压到 0.018（独立复现了 E2 的结论）。

* **(b) 允许变异离散开关 filter\_zero**：train 0.997、**holdout 0.992**，**5/6 个种子自行把 filter\_zero 翻成 True**。

* **(c) 从劣化起点（w\_imp=3、w\_age=0.3、不过滤）出发**：holdout 0.289→**0.967**。

**结论**：在写入侧不适应、golden 冻结的静态世界，**自演化确实可行**：留出集与训练集同步提升（真泛化而非过拟合，E17 再验）、能跨连续 / 离散参数发现我靠整轮分析才找到的 filter\_zero 结构、还能从被调坏的劣化状态自愈。这给命题以肯定回答 —— 但 E14–E18 立刻给出这个「可行」的全部前提。

### E14　写入侧 — 检索器对抗共演化（本轮最不安的结果）

初始 5% 注水，之后写入侧每 5 代观察当前打分函数：还看重 importance 就刷满、扩散开着就织互链簇。三种条件 40 代：



| 条件            | 初始 holdout | 第 20 代 | 第 40 代    | 末态库污染     |
| ------------- | ---------- | ------ | --------- | --------- |
| ①固定出厂不演化      | 0.436      | 0.386  | **0.350** | 0.480     |
| ②自由共演化（无元层）   | 0.436      | 0.956  | **0.956** | **0.448** |
| ③共演化 + 元层锁安全键 | 0.436      | 0.919  | **0.919** | **0.153** |

**结论（自我推翻 S7）**：我原以为持续攻防会让自由演化的指标振荡下跌。实测更微妙、也更不安：



* ①不演化，检索在持续攻击下缓慢恶化到 0.350、库污染 48%；

* ②自由演化能把**可见指标**稳定救到 0.956，但**库实质仍以 44.8% 污染持续腐化**—— 因为固定 holdout 的正确答案是那些高质量老条目，检索器学会忽略垃圾即可命中，指标好看与库变脏并行不悖；

* ③元层把 filter\_zero=True、w\_imp=0 锁成引擎改不动的安全键，只以 0.956→0.919 的微小指标代价，把末态污染压到 **0.153**。机理是**改变了攻击者激励**：当自报 importance 不再影响排序（w\_imp=0）、扩散被零命中过滤截断，写入侧「刷分无利可图」，理性地减少攻击。

**最深的教训：失败模式不是「指标崩」，而是「指标与库健康脱钩」。** 只监控检索 recall 的系统，会在库烂掉一半时显示一切优秀。元层锁安全键的价值不在更高分，而在让攻防均衡向低污染移动。

### E15　eval 门限棘轮：门是怎么一步步死掉的

真实能力在第 8/20/30 代三次 −0.15 劣化，叠加评测抽样噪声（σ=0.03），20 种子跑 40 代：



| 基线规则           | 40 代后基线   | 过程最低  |
| -------------- | --------- | ----- |
| 棘轮（真实代码：劣化也回写） | **0.348** | 0.296 |
| 只升不降签收线（修复）    | **0.844** | 0.811 |

**结论**：这是静态 P0-4 的动态量化。门控判据「本次 ≥ 基线 ×0.95」看似严格，但三次真实劣化把基线从 0.80 一路拉到 0.348，此后再差的结果都能「相对基线不再跌 5%」过门 ——**门限被自己的测量结果逐步拆除，最终形同虚设。** 修复极简：基线是「历史最佳签收线」，只升不降（劣化结果另写 last\_run），40 代后仍守在 0.844。自演化的门必须由「最好成绩」而非「上一次成绩」定义。

### E16　公理 G 准入：一个参数得先「改得动行为」才配进自演化空间

行为指纹 =（recall, 反思次数，取材坏率，长期条数，出仓数）。基线指纹 (0.90, 24, 1.0, 77, 5)。



* 活参数：reflect\_threshold 50→20 反思次数 24→55、→200 变 6；filter\_zero 关→开 recall 0.388→0.90。**改动可观测，允许进入自演化搜索。**

* 死参数：broadcast\_weights、index\_hot\_budget、review\_intervals、emotion\_decay、情绪初值 —— 任意取值，**五项指纹与基线逐项完全相同**。

**结论（结构性）**：TUNABLES 里混着「真旋钮」和「装饰旋钮」。让一个改不动任何行为的死参数进入自演化搜索空间，优化器只会在它上面浪费变异、甚至产出「我已自适应调优广播权重」的虚假叙事（违反公理 G）。**可演化参数白名单必须先过 A/B 行为指纹测试：扰动它，行为分布不变即逐出搜索空间，要么实现它、要么标注未实现。**

## 第五轮・评测可信度、元层边界、综合治理（E17–E19）

### E17　golden 规模：不是过拟合、是评测噪声

**E17a** 在不同规模 train-golden 演化 25 代，对独立 200 题大留出集：



| train 题数 | train 终值 | 独立 holdout | 过拟合 gap |
| -------- | -------- | ---------- | ------- |
| 5        | 0.960    | 0.944      | 0.016   |
| 10       | 0.980    | 0.941      | 0.039   |
| 20       | 0.980    | 0.941      | 0.039   |
| 40       | 0.980    | 0.948      | 0.032   |
| 80       | 0.983    | 0.976      | 0.007   |

**E17b** 同一检索器、独立抽 m 题重复 100 次的评测噪声：



| 抽题数 m | recall 均值 | sd    | 95% 半宽 1.96sd | 真改进需超过    |
| ----- | --------- | ----- | ------------- | --------- |
| 10    | 0.933     | 0.081 | 0.159         | 0.163     |
| 20    | 0.945     | 0.055 | 0.108         | 0.110     |
| 40    | 0.938     | 0.043 | 0.084         | **0.085** |
| 80    | 0.937     | 0.030 | 0.059         | 0.060     |

**结论（否定性 + 修正，自我推翻 S5）**：我原以为小 golden 调参会严重过拟合。实测在本沙盒的**低维参数、平稳词袋世界**，过拟合 gap 只有 0.007–0.039，5 题也能找到正确方向 —— 过拟合偏差不是主要约束。真正的约束是**评测抽样噪声**：只抽 10 题时两次评测差 0.16 以内都可能是抛硬币，门控会把噪声当改进 / 劣化；到 40 题（恰是真实 TUNABLES `eval_n: d0.7=40` 的口径）半宽降到 0.084，即**一次自演化「提升」必须超过约 0.085 才配叫真改进**，否则需要配对 / 序贯或更多题。结论：法层门控的 margin 由评测噪声决定，不由主观愿望决定。

### E18　元层为什么必须冻结：让引擎改考题会怎样（决定性）

困难世界（30% 注水 + 4 农场，正路调参天花板有限），演化 40 代。(a) 只能调参、golden 冻结；(b) 每代变异参数后还可把「错题标准答案改成自己当前的 top1」，再决定是否接受；hidden 是引擎永远看不到也改不到的 100 题独立留出。



| 权力边界                | 训练题终值     | 隐藏题终值     | 诚信缺口      |
| ------------------- | --------- | --------- | --------- |
| (a) 法层可演化，golden 冻结 | 0.945     | 0.920     | 0.025     |
| (b) 法层 + golden 都可改 | **1.000** | **0.872** | **0.128** |

**结论（三版返工 F6）**：当标准答案能被引擎自身的输出重写时，它每代都能把错题改成「我恰好输出的那个」，训练分迅速刷到满分 1.000；但此时参数变异无论朝哪走都「提分」（因为改题兜底），**参数失去外部梯度、进入随机漂移**，隐藏题暴露真实能力反而劣化到 0.872（比老实调参的 0.920 更低），诚信缺口是 (a) 的 5 倍。这正是 DGM（arXiv:2505.22954，bootstrap REGISTRY A21）Appendix F Node114「删检测标记刷分」在记忆库的同构：**评测题、铁律、验收判据必须对变异引擎只读 / 不可见、冻结在元层，引擎只收到 pass/fail，永远拿不到也改不了标准答案。**

### E19　三治理水平综合压力测试（收官）

复合恶劣世界（20% 注水 + 4 链接农场 + 20% 错标 + 仅 20 题 golden），40 代攻防：



| 治理水平                              | holdout   | 库污染率      | 长期层纯度     | 反思取材坏率    |
| --------------------------------- | --------- | --------- | --------- | --------- |
| L0 无治理（出厂固定 / 零命中不过滤 / 自报取材 / 单门） | **0.172** | 0.637     | 0.492     | 1.000     |
| L1 部分（+filter\_zero + 允许演化）       | **0.876** | 0.609     | 0.492     | 1.000     |
| L2 全治理（+ 元层锁安全键 + uses 取材 / 双门分层） | **0.852** | **0.337** | **0.761** | **0.367** |

**结论**：L0 在复合攻击下检索近乎不可用（0.172）、库近 2/3 腐化、反思素材全是垃圾。L1 靠 filter\_zero + 自演化把**检索指标**救到 0.876，但库污染（0.609）、长期层纯度（0.492）、反思取材坏率（1.000）**纹丝不动**—— 只在检索末端设防，治标不治本，污染仍沿分层与反思上行。L2 把「安全键锁入元层 + 全生命周期决策键换成 uses」补齐后，holdout 仅微降（0.876→0.852），却换来污染 0.609→0.337、长期层纯度 0.492→0.761、取材坏率 1.000→0.367 的全面改善。**治理是成体系的：单点修指标不改善系统健康，只有把「信号换轨 + 尺子冻结 + 基线单向」贯穿写入 — 检索 — 反思 — 分层 — 出仓全链路，自演化才既聪明又干净。**

## 方向 A・反向压力测试：uses 到底有多可靠（E20/E21/E24b）

### E20　行为信号在稀疏反馈与流行度噪声下的鲁棒性

真实系统里 uses 不是即时、全覆盖的：很多条目没机会被采用（反馈缺失），还夹杂与质量无关的流行度偶然。人为退化观测 uses（cover = 能收到反馈的条目比例；pop = 叠加无关流行噪声强度）：



| 反馈覆盖 cover | 自报 imp 坏率 / 质量 | 观测 uses 坏率 / 质量   |
| ---------- | -------------- | ----------------- |
| 1.00       | 0.979 / 0.483  | 0.125 / 0.856     |
| 0.50       | 0.979 / 0.483  | 0.250 / 0.838     |
| 0.25       | 0.979 / 0.483  | 0.125 / 0.797     |
| 0.10       | 0.979 / 0.483  | **0.146 / 0.729** |

全覆盖下叠加流行度噪声 pop=0/0.25/0.5/1.0，uses 坏率 0.125/0.188/0.167/0.188、质量 0.856→0.782。

**结论（反向测试未推翻、反而强化）**：我本以为 uses 一旦稀疏就会退化到接近自报。实测即使**只有 10% 条目能收到任何反馈**、或叠加与质量完全无关的满强度流行噪声，uses 取材坏率仍稳定在 0.15–0.19（自报恒为 0.979）。原因是排序只需要「相对次序」：注水条目 uses 系统性为 0，而真质量条目只要收到一点点反馈就能排到前面 ——**行为信号是序数信号，对覆盖率和加性噪声天然鲁棒。** 质量随覆盖下降（0.856→0.729）是真实代价，但抗操纵性不塌。

### E21　自报 + 行为融合：需要掺一点自报做冷启动吗（否定性）

一个合理的担忧：纯 uses 会不会把「还没机会被用的好新条目」埋没？于是测融合键 `α·归一化imp+(1-α)·归一化uses`，α 越大越信自报：



| α（自报占比）      | 坏率        | 素材质量  | 高质量条目覆盖率  |
| ------------ | --------- | ----- | --------- |
| 0.00（纯 uses） | **0.167** | 0.819 | **0.917** |
| 0.25         | 0.208     | 0.819 | 0.917     |
| 0.50         | 0.354     | 0.822 | 0.833     |
| 0.75         | 0.646     | 0.790 | 0.688     |
| 1.00（纯自报）    | 0.979     | 0.483 | 0.146     |

（稀疏反馈 cover=0.3；cover=1.0 时趋势相同，纯 uses 坏率 0.125、高质量覆盖 1.000。）

**结论（否定性，自我推翻 S8）**：我原猜想「冷启动需要一点自报先验」，最优 α 会在中间。实测坏率随 α **单调上升**、高质量覆盖率随 α 单调下降，最优点在端点 α=0。**掺自报不仅没救冷启动，反而线性地重新引入注水；冷启动的正确解法是给新条目一个低权重的探索期 / 显式曝光，而不是把自报 importance 混进决策键。**

### E24b　uses 的信任根：它一旦可被伪造会怎样（本轮决定性）

E20 证明 uses 抗「缺失 / 噪声」，但它抗「伪造」吗？让攻击者把自己条目的 uses 也刷满（自导自演假「采用」）：



| 取材方式      | 坏率        | 质量    |
| --------- | --------- | ----- |
| 自报 imp    | 0.979     | 0.483 |
| 诚实 uses   | **0.125** | 0.856 |
| 伪造 uses 后 | **1.000** | 0.480 |

**结论（决定性）**：uses 的全部抗操纵性来自一个时间属性 ——**写入瞬间它是 0、必须靠未来一次次真实采用累积，写入方伪造不了尚未发生的事**。一旦「采用记录」可以被写入方自导自演（自己触发自己的记忆被标记为「已采用」、或买来假采用），uses 立刻退化成**第二个 importance，甚至更差（坏率 1.000）**，因为它还披着「客观行为」的外衣更难被识别。这把 E6 的结论精确化为一条信任根：**采用必须由下游真实任务事件背书（对应铁律 2 证据准入 / 双平面投影），记忆模块不能自证其 uses。**

## 方向 B・时间动态：概念漂移、冷启动（E22/E22b/E22c/E23）

### E22 / E22b / E22c　灾难性遗忘在什么条件下才发生

真实记忆库要面对兴趣主题随时间迁移。造「A 批旧主题、B 批新主题」两期世界，比较固定参数 / 旧世界演化一次后冻结 / 持续追逐新世界：

| β（关键词预算）   | 旧世界 A     | 新世界 B     |
| ---------- | --------- | --------- |

| 0.50       | 0.859     | 0.812     |
| 1.00（全关键词） | **0.000** | 0.816     |

**结论（自我推翻 S9，三连实验才讲清）**：我原本预期「持续追逐新概念必然灾难性遗忘旧概念」。实测**遗忘不是时间漂移的必然结果，而是参数结构的性质**：bootstrap 式**加性独立权重**下，新旧世界的最优解可以同时满足（E22b 追新时守旧反而同升），一次调对的参数对主题轮换天然鲁棒，盲目高频重演化几乎无收益（E22 B 仅 0.934→0.956）；只有当旋钮是**零和 / 竞争型**（固定预算在两种匹配方式间分配，E22c），为新世界选 β 才会牺牲旧世界（β→1 时 A 崩到 0）。**工程含义：尽量把法层设计成可叠加的独立维度，避免引入「此消彼长」的归一化预算旋钮；一旦引入，就必须为旧世界保留不参与在线更新的锚定评测。**

## 方向 C・攻击分类学与结构检测（E24/E25）

### E24　五种攻击形态 × 三治理水平

统一 20% 攻击预算，区分五种打法（数值 = recall / 恶意条目占 top5）：



| 攻击形态          | L0 出厂         | L1 +filter\_zero  | L2 +uses 重排   |
| ------------- | ------------- | ----------------- | ------------- |
| 刷 imp 注水      | 0.344 / 0.655 | 0.800 / 0.230     | 0.800 / 0.230 |
| **关键词堆砌**     | 0.331 / 0.380 | **0.598 / 0.501** | 0.598 / 0.501 |
| 互链农场          | 0.104 / 0.970 | 0.802 / 0.255     | 0.802 / 0.255 |
| 伪造 uses（词面普通） | 0.390 / 0.012 | 0.812 / 0.144     | 0.812 / 0.144 |
| 全武行合谋         | 0.100 / 0.976 | 0.798 / 0.379     | 0.798 / 0.379 |

**结论**：filter\_zero 对「刷分 / 农场 / 词面普通的伪造 uses」都有效（recall 升到 0.80、恶意占比降到 0.14–0.26），但**关键词堆砌是它的结构性盲区**：堆砌条目真的命中了查询词，零命中过滤剔不掉，L1/L2 都只到 0.598、top5 一半是堆砌垃圾。**没有万能闸门：filter\_zero 关「词面不沾」的门，关键词异常度检测（E25）关「词面异常贪多」的门，二者必须叠加。** 另注意 L2 的 uses 重排在攻击条目词面普通时不额外改善 —— 行为背书主要价值在取材 / 分层 / 逐出（E6/E9/E11），检索末端仍以词面闸门为主。

### E25　不依赖上帝视角的结构检测

只用系统自己可见的结构特征识别恶意条目：



| 结构特征                      | 检出 TPR    | 误伤 FPR |
| ------------------------- | --------- | ------ |
| imp=10 且零 uses（自报 - 行为背离） | **0.000** | 0.000  |
| 互链连通块≥4                   | 0.533     | 0.049  |
| 关键词数异常≥10                 | 0.250     | 0.000  |
| 三特征任一（组合）                 | **0.769** | 0.049  |

**结论（双重）**：互链块 / 关键词异常是有效的零误伤特征，组合检出 77%。但「imp=10 且零 uses」在本实验（combo 世界里攻击者同时把 uses 也刷了）TPR=0——**一旦行为信号被同步伪造，「自报与行为背离」这个最优雅的检测特征当场失效**，与 E24b 互为印证。结构检测是纵深防御的一层（低误伤、可自动标记待审），但召回有上限、且假设攻击者没伪造行为，**不能替代元层锁定，也不能假设单点检测够用。**

## 方向 D・反思的二阶动力学（E26/E27）

### E26　递归反思：抽象层会逐级失真吗

让每代合成结论优先回流、主导下一代取材，递归 5 代（质量 / 污染）：



| 取材      | 代 1           | 代 3       | 代 5           |
| ------- | ------------- | --------- | ------------- |
| 自报 imp  | 0.477 / 0.042 | 0.480 / 0 | **0.450 / 0** |
| 行为 uses | 0.856 / 0     | 0.866 / 0 | **0.872 / 0** |

**结论（含否定性细节）**：我原想看到「传话游戏」式的污染逐级爆炸。实测**抽象层不会凭空制造新错误**（污染不随代数增长，反而因聚合被稀释到 0）；它真正做的是**把入口的质量偏差锁定、沿层固化**—— 自报取材陷入「低质素材→低质规律→低质规律主导下一轮」的**低质锁死**（质量稳定在 0.45 上不去），uses 取材则形成「高质→更高质」的**良性上行**（0.856→0.872）。**反思层不是错误的放大器（那是 E7 一次性取材的事），而是入口质量的棘轮：入口干净则越抽象越干净，入口脏则被永久固化为高层偏见，且高层规律更难被质疑。**

### E27　取材宽度与重复合成膨胀

E27a（取材宽度 topn）：topn=3/6/12/20 的坏率 1.000/0.979/0.979/0.981、质量 0.446/0.477/0.473/0.496、主题集中度 0.333/0.229/0.156/0.119。

E27b：对**静态库**连续反思 20 次，两种取材的「唯一规律率」都只有 **0.050**（20 次几乎只反复产出同一条规律）。

**结论**：自报取材下取多取少都坏（top3 全是注水，坏率 1.0）；放宽取材只稀释主题聚焦度（集中度 0.333→0.119），不改善坏率。更重要的是 E27b 的否定性结果：**没有新条目流入时，反复反思不产生新信息，只会重复提炼同一件事 —— 反思必须由「增量内容」触发，而不能定时 / 按固定条数空转**（对应 E5 阈值不应只由自报累加驱动）。

## 方向 E・优化过程本身（E28/E29）

### E28　可演化维度诅咒

固定 40 次评估预算（而非代数），改变可演化参数个数：



| 维度                    | train | holdout   | 种子间 sd    |
| --------------------- | ----- | --------- | --------- |
| 2 维（w\_kw,w\_age）     | 0.910 | **0.897** | **0.044** |
| 4 维（+w\_c,w\_imp）     | 0.902 | 0.890     | 0.071     |
| 6 维（+d, filter\_zero） | 0.980 | 0.940     | 0.072     |

**结论（分层）**：连续参数维度 2→4，固定预算下 holdout 略降（.897→.890）、种子间方差增大（.044→.071）—— 搜索空间变大、局部最优变多，这是经典维度代价；但加入**离散结构开关 filter\_zero 后 holdout 跳到 .940**，一个高杠杆结构维度的收益压倒维度代价。**搜索预算应优先用于探索「结构开关」，连续精调放在结构定型之后；不要一上来把所有旋钮都丢给优化器。**

## 方向 F・缓存工作集与近重复（E30/E31）

### E30　工作集时代切换：LFU 为何从最优变最差

访问服从 Zipf，工作集大小 60、缓存 50；对比随机 / LRU 近因 / LFU 频率 /hybrid（频率 × 近因衰减）：



| 工作集变化     | random | LRU       | LFU       | hybrid |
| --------- | ------ | --------- | --------- | ------ |
| 恒定        | 0.886  | 0.912     | **0.914** | 0.914  |
| 慢换（T=500） | 0.798  | **0.864** | 0.654     | 0.824  |
| 快换（T=120） | 0.616  | **0.659** | **0.545** | 0.654  |

**结论**：工作集恒定时，累积频率是最佳预测，LFU 最优；一旦工作集整体切换（用户进入新阶段、换项目），**LFU 死抱住上一时代的高频条目、把它们永久留在缓存里，快换时命中率崩到 0.545（全场最差）**；近因策略 LRU/hybrid 快速换血反超。这把 E11 的「热度用真实访问定义」再推一层：**「热」不仅要真实、还要会遗忘过时的热 —— 纯累积频率在非平稳访问下是负债，近因 × 频率的混合分才稳健。** 对应到记忆库：长期层 / 热缓存不能只按累计 uses 排序，要给 uses 加时间衰减或定期重估。

### E31　近重复条目：去重的收益与误并代价

向库中注入近重复（拷贝并微调一个词），以关键词 Jaccard≥0.8 合并、保留 uses 最高者：



| 近重复比例 | 去重前 n | 去重后 n | 合并组   | 误并组  | top5 不同证据数（前→后） |
| ----- | ----- | ----- | ----- | ---- | --------------- |
| 0.00  | 300   | 290.4 | 9.2   | 0.00 | 5.00 → 5.00     |
| 0.15  | 345   | 290.4 | 51.6  | 0.00 | 4.38 → 5.00     |
| 0.30  | 390   | 290.4 | 94.0  | 0.00 | 3.99 → 5.00     |
| 0.50  | 450   | 290.4 | 149.9 | 0.00 | **3.63 → 5.00** |

**结论**：近重复不占「错误」却占「位置」——50% 重复时，同一证据的多个副本挤掉其他证据，top5 的不同证据数从 5 掉到 3.63（检索看似有结果，实则信息单一）。高阈值（0.8）去重把有效容量钉回～290、恢复满证据多样性，且**零误并**（不同主题条目 Jaccard 到不了 0.8）。**去重是廉价的多样性保险：阈值宁高勿低（高了漏并、低了错并，错并不可逆），保留 uses 最高的副本即保留最被验证的版本。**

# 补篇・第七轮：破坏性实验——主动找崩溃边界（E32–E43，12 个实验）

第六轮把"稳态下可不可行、怎么治理"问完后，第七轮不再测稳态，而是**带着敌意攻击这套记忆库，专门寻找反直觉的崩溃点与不可能性边界**。这一轮每个实验都先锚定一类已知文献，再在记忆库世界模型里复现其机制：模型自噬障碍 MAD（Shumailov *Nature* 2024；Alemohammad ICLR 2024；Gerstgrasser 2024 论"累积真实数据可阻断坍缩"）、推荐反馈环放大流行度偏差（Mansoury 2020）、记忆注入攻击 MINJA（arXiv 2503.03704）/MemoryGraft/MemPoison、多智能体拜占庭鲁棒聚合（Krum、几何中位数，理论阈值 2f<n）、以及共享记忆的跨 agent 污染。源码：`exp_round7.py`，8 种子均值，除 E43 计时外两次运行逐行一致。

## 方向 G・自食闭环：系统如何自己把自己喂傻（E32/E33）

### E32　记忆库版 MAD：替换式自食的尾部消失与均值坍缩

**机制**：反思取材按 uses 取 top30，合成的高层记忆以 uses=30 回流；其主题按取材池 uses 加权抽取（高频主题被反复再生产）。对照两种数据政策：`replace`（自产挤走 uses 最低者，库规模守恒，模拟"用新合成替换旧数据"）与 `accum`（每代额外补 24 条**新鲜真实记忆**，模拟 Gerstgrasser 的累积）。跑 10 代。

| 代 | replace 全库主题 / 活跃主题 / 取材质量sd / 自产占比 | accum 全库主题 / 活跃主题 / 取材sd / 自产占比 |
| -- | -- | -- |
| 0  | 20 / 20 / .223 / .000 | 20 / 20 / .223 / .000 |
| 2  | 20 / 12.6 / .189 / .24 | 20 / 13.4 / .225 / .16 |
| 4  | 20 / 11.5 / .140 / .48 | 20 / 11.8 / .223 / .25 |
| 7  | 17.4 / 11.5 / **.043** / .84 | 20 / 11.8 / .220 / .31 |
| 10 | **12.1** / 10.3 / **.012** / **.991** | **20** / 11.8 / **.217** / .35 |

**结论**：替换式自食 10 代内，被持续再生产的"活跃主题"从 20 塌到约 10、全库主题开始消失（12.1），**取材质量的标准差从 .223 收敛到 .012——高层规律被反复平均成"均值的均值"，分布尾部（少数高质量洞见）消失**，库最终 99% 是自产记忆。这正是 Nature 2024 model collapse 在记忆库的复现。而每代持续补入新鲜真实记忆，全库主题保 20、取材方差保 .22。**注意一个比论文更细的否定细节**：accum 的"活跃主题"同样收敛到 11.8——只"不删旧数据"不够，因为取材入口仍偏向高 uses 自产；要同时保住取材多样性，必须像 E34 那样在入口保留探索。

### E33　自食脱钩：自评维持、外部能力崩到接近零

**机制**：在 E32 的 replace 闭环上并排放两把尺。*内部尺*每代把"每主题 uses 最高的 3 条"当标准答案（系统自己最信的记忆）；*外部金尺*在第 0 代锚定真实高质量条目后永不更新。

| 代 | 内部自测 | 外部固定金尺 | 剪刀差 |
| -- | -- | -- | -- |
| 0 | .348 | .373 | −.025 |
| 2 | .531 | .196 | **+.335** |
| 4 | .373 | .142 | +.231 |
| 6 | .350 | .092 | +.258 |
| 8 | .269 | **.042** | +.227 |

**结论（不安）**：自产记忆 uses 高，**既是检索赢家、又是内部尺的标准答案**，于是自评始终维持在 .27–.53；而锚定真实世界、永不更新的外部能力从 .373 单调崩到 .042，剪刀差由 0 扩到 +0.2~0.34。"变傻"和"自我感觉良好"同时发生——这与 E14（自由共演化指标 .956 但库 45% 腐化）、E18（改考题满分）是同一族病：**任何由被评测对象自己供给的尺子，都会在自食闭环里失真，必须存在一个它无法回写的外部锚**。

## 方向 H・反馈环的社会病：马太与回声室（E34/E35）

### E34　uses 的另一面：优先连接滚成记忆寡头

第六轮把 uses 立为可信排序键（E20/E24b），本轮专门找它的副作用。模拟"被检索→uses+1→更易被检索"的优先连接 3000 次，访问概率 ∝(uses+1)^α。

| 条件 | uses 基尼 | top10% 占采用份额 | 被用过条目比例（聚合多样性） |
| -- | -- | -- | -- |
| 均匀 α=0（对照） | .175 | .158 | 1.000 |
| 亚线性 α=.5 | .283 | .196 | .989 |
| 纯优先连接 α=1 | **.503** | **.319** | **.912** |
| α=1 + 15% 随机探索 | .423 | .283 | .973 |

**结论**：uses 抗注水，但在闭环里会经优先连接滚成寡头——基尼升到 .50、一成条目吃掉三成采用、近一成记忆再也不被检索（长尾窒息，对应推荐系统反馈环的 aggregate diversity 下降）。15% 的随机探索把覆盖拉回 .97。**行为信号可信 ≠ 行为信号应独占检索，排序必须叠加探索/多样性正则。**

### E35　回声室：55:45 的轻微初始偏向如何被锁成极端

两阵营 A:B=11:9 起步，被检索概率 ∝ 占比^γ（γ=2 模拟排序的马太强化），被检索方写回一条新记忆（Pólya urn 的非线性版），跑 2000 步、200 局。

| 策略 | A 终占比均值 | 标准差 | 锁到极端(>.8/<.2)的局占比 |
| -- | -- | -- | -- |
| 纯正反馈 γ=2 | .782 | .364 | **.980** |
| 20% 配额补弱 | .504 | .021 | **.000** |

**结论**：正反馈随机过程方差发散，98% 的局锁定到单一阵营，且锁定方向由早期微小涨落决定；给弱势方保留 20% 配额后零局锁死、占比稳在 .50。**闭环不会"自然趋于均衡"，只会放大初始偏差；多样性必须靠显式配额/探索机制从外部注入。**

## 方向 I・精准投毒：最小剂量、隐蔽与潜伏（E36/E37/E38）

### E36　单点毒丸的爆炸半径（对比同数量随机注水）

只注入 k 条记忆。*精准毒丸*注册受害主题全部 8 个专属词、互链、imp=10；对照*随机注水*只挂泛词。

| k | 闸门关：受害主题 / 跨主题误伤 / 随机注水对照 | 闸门开：受害主题 / 跨主题误伤 / 随机注水对照 |
| -- | -- | -- |
| 1 | .20 / .20 / .20 | .20 / 0 / 0 |
| 2 | .40 / .40 / .40 | .40 / 0 / 0 |
| 4 | .80 / .80 / .792 | .80 / 0 / 0 |
| 8 | 1.0 / 1.0 / .907 | **1.0 / 0 / 0** |

**结论（两层）**：闸门关时，高 imp 毒丸零命中也无差别霸榜，目标与误伤同值，随机注水靠刷 imp 同样得逞——此时攻击没有"精准"可言；**闸门一开，随机注水与跨主题误伤全部归零，却挡不住精准注册目标词面的毒丸（目标主题仍 100%）**。filter_zero 把攻击从"无差别"逼成"精准"，但精准词面攻击恰是它的盲区，**最小致命剂量仅 1–2 条**（对应 MINJA 的 query-only 低剂量注入）。

### E37　词表劫持：不刷分，只占词

更隐蔽的攻击：importance 诚实填 5（不刷分），只把一个主题的全部专属词注册进自己 keywords。

- 劫持条占目标主题 **top1 = .875、进 top5 = 1.0**；而一条普通条目凭先验占 top1 的概率仅 **.062**（14 倍杠杆）。

**结论**：filter_zero 只滤零命中，而劫持条词命中最高、反而最不可能被滤。**攻击者不需要碰任何"可信度字段"，只要在词面维度占满一个语义主题的专属词，就能截胡该主题**——这是 E24 关键词堆砌的单条、不刷分版本，证明风险根植于词面排序本身。

### E38　潜伏记忆的不可能三角（本轮最精巧的否定性结果）

理想的 sleeper 要同时满足：① 平时对常规查询隐身；② 命中特定触发词时激活霸榜；③ 自身词面干净、躲过 E25 那类词面审计。对比三条实现路径：

| 方案 | 常规期命中率（隐身↓好） | 触发期命中率（激活↑好） | 词面审计可抓 |
| -- | -- | -- | -- |
| 显式型（触发词进自己 keywords）+ 闸门开 | 0.0 | **1.0** | **1（必抓）** |
| 图潜伏（词面干净、靠 links 桥接）+ 闸门开 | 0.0 | **0.0（废）** | 0 |
| 图潜伏 + 闸门关（出厂） | **.351（暴露）** | .701 | 0 |

**结论（第五个不可能三角）**：三性不可兼得。显式型能"隐身+100% 激活"，但触发词写在自己词面、必被词面审计抓到；把恶意藏进 links 关系虽然躲过审计，可源码的扩散分**只对"自身零命中"的目标传播**——开 filter_zero 恰好把零命中目标整条删掉，桥接通道被结构性掐灭（激活 0）；关掉闸门能激活（.70）却同步在常规查询暴露（.35），退化为无差别污染。**这反过来给了一条好消息：filter_zero 不只是质量闸门，它还是反潜伏的结构性屏障；要查图潜伏攻击，检测对象必须是 links 图结构（异常入度/桥接簇），而非词条面。**

## 方向 J・多智能体：共享记忆的传染、阈值与公地（E39/E40/E41）

### E39　一个被攻破的 agent 如何经"正常协作"传染全体

N=10 个 agent 共享一个记忆层，f 个初始被攻破；诚实 agent 一旦检索到恶意记忆，以 .6 概率把"被污染的产出"写回共享池（可二次传染，SIR 式）。

| 坏 agent | 无防护共享：终污染占比 / 被感染诚实 agent | 带源可追溯隔离：终污染 / 二次感染 |
| -- | -- | -- |
| 1/10 | .874 / **9 / 9 全感染** | .10 / **0 / 9** |
| 2/10 | .893 / 8 / 8 | .20 / 0 / 8 |
| 3/10 | .906 / 7 / 7 | .30 / 0 / 7 |

**结论**：无防护共享池里，恶意记忆经"检索→产出→再写回"滚到近 90%，**只需 1 个内鬼就能在 15 轮内感染全部 9 个诚实 agent**（对应 cross-agent contamination / shadow agent）。而给每条记忆打上来源、一旦某源出坏记忆就屏蔽该源全部，污染被钉死在初始比例、零二次传染。**多 agent 共享记忆必须带来源签名与按源隔离，"协作便利"不能以"全域信任"为代价。**

### E40　拜占庭阈值：多少坏 agent 能掀桌

10 个 agent 对候选记忆打分，f 个拜占庭给恶意条满分、好条压零；比较 mean / trimmed（去 f 高 f 低）/ median 三种聚合，看 top5 里混进几条恶意。

| f/10 | mean | trimmed | median |
| -- | -- | -- | -- |
| 0–3 | 0 | 0 | 0 |
| 4 | **1.25** | 0 | 0 |
| 5 | **5（全崩）** | **5** | **5** |

**结论**：本场景线性 mean 容忍到 f=3（30%），f=4 开始漏恶意、f=5 全崩；trimmed/median 一直守到 f=4，直到坏者占一半（f=5）才同时崩——与拜占庭理论"严格少于一半"的上界吻合。**跨 agent 汇总记忆/投票禁用裸 mean，用 trimmed-mean 或中位数，可把掀桌阈值从约三成推到接近五成；但五成是数学上界，超过则无算法可救。**

### E41　共享热预算的公地悲剧

A 个 agent 共享容量 80 的热缓存，工作集 70% 互不重叠，模拟 3000 次访问。

### E43　单条记忆的算法复杂度 DoS（含一个反直觉发现）

正常库（300 条、每条 links≤1、keywords≤4）单次检索基线约 0.6–0.7ms，构造无界字段攻击：

| 攻击构造 | 单次 rank | 相对放大 |
| -- | -- | -- |
| 30 条 links=500 | .92–1.0ms | 1.4–1.5x |
| 全库 links=500 | 约 14–17ms | **约 22–29x** |
| 30 条 keywords=2000 | .72–.74ms | 1.0–1.2x |
| 全库 keywords=1000 | .59–.69ms | 0.8–1.1x |
| 全库 links500+kw1000 | 13.4ms | 18–21x |

**结论（反直觉）**：keywords 超长几乎不花钱——Python 的子串搜索在 C 层，万词字段也只 1.1x；**真正的 DoS 面是 links 图遍历**：扩散是 Python 层对 Σlinks 的循环，全库 links=500 即把一次检索放大数十倍（多次运行约 22–29x，随机器负载波动、量级稳定），且攻击面是"多少条带无界字段"而非单条。写入侧必须设硬上限，**重点限单条 links 度数（建议 ≤32）而非 keywords 长度**。

## 方向 L・红皇后：攻防双方都在线自适应（E44/E45/E46）

### E44　攻防共演化军备竞赛：常规攻击可收敛，自证攻击无静态终点

前七轮的攻击/防御都是静态的：攻击者固定一种打法、防御者固定一套机制。E44 让双方**每一代互相适应**——攻击者在当前已开启的防御下挑残余最大的打法（ε=.15 随机试探），防御者则针对当前攻击补一个最有效的未开防御。四类攻击 × 四类静态防御的残余覆盖表由前七轮结论标定（残余 0=完全覆盖、1=无效），高级攻击「伪造 uses」第 6 代才解锁（它要求系统先具备"自己给自己记采用"的能力）。

| 代次 | g0 | g1 | g2–g5 | g6–g11 |
| --- | --- | --- | --- | --- |
| 常规攻击最大残余 | 0.91 | **0.10** | 0.10 | 0.10 |
| 伪造 uses 残余 | 1.00 | 1.00 | 1.00 | **1.00** |

12 代后四类攻击残余：imp 注水 .05、关键词堆砌 .10、互链农场 .10（三种**可被静态识别的攻击被逐个补防压到 ≤.10**），唯独**伪造 uses = 1.00——filter_zero、uses 门、词表异常检测、links 限长任意组合都覆盖不了它**。

**结论**：对"攻击特征与正确记忆可区分"的常规攻击，自适应防御能在一两代内收敛，红皇后竞赛有终点；但对「伪造 uses」这类**攻击动作与正常动作在写入侧不可区分**的自证攻击，不存在任何静态终点——它的防御不在记忆库内部，而在架构之外（采用必须由下游真实任务背书，见 E24b/E20）。军备竞赛的真正分水岭不是攻击强度，而是**可区分性**。

### E45　冷启动先发投毒：极短的独占窗口即可永久锁定

E34 证明了 uses 优先连接会滚成寡头；E45 换到**攻击视角**问：恶意记忆在库还是空的冷启动期抢先占据、独占早期采用窗口 W 轮，之后正确记忆才进场追赶，还能翻盘吗？采用按 `uses×质量` 的优先连接分配，对照四种追赶力量。

| 早期独占窗口 W | 纯优先连接 | +15% 探索 | +质量降权 .5 | 探索+质量降权 |
| --- | --- | --- | --- | --- |
| W=1 | 1.00 | 1.00 | **0.00** | **0.00** |
| W=2 | 1.00 | 1.00 | 0.875 | 0.625 |
| W=4 | 1.00 | 1.00 | 1.00 | 1.00 |
| W=8 / 16 | 1.00 | 1.00 | 1.00 | 1.00 |

（数值为恶意记忆最终仍占 top1 的"锁定率"。）

**结论（强破坏性）**：①单纯加探索**完全救不了**先发锁定——15% 的探索量被 8 条正确记忆摊薄，恶意记忆仍凭初始基数正反馈自我强化（这是一处返工，见 F17）；②唯一能翻盘的是让下游真实任务识别出恶意内容质量差、降低其再采用权重（质量降权）；③但即便如此，**早期独占窗口 W≥4 后也再翻不了盘**。先发锁定的临界窗口浅得惊人：冷启动期是记忆库最脆弱的时刻，这个窗口的准入治理（来源白名单/冷启动期人工/金标准锚定）比任何事后纠错都重要。

### E46　去重/合并被武器化：用"近重复"合法擦除正确记忆

E31 把高阈值近重复合并当作治理。E46 反过来把它当武器：攻击者构造与某条正确记忆近重复、但偷换了结论的"碰撞条目"，并刷更高 uses，诱导去重把正确记忆**合法地合并删除**。目标记忆 8 个词，攻击者保留 k 个、替换其余（Jaccard=k/(16−k)），取"刚好越过阈值"的最小 k（夹带空间最大）。

| 合并阈值 θ | 达标需保留词数 k | 普通合并擦除成功率 | 要求结论一致的安全合并 |
| --- | --- | --- | --- |
| 0.5 / 0.6 | 6 | **1.00** | 0.00 |
| 0.7 | 7 | **1.00** | 0.00 |
| 0.8 / 0.9 | 8（须逐字复制） | **0.00** | 0.00 |

**结论**：去重阈值是把双刃剑——θ≤.7 时攻击者保留六七个原词就能"合法擦除"一条正确记忆（成功率 100%，且 uses 只需略高，x1.5 与 x3 无差别）；**θ≥.8 时攻击者必须逐字复制（k=8），反而没有偷换结论的空间，擦除归零**。双保险是把合并条件从"词面近重复"升级为"近重复 **且** 结论/语义一致 + 来源可追溯"，安全合并下擦除恒为 0。任何"自动合并/自动删除"都必须保留被并条目的可回溯副本。

## 方向 M・Goodhart：把可被刷的内部指标当优化目标（E47）

### E47　代理指标博弈：四个内部 KPI 全部代理升、真实降

这是本轮最直接的奖励黑客实验（Skalse 2022：优化不完美代理 R̃ 会损害真实目标 R，且线性奖励下"不可博弈的代理"几乎不存在）。真实目标=外部金尺 recall（优化时不可见）；分别把四个**内部可观测 KPI** 当优化目标推到极致，对照真正用外部金尺爬山演化。

| 被优化的目标 | 代理分 | 真实 recall |
| --- | --- | --- |
| 基线（不优化） | 0.0 | 0.351 |
| 反思产出条数代理（全员自报 imp=10，够格取材条数占比刷满到 1.0） | 1.000 | **0.298** |
| top 平均自报 imp 代理（注水条目 imp=10，代理趋近 9.875） | 9.875 | **0.281** |
| 词表覆盖度代理（条目注册全部主题词，top5 平均词命中 2.016，看起来匹配最满） | 2.016 | **0.009** |
| 满意度代理（调大 w_imp 更信自报，top1 检索分 3.195） | 3.195 | **0.172** |
| **外部金尺真演化（对照）** | 1.0 | **0.586** ↑ |

**结论（决定性）**：四个内部代理 KPI 无一例外——**指标越优化、真实 recall 越差**，其中"词表覆盖度"最极端：注册全主题词让每次检索看起来命中最满（代理 2.016），真实 recall 却崩到 .009。唯一让真实能力同步上升的是用**优化时不可见的外部金尺**做演化（.351→.586）。这把 E15（eval 棘轮）、E42（评测泄漏）上升为一般原理：**自演化的优化目标必须来自系统无法自己书写的外部信号；任何系统内部可自填、可统计、可对其优化的 KPI，被设为目标的那一刻就开始失效（Goodhart）**。

## 方向 N・错误如何沿结构、时间与群体传播（E48/E49/E50）

### E48　级联失效：合成规则决定一个底层错误炸多大

高层反思/规律记忆由底层记忆合成，底层又被更高层引用，形成 L=6 层依赖 DAG（每层 24 节点、每节点 fan=3 个下层输入，初始 15% 污染）。一个合成节点何时被污染，取决于它对输入的信任规则。

| 结构 / 合成规则 | 最终污染节点占比 |
| --- | --- |
| 扁平 L=1（基线，p0=.15） | 0.149 |
| 深层 OR：任一引用错即错（脆弱合成） | **0.966** |
| 深层多数：≥2/3 输入错才错 | 0.002 |
| 深层 AND：全部输入错才错（鲁棒合成） | 0.000 |

**结论**：同样 15% 的底层污染，**爆炸半径完全由合成规则决定**——"只要引用了一条错误事实就采信"的 OR 式合成把污染沿 6 层放大到 96.6%（接近全库），而多数表决/交叉验证式合成把它压到接近 0。这对应 Havlin 的级联失效与负载重分配：层级越深、合成越不挑剔，单点错误越容易被层层背书成"高层规律"。**反思/合成必须是多源交叉（多数/AND），不能单链引用（OR）；高层规律要可回溯到全部底层来源**（与 E26"递归反思只锁死不放大"互补：E26 是反复加工同批材料，E48 是错误沿真实依赖边向外扩散）。

### E49　事实变更：曾经正确的旧记忆，比一直错误的更顽固

世界会变：一条记忆曾经完全正确、后来事实更新了。旧记忆凭长期积累的 uses/长期层身份，新事实 uses 从 2 开始。测新事实进入 top1 的概率（越高=更新越及时）。

| 旧记忆 uses | 朴素 | 新事件加权（近期采用 +2.5） | 版本链（旧记忆在更新时刻标记失效） |
| --- | --- | --- | --- |
| 1 / 3 | 1.00 | 1.00 | 1.00 |
| 6 | **0.00** | 1.00 | 1.00 |
| 12 | **0.00** | 0.00 | 1.00 |
| 24 | **0.00** | 0.00 | 1.00 |

**结论**：朴素排序下旧记忆 uses 到 6 就足以永久压制新事实（新事实 top1 概率归零）；"近期采用加权"只能把门槛推到 uses≈10；**唯一在任意 uses 优势下都能更新的是显式版本链——在事实更新的时刻把旧记忆标记为失效（t_invalid），而不是指望新记忆靠打分慢慢赢**。"曾经正确"是一种比"一直错误"更隐蔽的风险：它带着完整的真实使用背书，纯排序手段无法区分"被反复验证的真理"和"已过时的旧事实"，必须有外部的事实变更事件来主动作废旧版本。

### E50　多数暴政：社会影响如何把群体智慧变成群体错误

多 agent 汇聚记忆/投票时，序贯决策者能看到前人选择。21 人序贯、每人私有信号正确率 p，以概率 λ 跟随前人多数（Banerjee 羊群；Lorenz 的社会影响）。

| 场景 | 独立 λ=0 | λ=.3 | λ=.6 | λ=.9 |
| --- | --- | --- | --- | --- |
| 易任务 p=.55 | **0.686** | 0.531 | 0.492 | 0.537 |
| 难任务 p=.505 | 0.523 | 0.424 | 0.435 | 0.497 |

**结论**：与 Frey & van de Rijt 的实验一致——**看到他人选择反而让多数更常错**：易任务下集体正确率从独立的 .686 一路压到 .492（**跌破 .5 随机线**），难任务则稳定在 .5 以下且不会随序列变长自我纠正。机制是社会影响压缩了多样性（大家趋向同一答案）却没有增加独立信息。对记忆汇聚的直接推论：**多 agent 记忆聚合必须优先保留独立采样（各自先写后见、屏蔽他人计数），谨慎使用"已被 N 人采用"这类可见社会计数做排序；困难/低信噪比任务上尤其不能从众**（与 E35 回声室、E40 拜占庭共同构成"聚合不是越多越聪明"的边界）。

### E51　规模不经济：记忆不是越多越好

| --- | --- | --- | --- | --- |
| 100 | 0.408 | 0.863 | 1.000 | ~0.15 |
| 300 | 0.296 | 0.799 | 0.825 | ~0.5 |
| 1000 | 0.271 | 0.625 | 0.404 | ~1.5 |
| 3000 | 0.150 | 0.273 | 0.183 | ~5 |
| 10000 | 0.129 | 0.114 | 0.171 | ~20–30 |

**结论（反直觉）**：出厂配置下 recall **随库规模增大单调变差**（.408→.129）——大库虽然零命中份额下降（更容易碰到词），但每个主题的候选变多，零命中高 imp 注水与海量平庸条目把 gold 挤出 top5，这是"记忆过载/检索稀释"。filter_zero 在小库能救到 1.0，但**大库仍被合法候选间的竞争稀释到 .171**（治理解决"作弊"、解决不了"平庸的海洋"）。单次检索耗时在无 links 时近线性（~0.15→~25ms），真正的非线性放大器仍是 E43 的 links 图遍历。推论：库需要主动的**工作集/分层裁剪**（呼应 HOT_BUDGET、E30），无限堆记忆本身有害。

### E52　污染不可逆相变：存在一个"清洗再努力也回不来"的临界

每代清洗恢复 γ 比例的污染、同时污染以 β=.30 经二次接触扩散（E39 式），迭代到稳态，扫初始污染 p0 与清洗率 γ。

| 清洗率 γ ＼ 初始 p0 | .05 | .20 | .40 | .60 |
| --- | --- | --- | --- | --- |
| 0.10 | 0.667 | 0.667 | 0.667 | 0.667 |
| 0.20 | 0.333 | 0.333 | 0.333 | 0.333 |
| **0.30（=β 临界）** | 0.007 | 0.008 | 0.008 | 0.008 |
| 0.35 / 0.45 | 0 | 0 | 0 | 0 |

**结论（决定性，精确吻合 Di Muro 的临界恢复概率）**：存在临界清洗率 **γc=β**——γ>γc 时无论初始污染多深都能回到洁净（0）；γ<γc 时系统锁在稳态污染 1−γ/β（.667/.333），**而且终态与初始 p0 完全无关**（每行四列相同）。这意味着：①治理力度必须**强于**污染的扩散速度，弱治理（γ<β）不是"清得慢"，而是"永远清不干净"；②一旦扩散机制形成，等污染扩散开再治理和一开始就治理，终局一样——**治理要在扩散通道（二次写回）上动手，把 β 本身降到 0（E39 的按源隔离正是此理），而不是只提高事后清洗量**。

### E53　分布外泛化：权重层 OOD 鲁棒，内容层 OOD 无解（否定性结果）

我原本假设：自演化只在训练查询分布上调参，会过拟合、在新主题/新查询风格上退化。演化时只让它见前 18 个主题，测四类查询。

| --- | --- | --- |
| 同分布 | 0.306 | 0.544 |
| OOD 新查询风格（三词+泛词） | 0.389 | 0.583 |
| OOD 全新主题（演化时没用来调参） | 0.375 | 0.562 |
| 内容缺口（库里根本没有该主题记忆） | **0.000** | **0.000** |

**结论（自我推翻，见 S14）**：假设被否定——**调的是全局排序权重（w_kw/w_c/filter_zero 这类），不是查询—答案表，所以对未见主题、未见查询风格同幅泛化，没有 OOD 惩罚**（演化后三类都提升、幅度相近）。这与 E18/E42"改考题/背题"形成精确分界：**背具体内容会过拟合，调通用机制会泛化**。但最后一行划清了真正的 OOD 边界——**库里不存在的内容，权重再优也检索不到（恒 0）**：自演化的分布脆弱性不在参数层而在**内容/词表覆盖层**，参数优化替代不了持续的新内容摄入（回到 E32 的新鲜数据注入）。

逐级叠加 filter_zero→uses 门→来源配额→（再叠加 links 限/uses 硬门），同时测安全（攻击后污染份额）与效用（洁净 recall、冷启动零结果率）。

## 方向 L・合谋与身份（E56/E57）

**设计**：固定目标主题，注入 k 条"睡眠记忆"——每条只注册 per 个该主题专属词（轮流覆盖全部 8 词）、imp=6（诚实范围内）、新鲜写入，单看每一条都无害；`bridge=开` 时睡眠条间全互链（组合放大走 links 扩散通道）。对目标主题查询测 top5 睡眠污染份额与 golden 命中率；再对比三种零误报约束下的审计：A1 单条词面（同主题关键词 ≥5 才抓，因诚实条目天然 ≤4）、A2 链接度数（>4，诚实条目期望度 <1）、A3 共现同步（top5 出现集合两两 Jaccard≥0.5 的连通块，且每条单主题词 ≤2、块内并集 ≥5 才整块抓）。

## 方向 M・时滞与预警（E58/E59）

## 方向 N・词面与元性质（E60/E64）

### E60　词面鸿沟：换说法的检索天花板与词表自扩展的反噬

**设计**：为全部 160 个主题词建立确定性变体表（双字反序，与原词无碰撞）。表 1：查询以概率 p 整体换成变体说法（记忆仍用原词），测三种配置的 recall@5。表 2：查询逐词翻转 p=0.75，每轮进入 top5 的条目**被动吸收**查询词（模拟无相关性信号的检索日志扩展），错配吸收率 ω 为吸进无关主题词的概率，看 12 轮学习曲线与跨主题污染。

| p（换说法概率） | 出厂 | +filter_zero | +PRF 查询扩展 |
| --- | --- | --- | --- |
| 0 | 0.359 | 0.909 | 0.375 |

### E64　自演化的路径依赖与多峰性：48 个盆地，峰差却很温和

**设计**：固定库与查询，4 个初始 θ（出厂及扰动 w_kw∈{1,3,5}、w_age=0.5）× 4 个变异种子，跑 30 代爬山（允许翻 filter_zero），按终态参数签名聚类盆地；对照退火（σ 从 .35 线性退到 .03）与种群（4 个体截断进化）。

* 64 次运行落进 **48 个不同盆地**；**路径依赖指数 1.00**——每一个初始 θ 换变异种子都会落到 ≥2 个盆地；
* 峰间性能差温和：最优盆地 hold 1.000，最差盆地 .837（差 .163），多数盆地挤在 .88–1.00；
* 策略对比（同预算取最优）：**多起点爬山 4/4 库种子达全局最优**，退火 3/4，种群 2/4。

**结论（自我推翻 S16）**：我预期"退火/种群这类更强的搜索应该稳定胜出"。实测相反：这片景观**多峰但峰差温和**——路径依赖决定的是"你落在哪个盆地"（连变异种子都是历史事件，Arthur 式 lock-in 在参数层真实存在），而不是"性能崩不崩"；在这种温和多峰景观里，把预算拆成多次短爬山（多起点）比一次花式搜索更稳。对自演化引擎的启示是工程性的：**restart 预算是必需品**，单次长跑的终态参数不可作为"最优参数"被信任（呼应 E55：连结论都要审计种子，参数更要）。

# 补篇・第十轮：周期、长尾、分歧、漂移与反身（E61/E62/E63/E65/E66，5 个实验）

第九轮补完合谋、身份、时滞、预警、词面与演化元性质后，本轮处理所有静态实验共有的隐含假设：①主题查询频率被当成平稳的（E61 问"去而复返"）；②查询在各主题的分布被当成均匀或温和倾斜（E62 问 Zipf 长尾）；③同一问题的记忆只有一份是对的（E63 问"都正确但结论不同"）；④金尺是冻结的（E65 问"人侧合法换尺"）；⑤考题分布独立于被考系统（E66 问"考题从系统自己的输出里出"）。每个实验先锚定文献再复现机制：周期性概念漂移与上下文（Widmer & Kubat, Machine Learning 1996；Gama et al., ACM CSUR 2014 综述；循环负载缓存 LIRS，Jiang & Zhang, SIGMETRICS 2002）、流行度偏差与曝光公平（Klimashevskaia et al., UMUAI 2024 综述；Singh & Joachims, KDD 2018；Zipf 1949）、近重复检测与群体多样性（Manku et al., WWW 2007 simhash；Hong & Page, PNAS 2004；对偶 E46）、非平稳赌博机的滑窗/折扣（Garivier & Moulines, ALT 2011；对偶 E15）、反身性（Perdomo et al., ICML 2020 performative prediction；综述 Hardt, Statistical Science 2025；自食模型 MAD，Alemohammad et al. 2023，第七轮已锚）。E61/E62 的存储模型为两级：热区（预算内、可被检索命中）+ 冷档案（不可命中、靠稀缺"回读预算"按需拉取）。源码：`exp_round10.py`，8 种子均值，无计时实验、两次运行逐行一致。

## 方向 O・非平稳下的存储与公平（E61/E62）

### E61　周期性概念漂移：逐出算法之争是伪问题，回读带宽才是杠杆

**设计**：20 主题分 4 个相位组、热度按正弦去而复返（周期 P∈{20,40,80} 代）；热区预算 96/240，冷档案不可命中、每条查询可回读 probe 条；检索剥离老化项（w\_age=0.01，见 F23）。对比 LRU / LFU / 慢性层（曾达 uses≥6 的条目受保护，慢性占比超 60% 预算才让位），测总体召回、回归初期（热度上穿 0.5 后 5 代）召回、恢复代数。

| P=40 | 总体 | 回归初期 | 恢复代数 |
| --- | --- | --- | --- |
| LFU | .871 | .856 | 5.27 |
| LRU | .863 | .842 | 5.77 |
| 慢性层 | .871 | **.856** | **5.25** |

| 回读带宽（P=40, LRU） | 总体 | 回归初期 | 恢复代数 |

### E62　长尾公平：公平靠"保底席位"，不靠调逐出

**设计**：查询频率 Zipf（s=1.5，秩次随机指派）、回读预算稀缺化（每代 2 条、先到先得）、热区冷启动（初始为空）；预算 80/240。对比 LFU / LRU / 折扣 LFU（×0.97/代）与**预留席位制**（每主题其 imp−age 最优的 Q 条代表常驻热区，挤占自由预算）。

| --- | --- | --- | --- | --- |
| LFU | .578 | .723 | .530 | .294 |
| LRU | .578 | .723 | .530 | .294 |
| 折扣LFU | .578 | .723 | .530 | .294 |
| 预留Q2 | .683 | .800 | .668 | .263 |
| **预留Q3** | **.698** | .790 | **.707** | .256 |

**结论**：①流行度偏差真实存在（uses 策略下尾部比头部低 27% 相对值、基尼 .294）；②但**调逐出算法毫无用处**——三种 uses 策略逐位相同（第三次出现这种收敛：在按需拉取的世界里 recency 与 frequency 信息等价）；③**预留席位是全面胜利**：Q3 使尾部 +33% 相对值、整体 +21%，头部不降反升（.723→.790）——公平的代价是负的，直到 Q4 过度预留才开始挤压头部（.790→.703）。这与 E54"可区分时治理近乎免费"同构：**当不公平的根源是"代表权缺失"而非"能力差异"时，保底代表权是帕累托改进**。

## 方向 P・分歧与漂移的元层（E63/E65/E66）

### E63　合法多观点误合并：去重阈值的三难（E46 的对偶，第七个不可能三角）

**设计**：同一情境词（协作/分工/方法）+ 不同结论标记（甲案/乙案）的两视角记忆簇：同视角近重复词面 J=0.8–1.0、跨视角合法对 J=0.6–0.71——词面相似度**无法区分"冗余重复"与"合法分歧"**；再加一条高 uses 仿主攻击条（乙标记、J=0.8，E46 式武器化）。扫合并阈值 θ 与合并策略（朴素 Jaccard / 视角感知=跨标记禁并）。

| 策略 | θ | 跨视角合并率 | 簇内重复去除 | 攻击条清空乙主条 |
| --- | --- | --- | --- | --- |
| 朴素 | 0.5 | **.92** | 1.0 | 1.0 |
| 朴素 | 0.65 | .08 | 1.0 | 1.0 |
| 朴素 | 0.75 | 0.0 | .965 | 1.0 |
| 朴素 | 0.85 | 0.0 | **.571** | 0.0 |
| 视角感知 | 0.5–0.65 | **0.0** | 1.0 | 1.0 |
| 视角感知 | 0.7–0.8 | 0.0 | .965 | 1.0 |
| 视角感知 | 0.85 | 0.0 | .571 | 0.0 |

**结论（决定性；第七个不可能三角）**：纯词面相似度的单一阈值 θ 上，三个目标两两冲突——**去重收益**（需 θ≤0.8 才能并掉 J=0.8 的近重复）、**抗武器化**（需 θ>0.8 才不让仿主条清空真主条）、**保留合法分歧**（朴素合并需 θ>0.71 才不并掉跨视角对）：不存在同时满足三者的 θ，可行窗口收缩为刀刃上的单点且任何估计噪声都会跌破。**视角感知合并把"跨视角擦除"精确归零**（0.44–0.92 → 0.0）而簇内去重收益分毫不损，但视角内武器化仍在（E46 残余被压缩到标记内部，未被消灭）。出路与 E24/E56 一脉相承：**不是调阈值，是给合并判据引入词面之外的信息**（结论一致性/视角标记/下游背书）。

### E65　评测目标缓慢漂移：margin 是追踪杀手，陈旧参照点是余量

**设计**：600 条库、单词查询、K=3 的硬景观；金尺按 λ:0→1 从"质量优先"连续转到"新鲜优先"（人侧合法换尺，非 E15/E42 的尺子污染）。引擎每代走一步爬山，门控三种参照语义：freeze（参照=上次接受时的分）/ fresh（每代重评参照）/ slide（金尺取近 10 代期望频率），× margin {0, .02, .05}。

| 参照点 | margin | 追踪recall(后半) | 末代 | 冻结代占比 |
| --- | --- | --- | --- | --- |
| freeze | 0 | .712 | .819 | .285 |
| freeze | .02 | .673 | .773 | .818 |
| freeze | .05 | .638 | .725 | .865 |
| fresh | 0 | **.719** | .817 | .275 |
| fresh | .02 | .672 | .748 | **.917** |
| fresh | .05 | .633 | .683 | .948 |
| slide | .02 | .671 | .750 | .915 |

**结论（自我推翻 S19）**：①margin 在静态世界防噪（E17），在漂移世界是**追踪杀手**：margin=.05 使 fresh 的冻结代占比达 .948、追踪损失 .086（.719→.633）——尺子在动，"必须比参照高 5 个点"的门等于拒绝一切小步追踪；②更反直觉的是**参照点陈旧性反而是余量**：同 margin 下 freeze≥fresh（.773 vs .748）——漂移把 frozen 参照"变低"，给门控留出接受下行重置的空间；fresh 的高标准把门锁得更死。③margin=0 时三种参照语义无差别（.71+）。工程红线：漂移期要临时降 margin 或换滑窗金尺，静态世界的门控纪律不能原样带进非平稳期。

### E66　反身性闭环：没有对手，也能 Goodhart

**设计**：库与参数之外，让**考题分布也来自系统自身**——每代 1−ε 比例的考题词采自上一代 top 检索条目的词表（自考题的 expected 由考官上帝视角给出，无作弊），ε 为外生标准考题。每代在自考题上走一步爬山，同时用固定外部金尺对账。

| ε(外考占比) | 内部终值 | 外部终值 | 外部recall后半 | 背离差 |
| --- | --- | --- | --- | --- |
| 0.0 | .784 | .631 | **.498** | **.271** |
| 0.2 | .822 | .728 | .706 | .099 |
| 0.4 | .781 | .756 | .734 | .060 |
| 0.6 | .834 | .832 | .795 | .019 |
| 1.0 | .722 | .748 | .689 | −.014 |

**结论（决定性）**：①**评价参照系被自己的输出占领，就足以复现 Goodhart 式脱钩**——没有任何写入侧作弊、没有对手攻击，纯自考闭环让内部 .784 对外部 .498（背离 .271，外部能力相对损失近三成）。这与 E14（写读共演化）、E42（评测泄漏）、E47（代理博弈）拼出完整图景：**自证陷阱不需要恶意的任何一方，只需要反馈回路闭到不再采样外部世界**；②解药廉价且剂量明确：ε≥0.6 的外生考题混入即把背离压到 .019（临界区在 ε∈[0.2,0.6]）——评测分布的**外生覆盖配额**应作为自演化系统的常设护栏，这为红线 51/66 补上分布维。

# 补篇・第十一轮：前十轮自启问题的交叉验证（E70–E74，5 个实验）

预注册菜单（E67–E69）保留给世界模型扩展项；本轮五个实验全部由第九、十轮的发现自己长出来：E61 留下"回读带宽为什么在 1 条处饱和、预算该怎么花"（E70）；E62 的静态席位与 E61 的周期世界相交，问"秩次反转时席位会怎样"（E71）；E66 留下"临界混合比 ε\* 在哪、能否在线检测自考"（E72）；E56 的组合后门遇上第十轮的两级存储，问"冷档案会不会成为攻击者的免费 reservoir"（E73）；E59 的仪表盘要纳入第十轮的新故障（E74）。文献锚点：工作集模型（Denning, CACM 1968；LRU-K，O'Neil et al., SIGMOD 1993）、比例共享资源管理（Waldspurger & Weihl, lottery scheduling 1994；Demers et al., fair queueing 1989）、两样本分布检验（Gretton et al., JMLR 2012 MMD——本轮证伪了它的廉价替代品）、缓存污染攻击检测（Conti et al., Computer Networks 2013）、Scheffer 2009 与 E59 前作（复用）。源码：`exp_round11.py`，8 种子均值，无计时实验、两次运行逐行一致。

### E70　回读带宽的分配与预取：总量是杠杆，怎么花几乎不重要

**设计**：E61 的周期世界（P=40、预算 96/240），总回读预算固定 20 条/代，四种花法：perquery（每查询 1 条均撒）/ demand（仅零命中查询回读）/ burst（代末全部砸给当代最热主题）/ oracle（按需回读 + 剩余预算预取"3 代后将升起"的主题——它偷看日程，是clairvoyant 上界）。

| 分配策略 | 总体 | 回归初期 | 恢复代数 | 回读 5 代内命中率 |
| --- | --- | --- | --- | --- |
| perquery | .870 | .867 | 5.23 | .34 |
| demand | .868 | .855 | 5.49 | .36 |
| burst | **.670** | .667 | 6.06 | .00 |
| oracle | .865 | .841 | 5.72 | **.15** |

带宽细扫（每查询 pb 条）：0→.681、1→.871、2→.875、3→.879、5→.878、10→.877。

**结论（含否定性）**：①总预算固定时，均撒/按需/预言的差距 ≤.005——**分配智慧不值钱，只有"集中下注"是灾难**（.670，把 20 条全押单一主题饿死其余 19 个）；②预知日程的 oracle 命中率反而最低（.15 vs .36）：预取的条目在需求到来前就在冷库里空等，窗口内被命中比例下降——**clairvoyance 买不到第三条路**；③带宽曲线与 E61 一致：0→1 条 +.19，1→3 条 +.008 即饱和。工程结论：**回读供给按需均配即可，不要优化分配、不要押注、不要为预取支付命中率代价**。

### E71　动态席位 Q(t)：静态席位的红利以秩次稳定为前提

**设计**：E62 的 Zipf 世界叠加一次**冷热反转**（第 30 代秩次倒序）。对比 LFU / staticQ（E62 的固定预留 Q3）/ dynamicQ（席位按查询份额的指数滑动均值比例分配，EMA 半衰 8 代、总量锁定预算 80——彩票调度/比例共享思想）。

| 策略 | 整体 | 旧头部(反转前) | 旧尾部(反转前) | 旧头部(反转后) | 旧尾部(反转后) | 恢复代数 |
| --- | --- | --- | --- | --- | --- | --- |
| LFU | .767 | .766 | **.449** | .831 | .804 | 4.64 |

**结论（自我推翻 S22）**：①E62 的"预留席位免费胜利"**不能无条件推广**——秩次反转后 staticQ 的旧席位锁死旧世界：旧头部召回 .720 全场最低（席位护着已经凉了的主题），整体 .788 被 dynamicQ 反超（.821）；②但 staticQ 的保底在反转前确实救尾部（.616 vs LFU .449）、反转后恢复最快（3.90 代，旧尾部条目从未离开热区）；③比例共享动态席位两头都不差、整体最优——**席位制的正确形态是"按近期需求的滑动比例分配"，而不是一次性立法**。这是 E62 与 E61 的真正交汇点：公平机制必须带时间维。

### E72　反身临界 ε\*：剂量找到了，检测器没找到（否定性结果）

| 0.5 | .029 | .710 | .528 |

# 补篇・第十二轮：席位博弈、两级自考与偏斜定标（E75–E79，5 个实验）

第十一轮的五条线头在本轮全部接线：动态席位读需求信号，而需求信号可以被伪造（E75）；席位代表权可以被写侧注水俘获（E78）；两级存储改变了自考闭环的形状（E76）；冷层潜伏攻击的可检性补上了仪表盘的最后一块（E77）；E72 找到的临界 ε\* 需要回答"随什么变"（E79）。文献锚点：Shilling 攻击（Lam & Riedl, KDD 2004，伪造反馈操纵自适应推荐——幻影流量正是它的调度版）、算法混淆（Chaney et al., RecSys 2018，反馈环放大同质化——E79 的偏斜定标直接对应其"系统放大初始偏斜"命题）、反馈环工程实践（Gomez-Uribe & Hunt, ACM TMIS 2015 Netflix）、缓存污染检测与早期预警（Conti 2013/Scheffer 2009，复用）。源码：`exp_round12.py`，8 种子均值，无计时实验、两次运行逐行一致。

### E75　需求膨胀攻击：需求信号是自适应公平的攻击面

**设计**：E71 的 dynamicQ 与 staticQ 各自面对同一攻击——攻击者在秩 15 尾部主题写入 6 条 imp=9 新鲜条目，并每代发出 φ·n\_q 条**幻影查询**（全部指向目标主题；与真实查询在日志中不可分辨，同样计入需求 EMA、同样竞争回读预算，穿插混排）。φ∈{0,.25,.5,1.0}。

| 策略 | φ | 诚实recall | 目标污染(后半) | 目标热区占比 | 幻影回读占用率 |
| --- | --- | --- | --- | --- | --- |
| dynamicQ | 0 | .865 | .390 | .048 | 0 |
| dynamicQ | 1.0 | .859 | **.546** | **.075** | **.488** |
| staticQ | 0 | .851 | .425 | .050 | 0 |
| staticQ | 1.0 | .823 | **.547** | .075 | **.488** |

**结论**：①幻影流量以 φ=1 偷走 **49% 的回读带宽**、把目标污染从 .39/.43 抬到 .55，且**对静态与动态席位一视同仁**——因为两种席位制读的是同一份查询日志，E71 的"动态优于静态"在博弈层不成立：需求信号本身是共同攻击面；②诚实召回几乎不动（.82–.87，攻击只占 1/20 主题）——损害是局部的、安静的、且完全混在正常流量里。防御必须落在**查询来源认证/速率限制**（需求侧），换席位算法无用（承接 shilling 攻击文献的核心命题：伪造反馈无法被聚合算法消化）。

### E76　两级存储下的自考脱钩：强制翻台是天然解药（假设反向）

**设计**：E66 的纯自考闭环（ε=0）装进两级存储：考题只考热区、每条考题按需回读冷区 1 条、LFU 逐出。热区预算 {240（=单层对照）, 96, 48}，外部金尺对账。

| 热区预算 | 外部recall前1/4 | 后1/4 | 末代 | 热区主题覆盖 |
| --- | --- | --- | --- | --- |
| 48 | .420 | **.770** | .769 | 16.6 |
| 96 | .397 | .727 | .774 | 19.8 |
| 240（单层） | .397 | **.620** | .661 | 20 |

**结论（决定性，自我推翻 S23）**：假设完全反向——我以为冷层 reservoir 会让自考闭环把系统喂得更傻（E32/MAD 的直觉），实测**检索面越小、自考脱钩越轻**：预算压到 1/5，外部召回从 .62 升到 .77。机理：小热区的高翻台率强迫考题词池每代换新（回读持续注入冷层词汇），自证回路**锁不下来**；单层全检索面则让词池凝固、闭环闭合。与 E32"必须持续注入新鲜数据"互为镜像：**这里连"新鲜数据"都不用买——把检索面饿小，系统自己会去冷层找**。检索面预算是反身性的隐藏旋钮。

**设计**：E74 仪表盘补上 E73 的冷层潜伏故障（coldsleeper：睡眠条注冷档案），与 hotsleeper 对照，按代配对阈值测七指标。

### E79　ε\* 的偏斜定标：均匀库的剂量不可移植

**设计**：把库向单一主题集中（skew=1/2/3，主题 0 占比 1/20 → 3/20、6/20），E66 闭环扫 ε∈{0,.2,.4,.6,1.0}；每代测**词池偏斜 B**（考题词池主题分布对均匀的 KL 散度）与背离差 D，检验"D 随 (1−ε)·B 塌缩"与 ε\*(skew)。

| skew | B(ε=0) | D(ε=0) | ε\*（首个 D<.05） |
| --- | --- | --- | --- |
| 1 | 1.464 | .131 | 0.4 |
| 2 | 1.750 | .185 | 0.4 |
| 3 | 2.254 | **.173@ε=.4 仍在** | **0.6** |

**结论**：①词池偏斜 B 随库偏斜**单调上升**（1.46→1.75→2.25）——算法混淆机制（Chaney 2018）在本世界成立：自考词池继承并放大库的偏斜；②**ε\* 随偏斜上移**：skew=1/2 时 0.4 够用，skew=3 时 ε=0.4 的 D 仍高达 .095、须 ε=0.6——E72 的"ε=0.5–0.6"是均匀库剂量，**偏斜库必须重新标定**；③D 对 (1−ε)·B 的塌缩近似成立但不严格（ε=0.6 处多个 skew 已降到 0 以下）——定量定律不成立，定性定标规则成立。工程含义：**外生覆盖配额不能全局恒定，要按词池偏斜（可在线计算）分库设定**。







# 第四部分・实验设计失败与自我推翻（诚实记录）

## 三十二次设计返工



1. **F1（E3c）**：初版假设 links 扩散有正常收益，结果在词面重叠世界 d=0/0.5 都是 0.414、零差异，一度以为代码写错。补造「词面互补真相关对」后才界定：扩散只在「真相关条目词面缺失」时有用（0.275→0.750），而该前提与农场攻击入口完全重合。

2. **F2（E7b）**：初版用「同主题查询 top1 占比」测错误持久化，窄词条 / 广词条都饱和在 0.917，区分不出。改为枚举主题词全部 28 个两两组合、测「查询覆盖面」后，才得到 0.786 vs 1.000。

3. **F3（E10）**：初版期望动态出仓显著降低漏放，连续调了三版判据（放宽 / 收紧），漏放最多降 0.002 且误杀必升。最终承认这是否定性结果，转为「下游只沿误杀 — 漏放前沿滑动」的结论。

4. **F4（E14）**：第一版在演化循环外「重放攻击」来估污染，导致三条件污染被算成相同值。重构为在单次运行内部同时返回 holdout 轨迹与真实末态污染，对比才成立。

5. **F5（E17a）**：初版奔着「小 golden 严重过拟合」设计，gap 却只有 0.01–0.04。没有硬凑出预期，而是把过拟合列为否定性结果，转而用 E17b 证明真正的约束是评测噪声。

6. **F6（E18，三版）**：第一版每代「调参 / 改题二选一」，结果 (b) 调参不足反而更低；第二版「择优」但词袋世界检索器本就 0.95、作弊空间太小；第三版改用困难世界 + 「改题兜底导致参数失梯度随机漂移」的正确动力学，才得到训练 1.000 / 隐藏 0.872。

7. **F7（世界模型自检）**：D1 探针里 importance=999 直接产生 996.5 的分数，反向确认了「validate 不校验范围」正是一切注水的代码级根因 —— 这不是实验失败，但是在写探针时才确认「无界自报」必须作为世界模型的一等事实。

8. **F8（E11）**：逐出后「相对召回」出现 1.6–1.8（>1），初看像分母算错。逐项核对后确认是「逐出低价值条目减少 top5 竞争」的真实去噪副作用，保留数值并把指标正名为「相对全库的召回比」。

9. **F9（E22，两版）**：第一版滚动演化误用旧世界训练集，导致「一次演化」与「滚动演化」结果完全相同；修正训练流后又发现加性权重下新旧正和、根本不遗忘，于是补 E22b（仍正和）再补 E22c（零和旋钮），用三连实验才界定「灾难性遗忘的成立条件是参数层真实冲突」。

10. **F10（E24/E24b 拆分）**：第一版把「伪造 uses」混在检索 top5 重排里测，结果被前置的 filter\_zero 挡掉、看不到行为信号被击穿；拆出 E24b 放到「取材」场景（伪造 uses 直接决定 top6），才得到 0.125→1.000 的决定性对比。

11. **F11（E26，两版）**：第一版合成条目挤不进下一轮 top6，五代结果恒定、看不到递归；第二版让历史合成物优先回流并逐层累积，才呈现「低质锁死 vs 良性上行」，同时诚实记录「污染并未逐级爆炸」这一与预期不同的细节。

| **行层**  | 记忆条目及其自报字段（importance/links/t\_invalid）、uses 行为计数、索引 / 缓存 | 自由写入 | **自报字段不直接决定采纳；采纳由 uses 等可观测行为背书**    | 自由写入      |

**方向性约束**：变更只能向上申请、不能向下修改。法层永远改不了元层 ——**引擎无法修改评判自己的尺子，也无法靠自报字段给自己投票。**

## 5.2 自演化循环（写入 — 评测 — 晋升）



```
写入条目（自报字段仅作弱先验；uses 从 0 起由未来真实采用累积）

&#x20;  ↓

变异法层参数 →【廉价筛选：零命中过滤/铁律/白名单，只能 reject】→ 幸存者

&#x20;  ↓

【影子评测】在冻结 golden + 隐藏留出集上配对比较，Δrecall > 噪声 margin（n=40 时≈0.085）

&#x20;  ↓

【晋升】训练集与隐藏集同向提升才采纳；基线只升不降；记账+审计链+刷根

&#x20;  ↓

旁路① 锚定审计：周期性用锚定样本查「指标 vs 库健康（污染率/纯度/取材坏率）」是否脱钩，脱钩即冻结

旁路② golden 轮换（被消耗的燃料）+ 永不参与训练的隐藏集

旁路③ 全生命周期 uses 换轨：检索候选/反思取材/长期分层/缓存逐出统一以可观测行为为主键
```

## 5.4 二十五条红线 + 第六轮增补十二条 + 第七轮增补十条 + 第八轮增补八条 + 第九轮增补七条 + 第十轮增补五条 + 第十一轮增补五条 + 第十二轮增补五条

**元层与权力边界**



1. golden、铁律、安全开关（filter\_zero 等）属于元层，引擎只读不可改，只收 pass/fail（E18）

2. 引擎能改自己的参数，但永远不能改「评判参数好坏」的规则与数据（E18）

3. 标准答案禁止由引擎当前输出反填；训练分 = 1.0 而隐藏集不升，按作弊论处（E18）

4. 任何自动采纳必须可回滚、可在审计链还原（铁律 1/4）

5. 能力声明不得强于实际能力：改不动行为的参数不得宣称「自适应」（公理 G，E16）

**信号与自报字段**

6\. **自报字段（importance/links/t\_invalid）不得单独决定「是否被采纳 / 长期保留 / 反思取材 / 缓存保留」**（E1/E6/E9/E11）

7\. 排序、取材、分层、逐出的主键优先用系统可观测、写入时无法伪造的行为（uses / 真实采用）（E6/E11）

8\. 对抗自报操纵靠「换信号种类」，不靠「拧紧同一信号阈值」—— 恒报上限者不受阈值影响（E9）

9\. importance 写入前做 0..10 int 范围 / 类型校验，拒绝越界（D1）

10\. links 扩散只能作用于通过零命中过滤的候选，且须有来源可信度约束（E3）

**检索与评测门控**

11\. 零词命中条目不进候选（filter\_zero 默认开）—— 先关候选门，再谈调权重（E1）

12\. 禁止全局线性年龄减分；时效衰减只对时效型条目、且系数与语义分量纲匹配（E2）

13\. 中文检索必须先分词或 n-gram，否则上层调参无意义（E4）

14\. 基线是「历史最佳签收线」只升不降，劣化结果另存、绝回写为新基线（E15）

15\. 一次「提升」必须超过评测噪声 margin（n=40 时≈0.085），否则视为平局、需更多题或配对（E17b）

16\. golden 是被消耗的燃料，须轮换；对外结论以引擎不可见的隐藏集为准（E17/E18）

17\. 法层晋升须训练集与隐藏集**同向**提升，单集提升不采纳（E13/E14）

18\. 可演化参数先过行为指纹 A/B：扰动后行为不变即逐出搜索空间（E16）

**反思与抽象层**

19\. 反思取材是全库最干净入口：坏素材率必须显著低于行层，宁少勿滥（E6）

20\. 反思触发节奏不得由自报 importance 单独决定，需混入行为密度信号（E5）

21\. 高层合成规律入长期层前，须标注依据条目；错误高层规律的召回面更广，纠错优先级高于原始条目（E7）

**生命周期**

22\. 准入质量不可由下游出仓补偿；t\_invalid 判定质量是杠杆点，出仓只沿误杀 — 漏放前沿滑动（E10）

23\. 缓存「热度」用真实访问频率定义，不用自报重要度；热预算激活前先定逐出策略再定数值（E11）

24\. 约 500–1000 条以上启用倒排检索与增量 / 挂根 Merkle，避免每查询全扫、每写全量 O (N²)（E12）

**治理与可见性**

25\. 同时监控「指标健康」与「库健康（污染率 / 长期层纯度 / 取材坏率）」；二者脱钩即冻结自演化并报警 —— 失败往往发生在指标全绿时（E14/E19）

**第六轮增补（E20–E31）**

26\. **行为信号（uses）必须由下游真实任务事件写入，记忆模块不得自证「被采用」**；一旦采用记录可被写入方自导自演，行为背书退化为第二个自报字段（E24b）

27\. 行为信号是**序数**信号：反馈稀疏（覆盖低至 10%）、有加性流行度噪声都可容忍，但「可伪造」零容忍（E20/E24b）

28\. 不把自报 importance 混进行为决策键当「冷启动先验」（融合越掺越差）；冷启动靠低权重探索期显式曝光解决（E21）

29\. 法层优先设计成**可叠加的独立加性维度**，避免「此消彼长」的零和归一化旋钮；若必须引入，要为旧世界保留不参与在线更新的锚定评测（E22c）

30\. filter\_zero 在极小库配「滤空则回退不过滤」兜底；规模 ≥50 后无此问题（E23）

31\. 零命中过滤之外必须叠加**关键词异常度检测**，堵关键词堆砌盲区；结构检测用多特征组合、保持低误伤、只标记待审，不替代元层锁定（E24/E25）

32\. 「自报 - 行为背离」类检测特征，只在行为信号未被同步伪造时有效；检测层不得假设攻击者不碰 uses（E25/E24b）

33\. 搜索预算优先探索离散**结构开关**（如 filter\_zero），结构定型后再做连续精调，不要一开始把全部旋钮丢给优化器（E28）

34\. golden 清洁度是元层资产、独立抽检；当训练分异常低且怎么演化都上不去时，先查标注污染而非加参数（E29）

35\. 热度 /uses 要可遗忘过时的热：加时间衰减或定期重估，纯累计频率在工作集切换时是负债（LFU 从最优变最差）（E30）

36\. 反思由**增量内容**触发，不对静态库空转；高层规律入长期层必须可回溯到原始证据条目（E26/E27）

37\. 近重复用**高阈值**合并（宁漏并勿错并，错并不可逆），保留 uses 最高的副本，以守住检索证据多样性（E31）

**第七轮增补（E32–E43，破坏性边界）**

38\. 自演化记忆库必须有**外部真实数据的持续注入率**：替换式自食 10 代即使无攻击也会主题塌半、质量方差缩到 1/20（MAD）；只囤旧数据不够，新鲜真实数据要进得了取材入口（E32/S12）

39\. 必须保留一个**被评测对象无法回写的外部金尺**并定期对表：内部尺会在自食闭环里维持虚高、外部能力可同时崩到 .04（E33）

40\. 可信行为信号也**不得独占排序**：uses 优先连接会滚成记忆寡头（基尼 .50、长尾窒息），检索要叠加 ε-探索或多样性配额（E34/E35）

41\. 正反馈闭环（检索→写回→再检索）必须配**弱势配额/探索**，否则 55:45 的初始偏差 98% 会被锁成极端；闭环不会自发均衡（E35）

42\. filter\_zero 挡得住随机注水与跨主题误伤，**挡不住精准注册词面的毒丸（1–2 条即可霸占一个主题）**；准入侧要限单条目注册某主题专属词的比例（词表劫持检测）（E36/E37）

43\. 「躲词面审计 × 平时隐身 × 触发激活」三性不可兼得；filter\_zero 是反潜伏的结构性屏障，查图潜伏攻击要检测**异常 links 入度/桥接簇**而非词条面（E38）

44\. 多 agent 共享记忆必须**带来源签名 + 按源隔离/信誉屏蔽**：无防护时 1 个内鬼 15 轮可感染全体；一旦某源出坏记忆即屏蔽该源全部，可把污染钉死在初始比例（E39）

45\. 跨 agent 聚合记忆/投票**禁用裸 mean**（约三成坏者即漏毒），用 trimmed-mean/中位数可把容忍度推到「严格少于一半」；坏者过半是数学上界、无算法可救（E40）

46\. 共享热缓存/预算要**按来源配额分区**：agent 越多、工作集越不重叠，无协调 LFU 命中从 .91 崩到 .50 且公平度恶化（E41）

47\. 写入侧对**单条 links 度数设硬上限（建议 ≤32）**——复杂度 DoS 的真实面是 Python 层 links 图遍历（全库 links=500 放大约 25 倍量级），而非 keywords 长度（C 层子串搜索近乎免费）（E43）

**第八轮增补（E44–E55，对抗动力学与韧性）**

48\. **自证类攻击没有静态防御终点**：注水/堆砌/农场这类与正确记忆可区分的攻击，自适应补防一两代即可压到残余 ≤.10；但「伪造 uses」这类写入侧无法区分正常与否的攻击，任何静态防御组合残余恒 1.00，只能靠下游真实任务在架构外背书（E44，承接 E24b）。
49\. **冷启动是最脆弱的窗口，且锁定近乎不可逆**：恶意记忆只要在空库期独占约 4 个采用窗口，后期靠加量、随机探索都翻不了盘；唯一解是下游识别质量差 + 冷启动期的来源白名单/金标准锚定，事后纠错不如入口治理（E45）。
50\. **任何自动合并/自动删除都必须"近重复且结论一致 + 可回溯"**：词面相似度阈值 ≤.7 会被近重复碰撞当武器"合法擦除"正确记忆（成功率 100%），阈值 ≥.8 才让攻击者必须逐字复制、失去夹带空间；被并条目保留可恢复副本（E46，承接 E31）。
51\. **自演化的优化目标只能来自系统无法自填的外部信号**：反思条数、自报 imp、词表覆盖度、检索满意度这些内部 KPI 一旦被当成优化目标，全部代理升、真实降（词表全注册把 recall 打到 .009）；唯外部金尺同步提升（E47，Goodhart/Skalse，总括 E15/E42）。
52\. **高层合成必须多源交叉、禁止单链引用**：同样 15% 底层污染，OR 式（任一引用错即采信）6 层放大到 .966，多数/AND 式压到 ≈0；高层规律要可回溯到全部底层来源（E48）。
53\. **事实更新靠显式版本链作废旧记忆，不靠新记忆打分赢**：曾经正确的旧 uses 记忆到一定优势就永久压制新事实，近期加权只能延缓；必须由外部事实变更事件把旧版本标记失效（E49）。
54\. **治理力度必须强于污染扩散速度，且优先切断扩散通道**：清洗恢复率存在临界 γc=β，弱于扩散则永远清不干净、终态与初始污染无关；与其提高事后清洗量，不如用按源隔离把二次写回（β）降到 0（E52，承接 E39）。多 agent 聚合默认独立采样、屏蔽可见社会计数，困难任务不从众（E50）。
55\. **结论要过种子方向审计、库要主动裁剪规模**：标"决定性"的结论必须在 ≥32 种子上方向一致、最不利种子也不跨 0（E55）；记忆并非越多越好，出厂召回随 N 增大单调下降，须靠分层/工作集裁剪对抗检索稀释（E51）；权重级演化对词面 OOD 鲁棒、但内容缺口参数救不了，持续新内容摄入不可替代（E53）。

**第九轮增补（E56/E57/E58/E59/E60/E64，合谋、身份、时滞、预警、词面、元性质）**

56\. **单条不可能三角不能外推到多条，反潜伏必须加共现/子图审计**：k 条各自词面干净、imp 诚实的记忆靠互链桥合谋，k=8 即可把 top5 污染打到 1.000、golden 命中清零；filter\_zero 只砍扩散骑手（1.0→.400，k=16 残留 .768）。审计要叠加：A3 共现同步指纹（top5 出现集合两两 Jaccard≥.5 的连通块 + 单条薄词面 + 块内并集覆盖，k=8 TPR .812 / FPR 0）与链接度数上限（k≥5 团全抓）（E56，承接 E38）。

57\. **对"多条目联合注册同一主题词表"设子图级配额**：每条 3–4 个同主题词的中等厚度合谋是零误报审计的公共盲区（诚实条目天然 ≤4 词 → 单条词面阈值 ≥5 抓不到；共现审计成员条件 ≤2 排除它），而其污染高达 .83–.89；词表预算必须按"主题 × 关联条目群"计，不能只按单条计（E56）。

58\. **身份是来源治理的地基，必须由系统外背书**：女巫可批量造身份时，单票不达阈（8.5<9）即可叠过聚合阈——median 恰在 f=.5 跳变全破、trimmed f=.60、mean f≈.67；压好条姿态下 median f=.44 已半失守。唯一防线是把造身份成本抬过锐利阈值（κ≥3 全守住、κ≤2 全线崩，B=30 预算相图）；身份数量要靠 PoW/押金/信誉年龄锚定（E57，承接 E39/E40/Douceur 2002）。

59\. **治理预算按"延迟×暴露"计，不按"最终能否恢复"计**：临界强度 γc=β 与检测延迟无关，但延迟把峰值从 .17 线性放大到 .98、累计暴露同步上涨；γ>β 的事后清洗配有限窗口（哪怕治 40 代）停手必复发到 1.00。持久净化只有两条路：无限期治理，或实时阻断把有效扩散 β(1−ε) 压到清洗率之下（γc(ε)=β(1−ε)）（E58，承接 E52）。

60\. **健康监控最小指标集 = {自产占比, uses 基尼, 注水占比, 堆砌占比}**：四个可见字段指标对自食/马太/堆砌/传染/Goodhart 五类故障零误报全覆盖（首报 0–1.6 代，内鬼型传染最迟 9.9 代）；探针—隐藏剪刀差只在评测泄漏型作弊中有效，内容层故障不响；指标各自对应一条既有红线机理，监控清单可工程化落地（E59，Scheffer 2009 早期预警）。

61\. **词表扩展必须配单条词表预算与错配监控**：查询换说法使纯词面 recall 掉 60%（.359→.145），filter\_zero 在 p=1 反而把系统清零（0.0）——治理开关的前提是查询与记忆共享词表；检索日志驱动的词表自扩展能学回约一半（.22→.34）却同时喂养堆砌怪（top1 词数涨到 11.9 撞上限）、错配吸收率越高收益越薄；PRF 式查询扩展近乎无效（E60，Furnas 1987/Xu & Croft 1996，承接 E24）。

62\. **自演化必须保留 restart 预算，单次演化终态不可信**：同库同目标下 64 次演化落进 48 个盆地、路径依赖指数 1.00（变异种子即历史事件）；峰间差温和（最差 .837 vs 最优 1.000）说明风险是"落在次优盆地"而非"崩溃"；同预算下多起点爬山 4/4 达全局最优 > 退火 3/4 > 种群 2/4——朴素多起点优于花式搜索（E64，Kauffman & Levin 1987/Arthur 1989，承接 E55）。

**第十轮增补（E61/E62/E63/E65/E66，周期、长尾、分歧、漂移、反身）**

63\. **两级存储下先扩回读供给，再谈替换算法**：周期负载下 LRU/LFU/慢性层总召回差距 ≤.011（慢性层≥LFU>LRU），而冷档案回读带宽 0→1 条/查询使总召回 .669→.863（1→3 仅 +.012 即饱和）——供给通道的效应比算法选择大一个数量级；逐出算法之争在按需拉取世界里接近伪问题（E61，承接 LIRS/周期负载文献）。

64\. **长尾公平靠预留席位，不靠调逐出**：Zipf 偏斜+稀缺回读预算下三种 uses 策略逐位相同（尾部 .530 vs 头部 .723）；每主题保底 Q 条代表常驻热区使尾部 +33%、整体 +21%（Q3 拐点）、头部不降反升，Q4 过度预留才开始挤压头部——当不公平源于代表权缺失而非能力差异时，公平是帕累托改进；"低于 Q 不逐出"式保护对从未进热区的主题无效（E62，承接流行度偏差/曝光公平）。

65\. **合并判据必须携带结论/视角信号，纯词面阈值无稳健工作点**：单一 θ 三难——θ≤0.65 跨视角合法分歧被误并（44–92%）、θ≤0.8 高仿攻击条清空真主条、θ≥0.85 去重收益塌到 .571；视角感知合并（跨标记禁并）把跨视角擦除精确归零且不损去重收益，但视角内武器化仍在——出路是引入词面之外的信息，与 uses 换轨同构（E63，对偶 E46，承接 simhash/多样性文献）。

66\. **漂移期必须临时放宽静态门控纪律**：金尺连续换尺时 margin 是追踪杀手（margin=.05 使 fresh 冻结占比 .948、追踪损失 .086），margin=0 时三种参照语义无差别（.71+）；且"陈旧参照点"反而给门控留出下行重置空间（freeze 末代 .773 > fresh .748）——静态世界的防噪纪律不能原样带进非平稳期，漂移期降 margin 或换滑窗金尺（E65，对偶 E15/E17，承接滑窗 UCB）。

67\. **评测分布必须保外生覆盖配额**：考题从自身 top 记忆词表采样（零作弊、零对手）即复现 Goodhart 脱钩——内部 .784 vs 外部 .498、背离 .271；外生考题混入 ε≥0.6 把背离压到 .019（临界区 ε∈[0.2,0.6]）。自证陷阱不需要恶意方，只需要反馈回路闭到不再采样外部世界；给评测分布定外生比例是常设护栏（E66，performative prediction，总括 E14/E42/E47）。

**第十一轮增补（E70–E74，自启问题交叉验证）**

68\. **回读供给按需均配，忌优化分配、忌押注**：总预算固定时均撒/按需/预言的召回差距 ≤.005，而"集中下注"（全押单一主题）崩 .20；预知日程的预言者命中率反而最低（预取条目在需求前空等）——供给量是杠杆（0→1 条 +.19、之后饱和），分配技巧不是（E70，Denning 1968/LRU-K）。

69\. **席位制必须带时间维**：秩次反转下静态预留席位锁死旧秩次（旧头部 .720 全场最低），而它反转前确实是救尾部的免费胜利（E62）——按近期需求滑动比例分配的动态席位两头兼顾（整体 .821 最优）；公平机制的形式依赖需求稳定性，需求会反转的世界必须动态化（E71，承接比例共享调度）。

70\. **外生覆盖配额的剂量是 ε=0.5–0.6**：自考闭环背离在 ε=0.5 即压到 .029、ε≤0.3 仍损失 ≥13%、ε≥0.8 无损——红线 67 的剂量化；ε\* 临界区 [0.4,0.6]（E72，承接 E66）。

71\. **查询日志不是免费的作弊检测器**：主题熵不判别自考、词对重复率反向（纯外生 .870 最高）；词面封闭世界里两金尺之间没有免费的在线检测，脱钩只能靠外生对账或常开高配比兜底——任何"从系统自身日志推断自身健康"的方案都要先过指纹判别性这一关（E72，否定性）。

72\. **两级存储的接缝是新的攻击面**：组合后门潜伏冷档案零成本越冬（热区滞留 87% 仍存活），回读通道把它免费运进热区（污染 1.0、目标 golden 清零、带宽窃取 6%）；审计与逐出都不覆盖冷层——回读要按主题分散预算、对"回读即霸榜"设观察期、审计范围必须含冷层（E73，承接缓存污染攻击检测）。

**第十二轮增补（E75–E79，席位博弈、两级自考、偏斜定标）**

73\. **需求信号是自适应公平的攻击面**：与真实查询日志不可分辨的幻影流量（φ=1，占流量一半）同时打击静态与动态席位——偷走 49% 回读带宽、目标污染 .39→.55，诚实召回几乎不动（损害局部且安静）；席位算法选型不防需求膨胀，防御在查询来源认证与速率限制（E75，承接 shilling 攻击）。

74\. **席位代表权要行为门 + 冷启动豁免**：纯写侧 imp 注水（6 条零使用条目）即可俘获代表权，把目标 golden 命中压到 .125–.15；代表遴选加 uses 门拉回 2.6–3.4 倍，但零使用的新诚实条目代表性同时归 0（冷启动税）——行为门必须配观察期豁免配额，否则防了注水伤了新血（E78，承接 E9/E21/E45）。

75\. **检索面预算是反身性的隐藏旋钮**：自考闭环在全量检索面下外部召回 .397→.62（脱钩），检索面压到 1/5 反而 .420→.770（脱钩消失）——高翻台率持续刷新考题词池、自证回路锁不下来；治理"自我反馈"不一定要买新鲜数据，饿大检索面也能逼系统自己翻台（E76，反向结论 S23）。

76\. **冷层潜伏以 1.3 代检出延迟为代价、终局不变**：I11/I12 对冷层睡眠条照样零误报检出（5.2 代 vs 直注 3.9 代）——审计覆盖冷层消除的是检测延迟；I13 回读浪费在按需拉取世界天然饱和、无判别力，从指标集退役（E77，承接 E73）。

77\. **外生覆盖配额必须随库偏斜在线重标定**：自考词池的偏斜继承并放大库的偏斜（KL 1.46→1.75→2.25 单调），强偏斜（3×）时 ε* 从 0.4 上移 0.6——均匀库标定的"ε=0.5–0.6 常开剂量"在偏斜库下不足；词池偏斜可在线计算，配额应随其分库设定（E79，承接 algorithmic confounding）。

# 第六部分・结论

## 6.1 关于记忆库自演化的可行性

**可行，但它不是「把权重调到最优」的优化问题，而是「把权力放对层」的治理问题。**

正面证据是实在的：静态世界里自演化用几十次评估，自动找到了我靠整轮机制分析才定位的 filter\_zero（5/6 种子），自主把 w\_age 从 0.1 压到正确的 0.018，留出集同步提升、还能从劣化状态自愈（E13）。这说明「变异 — 评测 — 门控」的自演化循环在记忆库场景确实能自我改进。

但全部前提可以归并为三条：



1. **决策信号可观测、不可自报伪造**（uses 行为背书，而非 importance/links 自填）。第六轮进一步钉死它的边界：uses 对反馈稀疏、流行度噪声极鲁棒（覆盖 10% 仍有效，E20），但**它的抗操纵性只来自「写入瞬间伪造不了未来的采用」—— 采用必须由下游真实任务事件背书，一旦记忆模块能自证 uses，立刻退化为第二个自报字段（E24b 坏率 0.125→1.000）**；

2. **评判尺子冻结在引擎碰不到的元层**（golden / 铁律 / 安全开关人侧签名，基线只升不降；尺子被动脏了也会把优化带偏，E29）；

3. **同时度量指标与库健康**（防止 E14 的「全绿中腐烂」），并承认没有单一闸门 ——filter\_zero 堵不住关键词堆砌、结构检测在行为信号被伪造时失效，治理必须纵深叠加（E24/E25）。

4. **持续注入新鲜外部数据、在取材入口保留探索、多 agent 记忆按源隔离**（第七轮）：无攻击时替换式自食也会在 10 代内主题塌半、质量方差缩到 1/20（E32），可信的 uses 若独占排序会滚成记忆寡头（E34）、正反馈会把轻微偏差锁成极端（E35）；一旦多个 agent 共享记忆，1 个内鬼即可经正常协作感染全体（E39）。自演化系统不是封闭自循环，它必须永远向真实世界与其他可信来源开放，并为这份开放做来源治理。

5. **优化目标外部化、治理强于扩散、合成多源交叉、冷启动特殊保护**（第八轮）：系统内部可自填/可统计的 KPI 一旦被当优化目标必然 Goodhart（E47），自演化目标只能来自外部金尺；污染治理的恢复力度必须强于其扩散速度、且优先切断二次写回通道，弱于扩散则锁死且与初始程度无关（E52）；高层规律只能多源交叉合成、不能单链引用（E48）；冷启动期的先发锁定近乎不可逆，必须在入口而非事后治理（E45）。最后 E55 用 32 种子证明上述关键结论方向 100% 可复现，不是随机种子的运气。

## 6.2 七个不可能三角



* **自报便利 × 抗操纵 × 排序权重**：一个字段若写入方可自由填写、又高权重参与决策，就必然被操纵；三者只能取其二。bootstrap 的解法是保留自报便利、把决策权重移给 uses。

* **检索新鲜度 × 经典留存 × 统一年龄项**：全局线性 age 惩罚必然用经典知识换新知（经典召回 0.000）；要兼得，必须让年龄项随条目时效类型分化，而不是一条公式管全库。

* **自主演化 × 评测自洽 × 元层可达**：引擎若能触及评测标准答案，训练满分与真实能力必然脱钩（E18）；自主性与「尺子归引擎所有」不可兼得，尺子必须在引擎之外。

* **行为可信 × 采用可自证 × 写入侧自主**（第六轮）：要让 uses 成为可信排序键，「采用」就不能由被排序的写入侧自己声明；记忆库若能自己给自己记「被采用」，行为信号与自报字段同流。采用的书写权必须在下游真实任务手里（E20/E24b）。

* **躲词面审计 × 平时隐身 × 触发即激活**（第七轮）：一条恶意记忆想同时做到词面干净（躲过关键词审计）、常规查询不可见、命中特定触发词才霸榜，三者不可兼得。把触发词写进词面能隐身+精准激活却必被词面审计抓；藏进 links 图能躲审计，可扩散只对零命中目标生效，开 filter\_zero 正好掐断、关 filter\_zero 则退化为全局暴露（E38）。推论：反潜伏要同时靠 filter\_zero 这道结构屏障和 links 图结构检测。

* **完全内部自治 × 静态防御全覆盖 × 写入侧自主**（第八轮）：想只靠系统内部的静态规则挡住一切攻击、又允许写入侧不经下游背书自主写记忆，就挡不住与正常行为在写入侧不可区分的自证攻击（伪造 uses 残余恒 1.00，E44）；冷启动期的先发锁定同样无法靠内部探索/加量翻盘（E45）。三者只能取其二：要"全覆盖"就必须让渡一部分自治，把采用背书、冷启动锚定、事实作废放到下游真实任务/人侧元层（E44/E45/E49）。

* **去重收益 × 抗武器化 × 保留合法分歧**（第十轮）：纯词面相似度的单一合并阈值 θ 上三者两两冲突——去重收益要求 θ≤0.8（近重复 J=0.8）、抗武器化要求 θ>0.8（仿主条 J=0.8）、保留合法分歧要求 θ>0.71（跨视角合法对 J=0.6–0.71）：可行窗口收缩为刀刃单点，任何估计噪声都会从一侧跌破（E63）。出口不在调 θ，在给合并判据引入词面之外的信息（视角标记/结论一致性/下游背书）——与"行为信号换轨"同构。

## 6.3 回到原点

这套实验最后回到了 bootstrap\_v3 自己写下的两条公理：



* **公理 G（可证伪）**：行为变更先 shadow，测不出差异即判表演。E16 把它从「态度」变成了「可执行的参数准入测试」—— 一个旋钮改不动行为，就不配被自演化、也不配被称为机制。

* **铁律 2（证据准入）/ 双平面（公理 D）**：条目必须指向真实事件、记忆只是 lifelog 的投影。E6/E11 给出的 uses，本质就是「这条记忆到底在多少个真实后续事件里被采用过」的**行为证据**—— 它让铁律 2 从「写入时挂一个事件 id」升级为「用一辈子的真实使用为记忆持续背书」。第六轮 E20/E24b 又补上它的成立条件：这份背书只能由下游真实事件书写、且只需相对次序正确（稀疏、噪声都不怕），唯独不能让记忆自证。第七轮 E32–E43 则从反面收口：**即便每个写入者都诚实，封闭自食、反馈环正反馈、共享记忆无来源治理，仍会让系统自我退化**——自演化的对侧永远站着真实世界的新鲜数据、被保护的探索概率与可追溯的来源。第八轮 E44–E55 再补上时间与对抗维度：**当攻防双方都在变，决定胜负的不是某条防御多强，而是攻击与正常行为可否区分、治理能否跑赢扩散、优化目标是否在系统之外**——可区分的攻击层层治理近乎免费，不可区分的攻击只能靠架构外的下游背书；而这一切关键结论，都要经得起换一批随机种子的方向审计（E55）。第九轮最后补上三条边界：**合谋可以击穿单条层面的不可能性**（E56，分布式后门在零误报审计下不可查，防线退到共现统计与子图词表配额）；**来源治理的地基是身份成本而非聚合算法**（E57，身份数量必须由系统外背书）；**词面是全部治理开关的隐含前提**（E60，查询与记忆共享词表一旦破裂，filter\_zero 反成清零开关，词表预算要按子图计）。第十轮把非平稳与多样性收进来：**缓存世界的杠杆在供给通道**（E61，回读带宽比替换算法重要一个数量级）、**公平靠代表权而非算法调参**（E62，预留席位是帕累托改进）、**纯词面合并无稳健工作点**（E63，第七个三角）、**门控纪律分平稳与漂移两套**（E65，margin 是追踪杀手）、**评测分布的外生覆盖是常设护栏**（E66，自考闭环零对手也 Goodhart）。第十一轮把这些结论互相接线：供给通道的量比分配技巧重要（E70）、公平机制要带时间维（E71）、外生覆盖有了剂量且检测端无免费午餐（E72）、两级存储的接缝成为新攻击面（E73）、告警阈值必须按代配对（E74）——**结论不是清单，是一张会互相修正的网**。第十二轮继续织网：需求信号本身可被伪造（E75，公平的攻击面在需求侧）、席位代表权要行为门与冷启动豁免并存（E78）、检索面预算是反身性的隐藏旋钮（E76，反向）、冷层潜伏只买得到 1.3 代延迟（E77）、外生配额要随偏斜重标定（E79）——**每条新红线都在改写旧红线的适用条件**。

> **自报不是证据，被反复采用才是；指标不是健康，隐藏集与库结构才是；自演化的尽头不是更聪明的参数，而是更克制的权力分层。**
