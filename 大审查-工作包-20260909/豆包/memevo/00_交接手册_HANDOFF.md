## 0. 一句话现状

围绕真实源码 `bootstrap_v3.py`（agent 记忆库 v3.8.1，2416 行），用一个**零第三方依赖、纯标准库、确定性可复现**的世界模型 `mem_common.py` 忠实复刻其检索/反思/分层/演化机制，已完成 **12 轮共 78 个沙盒实验（E1–E60、E64–E66、E70–E79，含 E22b/E22c/E24b）**，核心结论：**记忆库自演化"可行"，但有五个硬前提**（行为信号换轨且由下游背书、评判尺子冻结在元层、指标与库健康双度量、持续新鲜数据+探索+来源治理、优化目标外部化且治理跑赢扩散），并归纳出**七个不可能三角、67 条架构红线**。第九轮补链：分布式后门击穿单条不可能三角的外推、最小共现审计与其盲区（E56）；女巫攻击证明身份成本是来源治理的锐利地基（E57）；治理延迟不改变临界强度但线性放大代价、有限窗口必复发（E58）；四指标零误报健康仪表盘（E59）；词面鸿沟天花板与词表自扩展反噬（E60）；演化路径依赖与多起点优势（E64）。第十轮补链：周期负载下供给通道（回读带宽）比替换算法重要一个数量级、策略之争接近伪问题（E61）；长尾公平靠预留席位不靠调逐出、Q3 是免费胜利拐点（E62）；纯词面合并阈值的三难=第七个不可能三角，视角感知合并归零跨视角擦除（E63）；漂移期 margin 是追踪杀手、陈旧参照点反成余量（E65）；自考闭环零对手也 Goodhart、外生覆盖 ε≥0.6 是解药（E66）。第十一轮自启交叉：带宽怎么花不重要总量才重要、集中下注是灾难（E70）；静态席位红利以秩次稳定为前提、比例共享动态席位全面最优（E71）；反身临界 ε*∈[0.4,0.6] 但查询日志无免费自考指纹（E72）；冷档案是组合后门的零成本 reservoir、回读通道成免费电梯（E73）；仪表盘 v2 六指标零误报覆盖七场景、阈值须按代配对（E74）。第十二轮接线：幻影流量偷 49% 带宽且对两种席位制一视同仁、防御在查询来源认证（E75）；席位代表权会被写侧注水俘获、uses 门拉回 3 倍但有冷启动税（E78）；两级存储反向推翻 reservoir 假设——强制翻台是自考脱钩的天然解药（E76，S23）；冷层潜伏只买 1.3 代检出延迟、I13 无判别力退役（E77，S24）；外生配额随库偏斜重标定、强偏斜 ε* 0.4→0.6（E79）。当前没有未完成的实验，处于"可随时开第十三轮"的干净状态。

## 3. 世界模型接口手册（`mem_common.py`，接续必背）

### 3.1 常量
- `TOPIC_WORDS`：20 个主题、每主题 8 个**互斥**中文专属词；`TOPICS`=其键列表；`GENERIC_WORDS`=10 个高频泛词（造噪）。
- 出厂手写参数 `FACTORY=dict(w_kw=3.0, w_c=1.0, w_imp=1.0, w_age=0.1, d=0.5, filter_zero=False)`。
- `REFLECT_THR=50`（importance 累加触发反思）、`LONGTERM_THR=7`（imp≥7 进长期层）、`RETIRE_TTL=90`（失效后 90 天出仓）、`DECAY=.7`、`HOT_BUDGET=200`（**死参数**，真实代码声称"重要度×时效逐出"但未实现）。

### 3.2 条目字段（make_library 产出的 dict）
`id(f"M{i:04d}"), topic, true_quality(0..1 上帝视角,检索器看不见), keywords(list), content(list), importance(自报,可见), honest_imp(诚实应报值), vanity(是否注水bool), created_day, t_invalid(失效日/None), truly_invalid(上帝视角bool), uses(历史真实复用次数), links(list of id), is_farm(bool)`。
**铁律：任何"治理/排序"逻辑只能用可见字段，`true_quality/truly_invalid/honest_imp` 只能用于造数据和 golden 评分，否则等于作弊。**

### 3.3 关键函数签名
- `make_library(n=200, seed=0, vanity_frac=0, farm_clusters=0, farm_size=0, mislabel_frac=0, q_power=2.0, now_day=365, verbose=False)` → list[dict]。质量用 `Beta(q_power,q_power)`；uses=`(quality**1.5)*randint(0,40)`；正常 links 以 .15 概率链同主题另一条。
- `make_queries(ents, n_q=80, seed=100, expected_per_q=3, words_per_q=2)` → **list[dict]**，元素是 `dict(topic, query="词 词", expected=[id...])`（注意不是字符串！E53 曾因此崩过）。主题池不足 expected_per_q 会 skip。
- `rank(ents, query, theta=FACTORY, now_day=365, tokenize="space", drop_invalid=True)` → `[(id,[base,e,word_hit])]` 降序。
- `evaluate(ents, queries, theta, K=5, ...)` → `dict(recall, MRR, precision, zero_share, farm_share)`（return_detail=True 时额外返回最后一次 rank）。
- 生命周期：`split_layers(ents)→(longterm,inter)`；`retire(ents,now,ttl,dynamic=False)→(keep,out,false_kill,miss_invalid)`；`evict_to_budget(ents,budget,policy)→(keep,out)`，policy∈lru/imp_time/random/quality_oracle。
- 反思：`append_stream(seq,thr,honest=False)→(fires,spans)`；**`reflect_materials(ents,topn=6)→(top_list, 坏率)` 是二元组**（E47 曾因漏解包出错，别再犯）；`synthesize(top)→dict(topic,syn_quality,pollution,keywords) or None`。
- 演化：`evolve(ents,q_train,q_hold,theta0,n_gen=30,seed=0,sigma=.15,gate_margin=0,mutate_filter=False,adversary=None)→[(train,hold,theta)...]`，只变异 `w_kw/w_c/w_imp/w_age/d`（mutate_filter 时加 filter_zero 翻转），门控=训练分提升过 margin 才接受。
- 工具：`mean(xs)`/`sd(xs)`（总体标准差，均 round 到 3 位）。

### 3.4 检索器忠实复刻的四个"坑点"（实验结论的物理来源）
1. 打分 `base=3·kw_hit+1·c_hit+1·importance−0.1·age`；**kw_hit>0 时 c_hit=max(c_hit,1)**（源码 L901）。
2. **filter_zero=False：零词命中条目不过滤**，照样靠 importance−age 进排序——绝大多数"霸榜/老化"问题的总根源。
3. **links 一跳扩散只发给"自身 word_hit==0"的目标**，加 `d·命中分`；多条命中桥可累加。这导致：开 filter_zero 会**结构性掐断**图潜伏通道（E38 不可能三角的关键）。
4. importance 是**自报且 validate 不校验范围/类型**，可报 999；它同时参与排序、反思取材、长期层分层——"被排序者掌握打分权"是全报告主线。

## 4. 八轮 57 实验全景索引（结论一句话 + 数字在哪个结果文件）

> 完整数字与表格在主报告"实验总表 + 各补篇"。这里给导航地图，便于按需回查。

**第一轮 E1–E4（检索缺陷，results_all）**：出厂召回随库龄 30 天 .920→365 天 .403 单调崩塌；中文无空格分词退化（.398→.173）；links 词面重叠无收益（E3c 否）；零命中不过滤是总根源，开 filter_zero 回 .92+。

## 6. 可复现铁律（接续实验必须 100% 遵守，否则数字不可信）

Python 的 `hash()` 对字符串**跨进程随机化**、`set/dict` 迭代序不保证、全局 `random` 默认吃系统熵。要做到两次逐行一致：
1. **永远用局部随机源** `rnd=random.Random(seed)`，禁止直接用模块级 `random.xxx`（确定性实验里）。多种子用固定种子列表（现用 `[11,23,37,51,67,83,101,127]`，元审计 E55 用 range(32)）。
2. **任何并列排序加确定性 tiebreak**：`sorted(xs,key=lambda x:(-主键, x["id"]))`，字典序/数值次序兜底。
3. **从集合采样先 `sorted()`**：`rnd.sample(sorted(set(...)), k)`、`rnd.choice(sorted(...))`。
4. 遍历条目用稳定顺序（make_library 产出本就有序）；不要边遍历边改 dict 后依赖其顺序。
5. 汇总用 `statistics`/`M.mean`，浮点比较只比 round(…,3) 后的结果。
6. **计时类实验（E43、E51 单次 ms）不要求逐位一致**，报告只写量级区间，并在结果文件/报告里注明"随机器波动"。
7. 改任何 `exp_roundN` 参数 → 必须重跑该轮并同步 `results_roundN.txt` 与主报告数字；改 `mem_common` → 必须重跑 `run_all` 全量回归（它影响所有轮）。
8. 报告里数字的**唯一权威来源是 results 文件**，禁止凭记忆/转抄写数。

## 8. 返工方法论教训（F/S 全表在主报告第四部分，摘要）

- 攻击面要想清楚是"单条"还是"多少条带无界字段"（F16 DoS）；MAD 对照必须"每代持续注入新鲜数据"而非只不删（F15）；单条目标命中统计用 binary 命中率、不是恒除以 5 的 top5 份额（F14）；拜占庭恶意条真值必须确实低、否则"无攻击就有恶意"（F 教训）；评测泄漏副本要计入 expected（否则看不到背题虚高）。
- 第八轮新增：F17 等比 uses 衰减救不了先发（要份额动力学）、F18 多防御叠加残余取 min（最有效）不是 max、F19 级联要固定层宽+显式区分 OR/多数/AND 才能打出放大。
- **通用心法**：每个实验平均返工 2–3 版才打对机制；若反复打不出预期，优先像 E38/E53 那样**转成"否定性/不可能性结论"诚实记录**，不要硬凑预期数字。

## 9. 接续实验思路（第九轮及以后，可直接开工）

> 选题原则：避开 §7 已否方向；每个都先锚定文献、在世界模型里复现机制；优先补"现有结论链条上尚未闭合的环"。按**推荐优先级**排序，E56 起编号。

### 第一梯队（补现有链条的关键缺口，最值得先做）

**E56【已完成 2026-09-10，见主报告补篇・第九轮】　组合式/分布式后门（E38 不可能性的真正延伸）｜最独特**
- 动机：E38 证明"单条"记忆躲审计×隐身×触发不可兼得；但**多条各自干净、只有共现才作恶**的分布式后门（sleeper 拆开藏）尚未测——这是单条不可能性能否被"合谋"绕过的问题。
- 设计：k 条记忆每条只注册 1–2 个无害主题词（单条词面审计全过、单条零命中/低排名），当查询同时命中 ≥m 条时，经 links 桥/分数叠加让其组合体占据 top；扫 k、m、桥强度；对比单条审计、共现图审计（连通块/同步出现指纹）。
- 预期/可能否定：若 filter_zero 仍在组合层掐断，则把"单条不可能三角"强化为"分布式也不可能"（又一个否定性好结果）；若能成，则红线必须加"共现/子图审计"。
- 区分：E36/E37 是单条、E39 是多 agent 污染传播，本实验是**单 agent 内多条记忆合谋**。

**E57【已完成 2026-09-10，见主报告补篇・第九轮】　女巫攻击（Sybil）：来源治理的最后一块拼图**
- 动机：E39 的"按源隔离"、E40 拜占庭都**假设源身份不可伪造/数量已知**；攻击者若能批量制造虚假来源（多个 agent id/多个写入者），就能制造"虚假多数"冲垮隔离与中位数。
- 设计：N 个源中攻击者控制 c 个女巫，每个女巫独立投低强度恶意（单看都不达阈），聚合时叠加；测"按源隔离/中位数/trimmed"随女巫比例的失效点；唯一防线=**造身份的成本**（PoW/准入押金/信誉年龄），扫身份成本与女巫比例的相图。
- 区分：E40 是固定总数下 f 个坏者、值真坏；这里坏者可无限复制身份、每个值"半坏"以规避单源阈值。文献：Sybil attack（Douceur 2002）、声誉系统女巫。

**E58【已完成 2026-09-10，见主报告补篇・第九轮】　检测/治理延迟的代价（E52 的时间维）**
- 动机：E52 假设清洗即时发生；现实中污染从发生到被检出有 k 代延迟。测延迟如何放大爆炸半径、提高恢复所需 γc。
- 设计：污染发生后延迟 k 代才开始以 γ 清洗，期间按 β 扩散；扫 (k, γ) 找"延迟 k 后临界 γc(k) 上移多少"；对比"实时阻断二次写回（β=0）"与"事后清洗"两条路线的成本。
- 预期：得到类似控制论的结论——延迟每增加，所需治理强度非线性上升，进一步支持"在扩散通道上动手优于事后清洗"。文献：detection lag、epidemic control、控制论稳定裕度。

**E59【已完成 2026-09-10，见主报告补篇・第九轮】　健康度仪表盘：从全部失败模式反推最小领先指标（收口性、工程价值高）**
- 动机：八轮积累了几十种腐化/攻击模式，但"用哪些内部指标能最早预警"尚未系统验证。
- 设计：候选指标（自产记忆占比、uses 基尼、top 零命中份额、来源熵、反思取材坏率、词表覆盖异常度、links 度分布、指标—隐藏集剪刀差…）；对每种已知故障（MAD/马太/投毒/传染/Goodhart…）做**故障注入**，记录各指标首次显著偏离的代数（lead time）与假阳率；用贪心/覆盖选出最小指标集，做 ROC 式权衡。
- 价值：直接产出可落地的"记忆库健康监控清单"，是对 55 条红线的工程化收口。

### 第二梯队（表征与非平稳，补世界模型维度）

**E60【已完成 2026-09-10，见主报告补篇・第九轮】　词面鸿沟：同义/多义/跨表述的检索天花板**

**E61【已完成 2026-09-10，见主报告补篇・第十轮】　周期性/回归性概念漂移**

**E62【已完成 2026-09-10，见主报告补篇・第十轮】　长尾/稀有记忆的公平性**
- 动机：E34 马太是"条目间"正反馈；当**主题查询频率外生不均**（Zipf），稀有主题的 uses 永远积累不起来、被高频主题永久压制。

## 12. 世界模型的已知外部效度边界（别把沙盒结论当线上结论）
