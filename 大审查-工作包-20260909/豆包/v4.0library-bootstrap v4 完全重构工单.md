## 一、重构背景与目标

### 1.1 现状诊断

现有 `bootstrap_v3.py` 是一个 2416 行的单文件，承担了 11 种职责，存在以下系统性问题：

| 维度 | 现状 | 问题 |
|------|------|------|
| **代码组织** | 单文件，测试占 50% | 认知负荷高，PR diff 巨大，合并冲突频繁 |
| **状态管理** | 全局变量（DATA_DIR/DEPS） | test pollution，无法多库并发，已发生过 chdir 泄漏 |
| **存储** | 直接文件系统操作，无抽象 | 无法替换后端，无法 mock 测试，无法加缓存 |
| **一致性** | 4 文件写入无事务 | 崩溃后数据不一致，doctor 只能检测不能修复 |
| **检索** | 全量扫描 + 子串匹配 | 500 条目后性能急剧下降，中文无法分词 |
| **扩展性** | if-elif 硬编码，无插件机制 | 新功能必须改核心文件，无法第三方扩展 |
| **类型安全** | 裸 dict，无类型定义 | 字段拼写错误运行时才发现，无 mypy 检查 |
| **错误处理** | 混用 sys.exit/assert/raise | 不可捕获，不可恢复，测试难以模拟 |
| **可观测性** | 只有 print | 无耗时统计，无 metrics，无健康监控 |
| **安全** | 密钥扫描仅 3 种，Merkle 无域分离 | 安全承诺存在实质性缺口 |

### 1.2 重构目标

**功能性目标**：
1. 保留 v3 的所有核心概念（双平面记账、永不删除、慢车道、根锚定、铁律、反思机制、情绪系统）
2. 修复 v3 的所有 P0/P1 缺陷（见 CODE-REVIEW-2026-001）
3. 实现 v3 登记但未实现的优化（增量 Merkle、倒排索引、中文分词）
4. 新增能力：Python API、HTTP API、多库同步、插件生态

**非功能性目标**：
1. **可维护性**：单模块 < 500 行，分层清晰，职责单一
2. **可测试性**：单元测试覆盖率 > 85%，测试不依赖文件系统
3. **可扩展性**：核心功能可通过插件替换/扩展，不改核心代码
4. **性能**：10,000 条目下 retrieve < 100ms，append < 50ms
5. **类型安全**：mypy --strict 通过
6. **安全**：密钥扫描 20+ 种，Merkle 域分离，操作沙箱化
7. **可观测性**：结构化日志、metrics、tracing、健康检查
8. **数据一致性**：事务性写入，崩溃可恢复，自动修复

### 1.3 重构范围

**包含**：

## 二、设计原则

v4 架构遵循以下 12 条设计原则，按优先级排序：

### P1：领域驱动（Domain-Driven）
- 核心业务逻辑（铁律、慢车道、反思、情绪）属于领域层，不依赖任何基础设施
- 领域对象是纯 Python，可在任何环境运行和测试
-  ubiquitous language：代码中的命名与业务概念一致（Entry/AuditEvent/LedgerEntry/Charter/Law）

### P2：依赖倒置（Dependency Inversion）
- 高层模块不依赖低层模块，二者都依赖抽象
- 领域层定义接口（Repository/Port），基础设施层实现
- 所有外部依赖（文件系统、网络、时间、随机数）通过接口注入

### P3：单一事实源（Single Source of Truth）
- 每个数据概念只有一个权威定义
- 配置、schema、常量集中管理，不散落
- 版本号只有一个地方定义
- 渲染产物由数据生成，禁止手改

### P4：可测试性优先（Testability First）
- 每个组件都可在不依赖外部系统的情况下单元测试
- 内存存储后端是一等公民，与文件系统后端实现相同接口
- 时间、网络、随机数全部可 mock
- 测试金字塔：70% 单元 / 20% 集成 / 10% e2e

### P5：安全内建（Security by Design）
- 安全检查是写操作管道的必经环节，不可跳过
- 密钥扫描、schema 校验、权限检查作为中间件
- Merkle 树域分离，审计链防篡改
- 慢车道操作需要人类令牌，不可自动化绕过
- 最小权限原则：插件只能访问授权的接口

### P6：事件驱动（Event-Driven）
- 写操作发布领域事件，审计/账本/索引/缓存作为订阅者
- 事件是不可变的，是系统的真相源之一
- 支持同步和异步事件处理
- 事件溯源可选：关键操作可通过事件重放

### P7：渐进式复杂度（Progressive Complexity）
- 简单场景简单使用：`pip install` + 3 行命令即可用
- 高级场景可配置：插件、多后端、HTTP API、同步
- 默认配置对 80% 用户最优，20% 高级用户可深度定制
- 可选依赖：核心零依赖，高级功能通过 extra 安装

### P8：向后兼容（Backward Compatibility）
- v3 库可通过迁移工具无损升级到 v4
- v4 可读取 v3 格式的数据（只读兼容）
- API 版本化：CLI/HTTP API 有版本号，破坏性变更需 major version
- 数据 schema 版本化，支持向前和向后兼容

### P9：可观测性内建（Observability by Design）
- 每个操作有结构化日志（含操作名、耗时、结果、关键参数）
- metrics 是一等公民：计数器、直方图、仪表盘
- 健康检查端点：存储/审计链/索引/配置
- tracing：跨组件的操作追踪（可选，OpenTelemetry）

### P10：幂等与可重入（Idempotent & Reentrant）
- 所有写操作幂等：重复执行不产生副作用
- 操作可中断可恢复：崩溃后重启可继续或回滚
- 并发安全：多进程/多线程写入不导致数据损坏
- 操作有唯一 ID，可追踪可去重

### P11：显式优于隐式（Explicit over Implicit）
- 依赖通过构造函数/参数显式传递，不用全局变量
- 错误通过异常显式抛出，不用返回码或静默 pass
- 配置显式声明，不用隐式默认值散布在代码中
- 副作用显式标注（@writes/@reads 装饰器）

### P12：实用主义（Pragmatism）
- 不过度设计：每个抽象都有明确的动机和至少两个实现
- 不引入不必要的依赖：核心功能标准库实现
- 不追求完美：可工作的简单方案优于不可工作的完美方案
- 技术选型优先考虑成熟度和社区活跃度

## 四、分层架构详细设计

### 4.1 领域层（Domain Layer）

**职责**：封装核心业务逻辑和业务规则，是系统的"心脏"。不依赖任何外部框架或基础设施。

**包含**：
- 聚合根（Aggregates）
- 值对象（Value Objects）
- 领域服务（Domain Services）
- 领域事件（Domain Events）
- 策略/不变式（Policies / Invariants）
- 仓储接口（Repository Interfaces / Ports）

**约束**：
- 不 import 任何基础设施层模块
- 不使用任何外部框架（除了标准库和 pydantic）
- 纯函数优先，副作用最小化
- 所有业务规则在这里表达，不泄露到应用层或基础设施层

```python
# domain/aggregates/library.py
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional
from ..value_objects import (LibraryId, Level, PackageName, MerkleRoot,
                              EmotionVector, ImportanceAccumulator, Version)
from ..events import LibraryCreated, LevelChanged, PackageAdded

@dataclass
class Library:
    """库聚合根：一个知识库的完整状态和行为"""
    id: LibraryId
    version: Version
    level: Level
    packages: list[PackageName] = field(default_factory=list)
    emotion: EmotionVector = field(default_factory=EmotionVector.default)
    importance_accum: ImportanceAccumulator = field(default_factory=ImportanceAccumulator)
    merkle_root: Optional[MerkleRoot] = None
    created_at: datetime = field(default_factory=datetime.utcnow)
    updated_at: datetime = field(default_factory=datetime.utcnow)
    _events: list = field(default_factory=list, repr=False)

    def add_package(self, pkg: PackageName) -> None:
        if pkg not in self.packages:
            self.packages.append(pkg)
            self._events.append(PackageAdded(library_id=self.id, package=pkg))

    def change_level(self, new_level: Level) -> None:
        if new_level.requires_human_confirmation() and not self._human_confirmed:
            raise SlowLaneError(level=new_level)
        old = self.level
        self.level = new_level
        self._events.append(LevelChanged(library_id=self.id, old=old, new=new_level))

    def decay_emotion(self, decay_rate: float) -> None:
        self.emotion = self.emotion.decay(decay_rate)

    def add_importance(self, value: int) -> None:
        self.importance_accum += value
        if self.importance_accum.exceeds_threshold():
            self._events.append(ReflectionTriggered(library_id=self.id,
                                                      accum=self.importance_accum.value))

    def record_merkle_root(self, root: MerkleRoot) -> None:
        self.merkle_root = root

    def pull_events(self) -> list:
        events = self._events[:]
        self._events.clear()
        return events
```

```python
@dataclass
class Entry:
    """记忆条目：知识库的核心数据单元"""
    id: EntryId
    content: str
    source_event_id: AuditEventId  # 铁律2：必须指向审计事件
    importance: Importance = field(default=Importance(5))
    confidence: Confidence = field(default=Confidence.MEDIUM)
    validity: ValidityPeriod = field(default_factory=ValidityPeriod)
    keywords: list[Keyword] = field(default_factory=list)
    links: list[EntryId] = field(default_factory=list)
    tier: EntryTier = field(default=EntryTier.INTERMEDIATE)
    schema_version: int = 4
    created_at: datetime = field(default_factory=datetime.utcnow)
    updated_at: Optional[datetime] = None
    _events: list = field(default_factory=list, repr=False)

    def validate(self, policy: SecurityPolicy) -> list[ValidationError]:
        """领域校验：铁律2（证据）、铁律5（密钥）、schema 完整性"""
        errors = []
        if not self.source_event_id:
            errors.append(ValidationError("铁律2：条目必须有 source_event_id"))
        if policy.contains_secret(self.content):
            errors.append(ValidationError("铁律5：内容包含疑似密钥"))
        if len(self.content.encode()) > policy.max_entry_bytes:
            errors.append(ValidationError(f"条目超过大小限制 {policy.max_entry_bytes}"))
        return errors

    def is_longterm(self, threshold: int = 7) -> bool:
        return self.importance.value >= threshold

    def is_invalid(self, now: datetime, ttl_days: int = 90) -> bool:
        return self.validity.is_expired(now, ttl_days)

    def supersede(self, new_entry: "Entry") -> None:
        """铁律1：不删除旧条目，标记为 superseded"""
        self.validity.t_invalid = datetime.utcnow()
        self.links.append(new_entry.id)
        self._events.append(EntrySuperseded(old_id=self.id, new_id=new_entry.id))
```

**AuditChain（审计链聚合根）**

```python
# domain/aggregates/audit_chain.py
@dataclass
class AuditChain:
    """审计链：append-only 哈希链，系统的真相源（公理D）"""
    events: list[AuditEvent] = field(default_factory=list)
    _tail_hash: Optional[Hash] = None

    @property
    def tail_hash(self) -> Optional[Hash]:
        return self._tail_hash

    def append(self, event: AuditEvent) -> Hash:
        """追加事件，返回新的链尾哈希"""
        prev = self._tail_hash or Hash.genesis()
        event.prev_hash = prev
        event.hash = event.compute_hash()
        self.events.append(event)
        self._tail_hash = event.hash
        return event.hash

    def validate(self) -> list[ChainError]:
        """逐行验证哈希链连续性和跨月连接"""
        errors = []
        prev = Hash.genesis()
        for i, event in enumerate(self.events):
            if event.prev_hash != prev:
                errors.append(ChainError(f"事件 {i}: prev_hash 不匹配"))
            if event.hash != event.compute_hash():
                errors.append(ChainError(f"事件 {i}: 哈希不匹配（被篡改）"))
            prev = event.hash
        return errors

    def cross_month_validate(self, monthly_chains: dict[str, "AuditChain"]) -> list[ChainError]:
        """跨月链验证：新月首行 prev = 上月尾哈希"""
        errors = []
        months = sorted(monthly_chains.keys())
        for i in range(1, len(months)):
            prev_month = monthly_chains[months[i-1]]
            curr_month = monthly_chains[months[i]]
            if curr_month.events and prev_month.tail_hash:
                if curr_month.events[0].prev_hash != prev_month.tail_hash:
                    errors.append(ChainError(f"跨月断链: {months[i-1]} → {months[i]}"))
        return errors
```

#### 4.1.2 值对象设计

```python
# domain/value_objects.py
from dataclasses import dataclass
from enum import Enum
from typing import NewType

# 标识类值对象（NewType 提供类型安全）
LibraryId = NewType("LibraryId", str)
EntryId = NewType("EntryId", str)
AuditEventId = NewType("AuditEventId", str)
Hash = NewType("Hash", str)
MerkleRoot = NewType("MerkleRoot", str)
Version = NewType("Version", str)

@dataclass(frozen=True)
class Importance:
    value: int
    def __post_init__(self):
        if not 0 <= self.value <= 10:
            raise ValueError(f"importance 必须在 0-10 之间，当前 {self.value}")

class Confidence(Enum):
    HIGH = "高"
    MEDIUM = "中"
    LOW = "低"

class EntryTier(Enum):
    LONGTERM = "longterm"
    INTERMEDIATE = "intermediate"
    ATTIC = "attic"

@dataclass(frozen=True)
class ValidityPeriod:
    t_valid: Optional[datetime] = None
    t_invalid: Optional[datetime] = None
    def is_expired(self, now: datetime, ttl_days: int) -> bool:
        if not self.t_invalid:
            return False
        return (now - self.t_invalid).days >= ttl_days

@dataclass(frozen=True)
class EmotionVector:
    """四维情绪（L9 BCA 系统）"""
    valence: float = 0.0
    arousal: float = 0.5
    certainty: float = 0.5
    stakes: float = 0.0
    def decay(self, rate: float) -> "EmotionVector":
        return EmotionVector(
            valence=round(self.valence * rate, 3),
            arousal=round(self.arousal * rate, 3),
            certainty=round(self.certainty * rate, 3),
            stakes=round(self.stakes * rate, 3),
        )
    @classmethod
    def default(cls) -> "EmotionVector":
        return cls()

@dataclass
class ImportanceAccumulator:
    value: int = 0
    threshold: int = 50
    def __iadd__(self, other: int) -> "ImportanceAccumulator":
        self.value += other
        return self
    def exceeds_threshold(self) -> bool:
        return self.value >= self.threshold
    def reset(self) -> None:
        self.value = 0

@dataclass(frozen=True)
class Level:
    """安装档位 L0-L9"""
    code: str  # "L0" - "L9"
    name: str
    modules: tuple[str, ...]
    requires_human_confirmation: bool = False
    gate_text: Optional[str] = None
```

```python
class RetrievalService:
    """检索领域服务：打分逻辑、排序、链接扩散"""
    def __init__(self, config: RetrievalConfig):
        self.config = config

    def score_entry(self, entry: Entry, query: Query, age_days: float) -> float:
        """单条目标分：keywords 加权 + content 命中 + importance - 时间衰减"""
        kw_hit = sum(1 for token in query.tokens
                     if any(token in kw.text for kw in entry.keywords))
        c_hit = sum(1 for token in query.tokens if token in entry.content)
        if kw_hit:
            c_hit = max(c_hit, 1)
        score = (kw_hit * self.config.keywords_weight
                 + c_hit * self.config.content_weight
                 + entry.importance.value * self.config.importance_weight
                 - age_days * self.config.time_decay)
        return max(score, 0.0)

    def apply_link_diffusion(self, scores: dict[EntryId, float],
                              entries: dict[EntryId, Entry],
                              query: Query) -> dict[EntryId, float]:
        """[[links]] 一跳扩散：被直接命中的条目向其 links 传播分数的一半"""
        for eid, score in list(scores.items()):
            if score <= 0:
                continue
            entry = entries.get(eid)
            if not entry:
                continue
            for link_id in entry.links:
                if link_id in scores:
                    linked = entries.get(link_id)
                    if linked and not query.matches(linked):
                        scores[link_id] += score * self.config.link_diffusion_rate
        return scores
```

```python
# application/pipeline.py
class WritePipeline:
    """写操作管道：按顺序执行各阶段，每阶段可插拔"""
    def __init__(self):
        self.before_stages: list[PipelineStage] = [
            SchemaValidationStage(),
            SecretScanningStage(),
            SizeLimitStage(),
            DuplicateCheckStage(),
            SlowLaneCheckStage(),
        ]
        self.after_stages: list[PipelineStage] = [
            AuditLoggingStage(),
            LedgerRecordingStage(),
            IndexUpdateStage(),
            MerkleRootRefreshStage(),
            MetricsEmissionStage(),
        ]

    def execute(self, cmd: Command, handler: CommandHandler) -> Result:
        # 阶段 1：写前检查（全部通过才继续）
        for stage in self.before_stages:
            stage.before(cmd)

        # 阶段 2：执行核心逻辑（事务内）
        with uow.transaction():
            result = handler.handle(cmd)
            # 阶段 3：写后处理（在事务提交前，确保一致性）
            for stage in self.after_stages:
                stage.after(cmd, result)
            uow.commit()

        # 阶段 4：事务提交后（异步事件、通知）
        for stage in self.after_stages:
            stage.after_commit(cmd, result)

        return result
```

```python
# application/event_bus.py
class EventBus:
    """领域事件总线：同步+异步订阅者"""
    def __init__(self):
        self._subscribers: dict[type, list[EventHandler]] = defaultdict(list)

    def subscribe(self, event_type: type, handler: EventHandler) -> None:
        self._subscribers[event_type].append(handler)

    def publish(self, event: DomainEvent) -> None:
        """同步发布：在事务内调用，确保一致性"""
        for handler in self._subscribers.get(type(event), []):
            handler.handle(event)

    def publish_async(self, event: DomainEvent) -> None:
        """异步发布：事务提交后调用，用于通知、缓存失效等"""
        for handler in self._subscribers.get(type(event), []):
            if handler.is_async:
                # 放入后台队列
                self._queue.put((handler, event))
```

```python
# application/uow.py
class UnitOfWork:
    """工作单元：管理事务和仓储"""
    def __init__(self, entry_repo: EntryRepository,
                 audit_repo: AuditRepository,
                 ledger_repo: LedgerRepository,
                 state_repo: LibraryStateRepository,
                 event_bus: EventBus):
        self.entries = entry_repo
        self.audit = audit_repo
        self.ledger = ledger_repo
        self.state = state_repo
        self.event_bus = event_bus
        self._events: list[DomainEvent] = []
        self._in_transaction = False

    @contextmanager
    def transaction(self):
        if self._in_transaction:
            yield  # 支持嵌套事务（静默忽略）
            return
        self._in_transaction = True
        self._events = []
        try:
            yield
            # 提交前：发布同步事件
            for event in self._events:
                self.event_bus.publish(event)
            # 提交（基础设施层实现：WAL + 原子写）
            self._commit()
            # 提交后：发布异步事件
            for event in self._events:
                self.event_bus.publish_async(event)
        except Exception:
            self._rollback()
            raise
        finally:
            self._in_transaction = False
            self._events = []

    def publish(self, event: DomainEvent) -> None:
        self._events.append(event)
```

```python
class InvertedIndex:
    """倒排索引：token → posting list"""
    def __init__(self):
        self.index: dict[str, list[Posting]] = defaultdict(list)
        self.doc_freq: dict[str, int] = {}
        self.doc_lengths: dict[EntryId, int] = {}
        self.avg_doc_length: float = 0.0

    def add_entry(self, entry: Entry, tokenizer: Tokenizer) -> None:
        tokens = tokenizer.tokenize(entry.content + " " + " ".join(k.text for k in entry.keywords))
        tf = Counter(tokens)
        for token, freq in tf.items():
            self.index[token].append(Posting(entry_id=entry.id, tf=freq,
                                               fields=self._fields(token, entry)))
        self.doc_lengths[entry.id] = len(tokens)
        self._update_stats()

    def search(self, query: Query, tokenizer: Tokenizer,
               scorer: Scorer, top_k: int = 5) -> list[tuple[EntryId, float]]:
        query_tokens = tokenizer.tokenize(query.text)
        candidates = set()
        for token in query_tokens:
            candidates.update(p.entry_id for p in self.index.get(token, []))
        scored = {}
        for entry_id in candidates:
            score = scorer.score(entry_id, query_tokens, self)
            if score > 0:
                scored[entry_id] = score
        return sorted(scored.items(), key=lambda x: -x[1])[:top_k]
```

**BM25 排序**：

```python
class BM25Scorer(Scorer):
    def __init__(self, k1: float = 1.5, b: float = 0.75):
        self.k1 = k1
        self.b = b

    def score(self, doc_id: EntryId, query_tokens: list[str],
              index: InvertedIndex) -> float:
        score = 0.0
        dl = index.doc_lengths.get(doc_id, 0)
        avgdl = index.avg_doc_length or 1.0
        N = len(index.doc_lengths)
        for token in query_tokens:
            postings = index.index.get(token, [])
            df = len(postings)
            if df == 0:
                continue
            idf = math.log((N - df + 0.5) / (df + 0.5) + 1)
            tf = next((p.tf for p in postings if p.entry_id == doc_id), 0)
            tf_norm = (tf * (self.k1 + 1)) / (tf + self.k1 * (1 - self.b + self.b * dl / avgdl))
            score += idf * tf_norm
        return score
```

```python
# infrastructure/merkle/tree.py
class MerkleTree:
    """Merkle 树：域分离前缀 + 增量更新 + 持久化缓存"""
    LEAF_PREFIX = b"\x00"
    INTERNAL_PREFIX = b"\x01"

    def __init__(self, storage: MerkleStorage):
        self.storage = storage
        self._cache: dict[str, str] = {}  # path → file hash 缓存

    def compute_root(self, files: list[FileEntry]) -> MerkleRoot:
        """全量计算根（用于首次构建和校验）"""
        leaves = sorted([(f.path, self._leaf_hash(f)) for f in files],
                        key=lambda x: x[0])
        return self._build_tree(leaves)

    def incremental_update(self, root: MerkleRoot, all_files: list[FileEntry],
                            changed: list[str]) -> MerkleRoot:
        """增量更新：只重算受影响路径（O(log n) 而非 O(n)）"""
        # 1. 更新变化文件的叶子哈希
        for path in changed:
            f = next(f for f in all_files if f.path == path)
            self._cache[path] = self._leaf_hash(f)
        # 2. 从叶子到根，只重算包含变化叶子的节点
        # （实现：维护树结构，标记受影响节点，自底向上重算）
        ...

    def _leaf_hash(self, f: FileEntry) -> str:
        """叶子节点：域分离前缀 + 路径 + 内容哈希"""
        content_hash = hashlib.sha256(f.content).hexdigest()
        return hashlib.sha256(
            self.LEAF_PREFIX + f.path.encode() + content_hash.encode()
        ).hexdigest()

    def _internal_hash(self, left: str, right: str) -> str:
        """内部节点：域分离前缀 + 左子哈希 + 右子哈希"""
        return hashlib.sha256(
            self.INTERNAL_PREFIX + left.encode() + right.encode()
        ).hexdigest()

    def _build_tree(self, leaves: list[tuple[str, str]]) -> str:
        if not leaves:
            return hashlib.sha256(b"empty").hexdigest()
        layer = [h for _, h in leaves]
        while len(layer) > 1:
            next_layer = []
            for i in range(0, len(layer), 2):
                left = layer[i]
                right = layer[i+1] if i+1 < len(layer) else layer[i]  # 奇数时复制
                next_layer.append(self._internal_hash(left, right))
            layer = next_layer
        return layer[0]
```

## 六、并发与一致性模型

### 6.1 事务模型

**ACID 保证**：
- **原子性（Atomicity）**：写操作要么全部成功，要么全部回滚。通过 WAL 实现。
- **一致性（Consistency）**：事务前后数据满足所有不变式（铁律、schema、引用完整性）。
- **隔离性（Isolation）**：多进程写入通过文件锁串行化；读操作使用 MVCC（SQLite WAL 模式）。
- **持久性（Durability）**：事务提交后数据持久化到磁盘（fsync）。

**WAL 流程**：
```
1. 写操作开始 → 写入 WAL（BEGIN + 操作描述 + 预期状态）
2. 执行各步写入（条目/审计/账本/状态）
3. 全部成功 → 写入 WAL（COMMIT）→ fsync WAL → 应用变更到主存储
4. 任意失败 → 写入 WAL（ROLLBACK）→ 回滚已执行的步骤
5. 启动时检查 WAL：存在未 COMMIT 的事务 → 执行回滚
```

### 6.2 并发控制

**多进程写入**：
- 文件锁（`fcntl.flock` on Linux，`portalocker` 跨平台）
- 锁文件：`<lib>/.lock`
- 写操作获取排他锁（LOCK_EX），读操作获取共享锁（LOCK_SH）
- 锁超时：默认 30 秒，可配置
- 锁持有者崩溃后，锁自动释放（OS 级）

**多线程写入**：
- 进程内锁（`threading.RLock`）
- 同一进程内多线程串行化写操作

**SQLite 后端**：
- WAL 模式支持并发读写（多 reader + 单 writer）
- 写操作使用 `BEGIN IMMEDIATE` 获取写锁
- 忙超时（busy_timeout）默认 5000ms

### 6.3 幂等性

所有写操作幂等：
- `append`：同 id 重复写入返回已存在错误（不覆盖）
- `wrapup`：重复执行幂等（情绪衰减只在有新写入时触发）
- `retire`：重复执行幂等（已在 attic 的条目跳过）
- `reflect-done`：重复执行幂等（accum 已为 0 时跳过）
- `install`：已存在库进入校验模式（不覆盖）

操作唯一 ID：
- 每个写操作生成 UUID（`operation_id`）
- 记录在账本和审计链中
- 可用于去重和追踪

## 七、安全架构

### 7.1 安全模型

**威胁模型**（继承 v3 并增强）：
1. **防意外**：审计链 + Merkle 根 + 事务回滚
2. **防粗心**：写操作管道 + schema 校验 + 密钥扫描 + 慢车道
3. **防蓄意 agent**：包自哈希 + 人侧保管 + 人类令牌 + 插件沙箱
4. **防外部攻击**：HTTP API 认证 + 输入校验 + 路径遍历防护

**铁律执行机制**：

| 铁律 | 执行点 | 机制 |
|------|--------|------|
| 1. 永不删除 | 写操作管道 + 审计链触发器 | 所有"删除"=移 attic；审计链 UPDATE/DELETE 触发器禁止 |
| 2. 证据准入 | SchemaValidationStage | 条目写入前 source_event_id 非空校验 |
| 3. 凡引用给出处 | SchemaValidationStage + 内容扫描 | 引用他人观点必须有 REGISTRY id 或来源 |
| 4. 审计面只追加 | AuditRepository 实现 + DB 触发器 | append-only，跨月链连续 |
| 5. 永不存密钥 | SecretScanningStage | 20+ 种密钥模式扫描，命中即拒 |
| 6. 慢车道 | SlowLaneCheckStage + HumanToken | L8/L9 需要交互式确认或签名令牌 |

### 7.2 人类令牌（慢车道）

**三种确认方式**（按安全等级递增）：

1. **交互式确认**（默认）：
   ```
   $ lb install L8
   ╭─ 慢车道确认 ────────────────────────────────────────╮
   │ 即将安装 L8（超绝激进:自指演化），需要人类确认。     │
   │                                                       │
   │ 宪章全文：                                             │
   │ 1) 不变式(laws) > 本宪章(流程) > 其余指令            │
   │ 2) 变异候选须过 run_tests 全绿 + lint                 │
   │ ...                                                   │
   │                                                       │
   │ 请输入「确认安装 L8」以继续（输入其他内容中止）：     │
   ╰───────────────────────────────────────────────────────╯
   > 确认安装 L8
   ✓ 已确认，开始安装...
   ```

2. **命令行 `--yes`**（CI/CD 用，审计链标注"非交互式确认"）：
   ```
   $ lb install L8 --yes
   ⚠ 警告：使用 --yes 跳过交互式确认，审计链将标注为"非交互式确认"
   ✓ 开始安装...
   ```

3. **签名令牌文件**（最高安全等级，人侧保管）：
   ```
   $ lb install L8 --token-file ~/.secrets/lb-l8-token.sig
   ✓ 令牌验证通过（签名者：user@example.com，有效期至 2026-12-31）
   ✓ 开始安装...
   ```
   令牌文件是 GPG 签名的文本，包含授权级别、有效期、签名者。

### 7.3 插件安全

**权限模型**（RBAC）：
- `read`：读取条目、状态、审计链
- `write`：写入条目、发射审计事件
- `config`：修改配置
- `admin`：安装/卸载插件、修改铁律（L8+）
- `network`：网络访问（默认禁止）
- `filesystem_full`：完整文件系统访问（默认仅插件目录和库目录）

**沙箱**（可选，`plugins.sandbox: true`）：
- 文件系统访问限制：仅插件目录 + 库目录（通过 `open()` 拦截）
- 网络访问：默认禁止，可配置白名单
- 子进程：默认禁止
- 导入限制：仅允许导入安全模块白名单

**插件审核**：
- 首次安装插件时显示权限请求，用户确认
- 插件更新时如果请求新权限，重新确认
- 插件行为记录在审计链中

### 7.4 输入安全

- 所有外部输入（CLI 参数、API 请求、插件数据）经过 pydantic 校验
- 路径遍历防护：所有文件路径规范化后校验是否在库目录内
- JSON 解析限制：最大大小 16MB（可配置），最大嵌套深度 100
- 命令注入防护：不使用 `shell=True`，所有外部命令使用参数列表
- XSS 防护：渲染模板自动转义（Jinja2 默认）

## 十一、迁移策略（v3 → v4）

### 11.1 迁移原则

1. **无损迁移**：v3 库的所有数据（条目/审计链/账本/状态）完整迁移到 v4
2. **可逆迁移**：迁移前自动备份，迁移失败可回滚
3. **原地迁移**：在原库目录上迁移，不复制（大库节省空间）
4. **只读兼容**：v4 可读取 v3 格式数据（不迁移也能读）
5. **增量迁移**：大库可分批迁移，中断后可继续

### 11.2 迁移内容

| v3 概念 | v4 等价物 | 迁移操作 |
|----------|-----------|----------|
| 条目 JSON（八字段/十字段） | Entry（schema v4） | 字段映射 + keywords/links 类型转换 + schema_version=4 |
| `lifelog-YYYY-MM.md`（竖线格式） | AuditEvent（哈希链） | 格式解析 + 哈希重算（域分离）+ 按月分片 |
| `changes.jsonl` | LedgerEntry | 直接迁移（格式兼容） |
| `state.json`（emotion/importance_accum/merkle_root） | LibraryState | 字段映射 + 版本升级 |
| `bodies.json`（内容体） | 交付文件清单 | 直接迁移（v4 仍支持 v2.x 内容体交付） |
| `REGISTRY`（题录） | 内置题录数据 | 直接使用（v4 内置相同题录） |
| `TUNABLES`（参数） | AppConfig | 映射到配置 schema，写入 `<lib>/config.yaml` |
| 渲染产物（AGENTS/README/spec/...） | 渲染产物 | 重新渲染（v4 模板可能不同） |
| `.library-manifest.json` | 交付清单 | 重新生成（哈希算法可能升级） |

### 11.3 迁移命令

```bash
# 预检：检查 v3 库是否可迁移
lb migrate check --lib ./mylib
# 输出：
# ✓ v3 库检测到（version=3.8.1，条目=156）
# ✓ 审计链格式兼容
# ✓ 账本格式兼容
# ⚠ 3 个条目缺少 source_event_id（将标记为 genesis-v3）
# ⚠ 1 个条目 keywords 是字符串（将转换为列表）
# 预检通过，可以迁移。预计耗时 2 秒。

# 执行迁移（原地，自动备份到 mylib.v3-backup/）
lb migrate run --lib ./mylib
# 输出：
# 📦 创建备份 → mylib.v3-backup/
# 📋 迁移条目：156/156 ✓
# 🔗 迁移审计链：128 事件 ✓
# 📒 迁移账本：89 记录 ✓
# ⚙  迁移状态：✓
# 🎨 重新渲染产物：✓
# ✅ 迁移完成！v3 备份保留在 mylib.v3-backup/
#    验证：lb doctor --lib ./mylib
#    回滚：lb migrate rollback --lib ./mylib

# 回滚（如果迁移后发现问题）
lb migrate rollback --lib ./mylib

# 只读模式（不迁移，用 v4 读取 v3 库）
lb retrieve --lib ./mylib --text "查询"  # 自动检测 v3 格式，只读兼容
```

### 11.4 迁移测试

- 小型库（< 100 条目）：自动测试
- 中型库（100-1000 条目）：自动测试
- 大型库（> 1000 条目）：性能测试 + 手动验证
- 边界情况：空库、只有 attic 条目的库、损坏的审计链、超大条目
- 幂等性：重复运行 migrate 不产生副作用
- 回滚测试：迁移→回滚→数据与原 v3 库完全一致

| 维度 | v3 | v4 |
|------|----|----|
| 代码组织 | 单文件 2416 行 | 包结构，4 层，~30 模块 |
| 状态管理 | 全局变量 | 依赖注入，AppContext |
| 存储 | 直接文件操作 | 仓储抽象，3 后端（File/SQLite/Memory） |
| 事务 | 无（4 文件写入可能不一致） | WAL + 原子写 + 崩溃恢复 |
| 检索 | 全量扫描 + 子串匹配 | 倒排索引 + BM25 + 可插拔 |
| 中文分词 | 无（按空白分割） | jieba / bigram（可配置） |
| Merkle | 无域分离，全量重算 | 域分离前缀，增量更新，缓存 |
| 扩展 | if-elif 硬编码 | 插件系统（entry_points + 目录） |
| 类型 | 裸 dict，无类型 | dataclass + pydantic，mypy strict |
| 错误处理 | 混用 sys.exit/assert/raise | 自定义异常层次，CLI 统一处理 |
| 配置 | TUNABLES 硬编码 | Pydantic + YAML，5 层覆盖 |
| 日志 | print | 结构化 JSON，轮转，脱敏 |
| Metrics | 无 | Prometheus 格式，20+ 指标 |
| 健康检查 | doctor（手动） | doctor + /health，10 项检查 |
| API | 仅 CLI | CLI + Python API + HTTP API（可选） |
| 测试 | 40 个，混杂，依赖文件系统 | 金字塔 70/20/5，内存存储，契约测试 |
| 性能 | 500 条目后退化 | 10k 条目 retrieve < 500ms |
| 并发 | 不安全（可能链分叉） | 文件锁 + 事务 + SQLite WAL |
| 密钥扫描 | 3 种 | 20+ 种 |
| 慢车道 | --yes 即可 | 交互式确认 + --yes + 签名文件 |
| 插件安全 | 无 | 权限模型 + 沙箱（可选） |
| 迁移 | 一次性硬编码脚本 | 通用迁移框架 + 预检 + 回滚 |
| 单文件分发 | 是（唯一方式） | 可选（zipapp 构建），主推 pip install |
