## 一、记忆系统与「记忆 OS」路线

### A1 — MemGPT: Towards LLMs as Operating Systems（2023）
- **来源**：arXiv:2310.08560
- **简介**：把操作系统的虚拟内存思想引入 LLM——主上下文与外部存储之间由 agent 自主分页，通过中断驱动的自编辑记忆管理有限上下文窗口。分层记忆路线的奠基作。
- **落地**：`T2-弱`。**实际用途**：intermediate/longterm 两级目录 + attic 出仓对应「外部存储分层」；**分页换入换出、中断驱动、自编辑记忆均未实现**（代码无相关机制）。

### A14 — Memory OS of AI Agent（2025）
- **作者**：Jiazheng Kang, Mingming Ji, Zhe Zhao, Ting Bai（北邮 BAI-LAB）
- **来源**：arXiv:2506.06326；正式发表于 **EMNLP 2025 main**（2025.emnlp-main.1318, pp.25961–25970, DOI 10.18653/v1/2025.emnlp-main.1318）；代码 github.com/BAI-LAB/MemoryOS
- **简介**：为 agent 设计记忆操作系统：短/中/长期三级存储池，仿 OS 的页调度机制管理记忆的换入换出。注意与 MemTensor 的 MemOS（A16）及 PyPI 的 memoryos 包是三个不同实体——本领域存在持久命名撞车。
- **落地**：`T3`（命名消歧 + 规划挂账）。**实际用途**：用于与 A16 命名消歧；当前**仅有两级目录 + attic，热温冷三池、页调度、热度逐出均未实现**（`index_hot_budget=200` 是登记参数、未接线），列为规划方向，由 m-radar 跟踪重评。

### A16 — MemOS: A Memory OS for AI System（2025）
- **作者**：Zhiyu Li 等（MemTensor）
- **来源**：arXiv:2507.03724
- **简介**：把记忆提升为系统级资源统一调度：MemCube 封装明文记忆、激活记忆（KV-cache）与参数记忆三类，带来源/版本元数据与生命周期管理。
- **落地**：`T1-弱`。**实际用途**：schema 的 source_event_id / 时间戳 / validity 即「内容+来源元数据」对应；明文/激活/参数**三类记忆未建模**（当前仅明文 JSON）。

### A18 — MIRIX: Multi-Agent Memory System（2025）
- **来源**：arXiv:2507.07957
- **简介**：多 agent 记忆系统，提出六类记忆分类：Core、Episodic、Semantic、Procedural、Resource 与 Knowledge Vault（加密敏感存储）。
- **落地**：`T1-部分`。**实际用途**：仅落地 **Knowledge Vault 缺位决策**——铁律 5 密钥扫描保证敏感信息不入库；**六类记忆分类未建模**（原「六类映射表 D-004」查无此件，已删）。

### A12 — Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory（2025）
- **来源**：arXiv:2504.19413
- **简介**：面向生产的长时记忆层：抽取-整合双管线，对对话内容做去重、合并与增量更新后写入记忆存储。
- **落地**：`T2-弱`。**实际用途**：wrap-up 内容体以提示词纪律要求 harness/人做经验抽取与整合；**引擎不自动抽取/去重/合并**（无 update/merge 操作；同 id 覆盖被 J-001 拒绝）。

### A27 — MemInsight: Autonomous Memory Augmentation for LLM Agents（2025）
- **作者**：Rana Salama 等（AWS）
- **来源**：arXiv:2503.21760
- **简介**：让 agent 自主为记忆条目抽取属性标注（关键词、实体、语义标签），以提升检索与组织质量。
- **落地**：`T1`。**实际用途**：schema keywords 字段 + 检索关键词命中 ×3 加权（含类型强转），代码层闭环。

### A20 — LightMem: Lightweight and Efficient Memory-Augmented Generation（2025）
- **作者**：Jizhan Fang 等（zjunlp）
- **来源**：arXiv:2510.18866
- **简介**：轻量高效记忆增强生成：感官/短期/长期三级记忆，配合睡眠时（sleep-time）更新机制，在不牺牲性能的前提下压低记忆维护成本。
- **落地**：`T2-弱`。**实际用途**：随 L5 m-cron / L9 sleep-pipeline 内容体落地「睡眠时更新」纪律；三级记忆为概念对应，**无独立三级实现**（搭 A13 睡眠管线）。

### A6 — MemoryBank: Enhancing Large Language Models with Long-Term Memory（2023）
- **来源**：arXiv:2305.10250
- **简介**：给 LLM 装上长期记忆并引入艾宾浩斯遗忘曲线——记忆按使用证据与时间衰减，而非永久保留。
- **落地**：`T1-弱`。**实际用途**：检索打分含 −0.1·age 天的**线性**时效衰减（非艾宾浩斯曲线）；`review_intervals[1,7,30]` 是登记参数（来源标注已由 A2 更正为 A6）；L8 锦标赛 SOP（按证据留档/淘汰变体）随 L8 交付。

### A10 — A-MEM: Agentic Memory for LLM Agents（2025）
- **来源**：arXiv:2502.12110
- **简介**：受 Zettelkasten 启发的 agentic memory：记忆写成带原子事实与链接的结构化笔记，新笔记触发对旧笔记的演化（链接、增订），让记忆组织自生长。
- **落地**：`T2`。**实际用途**：**L3 档位「演化版(A-MEM)」的命名文献**，m-evolve 演化 SOP 随 L3 交付（26 份内容体引用）；代码层无自动演化，演化动作由 harness 按 SOP 执行。（原表漏列，本次补入。）

## 二、检索与图结构路线

### A8 — HippoRAG: Neurobiologically Inspired Long-Term Memory for LLMs（2024）
- **来源**：arXiv:2405.14831
- **简介**：受海马体索引理论启发：用知识图谱 + Personalized PageRank 做单跳/多跳检索，模拟新皮层-海马体协作的记忆索引。
- **落地**：`T1-弱`。**实际用途**：检索对条目 `[[links]]` 做**一跳扩散**（传播权重 0.5），是扩散激活的极简对应；**无知识图谱、无 Personalized PageRank**，不可等同。

### A9 — HippoRAG 2: From RAG to Memory: Non-Parametric Continual Learning for LLMs（2025）
- **来源**：arXiv:2502.14802
- **简介**：HippoRAG 升级：从检索工具升级为「非参数持续学习」框架，段落级深度整合 + PPR 扩散，让 RAG 具备持续学习语义。
- **落地**：`T3`。**实际用途**：L6 雷达的升级触发器理论锚（m-tools 内容体提及）；段落级整合/PPR 未实现。

### A11 — Zep: A Temporal Knowledge Graph Architecture for Agent Memory（2025）
- **来源**：arXiv:2501.13956
- **简介**：时序知识图谱 Graphiti：事实带双时态结构（发生时间与入库时间分离），事实失效打标记而非删除，修订史即资产。
- **落地**：`T1-部分`。**实际用途**：**已落地** validity.t_valid/t_invalid 双时态字段，失效条目不删除且不参与检索；**未落地** superseded-by 修订链（schema 无该字段，仅 absorb-md 迁移时降 importance=3）。

### A15 — G-Memory: Tracing Hierarchical Memory for Multi-Agent Systems（2025）
- **来源**：arXiv:2506.07398
- **简介**：多 agent 系统的三层层级记忆图（交互/查询/洞察），追踪跨 agent 的协作记忆。**本库判定不适用**（单人单 agent），挂多 agent 触发器。
- **落地**：`T3`。**实际用途**：m-radar 雷达触发器（出现多 agent 场景时重评），声明诚实。

### A17 — MemAgent: Reshaping Long-Context LLM with Multi-Conv RL-based Memory Agent（2025）
- **来源**：arXiv:2507.02259
- **简介**：RL 训练的长上下文处理策略：分段读取 + 固定长度记忆覆写（勿写「分页」），在超长文本任务中以固定记忆预算工作。**本库判定不适用**，挂长文触发器。
- **落地**：`T3`。**实际用途**：长文任务触发器；REGISTRY note「勿写分页」纪律保留。

## 三、认知架构、反思、规划与多智能体

### A4 — Cognitive Architectures for Language Agents (CoALA)（2023）
- **来源**：arXiv:2309.02427
- **简介**：语言 agent 认知架构综述：把 agent 组织为记忆模块、决策模块与行动空间，区分内部/外部记忆与各类推理动作，是架构级地图。
- **落地**：`T3`。**实际用途**：模块划分与雷达分类学的架构参照（与 A7 并列），无实现义务。（原表漏列，本次补入。）

### A2 — Generative Agents: Interactive Simulacra of Human Behavior（2023）
- **来源**：arXiv:2304.03442（Stanford / Google）
- **简介**：25 个 agent 组成的虚拟小镇：记忆流 + 反思（累积观察超阈值时合成高层洞察）+ 规划，涌现出可信的社会行为。反思机制的原始出处。
- **落地**：`T1`。**实际用途**：importance 累积 + 阈值 50 触发反思、reflect 素材打包、reflect-done 重置；检索三因子（recency=−0.1·age / importance / keyword+content relevance）代码层齐；反思合成本身在 harness 提示词（已声明 engineering adaptation）。

### A3 — Reflexion: Language Agents with Verbal Reinforcement Learning（2023）
- **来源**：arXiv:2303.11366
- **简介**：用「语言化自省」替代梯度更新：任务失败后 agent 生成文字反思存入情景记忆，下次重试时参考——口头强化学习。
- **落地**：`T2`。**实际用途**：experimental/auto-critic 自动批评家随 L7 交付；pitfall 强制根因分析；代码层无 critic 逻辑（提示词形态，符合设计）。

### A23 — Improving Factuality and Reasoning through Multiagent Debate（2023）
- **来源**：arXiv:2305.14325（MIT）
- **简介**：多个 LLM 实例对同一问题各自作答并互相批判修订，可显著提升事实性与推理质量；收益部分来自独立采样的去相关化。
- **落地**：`T2`。**实际用途**：experimental-l8/council 心智议会四席位随 L8 交付；**以单实例角色分饰替代多实例（已显式声明偏离）**。

### A5 — Voyager: An Open-Ended Embodied Agent with Large Language Models（2023）
- **来源**：arXiv:2305.16291（NVIDIA）
- **简介**：Minecraft 开放端 agent：技能库 = 可执行代码 + 自然语言描述，自动课程逐步探索，失败代码可回炉。
- **落地**：`T3`（概念参照，**未落地**）。**实际用途**：skills/ 目前仅 wrap-up.md / task-start.md 两个流程提示词，**不是「可执行+描述+复用」的技能库**；列为后续方向。

## 四、自进化与自指演化

### A21 — The Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents（2025）
- **来源**：arXiv:2505.22954（Sakana AI + UBC）
- **简介**：通过重写自身代码实现开放式自我改进的 agent，SWE-bench 解决率 20%→50%、Polyglot 14.2%→30.7%。核心安全设计：修改变体档案化、每次修改过实证基准、沙箱与人类监督、被否决变体永久归档（垫脚石）。**Appendix F 记录了亲身事故**：agent 在 Node 114 删除标记工具使用的特殊 token、绕过幻觉检测刷分（objective hacking）——论文处方是「检查函数对修改代理隐藏」并实证不隐藏时 hacking 显著频发；结论节引用 Goodhart 定律。
- **落地**：`T1`（最完整）。**实际用途**：基准黑名单 BASELINE_BLACKLIST、guard 三模式、L8 宪章、SOP 判据不可见注入、L8 人类令牌门、anchor 快照；L8 内容体全交付。

### A22 — A Survey of Self-Evolving Agents: On Path to Artificial Super Intelligence（2025）
- **来源**：arXiv:2507.21046
- **简介**：自进化 agent 综述：按 What（进化什么）、When（何时进化）、How（如何进化）给出分类学，覆盖工具、架构与记忆的进化。
- **落地**：`T3`。**实际用途**：L8 缺口定位（工具与架构列）的分类学参照。

### A19 — Memory-R1: Enhancing LLM Agents to Manage and Utilize Memories via RL（2025）
- **来源**：arXiv:2508.19828
- **简介**：用强化学习训练记忆管理器，对记忆条目执行 ADD / UPDATE / DELETE / NOOP 四操作，让「管理记忆」本身成为可学习行为。
- **落地**：`T1-部分`。**实际操作对照**：**ADD** = engine append（已落地）；**UPDATE** 无自动操作，走人工裁决换 id；**DELETE** 按铁律 1 不存在（retire 是移至 attic 而非删除）；**NOOP 未实现**。

### A13 — Sleep-time Compute: Beyond Inference Scaling at Test-time（2025）
- **来源**：arXiv:2504.13171（Letta）
- **简介**：把与当前查询无关的计算挪到空闲期（睡眠时）预计算，用离线算力换查询时性能——推理规模化的另一条轴。
- **落地**：`T2`。**实际用途**：L5 m-cron（m-sleep）月度整理与 L9 sleep-pipeline 固化管线内容体；调度依赖外部 cron/harness（代码层无内置调度器，形态诚实）。

## 五、认知科学与经典理论

### A29 — Why there are complementary learning systems in the hippocampus and neocortex（1995）
- **作者**：McClelland, J. L., McNaughton, B. L., & O'Reilly, R. C.
- **来源**：Psychological Review, 102(3)（经典文献，非 arXiv；REGISTRY 内简记为 Complementary Learning Systems）
- **简介**：互补学习系统（CLS）理论：海马体快速一次性学习具体情景，新皮层慢速学习统计规律，二者协作构成记忆系统骨架。
- **落地**：`T2`（补丁后随 L9 交付）。**实际用途**：experimental-l9/dual-memory 内容体——trajectories 快层一次成型只追加、pitfalls/patterns/reflections 慢层只由 wrap-up 与睡眠管线写入；引擎层对应为目录分工。

### A30 — A Cognitive Theory of Consciousness（1988）
- **作者**：Baars, B. J.
- **来源**：Cambridge University Press（经典文献，非 arXiv；REGISTRY 内简记为 Global Workspace Theory）
- **简介**：全局工作空间理论（GWT）：认知信息整合通过一个容量极小、全系统可访问的工作空间完成，各专用模块竞争写入。
- **落地**：`T2`。**实际用途**：experimental-l9/gwt 内容体随 L9 交付——task-start 显式仲裁，LLM 上下文窗口即现成全局工作空间。

### A31 — The Somatic Marker Hypothesis（躯体标记假说；见 *Descartes' Error: Emotion, Reason, and the Human Brain*, 1994）
- **作者**：Damasio, A. R.
- **来源**：G.P. Putnam's Sons（经典文献，非 arXiv；1996 为平装年版）
- **简介**：躯体标记假说：情绪是压缩的价值缓存，为决策提供快速偏置——没有情绪标记的纯理性决策反而失效。
- **落地**：`T1`。**实际用途**：state.emotion 四维向量（valence/arousal/certainty/stakes）+ wrapup ×0.7 衰减（测试锁定 0.5→0.35）；emotion 内容体随 L9 交付。

### A32 — A default mode of brain function（2001）
- **作者**：Raichle, M. E. 等
- **来源**：PNAS, 98(2)（经典文献，非 arXiv；REGISTRY 内简记为 Default Mode Network）
- **简介**：默认模式网络（DMN）：大脑在无外部任务时有自发的内省性活动——整理记忆、自问未解问题。
- **落地**：`T2`（补丁后随 L9 交付，**定位为研究性模块、随时可砍**）。**实际用途**：experimental-l9/dmn 的 OPEN-QUESTIONS 空闲自问清单，由 reflect/睡眠管线消费，产物走正常固化闸门。

### A33 — Mood and Memory（1981）
- **作者**：Bower, G. H.
- **来源**：American Psychologist, 36(2)（经典文献，非 arXiv）
- **简介**：心境一致性记忆：与当前情绪状态一致的材料更易被编码与提取——情绪参与检索重排。
- **落地**：`T2`（补丁后随 L9 交付，harness 层）。**实际用途**：dual-memory 内容体规定「命中后按当前 arousal/certainty vs 条目快照重排、certainty 低时强制检索」，由 harness 执行；**引擎 `_rank_entries` 本身不读情绪向量，非代码层重排**。

### A25 — Context Rot: How Increasing Input Tokens Impacts LLM Performance（2025）
- **作者**：Kelly Hong, Anton Troynikov（Chroma）
