## 0. 根问题与对象

```
根问题：一个会修改自己的系统，在人类注意力稀缺的前提下，能否安全地变好？
原始对象：bootstrap_v3.py（2415 行自演化记忆系统）
世界模型：evolve9.build_world —— 60 条目 × 6 类 query，
          每条目 = 真值(系统不可见) + 表象(length/formatting/density/citation)，
          judge = α×真值 + (1−α)×表象（α = "judge 多容易被忽悠"）
最大局限：玩具世界；真实 LLM-as-judge 0 次探索 → 具体数字不可外推，只结构性结论稳健
```

## 3. 实验思路的脊柱（可迁移的方法论）

### 3.1 链式提问——每轮由上一轮"漏出来的东西"触发
`E131"strict 无效？"→ 追因：回退只 0.5 次，审计没触发，无从区别（E41 同型错误）→ E132/E133 换正确场景重测 → 2×2 发现符号相反 → E134 判别式解药 → E135 扩四态 → 否定自己：split 才对 → E30 轮再上一层：连"标定"本身也不可信`
每一次"解决"都制造了下一个更准的问题——**轮次不是清单，是追问链**。

### 3.2 世界模型升级链（攻防升级）
```
judge 可信（1–17轮）→ judge 看表象（E81，A轮）→ judge 可被通道操纵（E84/E85）
→ 世界会漂移（E131 构造）→ 系统可改写世界的数据（E119–E123）
→ 世界的信噪比本身是实验变量（E125–E130 强/弱信号世界）
```
每升一级，前一级的护栏就会被重新定价（E111 盲评兜底、E119 审计错层、E123 整理前提）。

### 3.3 贯穿全项目的五个判别模式
1. **配对原则**（4+1 个）：准入×晋升（E7）、幅度×审计（E110）、档案×留出集门（E16）、写入×整理（E123）——性能 = 探索力×筛选力的**配对质量**
2. **先判别状态，再选动作**（5 次同构）：E7 门控位置 → E12 三态 → E133 回退原因 → E134 判别式回退 → E135 split；总原则：不要为所有状态选同一个动作
3. **测量已有可观测量 > 发明新启发式**：E32 采纳率、E44 零采纳、E50 先测精度；被证伪的 23+ 条几乎全是"让机制更聪明的改良"
4. **外部性三定律**：外部参照必须独立于观测通道（E81）；防御必须与污染同维度（E81/E84/E119）；judge 可排序不可判定（E81/E119/E122）
5. **边际收益 ≠ 结构必要性**：盲评边际 +0.023 但是地基（E111）；停摆监控平时 0 但是唯一救命机制（E44/E96）——评估机制要看它是不是**别人的前提**

### 3.4 统计纪律的演进（本身就是一条实验线）
```
固定 margin（假阳 0.42, E17）→ bootstrap 置信下界（E17/E24）
→ 8–12 种子惯例 → 功效审计揭穿（第27轮：只能检出>0.062）
→ 20/44 对 + 预注册 + 均值±se(t,n)（第28轮起）
→ 审计/门控类必须报触发次数（红线25）
→ 判别器用动作收益而非分类准确率评价（红线26）
```

### 3.5 诚实记录的制度化
- **30 次自我推翻**（第30轮计）：直觉准确率约 50%，这个记录比任何单条结论都值钱
- **23+ 次设计失败**的模式库：过于整齐=实现没动（F-18/F-20/E24/E135-stuck）；构造塌缩=处理与对照同时掉到零（E41/E137b）；缓存 key 用 id()（E14 数据×9 重估）；缺陷实现上加样本量无用（E27b 作废）
- 负面清单 19→23+ 条持续扩充；红线 27 条 + 后续增量（24 判别回退 / 25 触发次数 / 26 动作收益 / 27 参数错了也要能活）

## 5. 并账注意事项（本地线 × 并行线）

1. **编号冲突**：本地第 28 轮的"红线 25（审计类必报触发次数）"与并行线第 29 轮的"红线 25（判据频率=机制频率）"撞号；修正 108/109 两边也已各自占用。并账时需统一编号（建议：并行线顺延或加 P 前缀）。
