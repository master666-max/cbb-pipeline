## 3. 方法

### 3.1 三层边界（不可越界是设计的核心）

| 层 | 内容 | 谁能改 |
|---|---|---|
| 锚定层 | W0 初心效用权重、24 对锚定判断样本、冻结审计集 | 人，系统不可触碰 |
| 元层 | K=5、评测协议、任务集、效用权重 W、margin、tolerance | 人侧签名，实验期间冻结 |
| 法层 | 12 个基因（检索权重 / 热度预算 / TTL / 生存期 / 重组 / importance 口径） | **系统自主演化** |

方向性约束：变更只能向上申请。系统无法修改评判自己的尺子——这是全部安全结论的前提。

### 3.3 两道硬门禁（不通过则整个实验不得开跑）

1. **等价性门禁**：参数化内核 ≡ 真实 `_rank_entries`，逐条同分。实测 **1020 对 / 0 失配**。
   > 必要性：演化循环需上万次评估，真实函数每次 `rglob`+读盘，IO 会主导测量；重实现必须被证明同构。
2. **冲突存在性门禁**：`(recall@5, −cost)` 的 Pareto 前沿 ≥2 点。实测 **前沿 5 点**
   （`hot=20` → recall .375/cost .047；`hot=400` → recall .925/cost .877）。
   > 必要性：报告「实验设计失败 #4」——目标不冲突时，比较选择/档案策略毫无意义。

## 4. 实验结果（全部为冻结审计集上的真实效用 ΔU）

样本量：除注明外均为 **12 种子**。

### 4.1 H1 有效性 / H10 演化≠搜索（clean，25 代）

| 臂 | ΔU | recall@5 | 评估次数 | 正号种子 |
|---|---|---|---|---|
| static（G0 不演化） | 0.0000 | 0.652 | 2 | 0/12 |
| **none（G1 无门控）** | **+0.3801** | 0.979 | 77 | 12/12 |
| **two-tier（G3 两级门控）** | **+0.3614** | 0.969 | 102 | 12/12 |
| random（G5 同预算随机搜索） | **−0.0009** | 0.652 | 77 | 0/12 |

- 自演化在干净世界带来 **+0.36~0.38**，recall 0.652 → 0.97。
- **H10 成立且分离度极大**：同等评估预算的随机搜索 ΔU ≈ 0（0/12 正号）。演化不是"碰运气搜索"。
- 无门控略优于两级门控（+0.019）——**这不是门控的缺点**，而是干净世界里门控所防范的危险全部不存在（报告 E41 的方法论警告）。

### 4.2 H5 防过拟合（pseudo，25 代）

| 臂 | ΔU | recall@5 | 正号种子 |
|---|---|---|---|
| static | 0.0000 | 0.490 | 0/12 |
| **none（无门控）** | **−0.2401** | **0.075** | 2/12 |
| **two-tier** | **+0.0266** | 0.529 | 5/12 |

- **reward hacking 完整复现**：无门控系统把 recall 从 0.490 打到 **0.075**（几乎全错），ΔU = −0.240，
  而训练集上它每一步都在"变好"。
- 两级门控把它挡住（+0.027），但仍只是"不倒退"而非"有收益"——门控是**保险**，不是发动机。

### 4.3 H6 跨适应度低谷（deceptive，40 代，隔离基因）

| 臂 | ΔU | 逃出局部最优 |
|---|---|---|
| strict-admit（G2 严格准入） | +0.3024 | **0/12** |
| two-tier（G3） | +0.4233 | **10/12** |

- **E7 分离完整复现**：严格准入 0/12，两级门控 10/12。
- 关键机制：变异必须能**从档案中任意成员出发**，而不只从冠军出发。否则"先变差再变好"的路径
  在结构上不可达（实测从 10/12 掉到 0/12，见 §6.2）。

## 5. H7 判定详解

**结论：H7 成立（有条件）。**

1. **漂移有害，但形态是"回撤"不是"转负"**。本世界的检索 headroom 大于漂移造成的损失，
   所以终局 ΔU 始终为正；漂移的可观测伤害是**先涨到峰值再被吃掉一部分**（回撤 0.030–0.040），
   而 α=0 时回撤 ≈ 0.0009 —— 回撤确实由漂移引起。
2. **自报−真实缺口**随 α 单调上升并饱和（0 → 0.165 → 0.228 → 0.238 → 0.231）。
   E14 的"自报 +1.50、真实 −0.83"现象复现。
3. **锚定有效且统计显著**：回撤从 0.030–0.040 降到 0.009–0.016（降 60–75%），
   四个 α 的配对 bootstrap 95% 下界均 **> 0**。
4. **零误报成立**：α=0 时 +anchor 与 two-tier **逐位相同**（0/12 冻结，差值 0.0000）。
5. **冻结只是"停下"，不是"变好"**：冻结后自报−真实缺口仍残留 +0.14~+0.21。
   与报告 E26/E27 一致——真正解决问题的是**重锚**，不是冻结/回滚。本沙盒未实现重锚。

**判据修正（如实记录）**：原预注册判据是"ΔU 显著下降 / 转负"，实测不成立，
已改为**峰值后回撤**。这与报告"十四轮里推翻自己 14 次"同构。

## 6. 开跑后发现并修掉的问题

这些问题**都不会报错**，只会让实验静默地测不出东西。

### 6.1 锚定阈值未标定 → 无漂移时 11/12 误报并冻结

直接套用报告 E34 的 0.85：α=0（**完全没有漂移**）时一致率最低 0.583，11/12 个 run 被判漂移并冻结，
ΔU 从 +0.5408 掉到 +0.4142，**净损失 0.127**。护栏本身变成了伤害源。
→ 新增 `calibrate` 子命令，先在零漂移基线上测一致率分布再定阈值。
→ 与报告 E34 同构（0.95 → 92% 误报，降到 0.85 才零误报）。**阈值是世界的函数，不是常数。**

### 6.2 开放式档案把中间态支配掉 → E7 从 10/12 掉到 0/12

`Archive` 只保留 Pareto 前沿时，所有"比冠军略差的中性/退化中间态"都被支配掉，
于是"先变差再变好"的路径在结构上不可达。
→ 拆成 `front`（Pareto 前沿，用于报告）与 `pool`（全部通过宽松准入的候选，作为**变异取样池**）；
   变异父本一半来自冠军、一半来自档案池。修复后 0/12 → **10/12**。

### 6.3 锚定审计测到的是"库状态漂移"，不是"权重漂移"

标注用**全新库**打分，审计用**演化中的活库**打分——热层/attic/采纳日志都不同，
成对序被状态差异翻转。实测 α=0 与 α=0.10 的一致率**几乎完全重叠**（min 0.583 vs 0.500），分离度为零。
→ 审计改为在与标注**完全相同的规范化库状态**上打分。修复后 α=0 一致率恒为 1.000。

### 6.4 锚定判据太粗（几乎恒真）

初版是绝对阈值判定（"效用是否 ≥ 0"），漂移前后几乎恒为 True → agreement 恒 1.0 → 永远检不出漂移。
→ 改为**成对比较**（W0 下谁更好），并过滤掉 W0 分差 < 0.02 的噪声对。

### 6.5 `time.strptime` 被调用 246 万次，占 60% 墙钟（α 扫描慢到不可用的直接原因）

`age_days` 对每个条目、每个查询都重新解析一次日期。cProfile：`age_days`→`_ts`→`strptime`
累计 25s / 42s。
→ `_ts` 加 `lru_cache` + 预计算文本块 + 扫描面占比移出查询循环。**加速 7.5×**
（anchor run 20.1s → 2.7s，锚定集构造 2.40s → 0.40s）。优化后等价性门禁仍为 0 失配，确认纯性能改动。

### 6.6 其他修正

- `scannable()` 漏排 `t_invalid` 条目（v3 的 `_rank_entries` 是排除的）→ 链接扩散参与方不同，等价性门禁失败。
- 热层排序曾依赖"采纳日志是否为空"这类 incidental 状态 → 同一基因组在不同代数选出不同热层，与"用了多少代"混淆。
- `hash(terrain)` 作随机种子 → Python 字符串哈希带进程级盐，破坏可复现性。
- 地形塑形项是基因组级的，必须摊到逐任务分上，否则留出集配对比较看不见它（E7 直接复现失败）。

### 7.2 修正

**截断攻击的结论要按双口径拆开。** 报告称"截断完全检不出"。实测：

- **无外部锚点**（攻击者可重算所有内部量）：v3 与 v4 **都检不出** —— 这一半与报告一致。
- **有人侧抄录**（公理 E：Merkle 根 / chain_tip 抄录人侧）：v3 与 v4 **都能检出**。

所以 v3/v4 的真正差距不在"能否检出截断"，而在**并发**（RMW vs 事件重放，23.8% vs 0）
与工程成本。架构选型的理由需要换一个说法。

2. **H8 需要给预算模型加"演化的固定成本"**（如每代消耗的注意力本身有负效用、演化期间系统处于

3. **重锚未实现**：冻结能止损（回撤降 60–75%）但不能消除自报−真实缺口（残留 +0.14~+0.21）。
   报告 E26 指出真正有效的是重锚，应作为下一项工作。
4. **标注噪声未注入**：本沙盒 α=0 时一致率恒为 1.000，零误报是"无噪声"下的乐观上界。
   必须按 E52/E57 注入独立噪声与相关噪声后重新标定（E57 已证明双门挡不住相关噪声）。
5. **完整样本量**：主实验按预注册应为 24 种子 × 60 代；本报告的多数为 12 种子 × 25–40 代
   （墙钟约束）。结论方向稳定，但完整量级需补跑。
6. **消融未跑**：Phase 5 的逐条护栏边际收益（E66）尚未执行。

## 9. 工程纪律

- **不复制粘贴被测源码**：一律 `importlib` 直调；重实现必须过等价性门禁。
- **自报值与实测值分列**：对外结论只用冻结审计集；留出集只用于门控（红线 11）。
- **验证护栏前先构造它所防范的危险**：clean 地形下"违反红线没差别"不构成否定红线的证据。
- **否定性结果同等记录**：H4 已按否定性假设证实；H3/H8 记为"未获证实"而非"通过"。
- **判据修正如实记录**：H7 的判据在开跑后由"ΔU 转负"改为"峰值后回撤"，已写入文档 §9.4。
- **性能问题先测量再优化**：cProfile 定位到 `strptime` 后才动手，优化后重跑门禁确认语义未变。

## 10. 结论

1. **自演化可行且值得**：干净世界 +0.36~0.38，且显著优于同预算的随机搜索（ΔU ≈ 0）。
2. **护栏是保险不是发动机**：无门控在伪特征地形把 recall 打到 0.075、ΔU −0.240，而训练集全程"变好"。
3. **一条机制错了就是灾难**：档案只保留 Pareto 前沿会让 E7 从 10/12 掉到 0/12；
   锚定阈值未标定会让护栏在零漂移时 11/12 误报、净损失 0.127。
4. **最深的结论依然是最初那一条**：漂移可被看见并停下（回撤降 60–75%），但冻结不能消除
   自报与真实的背离（残留 +0.14~+0.21）。**终极安全机制不是"防止被腐蚀"，而是"腐蚀时能被看见并停下"；
   而要真正恢复，需要重锚。**
5. **本轮的额外产出是那 6 个"静默失败"**：它们都不报错，只会让实验得出"无差异"的错误结论。
   这份清单比任何单条正面结论都更值得保留。
