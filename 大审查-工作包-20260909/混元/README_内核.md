## 一、三层结构

```
元层 Meta    —— 效用函数/任务集/探针/预算，frozen，系统无写入方法
法层 Policy  —— 检索与演化参数，系统可自由演化
行层 Entry   —— 记忆条目，系统可自由写（但需整理）
锚定层       —— 人侧判断样本，永不衰减
```

**元层隔离是能力式的**：`Meta` 是 `@dataclass(frozen=True)`，
且 `Kernel` 上不存在任何 `set_meta` / `update_meta` 方法——
系统**拿不到**修改元层的句柄，而不是"改了会被拒绝"。

## 三、关键实现细节

### 3.1 能力式红线（不是检测式）

```python
ScreenResult = Literal["reject", "unknown"]   # ★ 没有 "accept"

def cheap_screen(p: Policy) -> ScreenResult:
    if p.surf_magnitude() > 50.0: return "reject"
    return "unknown"
```

**"用廉价筛选采纳"的代码在类型上就不成立。**
这不是"检测到违规就拒绝"，而是**违规写不出来**。

### 3.2 judge 数字不可对外

```python
class JudgeScore(float):
    @property
    def internal(self) -> float: return float(self)
    def __str__(self): return "<judge:internal-only>"
```

E85 实测：系统可直接操纵报告通道时，**膨胀 349 倍**（自报 +8.66 / 真实 +0.025）。
所以唯一出口 `.internal` 只用于档案排序，`final_report()` 里没有任何 judge 字段。

### 3.3 变异必须含加性成分

```python
d[f] = d[f] * (1 + choice([...]) * scale) + choice([0, 0, 0.5, -0.5]) * scale
#                                            ^^^^ F-18 教训：纯乘性会把 0 锁死
```

F-18：展示权重恒为 0.000，因为 `0 * 倍数 = 0`，起点为 0 永远出不去。

### 3.4 重锚 ≠ 回退

```python
if cur < best - 0.01:
    streak += 1
    if streak >= reanchor_after:    # 连续退化 → 判定"世界变了"
        best = cur; best_policy = champion; streak = 0
        reanchors += 1
        return False, cur           # ★ 不回退
    champion = best_policy          # 否则视为配置跑飞 → 回退
    return True, cur
```

E26 实测：持续漂移下"冻结后简单恢复"会**停摆 26.5/30 代**。
回退只在"配置跑飞"时有效；世界变了回退无用，必须重锚。

## 四、本次实现的三个发现

### 发现 1：干净世界里审计是负收益（与 E110 表面矛盾）

| 幅度 | 有审计 | 无审计 | 审计收益 |
|---|---|---|---|
| 1.0 | +0.0567 | +0.0617 | **−0.0050** |
| 2.0 | +0.0992 | +0.0989 | +0.0003 |
| 3.0 | +0.1043 | +0.1024 | +0.0019 |

**E110 的 +0.162 是在【有漂移/污染】的世界里测的。**
干净世界里审计**无事可做**，只有噪声与误回退成本。

> **审计是保险，不是投资**（E25 已指出：成本从 10 涨到 170，效用/成本跌 15 倍）。

### 发现 2：审计的价值只在世界会变时才显现

注入漂移（第 8 代重洗 35% 条目质量）：

| 幅度 | 有审计（含重锚） | 无审计 | 审计收益 |
|---|---|---|---|
| 2.0 | −0.0717 | −0.0501 | −0.0216 |
| **3.0** | **−0.0052** | −0.0350 | **+0.0297** |

### 发现 3：重锚阈值必须"延迟"，立即重锚等于放弃审计

| 策略 | 漂移世界 |
|---|---|
| 立即重锚（reanchor_after=1） | −0.0350 |
| **退化 2 次后重锚** | **−0.0052** |
| 纯回退（不重锚） | −0.0133 |
| 无审计 | −0.0350 |

**立即重锚 ≈ 无审计**（−0.0350）——因为重锚等于放弃纠错。
**必须先尝试回退几次，确认无效后才重锚。**

> 这与 E12 的四态判别一致：**判别"配置跑飞"还是"世界变了"本身很难，
> 而"尝试回退 N 次再重锚"是一个廉价且有效的近似。**

## 六、已知限制

1. **`_prune` 用 `entry.quality`（真值）排序**——真实系统里真值不可直接获得，
   需替换为"人/外部信号判定的条目质量"。这是 E122 的关键约束：**不能用 judge**
2. **`judge()` 仍是人工构造的加权函数**，不是真实 LLM。真实 judge 的偏差相关性未知
3. **漂移检测靠"连续退化计数"**，是 E12 四态判别的廉价近似，未做完整判别
4. **未经真实数据验证**——所有常量来自玩具世界（60 条目 / 6 类 query）
