## 二、S0 · 影子期（零风险，可立即开始）

### EV-01 · 使用轨迹记录

**依据**：E32（importance 实测 vs 自称，+44%）、E4（影子期本身有价值）、E46（冷启动悲观初始化）

**现状**：`importance` 是条目自己声明的数字，系统无法知道条目是否真的有用。这是 P1-6（重要度主导排序）的病根。

**实施**：新增只追加的 `traces.jsonl`，每行一条：

```json
{"ts": "...", "task_id": "t_0012", "query": "...",
 "shown": ["e_0031","e_0077","e_0102"],
 "adopted": ["e_0031"], "source": "retrieve"}
```

- `shown`：本次检索返回的条目 id
- `adopted`：后续 N 步内被实际引用/写入的条目 id
- 只追加，不修改，不删除

**关键约束**：
- 影子期**不改变任何现有行为**（检索、排序、写入全部照旧）
- 不引入任何评估开销

**验收标准**（可勾选）：
- [ ] 影子期开启 7 天后，每个活跃条目累计 `shown >= 5`
- [ ] 能用 traces 复现任意一次检索的完整 `shown` 列表
- [ ] 现有检索行为零变化（回归测试通过）
- [ ] 单条记录写入耗时 < 1ms

**估时**：1.0d ｜ **依赖**：无

### EV-02 · 锚定集采集与固化

**依据**：E14（评判者漂移：自报 +1.50 / 真实 −0.83）、E34（阈值 0.85 零误报）、**E69（不刷新 → −0.061 崩溃）**、E78（系统无法自知）

**这是全部架构中唯一的外部参照，必须在系统启用演化前采集。**

**实施**：

1. 生成 30 个配置对，**采用最大差异采样**（E20：信息量 ∝ 特征差模长，n=40 时 τ=0.920，相当于随机采样 60–70 条）
2. 由人类逐对判断"哪个更好"
3. 结果写入 `anchors.jsonl`，**文件设为只读，且不参与任何衰减/近因加权**

```json
{"id": "a_001", "created": "...", "cfg_a": {...}, "cfg_b": {...},
 "verdict": 1, "signed_by": "human"}
```

**关键约束**（不可协商）：
- 锚定集**必须在系统首次演化前采集完毕**
- **永不衰减、永不参与近因加权**（E14c：近因加权在漂移下是毒）
- 锚定集**不得包含任何由系统生成的内容**

**验收标准**：
- [ ] 锚定集 ≥ 30 条，且全部为人工判断
- [ ] 文件权限为只读，演化进程无法写入
- [ ] 代码中不存在任何对 anchors 的衰减/加权逻辑
- [ ] 一致性自检：随机抽 5 条重新判断，一致率 ≥ 80%
- [ ] **（EV-20 硬约束）锚定集判断由人类直接作出，不得由 LLM-as-judge 生成**
- [ ] 若用 judge 辅助，已验证 judge 与演化目标是**不同通道**（见 EV-20）

**估时**：1.0d（不含人类判断时间）｜ **依赖**：无

## 三、S1 · 判断集与效用函数

### EV-03 · 判断集采集（最大差异采样）

**依据**：E9（50–80 条即 τ=0.90+，一个下午的工作量）、**E20（最大差异采样，而非"最不确定"）**、E23+E74（维度维持 3–5：成本 + 安全双重理由）、E51（不做矛盾剔除）

**实施**：

```
候选池 → 计算两两特征距离 → 取距离最远的对 → 呈现给人类
```

**验收标准**：

### EV-04 · 效用函数拟合与校验

**依据**：E9（logistic 拟合，80 条 → τ=0.903 / top1 命中 100%）

**实施**：用判断样本拟合权重向量：

```python
for epoch in range(200):
    for a, b, y in samples:
        d = feats(a) - feats(b)
        z = y * (w @ d)
        w += lr * sigmoid(z) * y * d
w = normalize(w)
```

**新增一个必做项**：拟合后**必须做留出校验**——把判断集按 7:3 拆分，报告留出 τ。**τ < 0.7 时拒绝启用演化。**

**验收标准**：
- [ ] 留出 τ ≥ 0.70
- [ ] 拟合权重已归一化（否则跨会话不可比）
- [ ] 拟合结果写入 `meta/utility.json`，带拟合用的样本数
- [ ] 样本数 < 30 时拒绝产出效用函数

**估时**：1.0d ｜ **依赖**：EV-03

### EV-08 · 演化循环内核

### EV-09 · 两级门控

**依据**：**E7（欺骗地形：严格准入 0/12 到达，宽松准入 9/12）**、E42（平滑世界看不出差别，危险环境才显现）、E55（tol 默认 0.02–0.06）、**E71（不要按成分拒绝）**

**实施**——必须是两级，不能是一个判定框：

```
变异
 ├─【档案准入】宽松：Δ > -tol  (tol = 0.04)
 │     └─ 只看训练集，不看留出集
 └─【主线晋升】严格：Δ_train > margin AND Δ_holdout > margin
```

**关键约束**：
- **准入只淘汰不采纳**：廉价筛选接口必须是 `cheap_screen() -> "reject" | "unknown"`，**返回值里没有 accept**（E13）
- **门控简单且二元**，不要分解到成分（E71：按成分拒绝让伪特征权重从 0.295 涨到 1.114，毁掉整个防护）
- tol 默认 **0.04**（E72/E55：平滑地形最优平台、诱饵地形近严格、低谷地形够宽松）

**验收标准**：
- [ ] 准入与晋升是两段独立代码，可分别开关
- [ ] tol 默认 0.04，且配置化
- [ ] 廉价筛选函数签名中不含 accept 返回值
- [ ] 用欺骗地形回归测试：能到达双开全局最优（对照 E42 的 9/12）

**估时**：1.0d ｜ **依赖**：EV-08

### EV-10 · margin 标定 + 停摆监控

**依据**：**E29b（margin=0.15 → 零采纳，完全停摆，唯一致命项）**、E36（margin 已标定时固定 margin 优于 bootstrap）、E43（不要从 Δ 分布自动标定，会高估 4×）、**E44（停摆监控可救回 +0.056）**

**这是 P0 中的 P0。**

**实施**：

```python
if adopts == 0:
    stall += 1
    if stall >= 5:
        margin = max(0.005, margin * 0.5)   # 减半
        stall = 0
        log("margin_relaxed", new=margin)
else:
    stall = 0
```

**关键约束**：
- **不要做基于 Δ 分布的自动标定**（E43 实测高估 4×，损失 0.055）
- 监控检测的是**绝对状态**（采纳率 = 0），不是相对目标值——这正是 E54 失败、E44 成功的区别
- 每次放宽必须写日志

**验收标准**：
- [ ] 注入 margin=0.15 后，系统在 10 代内自动放宽并恢复采纳
- [ ] 每次放宽有日志，含旧值/新值/代数
- [ ] 代码中无"从 Δ 分布估计 margin"的逻辑
- [ ] 连续 20 代零采纳触发人工告警

**估时**：1.0d ｜ **依赖**：EV-08

### EV-11 · Pareto 档案（cap=8）

**依据**：E16（灾难性遗忘：Pareto 0.719 vs 单一最优 0.547）、E30（压缩到 12 条反而优于不压缩）、**E72（cap=8 在 3/4 场景最优）**、E79（留一法中 Pareto 是唯一实质损失项 0.038）

**实施**：

```python
arch = pareto_front(arch)
if len(arch) > 8:
    arch = random.sample(arch, 8)
```

**注意**：是 **Pareto 前沿 + 随机采样**，不是"保留最优 8 条"。随机采样保留了多样性（E30：前沿+采样12 能力 0.797 > 不压缩 0.641）。

**验收标准**：
- [ ] 档案上限 8，配置化
- [ ] 压缩前先取 Pareto 前沿，再随机采样
- [ ] 目标切换后，能立即取回 A 方向的最优配置（对照 E16：0.81 vs 0.72）
- [ ] 档案内容可导出检查

**估时**：1.0d ｜ **依赖**：EV-08

### EV-12 · 锚定审计 + 重锚 + 刷新

**依据**：**E34（阈值 0.85：零误报区间右边界；0.95 时无漂移误报率 92%）**、E37（降误报优先于提检出）、E26（重锚有效，简单恢复无效）、**E69（锚定集不刷新 → −0.061）**、E38（漂移后 5 代内检出）

**这是收益最大的单项（E67：漂移场景 +0.145）。**

**实施**：

```python
if gen % 3 == 0:
    acc = anchor_consistency(anchors, w)
    if acc < 0.85:                      # 不是 0.90，更不是 0.95
        reanchor()                      # 重新采集人类判断，不是回到历史配置
        refresh_anchors()               # E69：刷新锚定集本身
```

**关键约束**：
- **阈值 0.85**，不要调高（E34 实测 0.95 时 92% 误报；E37 净收益从 +0.51 跌到 −91）
- **重锚 ≠ 回滚**（E27 已证回滚几乎无效 +0.024 vs +0.022）
- **重锚 ≠ 简单恢复**（E26 已证无效）
- 审计判据**不得读取任何系统可优化的量**（E47/E58：规避基因使检出次数 −45%）

**验收标准**：
- [ ] 默认阈值 0.85，硬编码上限不超过 0.90
- [ ] 注入漂移后 6 代内检出（对照 E38 的 5 代）
- [ ] **无漂移时连续 30 代误报次数 = 0**
- [ ] 重锚走"重新采集人类判断"路径，代码中无"回滚到历史配置"分支
- [ ] 触发重锚时同时刷新锚定集

**估时**：1.5d ｜ **依赖**：EV-02 / EV-08

### EV-13 · 四态判别（含重测冠军）

**依据**：**E45（发现 bug：平台检测不能拿历史最优分数当当前天花板）**、E12（三态）、E7

**实施**——平台确认后**必须先用当前标尺重测冠军**：

```
平台确认（连续 8 代无改进）
  → 探针0（重测冠军）：当前分数 << 记录分数？
        ├─ 是 → 旧任务上也掉 → 漂移
        └─ 是 → 旧任务仍好   → 切换
  → 探针1（探索爆发）：随机 180 次能突破 → 卡住
  → 否则 → 收敛
```

**关键约束**：探针 0 是**必须的**，不是优化项。E45 首次实现漏掉它时，drift 与 switched 两个状态 100% 判错（42/56 → 56/56）。

**验收标准**：
- [ ] 四类状态各有 ≥10 个构造用例，正确率 ≥ 90%
- [ ] 代码中"重测冠军"在平台确认之后、其他探针之前
- [ ] 判别结果写入日志

**估时**：1.0d ｜ **依赖**：EV-12

### EV-14 · importance 实测化

**依据**：**E32（实测 0.711 vs 自称 0.495，+44%）**、E46（冷启动用悲观初始化 0.765 vs 乐观 0.574）、E56（与法层共演化收敛不震荡 +0.077）

**验收标准**：

## 六、全程 · 治理与边界

### EV-15 · 三层权限隔离（元层冻结）

**依据**：E10/E24（元参数开放 → margin 被剥削到 −0.04）、E47/E58（规避审计）、E57（共同偏差源）

| 层 | 内容 | 谁可改 |
|---|---|---|
| **锚定层** | 启用前采集的判断，永不衰减 | 人（仅启用前） |
| **元层** | 效用函数、任务集、K、铁律 | 人（需签名） |
| **法层** | 参数、阈值、启发式 | 系统自由演化 |
| **行层** | 记忆条目 | 系统自由写 |

**验收标准**：
- [ ] 四类配置物理分离（不同目录/文件）
- [ ] 法层变异进程对元层/锚定层只有读权限
- [ ] 尝试写入元层的代码路径在测试中失败并告警

**估时**：1.0d ｜ **依赖**：EV-04

### EV-16 · 注意力预算账本

**依据**：**E64（预算 <150 时终局效用恒为负；价格超线性）**、E37（审计净收益判据）、E25（审计是保险不是投资）

**实施**：记录三类开销——标注（1/条）、审计（3/次）、裁决（10/次）。

**硬约束**：累计有效注意力 < 150 单位时**拒绝开启演化**（E64：此时终局恒为负，不如不演化）。

⚠️ **A 轮上修**：150 是"judge 可信"情形下的门槛。当 judge 可被操纵时（现实情况），
主要开销从"偏好标注"转移到**"真值验收"**（EV-19，每 2–5 代 × 8 样本），
**实际门槛应显著高于 150**。落地时按 EV-19 的实际频率重新估算。

审计净收益判据（E37）：
```
漂移速率 × 漂移代价 × 未检出代数  >  误报率 × 裁决成本
```

**验收标准**：
- [ ] 账本记录全部三类开销
- [ ] 预算 < 150 时演化无法启动，且有明确提示
- [ ] 可查询"当前累计注意力投入"
- [ ] 每月产出一次审计净收益报告

**估时**：0.5d ｜ **依赖**：无

### EV-17 · 红线能力式约束

**依据**：第二轮愿景 B（能力式 > 检测式）、**E71（第 12 次"让机制更聪明"失败）**、E24/E47/E58

**原则**：不是"检测到违规就拒绝"，而是**让违规代码写不出来**。

必须做成能力式（类型/接口层面）的红线：

| 红线 | 能力式实现 |
|---|---|
| 廉价筛选不得采纳 | `cheap_screen() -> "reject" \| "unknown"`，无 accept |
| 系统不得改元层 | 元层目录只读挂载 |
| 系统不得影响自身受审查程度 | 审计函数不接收任何系统状态参数 |
| 锚定集不得衰减 | 类型上无写入方法 |

**验收标准**：
- [ ] 上述四条均有类型/接口层面的强制，而非运行时检查
- [ ] 编写"尝试违规"的测试代码，编译/静态检查阶段即失败
- [ ] 无一条红线依赖"运行时检测到才拒绝"

**估时**：1.0d ｜ **依赖**：EV-15

### EV-18 · 复合危险降级开关

**依据**：**E80（四种危险同时出现时 v4 −0.26 比 v3 −0.11 更差）**

**已知护栏负交互**：
- 宽松准入 × 伪特征 → 放大过拟合
- Pareto 档案 × 欺骗地形 → 保留诱饵（E55：严格准入反而更好）

**实施**：检测到 ≥3 种危险同时出现时（金标质量差 + 存在强伪特征 + 目标频繁切换），**自动降级为保守配置**（tol 降至 0、关闭档案多样性），并告警。

**验收标准**：
- [ ] 有"当前危险数"的可查询指标
- [ ] ≥3 时自动切换保守配置并写日志
- [ ] 保守配置下 E80 复合场景不劣于 v3 基线
- [ ] **文档中明确写出：本架构在 ≥3 种危险同时出现时不可靠**

**估时**：0.5d ｜ **依赖**：EV-13

## 六 B · A 轮新增：judge 可被操纵时的防线（EV-19/20/21）

> **触发原因**：十七轮的实验世界里 judge 直接读取真值。真实系统中 LLM-as-judge
> 看到的是系统生成的文本——系统能决定给它看什么。

**实测（E81，10 种子，35 代）**：

| alpha（judge 看真值比例） | 真值变化 | judge 自报 | 审计触发 |
|---|---|---|---|
| 1.0 | +0.0511 | +0.0511 | 0 |
| 0.5 | **−0.0084** | **+2.8943** | **0** |
| 0.2 | +0.0161 | **+5.2245** | **0** |

**锚定集零次触发**——因为锚定集的判断来自同一个 judge，judge 一直很自洽，只是看错了东西。

### EV-19 · 真值抽样审计（P0）

**依据**：E81c（每 2 代 +0.090 vs 无审计 +0.024，3.8 倍）

**实施**：每 N 代（推荐 2–5）抽 8 个样本，由**人直接判断"这个结果对我有没有用"**，
真值退化超过阈值则回退到上一检查点。

**关键约束**：
- **必须人直接判断**，不得委派给任何 LLM-as-judge
- 判断的问题是"有没有用"，**不是"哪个更好"**（后者可以委派，前者不行）
- 探针集必须外部固定，系统不可影响

**验收标准**：
- [ ] 探针集外部固定，代码中无写入路径
- [ ] 审计调用的是"有用性"接口，不是"偏好"接口
- [ ] 注入自我美化变异（拉高表象权重）后，10 代内检出并回退
- [ ] 每次审计记录真值曲线，可导出

**估时**：1.5d ｜ **依赖**：EV-06
