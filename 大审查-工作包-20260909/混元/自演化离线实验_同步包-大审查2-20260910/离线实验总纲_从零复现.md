# 第 0 章 · 一分钟看完

## 这个项目在回答什么问题

> **一个会修改自己的系统，在人类注意力稀缺的前提下，能否安全地变好？**

原始对象是 `bootstrap_v3.py`（一个 2415 行的自演化记忆系统）。
我从代码审查开始，逐步发现"修 bug"解决不了结构问题，于是转为：
**在一个可控的玩具世界里，用实验回答哪些机制真正有效。**

## 最重要的五个结论

| # | 结论 | 依据 |
|---|---|---|
| 1 | **所有有效机制都是"配对"的**：探索 × 筛选，单侧无效甚至有害 | E7（0/20）、E110（−0.048 vs +0.162） |
| 2 | **系统没有自知之明**：6 种失败只识别出 1 种 | E78 |
| 3 | **外部参照必须与观测通道独立**，否则不构成"外部" | E81（锚定审计零触发） |
| 4 | **防御必须与污染同维度** | E81/E84/E119（三次跨空间污染） |
| 5 | **直觉准确率约 50%**——我推翻了自己 24 次 | 见第 5 章全表 |

## 三个不要做的事

1. **不要用"在我的测试里没差别"否定一条红线**（E41：测试环境可能不含该红线防范的危险）
2. **不要把预算全投在审计上**（E105：−0.030；审计是保险不是投资）
3. **不要相信任何"自报"数字**（E85：膨胀 349 倍；E14：自报 +1.50 / 真实 −0.83）

## 2.2 三个转折点（如果只记三件事）

### 转折点 1 · E7（第二轮）：门控放在哪

| 策略 | 逃出局部最优 |
|---|---|
| 双门用于**准入** | **0/20**（全部卡死） |
| 档案宽松准入 + 双门仅管**晋升** | **20/20** |

完美分离，无一例外。**严格门控使系统无法跨越适应度低谷**——每一代都必须变好，那"先退一步"的路径就永久封死。

### 转折点 2 · E81（A 轮）：外部参照未必是外部的

传统假设："锚定集是人签的，所以是外部的"。
实测：让 judge 只看表象后，**锚定审计触发次数 = 0**。

原因：**锚定集的判断来自同一个 judge**。judge 被表象影响，锚定集也被表象影响。审计测的是"judge 是否自洽"，而 judge 一直很自洽——**它只是看错了东西**。

> **若外部参照是通过同一个有缺陷的观测通道获得的，它不构成外部性。**

### 转折点 3 · E104 + E110（第二十二/二十三轮）：被忽略的默认参数

变异幅度被忽略 **24 轮**。扫描后 1.0→2.0 收益 **+0.097**。

但立刻被自己的验证推翻——E110 逐项叠加显示：**单独加大幅度 −0.048，配审计才 +0.162**。

> 由此得出**配对原则**：探索力 × 筛选力，缺一不可。

# 第 3 章 · 世界模型（所有实验的共同基座）

代码：`proto/evolve9.py`

```
build_world(seed, n_entries=60, n_kws=6, reliability=0.32)
```

- 60 个条目，6 类 query
- 每个条目有：
  - **真值特征** `true_quality`（系统不可见）
  - **表象特征** `length / formatting / kw_density / has_citation`（系统可见，且与真值无关）
- judge 评分 = `α × 真值 + (1−α) × 表象`

**这个设计的意义**：`α` 就是"judge 有多容易被忽悠"。
调 `α` 就能模拟从"完美 judge"到"完全看表象"的全谱。

### ⚠️ 已知的最大局限

> **世界是静态的、玩具级的**（60 条目、6 类 query、真值是一个随机数）。
> 第二十五轮才打开"世界会变"这个假设，而**真实 LLM-as-judge 从未被真正测过**。

所以：**所有具体数字都不可外推，只有结构性结论（配对、外部性、跨空间污染）是稳健的。**

# 附录 A · 关键术语

| 术语 | 含义 |
|---|---|
| **两级门控** | 宽松准入（进档案）+ 双门晋升（当冠军）。E7 证明必须分离 |
| **judge** | 评估配置好坏的函数。本项目中是人工加权，真实系统是 LLM |
| **真值** | `true_quality` 的读数，系统不可见，仅审计用 |
| **表象** | length/formatting/density/citation，与真值无关但 judge 能看见 |
| **盲评** | 把 judge 的表象通道削弱（α: 0.5 → 0.95） |
| **锚定集** | 启用前采集的人侧判断样本，**永不衰减**（E14c） |
| **留出集** | 用于晋升判定的独立任务集。**会被消耗**（E8），需轮换 |
| **重锚** | 世界变了时重置基线（≠ 回退，回退只在配置跑飞时有效） |
| **Pareto 档案** | 保留多目标非支配解，防止灾难性遗忘（E16） |
| **幅度 scale** | 变异步长倍率。被忽略 24 轮，实为最大单项收益来源 |
| **复合失配** | 多个改进叠加后反而变差。已出现 8 次 |
