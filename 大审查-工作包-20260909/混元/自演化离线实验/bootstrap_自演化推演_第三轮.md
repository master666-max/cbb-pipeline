# 自演化 · 第三轮推演

> 承接前两轮。本轮追问五个尚未回答的问题：**元层从哪来、能不能自己改自己、档案该留什么、平台期意味着什么、预算怎么花**。
> 实验：`proto/evolve5.py`（本轮含 **2 次实验设计失败后的重建**，过程记在附录）

---

## 一、五个实验

### E9 存「判断」而非存「公式」——可行，且有明确样本量门槛

**问题**：第二轮提出"元层事实源应是带签名的人类判断样本，规则是派生品"。这可行吗？需要多少样本？

**设计修正**：最初测"拟合效用驱动演化的终值"，但演化增益（0.02）淹没在单种子噪声里，达成率在 −473%~137% 之间乱跳。改为测**选择一致性**——给 60 个候选配置，用拟合权重排序 vs 用真值权重排序，比 Kendall τ 与 top-k 重合。

| 判断样本数 | 权重误差 | 排序相关 τ | top1 命中 | top3 重合 |
|---|---|---|---|---|
| 5 | 0.785 | 0.654 | 60% | 50% |
| 10 | 0.460 | 0.825 | 60% | 67% |
| 20 | 0.453 | 0.817 | 80% | 60% |
| 40 | 0.380 | 0.833 | 70% | 80% |
| **80** | **0.217** | **0.903** | **100%** | **93%** |
| 160 | 0.160 | 0.943 | 100% | 87% |

**结论：约 50–80 条人类判断样本，就能让系统选出人真正想要的配置（τ>0.9，top1 全中）。**

这个数字很重要——它不是"海量标注"，是**一个下午能做完的工作量**。第二轮提出的"存判断不存公式"从哲学主张变成了可预算的工程项。

### E10 递归自我修改：没有退化，但这是个弱结论

把 `margin` / `tol` / `mut_rate` 这些**门控参数本身**开放给演化：

| 模式 | 留出集真实效用 | 终局 margin | 终局变异率 |
|---|---|---|---|
| 元参数冻结（基准） | 0.7806 | 0.0100 | 1.000 |
| **元参数开放演化** | **0.7931** | 0.0088 | 1.000 |

没有退化，甚至略好；margin 只从 0.010 微降到 0.0088，没有出现"把门槛放松到形同虚设"。

**但必须诚实说明这是弱结论**：本实验**没有给元参数提供作弊通道**——margin 不影响 `U_true` 的取值，演化它得不到任何直接收益，所以"没退化"是意料之中。真正危险的递归场景是"系统能通过放松门控来让自己更容易被采纳"，本实验未构造。

**这个实验的价值在于划界**：它证明"元参数可被演化"本身不必然崩坏，但**是否安全取决于是否存在剥削通道**。所以设计原则是：

> 元参数可以演化，**前提是它不能直接改变"自己被评判的结果"**。`margin`/`tol` 属于这一类（可演化）；`任务集`/`效用函数权重`/`K` 不属于（必须人侧签名）。

### E11 Pareto 档案 vs 单一最优档案

**场景**：先用**错误目标**（只看命中率，忽视噪声与成本）演化 25 代；然后目标被证伪、换成真目标，看恢复能力。

| 档案策略 | 恢复后效用 | 档案规模 |
|---|---|---|
| 单一最优档案 | 0.5919 | 1 |
| **Pareto 档案** | **0.6990** | 30 |

**Pareto 档案恢复到的水平高出 0.107**。

这可能是本轮最实用的一条：**当目标会被证伪时，档案的价值不在"记得曾经最好"，而在"保留了不同权衡方向的活样本"**。单一最优档案在目标变更后只剩一个已经跑偏的配置。

代价是档案规模（30 vs 1），需要第二轮已提到的档案治理（保留前沿 + 分叉点 + 随机样本，其余移 attic）。

### E12 平台期三态判别——36/36 完美

第二轮指出"收敛 / 卡住 / 世界漂移"三者表现相同但应对相反，必须能区分。本轮实现并验证判别器：

```
平台确认（连续 10 代无改进）
  → 探针1：提高探索强度（随机采样 180 点），若突破 → 卡住
  → 探针2：新任务 vs 旧任务性能差 → 漂移
  → 否则 → 收敛
```

| 真实状态 | 判别分布 |
|---|---|
| converged | converged ×12 |
| stuck | stuck ×12 |
| drifted | drifted ×12 |

**36/36 全部正确。**

> 注：第一次跑时 stuck 被 12/12 误判为 converged。原因是**我用宽松准入去构造"卡住"，而宽松准入自己就能逃出低谷**——判别器没错，是我的构造不成立。改用严格准入后完美分离。这个插曲本身说明：**判别器输出的是"当前策略下是否已到极限"，而非"地形是否已到顶"**。

### E13 两阶段门控：预算怎么花

固定昂贵评估预算 = 60，比较三种用法：

| 模式 | 留出集提升 | 实际代数 |
|---|---|---|
| 全部走昂贵门控 | −0.0100 | 15.0 |
| **廉价筛选只淘汰（正确用法）** | **+0.0150** | **25.4** |
| 廉价筛选也用于采纳（错误用法） | **−0.2728** | 60.0 |

两个结论：

1. **"只淘汰"不仅安全，而且更好**（+0.015 vs −0.010）——因为它把预算省下来跑了 25 代而不是 15 代。安全性与效率在这里不冲突
2. **用于采纳是灾难**（−0.273）——廉价评估的噪声被当成真实改进反复采纳，跑满 60 代一路劣化

这把第二轮的"成本不对称"主张从定性变成了定量。

## 二、架构修正

### 修正 7 · 元层的形态与预算

```
元层事实源 = 判断样本库
   { (情境, A方案, B方案, 人判 A 优于 B, 理由, ts, 签名) , ... }
   
派生品（全部可重算）：
   效用函数权重  ← 配对 logistic 拟合（E9：80 样本 → τ=0.90）
   铁律文本      ← 归纳渲染
   TUNABLES      ← 标定
```

**冷启动预算：50–80 条判断样本。** 这是一个下午的工作量，不是项目级投入。

**增量维护**：每次人类裁决自动生成 1 条判断样本（系统已经知道 A/B 和人的选择），所以**标注成本随使用自动摊薄**——用得越久，样本越多，拟合越准。这是"存判断"相对"存公式"的关键优势：公式不会随使用变好，判断样本会。

### 修正 8 · 元参数的演化权限分级

| 参数 | 是否可自动演化 | 理由 |
|---|---|---|
| `margin` / `tol` / `mut_rate` | ✅ 可 | 不直接影响被评判的结果（E10） |
| `探索强度` / `档案采样策略` | ✅ 可 | 同上 |
| **任务集** | ❌ 人侧签名 | 直接决定"被评判的是什么" |
| **效用函数权重** | ❌ 人侧签名 | 直接决定"什么叫更好" |
| **`K` / 评测协议** | ❌ 人侧签名 | 结构性约束（E2 已证：它让堆权重无法刷分） |

判据一句话：**能改尺子的，不能改；只能改怎么找的，可以改。**

### 修正 9 · 档案保留 Pareto 前沿

从 E11 的 +0.107 收益看，档案策略应从"保留最优"改为"**保留多目标前沿 + 谱系分叉点 + 随机样本**"。

三目标建议：`命中率 / 噪声率 / 成本`——正好对应 E9 中拟合出的三维效用。

### 修正 10 · 平台期自动判别协议

E12 验证过的两探针协议纳入常态运行：

```
每 N 代：若无改进 →
   探针1（探索）：随机采样 180 次 → 有突破 = 卡住 → 提高探索强度/放宽准入
   探针2（漂移）：新采样的真实任务 vs 旧任务 → 性能差 = 漂移 → 刷新任务集、重标定效用
   均无 = 收敛 → 停止演化，把算力投向别处
```

### 修正 11 · 廉价筛选器的接口约束

E13 定量确认后，接口应硬性约束为：

```python
def cheap_screen(candidate) -> Literal["reject", "unknown"]:
    """只能返回 reject 或 unknown，永远不能返回 accept"""
```

这是**类型级的保证**——与第二轮提出的"能力式安全"同构：不是"提醒你别用它采纳"，而是**返回值里根本没有 accept**。

## 三、更深的一层：三层递归结构

把三轮实验放在一起看，出现了一个递归模式：

| 层 | 准入 | 晋升 | 事实源 |
|---|---|---|---|
| 行层（记忆条目） | 宽松（append 即入） | **实测效用**（v3 缺：`importance` 自称） | 事件流 |
| 法层（策略配置） | 宽松（E7） | 双门配对 + 留出（E3/E7） | 事件流 |
| 元层（评判标准） | 人侧签名 | 人侧签名 | **判断样本库** |

每层都是"**宽松准入 + 严格晋升 + 可回滚**"。区别只在晋升判据的来源：行层靠实测、法层靠任务集、元层靠人类判断。

而**判断样本库本身也遵循同一模式**——它只追加（铁律 4）、带签名、可回滚（新增判断推翻旧判断，而非删除）。

这意味着**不需要为三层各写一套机制**，只需要一套"宽松准入 + 可插拔晋升判据 + 完整谱系"的引擎，配三个不同的判据实现。这可能是整个重构中最有价值的简化。

### 一个需要注意的不对称

元层的晋升判据是"人类判断"，而人类判断本身：

- 有噪声（E9 中模拟了 10% 判错率，拟合依然有效——**这是好消息，说明方法对噪声鲁棒**）
- 会随时间变化（三年前认为好的，今天未必）
- 可能自相矛盾（不同时间的判断冲突）

第三点值得单独设计：判断样本应带 `ts`，拟合时**近因加权**，冲突判断不删除旧的而是靠权重衰减。这与记忆条目的 TTL 机制同构——又一次印证了三层递归。

## 五、新增红线

11. **能改尺子的参数不可自动演化**（E10 的边界条件）——`任务集`/`效用权重`/`K` 必须人侧签名
12. **廉价筛选器只能返回 reject 或 unknown**（E13，类型级保证）
13. **档案保留 Pareto 前沿而非单一最优**（E11，+0.107）
14. **平台期必须跑三态判别，不得默认"收敛"**（E12，否则世界变化时安静退化）
15. **判断样本只追加、带 ts、近因加权**（冲突判断靠衰减而非删除）

## 六、下一步最该做的三件事

按"确定性 × 收益"排序：

1. **建判断样本库**（E9：80 条即可达 τ=0.90）——这是唯一有明确工作量、且解锁整个元层的事。而且每次人类裁决自动产生样本，越用越准
2. **实现三态判别协议**（E12：36/36，代码量小）——它防止的是"世界变了一切指标还绿"这种最难发现的失败
3. **实现两级门控 + Pareto 档案**（E7/E11）——这是自演化循环的主干，且行层记忆可复用同一套引擎

## 附：本轮两次实验设计失败的记录

诚实记录，因为它们各自都有信息量：

**失败 1（E9 度量选择）**：最初用"拟合效用驱动演化的终值"衡量，演化增益 0.02 被单种子噪声淹没，达成率在 −473%~137% 乱跳。**改为排序一致性（Kendall τ）后得到单调曲线**。教训：当信噪比极低时，换度量比加种子数更有效。

**失败 2（E12 stuck 构造）**：用宽松准入构造"卡住"，结果 12/12 被判为收敛——**判别器没错，是构造不成立**（宽松准入本就能逃出低谷，所以确实是收敛了）。改用严格准入后 36/36 正确。教训：这恰好再次印证 E7——**宽松准入下几乎不存在"卡住"**，因为多样性保留了跨越低谷的路径。
