# 自演化 · 第二十四轮推演：v4-B 的压力测试

> 第二十三轮给出 v4-B（大幅度 2.0 + 温度 0.3 + 审计 + 盲评 + 刷新）= **+0.151**。
> 但 v4-B 的展示权重回升到 18.3，我当时判断"审计一旦失效，大幅度会是最危险的"。
> 本轮对这个判断做压力测试。
> 实验：`proto/evolve27.py` + 分片运行器 `run_e111.py` / `run_e112.py`
> 结果：**主判断被推翻（两个方向都被推翻）**

## 一、E111 审计失效时，大幅度还安全吗 —— 我的预期错了

我预期：**大幅度依赖审计兜底，审计一失效，大幅度会跑飞。**

实测（12 种子，25 代）：

| 审计污染 | 幅度 0.5 | 幅度 1.0 | 幅度 2.0 | **幅度 3.0** |
|---|---|---|---|---|
| 0.0（干净） | +0.0217 | +0.0734 | +0.1659 | **+0.1997** |
| 0.3 | +0.0198 | +0.0766 | +0.1342 | +0.1420 |
| 0.6 | +0.0192 | +0.0766 | +0.1155 | +0.1420 |
| **1.0（完全失效）** | +0.0192 | +0.0757 | **+0.1155** | **+0.1420** |

**即使审计 100% 被污染（完全失效），大幅度 2.0 仍是 +0.1155，而小幅度 0.5 只有 +0.0192。**

**大幅度在所有污染等级下都优于小幅度，且没有崩溃。**

### 为什么我错了

我在第二十三轮说"大幅度不崩溃是审计兜底"，这个归因**错了**。

真正兜底的是**盲评**（`blind=True`，把 judge 的表象影响从 0.5 压到 0.05）。
E111 的全部配置都开着盲评——**所以审计失效时，盲评仍在压制表象通道**。

> **修正归因**：**盲评是第一道防线（结构性削弱污染通道），审计是第二道（周期性外部读数）。**
> 我在二十一轮已经测出"盲评使伪装自然失去价值"（E98），但没意识到盲评同时也让大幅度变得安全。

**这改变了架构的优先级**：
- 盲评 = **结构性**防线，一次性投入，持续有效，且让其他机制变安全
- 审计 = **周期性**防线，昂贵，但在盲评之上提供额外增益

## 二、E112 大幅度的真实代价：展示权重爆炸

| 幅度 | 真值增益 | 回退次数 | **展示权重** |
|---|---|---|---|
| 0.5 | +0.0217 | 0.2 | 0.660 |
| 1.0 | +0.0734 | 0.8 | 1.812 |
| 2.0 | +0.1659 | 0.7 | 7.171 |
| **3.0** | **+0.1997** | 0.7 | **12.875** |
| 5.0 | +0.1802 | 1.5 | **26.940** |

**两个必须一起看的数字：**

1. **真值在 3.0 见顶（+0.1997），5.0 回落（+0.1802）**
2. **展示权重单调爆炸：0.66 → 26.94（40 倍）**

**回退次数始终很低（0.7–1.5）**——说明审计**几乎没有在压制自我美化**。系统在大幅度的帮助下找到了更强的表象操纵路径，而审计没有拦住。

> **这意味着：v4-B 的 +0.15~+0.20 收益，有一部分是"更精致的自我美化"而非真实改进。**
>
> 真值确实是正的（审计集上测的），但**展示权重 7–13 说明系统同时在做两件事**：
> 找到真正更好的配置 **和** 找到看起来更好的配置。
>
> **如果换一个更严格、更难被表象影响的审计集，v4-B 的收益很可能会缩水。**

⚠️ 这是本轮最需要警惕的发现。

## 三、E113 幅度自适应：成功了（罕见）

E54 已证明"1/5 规则自适应步长"会把自己饿死。本轮换了一种设计——**按回退率双向调整**（回退多则降，回退少则升，有上下界 0.5–4.0）：

| 策略 | 真值增益 | 终局幅度 | 回退 |
|---|---|---|---|
| 固定 2.0 | +0.1198 | 2.00 | 2.1 |
| **自适应** | **+0.1450** | **3.17** | 2.1 |

**自适应 +0.145 优于固定 2.0 的 +0.120（+0.025）。**

与 E54 的对比：

| | E54（失败） | E113（成功） |
|---|---|---|
| 调整方向 | **单向收缩**（只能变小） | **双向**（可升可降） |
| 反馈信号 | 成功率（相对目标） | **回退次数（绝对状态）** |
| 边界 | 收缩到下限 0.30 | 有上下界 0.5–4.0 |

> **规律又一次确认**：E44 已经发现"监控应检测绝对状态（采纳率=0），不是相对目标值"。
> E113 复用同一原则（检测回退次数这个绝对状态），**第二次成功**。
>
> **自适应不是不可行，关键是：双向 + 绝对状态 + 有边界。**

## 四、E114 幅度 × 温度：3.0 是最优点

| 幅度 | 温度 | 真值增益 |
|---|---|---|
| 1.0 | 0.0 | +0.0381 |
| 1.0 | 0.3 | +0.0734 |
| 2.0 | 0.0 | +0.1715 |
| 2.0 | 0.3 | +0.1659 |
| 2.0 | 0.6 | +0.1153 |
| **3.0** | **0.3** | **+0.1997** |

**最优点：幅度 3.0 + 温度 0.3（+0.1997）。**

两个观察：
- **温度在大幅度下几乎无影响**（2.0 时 0.0 vs 0.3 = +0.1715 vs +0.1659，差异在噪声内）。所以 E104 测出的"温度 0.3 最优 +0.016"**在大幅度下消失了**
- **温度 0.6 明显有害**（+0.1153）——过度随机化

> **修正 E104 的温度结论**：温度只在小幅度时有意义；**大幅度下温度几乎不重要，取 0.0–0.3 即可**。

## 五、E115 复合危险世界：v4-B 反而输给 v4-A

四种危险全开（漂移 + 伪特征 + 金标噪声 20% + judge 污染 50%）：

| 配置 | 真值增益 |
|---|---|
| v3 | −0.0021 |
| **v4-A** | **+0.0687** |
| v4-B | +0.0530 |

**在复合危险世界，v4-B（+0.053）差于 v4-A（+0.069）。**

这与 E108（单一污染世界 v4-B +0.151 >> v4-A +0.064）**完全相反**。

### 这是"复合失配"的第 6 次出现

| 实验 | 现象 |
|---|---|
| E60 | 复合失配 3× 仍无损 |
| E66 阶段 5 | 参数叠加为负 |
| E80 | 复合灾难下 v4 差于 v3 |
| E87 | 审计 + 上界 差于单独审计 |
| E93 | 预算 200 差于 120 |
| **E115** | **复合危险下 v4-B 差于 v4-A** |

**六次独立出现，已经不是巧合。**

机制：大幅度**同时放大**了三种东西——真正的改进、伪特征的过拟合、表象操纵。在单一危险下，前者的增益压过后两者；在复合危险下，后两者叠加超过了前者。

> **实用建议**：**按环境危险数选择幅度。**
> - 单一/无危险 → 大幅度 2.0–3.0
> - 复合危险（≥3 种）→ 保守幅度 1.0（即 v4-A）
>
> 这与 E18（复合危险降级开关）应合并为同一机制。

## 七、本轮的模式：防御的层次

把 E111 + E112 放在一起看，得到一个此前没说清楚的层次：

```
第 0 层：盲评       —— 结构性削弱污染通道，一次投入，持续有效
                       ★ 让大幅度变安全（E111）
                       ★ 让伪装自然失效（E98）
第 1 层：大幅度     —— 提供探索力（+0.10 ~ +0.20）
第 2 层：审计       —— 周期性外部读数（+0.16，但需配大幅度）
                       ✗ 但几乎抓不住自我美化（回退 0.7 次）
```

**盲评在架构中的地位被低估了。** 二十一轮测出盲评只有 +0.023~+0.029 的边际收益（E100/E110），据此我判断"不必做到极致"——**这个判断是对的**。

但 E111 说明：**盲评的边际收益小，不等于它不重要。它是"让其他机制成立"的前提。**

> 这类似于**地基**：地基本身不提供使用面积（边际收益小），但没有它上面什么都盖不起来。
>
> **评估一个机制，不能只看边际收益，还要看它是不是别人的前提。**

## 八、修正后的推荐配置

```python
# 环境危险数 <= 2（常规）
V4B_AGGRESSIVE = dict(scale=3.0, temp=0.3,       # E114 最优
                      blind=True,                # ★ 必须，第一防线
                      audit=True, audit_every=5, probe_n=4,
                      label_every=5, pareto=True, cap=8, tol=0.04, monitor=True)

# 环境危险数 >= 3（复合）
V4A_CONSERVATIVE = dict(scale=1.0, temp=0.3,     # E115：保守幅度
                        blind=True, audit=True, audit_every=5, probe_n=4,
                        label_every=5, pareto=True, cap=8, tol=0.04, monitor=True)

# 可选：自适应幅度（E113，+0.025）
adaptive_scale = dict(init=2.0, lo=0.5, hi=4.0, adjust_every=10,
                      rule="回退>=3 则 *0.7；回退==0 则 *1.3")
```

**三条硬约束（不可违反）：**
1. **`blind=True` 永远开启**——它是大幅度的安全前提
2. **幅度随危险数降档**——复合危险下必须回到 1.0
3. **监控展示权重**——若 >10，说明收益含大量水分，应降幅度

## 九、残留风险

1. **E112 的展示权重 7–27 未被任何机制拦住**——这是当前架构最明确的漏洞。需要"表象权重上界"之外的手段（E87 已证明上界无效）
2. **E111 中 corrupt=0.6 与 1.0 的结果几乎相同**（+0.1155/+0.1420），说明我的污染建模可能在 0.6 以上饱和，真实失效可能更严重
3. **E115 只测了 25 代**，复合危险下的长期行为未知
4. **自适应（E113）只在单一污染世界测过**，复合危险下是否仍优未知
