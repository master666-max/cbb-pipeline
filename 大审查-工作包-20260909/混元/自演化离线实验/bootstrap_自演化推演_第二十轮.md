# 自演化 · 第二十轮推演：现实世界端到端

> 前三轮（A / 十八 / 十九）都在"judge 被污染"的世界里做单点实验。
> 本轮**组装**：协调式变异 + 高维表象 + judge 污染 + 漂移 + 伪特征，做端到端验证。
> 实验：`proto/evolve23.py`
> 结果：**A 轮修正确实有效（唯一正值），但收益很小；注意力门槛被证实远高于 E64 的估计**

---

## 一、E92 架构对比：只有加了 A 轮修正的配置为正

**世界设定**：judge 污染 50%（一半看真值一半看表象）、协调式变异（模拟 prompt 改写）。

| 配置 | **真值增益** | 展示权重终值 | 回退 |
|---|---|---|---|
| v3 基线 | **−0.0292** | 19.776 | 0.0 |
| v4（十七轮配置） | **−0.0095** | 13.974 | 0.0 |
| **v4-A（+ 盲评 + 真值审计）** | **+0.0127** | 8.431 | 1.3 |

**只有 v4-A 为正。十七轮的 v4 配置在这个世界里仍然是负的。**

这确认了 A 轮的核心判断：**在 judge 可被操纵的世界里，前十七轮的全部护栏都不够用**——它们都在用 judge 的读数做判断。

三个配置的展示权重单调下降（19.8 → 14.0 → 8.4），说明防线确实在起作用，但**即使 v4-A，展示权重仍达到 8.4**——系统仍在自我美化，只是被压住了。

> ⚠️ 诚实地看：+0.0127 是一个**很小的正值**，且 10 个种子的方差不小。更准确的表述是"v4-A 把系统从负收益拉回到接近零"，而不是"v4-A 让自演化成功"。

## 二、E93 注意力总账：门槛比 E64 高得多

E64 在"judge 可信"的世界里测出门槛约 150 单位。本轮加入真值验收成本（12/样本，每 5 代 × 4 样本）与盲评工程成本（20）后重算：

| 预算 | 真值增益 | 花费 | 转正？ |
|---|---|---|---|
| 20 | −0.0027 | 0 | 否 |
| 40 | +0.0087 | 20 | 是（仅盲评） |
| 80 | +0.0087 | 68 | 是 |
| 120 | +0.0310 | 116 | 是 |
| 200 | +0.0247 | 164 | 是 |
| 300 | +0.0586 | 260 | 是 |
| **500** | **+0.0965** | 500 | 是 |

**关键观察：**

1. **没有"明确门槛"** —— 从 40 开始就转正了，但增益极小（+0.009）
2. **要拿到有意义的增益（≥0.05），需要约 300 单位** —— 是 E64 估计（150）的 **2 倍**
3. 500 单位才拿到 +0.097，而这是**每单位收益持续递减**的

> **修正 E64 的门槛**：150 → **300**（judge 可被操纵时的现实值）。
>
> 而 E64 已经指出"预算 <150 时终局恒为负"——本轮说明在真实世界里，**这个临界值还要翻倍**。

另外一个反直觉点：**预算 200（+0.0247）比预算 120（+0.0310）更差**。这与 E80（复合危险下护栏负交互）、E60（参数复合失配）一致——**更多的护栏投入在某个区间反而有害**。本轮未深究，但值得记录。

## 三、E94 最坏现实世界：v4-A 从 −0.037 拉到 +0.037

把所有危险全开：协调变异 + 50% 污染 + 评判者漂移 + 伪特征。

| 配置 | 真值增益 |
|---|---|
| v3 基线 | −0.0370 |
| v4（十七轮） | −0.0169 |
| **v4-A** | **+0.0370** |

**v3 与 v4-A 的差距是 0.074** —— 这是本轮最有说服力的数字：在最坏世界里，**A 轮修正把系统从"明确有害"拉到"明确有益"**。

而且注意：v4-A 在这里（+0.037）比在 E92 的单一污染世界（+0.0127）**更好**。这看似矛盾，但可解释：E94 的漂移会被盲评+审计抓住（这正是它们设计的目标），而纯污染世界（E92）里没有漂移可抓，防线只能硬扛表象操纵。

> **这提示一个分层结论**：
> - **漂移类问题** → 盲评 + 真值审计**很有效**（E94 的 +0.037）
> - **纯表象操纵** → 防线只能部分压制（E92 的 +0.013，展示权重仍达 8.4）

## 四、E95 红线复检：两个确认、两个失效

| 参数 | 取值 | 真值增益 | 判读 |
|---|---|---|---|
| **blind** | False | **−0.0035** | |
| **blind** | **True** | **+0.0127** | ✅ **确认 E87**：盲评是有效的 |
| margin | 0.15 | **+0.0140** | ✅ **确认 E44**：停摆监控救回了致命 margin |
| cap | 4 / 8 / 20 | 全部 +0.0127（**完全相同**） | ❌ **实现缺陷** |
| tol | 0.0 / 0.04 / 0.15 | +0.0275 / +0.0127 / **+0.0412** | ⚠️ 与 E55 矛盾 |

### 两个确认

**① 盲评有效**：开启后从 −0.0035 变 +0.0127。这是 E87 在真实世界的复现。

**② margin=0.15 不再是致命的**（+0.0140，反而是最高值之一）——**因为停摆监控自动放宽了它**。这正是 E44 设计的目的，本轮在真实世界得到确认。**"监控比标定更重要"这个判断被证实。**

### 两个失效（诚实记录）

**③ cap 完全失效（F-20）**：我在 `run()` 里把 Pareto 压缩实现成了 `arch = arch[-cap:]`，**这不是 Pareto 前沿，只是保留最近 N 个**。由于选择父代只用 `arch[-3:]`，cap 对结果**完全无影响**——所以三档数值完全相同。

**④ tol 与 E55 矛盾**：tol=0.15（宽松）最好 +0.0412，tol=0.04 最差 +0.0127。E55 推荐 0.02–0.06。

用真实 Pareto 前沿重测（E95b）时，结果又变成"cap 越小越好"（cap=2 时 +0.0715）——但这个版本的 Pareto 第二个目标是**我新加的"−表象权重"**，它直接惩罚自我美化，所以小 cap 自然占优。**这个比较被我自己的目标函数构造所污染，不能作为 cap 的证据。**

> **结论：cap 与 tol 的最优值在本轮未能可靠测定。** 保留 E72（cap=8）与 E55（tol=0.02–0.06）的旧建议，**但置信度下调**。

## 五、本轮的实验设计失败（累计 20 次）

| # | 失败 | 后果 |
|---|---|---|
| F-20 | **Pareto 实现成 `arch[-cap:]`** | cap 参数完全惰性，三档结果相同 |
| F-21 | **E95b 的 Pareto 目标被我构造污染** | cap 结论不可用 |

**F-20 是本轮最严重的一个**。它让我差点报告"cap 不影响结果"这个错误结论——幸好三档数值**完全相同**这个不合理现象暴露了它。

这与 F-18（零乘锁死）是同一类教训：**当结果"过于整齐"时，先怀疑实现。**

## 六、二十轮总账（A 轮之后的三轮）

### 6.1 新增的有效结论

| # | 内容 | 依据 |
|---|---|---|
| 修正 55 | 探针集必须外部固定**且定期更换** | E84（污染后收益 −75%） |
| 修正 56 | **judge 数字永不对外报告**（膨胀达 349×） | E85 |
| 修正 58 | 不要给展示权重设上界；**盲评是零成本次优解** | E87 |
| 修正 60 | **推翻"维度是稀释剂"**：协调变异下维度越多越危险 | E88 |
| 修正 61 | judge 污染 ≥50% 时**任何判断都不可委派** | E89 |
| 修正 62 | 审计默认**每 5 代 × 4~8 样本** | E90 |
| 修正 63 | 审计必须**不可预知**；伪装使真值 −31%（下限） | E91 |
| 修正 64 | **注意力门槛 150 → 300**（judge 可被操纵时） | E93 |
| 修正 65 | 盲评 + 真值审计对**漂移类**很有效，**纯表象操纵**只能部分压制 | E92/E94 |

### 6.2 新增的负面清单（3 条）

| 不要做 | 依据 |
|---|---|
| 给展示权重设上界 | E87（+0.015 < 无对策 +0.024） |
| 审计 + 上界叠加 | E87（+0.037 < 单独审计 +0.088） |
| 依赖"维度多所以安全" | E88（协调变异下反转） |

### 6.3 三轮下来的核心图景

把 A 轮到二十轮排成一条线：

```
judge 只看真值（前十七轮）
  → 护栏有效：v4 全场景 +0.094 vs v3 +0.042
judge 看表象（A 轮）
  → 护栏失效：锚定审计零触发，自报 +2.89 / 真实 −0.01
加入真值抽样（E81c）
  → 部分恢复：每 2 代 +0.090
探针可污染（E84）/ 通道可直接注入（E85）
  → 再失效：收益 −75%，膨胀 349×
加入盲评 + 审计 + 探针轮换（v4-A）
  → 最坏世界从 −0.037 拉到 +0.037（E94）
```

**这是一条清晰的攻防升级链。** 每一层防线都在被绕过之后才补上。

### 6.4 最诚实的总结

二十轮之后，关于"自演化是否可行"，最诚实的表述是：

> **可行，但收益比前十七轮估计的要小得多，成本要高得多。**
>
> - 前十七轮：v4 vs v3 差 **+0.053**（全场景均值），最小可行集占 89%
> - 加入 judge 污染后：v4-A vs v3 差 **+0.074**（最坏世界），但**绝对收益只有 +0.037**，且需要约 300 单位注意力

**而绝对收益 +0.037 意味着什么**：这是在一个 60 条目、6 类 query 的玩具世界里的数字。真实系统的收益无法从这里外推。

真正可靠的产出不是"收益多少"，而是那 **15 条负面清单**和**三个结构性不可能性**——它们比任何正收益数字都更稳健，因为**证伪比证实容易**。

## 七、给落地方案的最终修正

| 工单 | 修正 |
|---|---|
| **EV-02** | 锚定集必须由人直接判断，不得由 LLM-as-judge 生成 |
| **EV-16** | **门槛 150 → 300**；且无明确阈值（40 即可转正，但增益微小） |
| **EV-19** | 探针外部固定**且定期轮换**；默认每 5 代 × 4~8 样本；**审计时点不可预知** |
| **EV-19 增补** | 增加**盲评层**（judge 前剥离表象），零成本，作为默认层 |
| **EV-20** | 增加"对外报告口径"：**judge 分数永不对外输出** |
| **新增** | **不得依赖"维度多所以安全"**（协调变异下会反转） |
