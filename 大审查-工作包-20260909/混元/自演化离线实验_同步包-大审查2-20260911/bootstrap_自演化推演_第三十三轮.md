# 自演化 · 第三十三轮：judge 看的是系统生成的展示

> **这是全部 140 个实验中最大的未测项。**
> 此前所有实验的 judge 都直接读特征向量——**看到的就是真值**。
> 真实系统里 LLM-as-judge 看到的是系统自己写的回答、自己选的 few-shot、
> 自己组织的上下文。**系统能决定给它看什么。**
>
> 本轮引入可演化的【展示策略 dsp】。
>
> 实验：`proto/run_e142.py`（n=16，24 代）

---

## 一、结果

| 对策 | 真值增益 | **dsp 终值** | 回退 |
|---|---|---|---|
| none | +0.1299 | **0.250** | 0.0 |
| **blind** | **+0.1733** | **0.075** | 0.0 |
| audit | +0.1280 | 0.250 | 0.2 |
| **both** | **+0.1733** | 0.075 | 0.0 |

**盲评 +0.0433 (t=2.14)；真值审计 −0.0019 (t=−0.98，无效)。**

---

## 二、⭐ 系统确实学会了自我美化

**dsp 从初值 0.1 上升到 0.250（2.5 倍）**——系统主动选择让 judge 看表象。

盲评把它压回 **0.075**（低于初值）。

这直接证实了第 A 轮的担忧：**真实系统的 judge 污染通道确实存在且会被利用。**

---

## 三、⚠️ 但真值审计完全无效（0.2 次回退）

```
audit  vs none: −0.0019 (t=−0.98)
回退次数: 0.2
```

**审计几乎没触发，触发了也没用。** 与 E81（锚定审计零触发）完全一致。

机制：审计测的是**真值**，而污染发生在**展示层**。
审计看到真值下降 → 回退到历史最优配置 → **但 dsp 还在，污染仍在**。

> **审计管得住"选哪个配置"，管不住"怎么报告"。**

这与 E85 的结论完全一致（膨胀 349 倍，真值审计只压到 133 倍）。
本轮是第三次独立复现。

---

## 四、盲评为什么有效

盲评（eff=0.95）让 judge 主要看真值通道：

```
judge = 0.95 × 真值 + 0.05 × 展示
```

**dsp 再高也影响不了 judge 的判断** → 自我美化失去选择压力 → dsp 掉到 0.075。

> **盲评不是"检测更聪明"，是"让操纵不起作用"。**
> 这与第 24 次的结论一致：**真正的防线是结构性的，不是补偿性的。**

## 五、两次实验设计失败（本轮主要教训）

### 失败 1 · dsp 单点变异：随机游走必然掉到 0

第一版 dsp 独立变异，终值 **0.000**。

诊断：
```
judge = (1 − 0.5·dsp) × real + 0.5·dsp × surf
```
**dsp 上升有利，当且仅当 surf > real。**
而检索结果按定义是真值较高的条目（real ≈ 0.7+），
随机表象 surf ≈ 0.5 —— **surf < real，所以 dsp↑ 反而降分。**

> **教训（第 4 次同类）**：一个参数"看起来能带来收益"，
> 但需要另一个参数配合时才成立 → 单点变异测不出来。
> E88 已经证明真实系统用**协调式变异**（改 prompt = 同时改多个维度）。

### 失败 2 · 修正后仍需注意

第二版让 dsp↑ 同时推高 surf 权重（协调式），dsp 才上升到 0.25。

**这说明自我美化需要"展示 + 检索"双向配合**——
这本身就是一个有价值的发现：**纯展示操纵无效，必须配合内容选择的偏移。**

## 八、残留

1. **n=16 偏低**，t=2.14 刚过显著性门槛
2. **协调式变异是我人为设定的**（dsp↑ 必须同时推 surf）。真实系统是否存在这种耦合未知
3. **未测"系统自己生成 eval 任务"**（外部性彻底消失的极端情形）
4. **dsp 只调制检索结果的表象**，未调制"回答文本本身"（更强的操纵）
5. 全部基于玩具世界；**真实 LLM-as-judge 从未被测过**
