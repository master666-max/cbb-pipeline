# 破坏性创新 · E156：多运行离群检测能救溢出探针吗？（第 44 轮）

> 任务：E155 的结论是"溢出探针是**聚合级**信号，单 seed 判不准
> （残留 sd≈2.9，而干净/破解的均值差只有 1.94）"。
>
> 本轮问：**多运行离群检测能不能把它变成逐运行可用？**
>
> 答案：**不能。而且原因比"样本不够"更根本。**

---

## 一、步骤 1：先把分布测准（n=30）

| 组 | 均值 | sd | 中位 | min | max |
|---|---|---|---|---|---|
| clean（无破解机会） | +1.202 | 2.868 | +0.144 | −3.000 | **+9.515** |
| hack（有破解机会） | +3.858 | 3.026 | +3.180 | −0.200 | +13.938 |

```
效应量 δ = +2.656   合并 sd = 2.948   Cohen's d = 0.901
单实例 z = 0.901        ← 远低于 2.8
并行 n=10 → z=2.85 ✅    ← 聚合可行
```

**Cohen's d = 0.90 是大效应量。** 聚合层面完全够用（n=10 即可），
问题只在**单个实例**上——分布严重重叠（clean 的 max +9.5 > hack 的 min −0.2）。

---

## 二、步骤 2：离群检测功效（bootstrap，4000 次试验）

判据：`target > mean(peers) + k · sd(peers)`

| 并行 n | 检出率(k=1.5) | 检出率(k=2.0) | 误报率(k=2.0) |
|---|---|---|---|
| **5** | **41.6%** | 31.4% | 12.7% |
| 10 | 31.8% | 22.6% | 8.1% |
| 20 | 25.2% | 16.3% | 8.1% |
| 50 | 21.4% | 14.3% | 6.8% |

### ⚠️ 反直觉：并行实例越多，检出率越【低】

原因：`mean(peers) + k·sd(peers)` 随 n 增大**收敛到一个固定值**
（clean 均值 1.202 + k×2.868）。

> **离群检测随着 peers 增多，本质退化成了一个绝对阈值。**
> n 小的时候阈值波动大，偶尔很低 → 检出率高，但误报也高。

对照（绝对阈值 1.8）：**检出 73.3%，误报 33.3%**，Youden = 0.40
最优离群（k=0.5, n=10）：检出 62.8%，误报 24.9%，Youden = 0.379

**绝对阈值略胜。**

---

## 三、步骤 3：ROC / AUC（无阈值公平比较）

| 方法 | AUC |
|---|---|
| **A) 绝对阈值（单值）** | **0.796** |
| B) 离群 n=3 | 0.715 |
| B) 离群 n=5 | 0.756 |
| B) 离群 n=10 | 0.782 |
| B) 离群 n=20 | 0.783 |

**离群检测的 AUC 从未超过绝对阈值**，且 n 越大越接近但始终略低。

> 减去 peers 均值 = **给 target 加了一个随机噪声项**。
> 只有当 peers 与 target **共享基线**时，减去它才是消除共同噪声。

---

## 四、步骤 4（关键对照）：共享基线能救吗？

设计：让 peers 与 target 来自**同一世界**（同 seed，不同随机流），
这样它们应该共享"世界基线"，减去均值就该有效。

| 方法 | AUC |
|---|---|
| A) 绝对阈值 | **0.848** |
| B) 离群 · peers 独立世界 | 0.804 |
| C) 离群 · peers **共享基线** | **0.765** |

### ⭐ 共享基线也无效，而且比独立世界更差

方差分解给出了原因：

```
clean 组内 sd（同世界、不同随机流）= 1.920
clean 组间 sd（不同世界）        = 1.985
```

**组内 ≈ 组间。**

> 我以为"同一世界 = 共同基线"。实测**不是**。
> **演化轨迹本身的随机性贡献了与世界相当的方差**
> （√(1.920² + 1.985²) = 2.76 ≈ 实测总 sd 2.87 ✓）

**根本含义**：最终的表象权重残留，主要由**演化过程的随机路径**决定——
不是由世界决定，也不完全由"有没有破解机会"决定（后者只推高均值）。

**没有共同基线可以消除 → 离群检测的任何形式都无效。**

---

## 五、结论

| 问题 | 答案 |
|---|---|
| 多运行能救溢出探针吗？ | **不能** |
| 是因为并行数不够吗？ | 不是，n=50 仍只有 14% 检出 |
| 真正原因？ | **残留的方差主要来自演化随机性，不存在可消除的共同基线** |

### 由此得到的能力边界（清晰版）

| 层面 | 能否检测"学会了破解" | 依据 |
|---|---|---|
| **聚合（n≥10）** | ✅ 能 | z=2.85，Cohen's d=0.90 |
| **单个实例** | ❌ 不能 | AUC 仅 0.80，分布严重重叠 |
| **多运行离群** | ❌ 不能（并不优于绝对阈值） | AUC 0.783 < 0.796 |

> **"这个特定的系统实例是否学会了破解"——在这个测量精度下基本不可回答。**
