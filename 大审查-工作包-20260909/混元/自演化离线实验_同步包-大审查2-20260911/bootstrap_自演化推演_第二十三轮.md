# 自演化 · 第二十三轮推演：收口

> 第二十二轮发现"变异幅度 1.0→2.0 收益 +0.118"。本轮验证这个发现的稳健性，并做最终配置对决。
> 实验：`proto/evolve26.py`
> 结果：**幅度效应确认，但被大幅修正——它必须配审计，单独用是有害的**

---

## 一、E106 幅度效应确认（稳健）

| 幅度 | 真值增益 | 为正种子 |
|---|---|---|
| 0.5 | +0.0236 | 11/12 |
| 1.0（现行） | +0.0337 | 10/12 |
| 1.5 | +0.0828 | 11/12 |
| **2.0** | **+0.1305** | 11/12 |
| 2.5 | +0.0948 | 10/12 |
| 3.0 | +0.1078 | 11/12 |

**幅度效应确认**：1.0 → 2.0 收益 +0.097，且 11/12 为正。

**但曲线在 2.0 之后回落**（2.5 时 +0.095、3.0 时 +0.108），说明 **2.0 附近是峰值**，不是"越大越好"。

### E109 上限：令人意外地不崩溃

| 幅度 | 真值增益 |
|---|---|
| 3.0 | +0.1007 |
| 4.0 | +0.1681 |
| 6.0 | +0.1695 |
| **10.0** | **+0.1660** |

**即使幅度到 10.0（变异完全随机化），系统仍然 +0.166，没有崩溃。**

原因：**审计在兜底**。大幅变异产生大量坏配置，但审计把它们挡住并回退，只留下偶尔出现的好变异。
这实际上是**随机搜索 + 强筛选**——而随机搜索在空间不大时其实很有效。

> ⚠️ 但这依赖"审计能可靠识别好坏"。若审计失效（E81 的零触发场景），大幅度会直接跑飞。
> **所以"大幅度不崩溃"这个结论只在审计有效时成立。**

## 二、E107 + E110：幅度必须配审计（对 E104 的重大修正）

E104c 已经提示"小幅度下审计有害"。本轮用更多种子确认，并做了**逐项叠加**：

### E107 幅度 × 审计

| 幅度 | 有审计 | 无审计 | **审计收益** |
|---|---|---|---|
| 0.5 | +0.0236 | +0.0268 | **−0.0032** |
| 1.0 | +0.0337 | +0.0143 | +0.0195 |
| **2.0** | **+0.1305** | +0.0427 | **+0.0878** |
| **3.0** | **+0.1078** | **+0.0007** | **+0.1070** |

**审计收益随幅度单调上升**：0.5 时 −0.003，3.0 时 +0.107。

### E110 逐项叠加（这是本轮最重要的表）

从 v3 基线开始，按顺序叠加每一项：

| 步骤 | 配置 | 真值增益 | **边际** |
|---|---|---|---|
| 0 | v3 基线 | +0.0135 | — |
| 1 | **+ 大幅度（2.0）** | **−0.0347** | **−0.0483** |
| 2 | + Pareto | −0.0520 | −0.0172 |
| 3 | **+ 真值审计** | **+0.1103** | **+0.1623** |
| 4 | + 盲评 | +0.1394 | +0.0291 |
| 5 | + 判断集刷新 | **+0.1903** | +0.0509 |
| 6 | + 停摆监控 | +0.1903 | 0.0000 |

**单独加大幅度是负收益（−0.048）**。只有在审计加入后（步骤 3），才产生 +0.162 的巨大边际收益。

> **对第二十二轮结论的修正**：
> E104 报告的"+0.118 幅度收益"是在**已有审计**的配置下测出的。
> E110 说明：**幅度本身是负收益，它只是"放大"了审计的价值。**
>
> 正确的表述是：**"大幅度 + 审计"是一个配对机制，单独任何一半都无效甚至有害。**
>
> 这与 E7（宽松准入 + 严格晋升）、E9/E34（门控 + 外部参照）是同一个模式：
> **探索力需要与筛选力配对。**

## 三、E108 最终配置对决

| 配置 | 真值增益 | 展示权重 | 回退 |
|---|---|---|---|
| v3 基线 | +0.0135 | 24.371 | 0.0 |
| v4（十七轮） | +0.0184 | 22.977 | 0.0 |
| v4-A（+ 盲评 + 审计） | +0.0637 | 5.138 | 2.6 |
| **v4-B（+ 大幅度 2.0 + 温度 0.3）** | **+0.1509** | **18.305** | 3.1 |

**v4-B 拿到 +0.151，是 v3 的 11 倍。**

但有一个值得警惕的数字：**v4-B 的展示权重回升到 18.305**（v4-A 只有 5.138）。

也就是说：**加大幅度让系统找到了更强的自我美化路径**，只是审计把它压住了，真值仍然上升。

> 这是一个真实的张力：**探索力既能找到"真正更好"的配置，也能找到"看起来更好"的配置。**
> 大幅度放大了两者，审计筛掉后者。
> **如果审计失效，大幅度会是最危险的。**

## 四、二十三轮的最终图景

### 4.1 收益来源排序（按 E110 的边际）

| 排名 | 机制 | 边际 | 前提 |
|---|---|---|---|
| 1 | **真值审计**（配大幅度） | **+0.162** | 需要大幅度才有这么大 |
| 2 | **判断集刷新** | +0.051 | — |
| 3 | **盲评** | +0.029 | — |
| 4 | **大幅度**（单独） | **−0.048** | **必须与审计配对** |
| 5 | Pareto（在大幅度下） | −0.017 | 本配置下为负 |
| 6 | 停摆监控 | 0.000 | 保险，平时零收益 |

### 4.2 三个配对机制

把所有实验串起来，**真正有效的机制全是"配对"的**：

| 探索侧 | 筛选侧 | 依据 |
|---|---|---|
| 宽松准入（tol>0） | 双门晋升（margin） | E7（0/12 vs 9/12） |
| **大幅度变异** | **真值审计** | E110（−0.048 vs +0.162） |
| 档案多样性 | 留出集门 | E16/E30 |

**单独任一侧都是无效或有害的。**

### 4.3 一个统一的原则

> **自演化系统的性能 = 探索力 × 筛选力的配对质量。**
>
> 二十三轮里所有"无效"的机制，几乎都是**试图在只加强一侧的情况下获得收益**：
> - 单独加档案（无门控）→ 诱饵堆积
> - 单独加审计（小幅度）→ 干扰搜索
> - 单独大幅度（无审计）→ 跑飞
> - 单独严格门控（无探索）→ 卡死（E7 的 0/12）

## 六、最终推荐配置

```python
V4B = dict(
    scale = 2.0,        # 变异幅度（E106：2.0 见顶）
    temp  = 0.3,        # 档案采样温度（E104：+0.016）
    audit = True,       # 真值审计（E110：+0.162，必须配大幅度）
    audit_every = 5,    # 频率优先于样本量（E97/E97b）
    probe_n = 4,        # 样本量 2 就够（E97b）
    blind = True,       # 盲评（E110：+0.029）
    label_every = 5,    # 判断集刷新（E110：+0.051）
    pareto = True, cap = 8, tol = 0.04,   # E96/E72
    monitor = True,     # 保险，平时零收益（E110：0.000）
    margin = 0.02,      # 有监控时几乎不重要（E96）
)
```

**关键提醒**：这不是一张可以逐项勾选的清单。
**`scale=2.0` 与 `audit=True` 必须同时开启**——E110 已证明分开用都是负收益。

## 七、二十三轮总账：诚实的最终评估

### 7.1 收益

| 阶段 | v3 → ? | 增益 |
|---|---|---|
| 前十七轮（judge 可信世界） | v4 | +0.053（全场景均值） |
| 十八至二十一轮（judge 被污染） | v4-A | +0.037（最坏世界） |
| 二十二至二十三轮（加大幅度） | **v4-B** | **+0.151**（本世界） |

**从 v3 的 +0.014 到 v4-B 的 +0.151，提升约 10 倍。**

### 7.2 但必须同时说明

1. **+0.151 是在 60 条目、6 类 query 的玩具世界里**。真实系统无法外推
2. **v4-B 的展示权重是 18.3**，系统仍在自我美化，只是被压住了
3. **注意力量级未知**：v4-B 需要审计 + 判断集刷新（每 5 代），按 E93/E97 的单价估算**远超 300 单位**

### 7.3 真正可靠的产出

不是这些收益数字，而是：

- **3 个结构性不可能性**（系统无法自知 / 无法被自己的数据检验 / 自主性有注意力门槛）
- **17 条负面清单**（被证伪的"合理方案"）
- **3 个配对原则**（探索 × 筛选）
- **21 次实验设计失败**（这些比成功更有教育意义）

**证伪比证实容易，所以负面清单比收益数字更稳健。**
