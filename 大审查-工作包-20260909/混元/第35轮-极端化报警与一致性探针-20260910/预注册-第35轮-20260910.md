## 一、文献与负面清单核对（设计时点）

- 换通道检测（E147）**先查负面清单**：#13"给展示权重设上界"（E87，比不做还差，3 次确认有害）、
  #14"审计+上界叠加"（E87）。本机制的差异必须写明：**静态上限**（E87，永远压着）vs
  **反应式复位**（本机制：仅在通道极端化报警时，把该通道复位到 root 值一次，不设常驻上限、
  不冻结变异）。若实验显示反应式复位也有害，#13 的适用范围扩大，如实记录。
- 一致性探针（E148）：MT-Bench 换位一致性（Zheng et al. 2023, arXiv:2306.05685）的玩具化
  ——同一 (task, config) 重复评分，分歧超阈值 → judge 不可信 → 暂停采纳（对应红线
  "预算不足禁自演化"的同族逻辑：judge 不可信也不该演化）。

## 二、E147 · 参数极端化报警 + 通道隔离（不依赖知道偏见在哪）

报警（可观测，无真值）：任一 SC2 通道 |w| ≥ 8.0（变异上限 20/-5 的一半）→ 报警。
动作：主配置该通道复位到 root 默认值，一次；不冻结、不设上限。

- 世界：E146 偏见世界（κ_g×w_kw，40% 条目）；臂（n=44）：
  1. `quarantine`（偏见，盲评关，+报警隔离）
  2. `quarantine_blind`（偏见，盲评开，+报警隔离）
  对照复用 E146 存档：`bias`（无隔离无盲评）、`bias_blind`（无隔离有盲评）——
  同种子/世界/节拍，直接可比。
- 判据（锁定）：
  - H1：bias_blind+quarantine − bias_blind > 0.03（隔离治盲评治不了的换通道伤害）
  - H2：bias+quarantine − bias > 0.03（无盲评时同样有效）
  - H3：无偏见世界报警次数 = 0 且增益不变（特异性别伤害；对照复用 E146 base）

## 三、E148 · judge 一致性探针（stochastic judge 的机制候选）

judge 加每调用噪声 jscore + N(0, 0.10)（独立流，不污染演化 RNG）。世界 none（干净世界
+噪声 judge，隔离"judge 噪声单因素"）。探针：每 4 代取 3 个存档 (golden, main) 对各
重评 2 次，平均分歧 |s1−s2| > τ=0.06 → 判 judge 不可信 → **冻结采纳**（此后每 4 代复测，
恢复一致才解冻）。

- 臂（n=44）：`noisy`（噪声无探针）/ `noisy_probe`（噪声+探针）；对照复用 E146 base
  （同世界无噪声无探针）。
- 判据（锁定）：
  - H4：noisy − base < 0（先量化 judge 噪声单因素的伤害，预注册方向为负）
  - H5：noisy_probe − noisy > 0.03（冻结止损有价值）
  - 附带：探针触发率（noisy 下应接近 1；base 世界若重跑应为 0——本轮不跑 base 探针臂，
    τ 的零误报由"确定性 judge 分歧恒 0 < τ"保证，写明即可）
