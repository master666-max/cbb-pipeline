## 一、执行摘要

自演化记忆库的架构设计与可行性问题，我们用 7 个探针 + 5 个推进批次 + 8 项破坏性创新，在只依赖真实代码路径的沙盒里全部跑成了带数字的实验。一句话结论：

**可行且值得**——修正架构（两级门控 + Pareto 历史档案 + 停摆监控 + 真值抽样审计 + 实测 importance + 行层重组）在 12×40 全协议下相对静态库 **F1 5/5 PASS**（真值净增益 +0.14~+0.31，正种子 11~12/12，Wilcoxon p≤0.001，bootstrap 95% CI 下界全 >0），存储/更新/遗忘/重组四能力全程走真实 bootstrap_v3 路径零违例，引擎甚至自主发现了与人工审查同款的检索缺陷（filter_zero）。

同时护栏的价值、失效条件与边界被逐条量化，三条最深原则：
1. **护栏是保险，不是投资**——必须来自独立真值通道（E81：同源锚定审计 0 触发；真值抽样 ≤3 代检出回退）。
2. **保留历史权衡**——Pareto 档案必须保留"曾为主线"的配置（R1-1：reward 形式切换下单主线真遗忘，档案 6/6 保留旧方向）。
3. **孤立的单通道必然被同源污染；"不一致"是系统唯一可靠的自指信号**（D1 多源分歧 / D2 gap 统计 / D4 假设级 τ 早警）。

## 二、问题与设计

- 三问题：修正架构是否在不破坏一致性的前提下稳定优于静态库？两级门控/Pareto/真值审计/实测化各自贡献多少？边界（注意力门槛、复合危险、judge 污染）如何量化？
- 被测对象 = 真实库：append 分流（importance>=7→longterm，L927）、同 id 拒绝（L930，铁律 1）、retire→attic（TTL，L1075）、links 一跳扩散（L907-914）、doctor 五态对账（L1032-1074）、哈希链+Merkle+ledger。
- 检索层 = _rank_entries 的参数化同构 + **P0 parity 门 100/100**（top-5 集合与真实 b3 完全一致）。
- 通道分离：judge（声称/名义）vs 真值（rv）；四层权限：锚定层(只读) > 元层(冻结) > 法层(引擎演化检索基因) > 行层(条目算子, 仅 append/retire 语义)。
- 场景：clean / spur-surface / spur-judge / stale / switch / switch-c / dup-drift(首领金标) / composite。
- 对照臂：static / bare / single / gated / gated-noAudit / gated-noPareto / gated-cap / gated-row / e81 族 / budget。

- E80 负交互未复现（需更强复合+污染晋升门+采纳密集，已留证）；
- E57 完全相关噪声下双门同化（异质标注是解）；复合危险无额外伤害；
- 词面/recall 度量盲区（收益在 top-k 质量/噪声/成本层需换度量）；
- 不可能性回应：无法同源自证（E81）→ 独立真值抽样+异质标注；无法自知失败（E78）→ 双通道 gap/τ 统计；自主性有注意力门槛（E64/H8）→ 预算账本，不足即关。

## 十、结论

1. 可行性：修正架构驱动的记忆库自演化在不破坏一致性的前提下稳定优于静态库（F1 5/5，12×40），四能力全程真实路径零违例，引擎能自主发现人工审查同款缺陷。
2. 机制：门控在危险窗口拦有害采纳；Pareto 在 reward 形式切换时保留旧方向；审计=保险、只在 judge 污染时兑付且可定价；importance 自称不可信时实测 3.29×；行层 retire 是安全的遗忘+重组原语；遗忘=时间×结构×使用联合决策。
3. 边界：注意力门槛 S 形须按系统标定；复合危险增益有限无额外伤害；最深约束=同源标尺无法自证——工程解是让不一致可见、可触发、有代价（分层：假设早警→低频真值确认→惩罚回退），并把过程做成可回放、可签入、可回查的界面（D6/D3）。

> 结语：一个能改变自己的系统，也会改变评判它的环境。本系列实验把"不追求不犯错，追求犯错可查可回"从口号变成了一组带数字、可复现、有边界声明的工程性质。

## 0. 为什么需要 V2：V1 骨架与任务要求之间的缺口

run_sandbox.py（V1）只做了一件事：在静态条目集上演化检索参数（w_kw/w_content/w_imp/w_age/filter_zero），对照 static/ungated/gated。它对「记忆库自演化」的覆盖不完整，与本次任务要求的四能力（存储 / 更新 / 遗忘 / 重组）存在 4 个缺口：

| 缺口 | V1 现状 | V2 必须补上 |
|---|---|---|
| G1 遗忘 | 无条目生命周期；retire/attic 路径只对 seed=1 库做过一次一致性检查 | 场景注入「事实过期/被取代」，测 TTL 出仓、防泄漏（过期事实不得被召回） |
| G2 更新 | 库是静态的；append 同 id 拒绝、t_invalid、supersede 语义从未被当作演化对象 | 演化世界引入版本流：新事实取代旧事实、冲突、纠正；引擎按 append-only 语义提案更新 |
| G3 重组 | 检索参数之外无可演化结构 | 引入 links 嫁接 / keywords 改写 / 跨条目反思合并（R-xxx）等「行层算子」，并测其只在存在可发现结构的场景有价值（E6 的诚实解读） |
| G4 评判通道 | gold 直接用 importance 或隐藏 rv，judge 看到的就是真值（A 轮已指出这是致命干净） | spur-surface 场景让「引擎能看见的表面特征」与「真值」错位，检验锚定审计 vs 真值抽样的差异（E81/E81c） |

V2 的实验对象也因此从「检索器参数」升级为完整的记忆库自演化引擎：法层（参数/开关）+ 行层（条目级算子）都开放给引擎提案，但全部经真实 v3 公开函数落盘，元层（K、任务集、真值审计、铁律）冻结在人侧。

架构前提（本实验接受、并把它当作被测对象而非信仰）：
- A1 四层权限：锚定层（人，只读且永不衰减）> 元层（人签名）> 法层（系统自由演化）> 行层（系统自由写，但经真实 API）。
- A2 引擎只能经 v3 公开函数（append/retire/reflect 素材 + eval/retrieve 读）作用于库；任何「更新」= append 新条目 + 旧条失效，无 in-place 改写。凡是需要 in-place 的「更新」诉求，本设计明确把它作为被测缺陷记录（见 H6b）。
- A3 检索层用 _rank_entries 的显式参数化同构 retrieve_top(cfg)，默认参数必须通过 parity 门与真实 _rank_entries 一致（5.1 P0）；库内容与写路径 100% 走真实 b3 代码。
- A4 沙盒中「真值」= 世界生成器隐藏的 rv（随场景按需漂移）；「judge 可见面」= 条目表面特征；两类通道物理分离（EV-19/20 硬约束）。
- A5 反思合成（R-xxx）在沙盒中用确定性规则聚合器模拟（离线、可复现），不调用任何 LLM。

## 2. 实验目标与假设

### 2.1 总目标
在可复现沙盒中回答三个问题：
1. 架构可行性：报告修正架构（S10/S11）驱动的自演化记忆库，是否在不破坏记忆一致性的前提下，于干净/过期/重复漂移/表象错位/目标切换场景中稳定优于静态库？
2. 机制必要性：两级门控、Pareto 档案、真值抽样审计各自贡献多少？裸演化为何必须上护栏？（用负对照量化「没护栏时它自信地走错且指标全绿」）
3. 边界诚实性：注意力门槛、复合危险（≥3）、judge 通道被表象污染时系统表现如何？把「做不到」写进判据而不是假装能做到。

## 3. 被测对象：自演化引擎架构（与 bootstrap_v3.py 的接线图）

### 3.1 四层 + 演算位置映射

| 层 | 内容 | 存放 | 谁可改 | 实验中的「物体」 |
|---|---|---|---|---|
| 锚定层 | 真值审计查询（独立于 judge 通道）、铁律、K=5 | anchors.jsonl（沙盒内只读）+ 世界生成器 | 人（=世界脚本，启动前固定） | 见 4.2 audit_q |
| 元层 | 效用函数（=真值 rv 上的 recall）、任务集定义、AUDIT_EVERY、阈值 | world 快照 + 常量区 | 冻结（脚本常量） | SCENE/SEED 之外的全部常量 |
| 法层 | 检索基因：w_kw/w_content/w_imp/w_age/filter_zero/links_gain/use_imp(自称或实测) | 引擎主线的 cfg | 系统（经两级门控） | cfg 值 |
| 行层 | 条目级算子：append 新条目(合并/纠正)、links 嫁接、keywords 改写、失效标记提案、R-xxx 反思合并 | 真实库 memory/ | 系统（仅经 b3 公开函数） | 算子序列（ops log） |

方向性约束（红线 1/4/6）：法层/行层变异永远不能写锚定层与元层；引擎进程对 anchors.jsonl 与评测协议只有读权限（沙盒内以独立目录 + 校验实现）。

### 3.2 演化循环（=报告 5.2 + A 轮修正的落地形态）

每代 g（世界时间推进一个 step，新事件按场景剧本注入）：

1. 提案：固定混合算子 ×3（约 10% 翻转离散基因 filter_zero/links_gain；其余对 w_* 单参数 ×(1±0.3) 缩放；无自适应步长——E54 已证伪 1/5 规则）。
2. 档案准入（宽松）：Δ > −tol（tol=0.04），只看 train 集；准入只淘汰不采纳（廉价筛选函数无 accept 返回值——E13）。
3. Pareto 档案：对 (train, hold) 双目标取 Pareto 前沿；超 cap=8 时随机采样至 8（E11/E16/E30/E72）。
4. 主线晋升（严格）：档案中首个满足 Δtrain>margin 且 Δhold>margin 的候选上位（E7 的「宽松准入+严格晋升」）；margin 初始 0.02。
5. 停摆监控：连续 5 代零采纳 → margin×0.5（下界 0.005）并记日志（E44，P0 中的 P0）。
6. 真值抽样审计（每 AUDIT_EVERY=3 代）：从审计查询池抽 8 条全新查询（用完即弃，不参与任何训练决策——E8 污染防线），以独立于 judge 的真值 rv 计 util；相对上一检查点跌幅 > REVERT_THR=0.03 → 回退到上一检查点主线 + margin×0.7 + rollback++（E81c 的轻量实现）。
7. 行层算子（仅 gated+行层 臂 / dup-drift 场景）：引擎基于轨迹（traces）提案 links 嫁接/keywords 改写/R-合并，只生成新条目或只读提案，不 in-place 改文件；提案同样过两级门控（用其落盘后对 train/hold 的效用增益计）。
8. 记账：每代把基因、各集 util、档案规模、margin、采纳/回退事件写入轨迹 TSV（值语义，杜绝按对象 id 缓存——报告教训 7）。

> 引擎不知道世界剧本（哪些条目会过期、主题会切换）；它只能通过检索结果与审计真值间接感知——这正是要论证的自演化可行性形态。

### 5.1 P0 parity 门（检索层可信基座）
1. 实现 retrieve_top(entries, q, cfg, k)：逐行转写 _rank_entries（L899-914）的计分公式与 links 扩散，把三个硬编码常数提为 cfg 键：w_kw=3.0, w_content=1.0, w_imp=1.0, w_age=0.1，另加 filter_zero（kw/c 双零 → -inf）与 links_gain=0.5。
2. parity 脚本：建 5 个随机真实库（lib_bridge.materialize），每库跑 20 条查询；对默认 cfg，比较 retrieve_top 与 b3._rank_entries 的 top-5 集合一致率；不一致即修，禁止带病前进。
3. 记录 parity 报告进 out_v2/parity.json（一致性、最大分差、断点条目）。

### 5.2 P1 世界生成器（world_gen.py）
统一条目模型（字段与 v3 schema 对齐，另含隐藏域）：

~~~text
Entry = {id, created_at, updated_at, content, keywords, links,
         source_event_id:"genesis", importance(名义), confidence:1.0,
         validity:{t_invalid?},        # v3 可见字段，真实入库
         _rv, _topic, _spur, _birth_gen, _obsolete_gen, _group  # 世界隐藏真值}
~~~

内容词法：topic 语义词 t0a..t5d + 噪声词；keywords 含 topic 主词。查询池按主题构造；每查询金标 = 该主题下当前代有效的 _rv 最高 K_GOLD=3 条。通道分离：
- judge 通道（train/hold 用）：计分能看到的 = 词面 + 名义 importance + 表面词（spur 场景含 SPUR/格式词）——模拟「LLM-as-judge 看到文本」。
- 真值通道（audit 用，独立抽取）：金标 = _rv，与表面词无关——对应 EV-19「人直接判断有没有用」。

场景剧本（每代注入事件流）：
- clean：无事件；rv 稳定；名义≈rv+ε。
- stale（遗忘压）：t0/t1 主题条目按剧本在某代起失效（世界侧把 validity.t_invalid 写入新注入事件的创建时刻；真实库 retire 用 Clock 前进验证 TTL），同时注入「纠错版」新条目（同 _group，links 指向旧 id）→ 测遗忘与更新。
- dup-drift（重复-重组）：同一 _group 事实由 3 个「写入者」以不同词面多次入库（真重复）；金标组给 _group 首领；正确做法是把它们合并/链接 → 测重组。
- spur-surface（表象错位）：名义 importance 与 rv 反向错位（spur 条 30%）；表面词 SPUR 高频但零信息；judge 通道优化会把权重导向表面 → 测 H2/H4/H5。
- switch（目标切换）：前 2/3 代优化 t0/t1，后 1/3 优化 t2/t3（judge 查询集切换）→ 测 H3 灾难性遗忘。
- composite：stale + spur + switch 同时 → H9 边界。
- drift-probe（专供 H10）：小规模，锚定审计的「人」权重 w 被系统当前输出逐步带偏（α 锚定）→ 检验只靠锚定审计能否检出。

世界快照按代序列化（事件、真值、查询池 seed 派生），保证 replay 与独立分析可重放。

### 5.3 P2 主实验（static / bare / gated × 场景 × seeds）
每 (scene, seed)：
1. world = build_world(scene, seed)；anchors.jsonl（只读）由世界在启动时生成（真值审计查询预抽样、运行期不追加）。
2. static 臂：主线 cfg 恒为默认；生命周期照默认策略跑（stale 场景下到 TTL 才 retire——即「只遗忘、不演化」）；不提案任何行层算子。
3. bare 臂：单主线、无档案/无门控：每代取 train 上 Δ>0 的候选直接上位（margin=0，无审计）——复现 E3「无门控」。
4. gated 臂：按 3.2 全流程（含真值抽样审计）。
5. 每 5 代一个检查点：check_integrity（真实库路径）+ 轨迹落盘；每 10 代 materialize 一份影子真实库并跑真实 b3 doctor/retire（Clock 注入验证 TTL），把真实路径输出与引擎内一致性快照对账。
6. 终局：每条查询在「从未被训练决策引用过的剩余审计池」上测终局效用（防 E8 污染：训练/晋升用的 hold 每 10 代轮换一次，审计池只出不进）。

运行档位：quick = seeds 4 × gens 12；full = seeds 12 × gens 40。预估（env_check 实测 append 单条约 <10ms；纯 util 计分 O(N×Q)）：full 主矩阵约 20-60 分钟/场景×3臂，P3/P4 另计；全部带 --quick 冒烟先行。

### 5.4 P3 消融与算子探针（在 gated 上逐项开关）

| 臂 | 改动 | 检验 |
|---|---|---|
| gated-noPareto | 档案=单最优 | H3 的 Pareto 贡献 |
| gated-noAudit | 关真值抽样审计 | H5/H1 的审计贡献（spur 场景必测） |
| gated-marginHigh | margin=0.15（E29b 致死量） | 停摆监控是否 ≤10 代救回 |
| gated-recency | 锚定/审计判断按近因加权（hl=15） | E14c 毒药对照：漂移下应显著劣于均匀 |
| gated-impDerived | 引擎把 importance 当派生量（按 traces 实测采纳率归一）参与计分 | H4 |
| gated+row-ops | 开行层算子（仅 dup-drift/clean 两场景跑） | H7 |

消融共享同一运行帧（每代三臂可复用同一批候选的 eval 结果——按 (scene,seed,gen,cfg-值,query) 值语义缓存，杜绝报告教训 7 的 id() 缓存 bug）。

### 5.5 P4 边界探针
- 预算曲线（H8/E64）：把「可调用的 eval 次数/代」当作预算 B，扫 B ∈ {10,40,80,150,300}，画终局效用 vs B；拟合门槛 B*。
- 复合危险（H9/E80）：composite 场景 × seeds 3 × {static,bare,gated}，如实记录分布；若 gated 也净负，写边界、不修（E80 的诚实输出）。
- judge-drift 检出（H10/E14/E38）：drift-probe 场景，注入 α∈{0.10,0.20}，测：仅锚定审计的触发率；阈值 0.85 的检出代数；干净 30 代误报数。
- 恶意算子注入（H6b）：写一个「绕过 API 直接 edit memory/*.json 字段」的作弊臂，断言 100% 被真实 b3 写路径拒绝（同 id）或破坏一致性后被 check_integrity/doctor 检出——量化「能力式边界的必要性」。

### 5.6 P5 真实路径抽查
每场景取 seed=1 的 gated 终局库：b3 doctor、eval、retire（Clock 前进 +90d）、b3.merkle_root 与 state.json 对账、guard snapshot/anchor 对账（人侧表 = 世界脚本生成的锚定文件）——把 H6 断言钉在真实代码输出上而非引擎模拟器。

### 5.7 P6 分析（独立进程，读盘不读内存）
analysis/analyze.py 读 out_v2/ 下全部 rows/traj/checkpoints → 输出：逐场景三臂均值表、配对 Δ 分布、sign-test k/12、Wilcoxon p、bootstrap 95% CI、轨迹曲线图、检查点一致性热图、预算曲线拟合。运行器与分析器分离，杜绝「用同一份带 bug 缓存跑出太漂亮的数」（报告教训 8）。

## 8. 数据采集与分析方法

### 8.1 产物 schema（全部 JSON/TSV，UTF-8，值语义）
- rows_{scene}.json：每臂每种子一行 → {scene, seed, arm, final_cfg, u_train/u_hold/u_audit(终局未用池), adopts, dips, rollbacks, arch_size, eval_units, sec, per-checkpoint 摘要}。
- traj_{scene}_{seed}_{arm}.tsv：每代一行 → gen, cfg 全基因(值), u_train/u_hold/u_audit_thisgen, margin, arch_size, stall, events(adopt/rollback/relax/audit_dip), ops(行层)。
- checkpoints/{...}.json：chain_bad/set_mismatch/merkle/attic 计数/库体积/铁律违例/traces 统计。
- integrity_real/{scene}_seed1_gated_end.json：P5 真实 doctor/eval/retire 输出。
- manifest.json：脚本、python 版本、b3.VERSION、seeds、gens、场景、每臂参数字典、文件指纹——复现第一道闸。
- anchors.jsonl（每个 (scene,seed) 一份，运行期只读校验：哈希比对，防引擎越权）。

### 8.2 统计协议（先写死在 analysis 里再跑数，避免后验挑方法）
1. 主判据：配对 sign-test（正种子数 k/12）+ Wilcoxon signed-rank（n=12，α=0.05 双侧）+ bootstrap 10^4 次 95% CI 下界（红线 15：CI 下界 > 0 才算「显著为正」，不用固定 margin 当显著）。
2. 诚实度：H2 用 per-seed gap 分布（中位数、P25），自报与真值均在同一条轨迹上测，消除采样偏差。
3. 污染控制：hold 每 10 代轮换重抽；audit 池只出（每检查点抽 8 弃 8）不入；终局报告用「从未参与任何决策」的独立池。
4. 误报统计：干净场景把「审计触发」当 FP 计；漂移场景把「≤6 代内触发」当 TP 计；报告混淆矩阵而非单一检出率（E34 教训：0.95 阈值「检出 8/8」是几乎永远报警下的空话）。
5. 报告纪律：先出「阴性/证伪表」，再出「支持表」；每条结论注明支撑实验与效应量，禁止用均值掩盖分布（报告第四部分方法论）。

### 8.3 分析方法
- 主表：场景×臂 的 u_audit 均值±std + 相对 static 的配对 Δ（含 CI）。
- 归因：消融差分（gated − gated-noX）得每条护栏的边际贡献；与报告 EV-09~12 的预期量级对照。
- 曲线：traj 平滑曲线（代 vs u_audit）按臂叠画；平台判别用报告 E12/E45 的「重测冠军」规则防误判。
- 预算曲线：u vs B 拟合（分段线性/幂律），报告拐点 B*。
- 一致性热图：检查点 × 指标 的绿/红矩阵（绿=零违例），直接把 H6 断言画成图。

### 9.2 可行性判据（验收清单——报告写完逐条勾选）
自演化引擎「架构设计可行」当且仅当：

- [ ] F1 H1 通过：≥3/5 场景（含 stale、spur）70% 种子为正且 CI 下界 > 0；
- [ ] F2 H2 确认门控必要性：gap ≥ 2×（否则「裸演化」也诚实，架构需重新论证）；
- [ ] F3 H3/H4 通过：遗忘防护与 importance 实测化拿到报告量级（±30% 容差）；
- [ ] F4 H5 通过：真值抽样审计在 spur 上带来 ≥ +0.03 净增益且审计只在真退化时触发；
- [ ] F5 H6 全程零违例（含 P5 真实 doctor 抽查）：即自演化引擎在存储/更新/遗忘/重组四能力上与记忆一致性不冲突；
- [ ] F6 H8 门槛被量化：运营策略可写死「预算 < B* 禁止开启演化」（E64 落成策略）；
- [ ] F7 H9 边界被如实写入（不因难看不通过，因不诚实不通过）；
- [ ] F8 可复现：固定 seed + manifest 在第二台机器跑出 headline 数字差 ≤ ±0.005（单线程确定性、无网络）。

判据的判据：如果 F1/F5/F8 通过而 F2 不通过，说明门控冗余 → 架构应简化；如果 F4 不通过而 F1 通过，说明场景没造出「judge 只看表象」的压力 → 先修场景（报告教训 3：判别器没错是构造不成立），不得用改判据来通过。

## 10. 已知陷阱、失败模式与诚实记录义务（设计内建）

| 陷阱 | 缓解 | 报告对应 |
|---|---|---|
| 检索器 replica 与真实代码漂移 | P0 parity 门 + P5 真实抽查双保险 | 报告「先修好 eval 再谈」教训 |
| 留出集被消耗 → 自报膨胀 | hold 10 代轮换 + 终局独立池 + 审计池只出 | E8 |
| 近因加权毒药 | 锚定/审计判断均匀加权；recency 只作为毒药对照臂 | E14c |
| 缓存串味（id() 复用） | 全程值语义缓存 + 运行/分析分离 | 教训 7/8 |
| 结果太漂亮 | 先跑 quick + 先写阴性表；怀疑优先于庆祝 | 教训 8 |
| 门控阈值拍脑袋 | 阈值全部来自报告（0.85/0.04/0.02…）并在 manifest 登记 | E34/E55/E17 |
| judge 通道同源 | 真值与 judge 通道物理分离（A4）；审计不读任何引擎可优化量 | E81/EV-19/20 |
| 报告里混口径 | 每个指标标注采集方法（真实 b3 or 引擎统计），不一致时以真实输出为准 | 公理 G |
| 注意力预算超支 | EV-16 账本化，预算 < B* 自动禁止 | E64/E22 |

三条不可能性在实验中的位置：系统无法自知失败（H9/E78：我们不设计「自查」，依赖外部真值审计）；系统无法被自己的数据检验（A4 通道分离 + H5 复现 E81 的零触发）；自主性有注意力门槛（H8 量化 B*）。实验的目标不是「证明没有边界」，而是把边界测出来并写成可执行策略——这本身就是可行性论证的一部分。

## 1. 实验目标与设计回顾

三个问题：(1) 修正架构驱动自演化记忆库是否在不破坏一致性的前提下稳定优于静态库；(2) 两级门控/Pareto/真值审计各自贡献；(3) 边界（注意力门槛/复合危险/judge 污染）诚实可测。

- 四层权限：锚定层(只读) > 元层(冻结) > 法层(引擎演化检索基因) > 行层(条目级算子，仅经 append/retire 语义)。
- 通道分离（A4/EV-19/20）：judge 通道(train/hold)=名义 importance 金标；真值通道(audit/终局)=隐藏 rv 金标。
- 引擎循环（§3.2）：固定混合变异 ×3 → 档案宽松准入(tol=0.04) → Pareto(cap=8) → 主线严格晋升(Δtrain∧Δhold>margin) → 停摆监控(margin×0.5) → 真值抽样审计(每 3 代，跌幅>0.03 回退)。

对照臂：static（静态库，零假设）/ bare（裸演化，负对照）/ gated（修正架构）/ single（严格单主线无档案）/ gated-cap（双能力轴 Pareto）/ gated-noAudit / gated-noPareto / gated-marginHigh / gated-row（+行层 retire 算子）。

## 6. 探针 1 · switch-c 冲突世界 / Pareto / 灾难性遗忘（H3）

### 6.1 构造
A 主题(t0,t1)：旧条目为真（rv 随 age 升，名义=真值+ε）；B 主题(t2,t3)：新条目为真（rv 随 age 降）。两阶段 train 集切换（ga=2/3 代）。新臂：single（严格单主线无档案）、gated-cap（档案按 A/B 双能力轴 Pareto，E16 机制）。新增 MUTATE_ZERO 置零算子。

### 6.2 发现 1：乘性变异算子 × 阶跃效用 → 全臂死区（40 代 × 8 seeds；out_v2_switchc40）

全部演化臂（bare/single/gated/gated-cap/gated-noPareto）uA_true = 0，adopt≈1。网格诊断（seed1）：w_age=0.10→0.01 时 A 主题真值 util 恒 0，w_age=0.00 时 =1.0 —— **效用是阶跃**（只要 w_age>0，age 罚项差 ~300×w_age 仍压过 importance 差 ~0.6；仅 w_age 精确归零才解锁）。乘性变异（0.1→0.07→0.049…）永远到不了 0，中间每步 Δ=0 不满足任何臂采纳条件 → 无人过谷。
> 新增教训（报告 E54/E73 家族之外）：固定乘性算子对"精确零点"型优化面存在系统性死区；需少量绝对采样/置零变异（MUTATE_ZERO=0.05 后问题消失）。

### 6.3 发现 2：修复后仍无灾难性遗忘（30 代 × 8 seeds；out_v2_switchc_zero2）

| arm | u_audit | uA_true(主线) | bestA(档案∪主线) | Δ真值 vs static |
|---|---|---|---|---|
| static | 0.3542 | 0.000 | 0.000 | — |
| bare / single | 0.8125 | 0.6250 | 0.6250 | +0.4583 (8/8) |
| gated / gated-cap | 0.7500 | 0.5000 | 0.5000 | +0.3958 (8/8) |

- 所有臂保留 A 能力（bestA==uA_true）：不是护栏之功，是**切换压力不存在**——B 域真值同样被 importance 编码（名义=真值+ε），w_age=0 对 B 中性甚至有利 → 单主线从不会被推着丢弃 A 配置。
- 附带记录：良性无危险环境下门控约 0.06~0.13 recall 小代价（gated 0.75 vs bare 0.81）。
- 结构性结论：单参数、顺序保持的全局权重空间（同主题内所有权重是乘性、不改变序）无法表达"改进 A 同时伤害 B"的参数冲突；真正会触发遗忘的是 **judge 通道不随域更新（旧时代高名义条目在新时代是噪声）+ 阶段切换** —— spur×switch 复合（报告 composite/E81 家族），作为探针 3 的主构造。

## 7. 探针 2 · 行层算子 × dup-drift（H7）

### 7.1 设计
- 世界：dup-drift 金标改为**仅组首领**（gold_exclude_roles=dup）——副本是可观测噪声；副本带 links 指向首领（可发现结构）。
- 新臂 gated-row：每代先用可见证据（links + 内容 Jaccard≥0.5 同 topic）检测近似重复簇 → 提案"冗余副本 retire、首领保留" → 宽松容差验收（tol=0.04，不损害即采纳，E7 哲学）→ 再演参数。行层操作 100% 走 append/retire 语义（铁律 1：移 attic 不删除）。

### 7.2 结果（20 代 × 6 seeds；out_v2_rowops2）

| 场景 | static | gated(仅参数) | gated-row(+行层) | row-ops 边际 | 正种子 |
|---|---|---|---|---|---|
| **dup-drift** | 0.2037 | 0.3519 | **0.4352** | **+0.0834** | 6/6 |
| clean | 0.2037 | 0.4815 | 0.4815 | 0.0000（零簇零操作） | 6/6 |

- dup-drift：平均移除 22/24 个副本、ops_rejected=0（宽松验收从不损害）；去重降低同组副本对 top-5 的拥挤 → 组首领/其他高价值条目可及 → recall +0.083（金标=首领故可观测）。Δ vs static 从 gated 的 +0.148 升到 gated-row 的 +0.232。
- clean（无 links/无重复）：检测零簇 → 零操作 → 与 gated 逐位一致（u_audit/gap/redun 全同）→ **无结构时重组零收益零代价**（E6 否定性结论的精确复现带）。
- 行层"重组"收益严格依赖可发现结构 → **H7 支持（场景依赖）**，与 E6/E28 自洽；有效方案=利用已有可观测量（links+重复度），非发明启发式（E73 家族）。

### 7.3 真实路径验证（引擎驱动的重组 = 真实 b3 retire）
seed1 gated-row 终局：活动 77 条，19 条引擎 retire 的副本以失效标记注入真实库 → 真实 b3 retire 移动 19 条 → attic；
- doctor 前后均「五态 全一致」；chain_bad=0、mem/audit mismatch=0、merkle_ok=true；attic_files 0→19；被 retire 条目真实检索泄漏 = 0。
- → 行层重组与记忆一致性（H6）不冲突，且真实代码路径保证。

### 7.4 指标教训（诚实记录）
"top-5 冗余度"（两两 token Jaccard）**未随去重下降**（0.642→0.653）：同主题 top-5 天然共享主题词，词面重叠分辨不出"真重复 vs 同主题多样性"。教训：冗余度须按**语义组内成员计数**，不以词面 Jaccard 为准。本轮判据只认 recall 增益。

# 探针 1 · Pareto 档案与灾难性遗忘（H3）— 结果与诚实收尾

> 时间 2026-09-08 ｜ 场景 switch-c（目标冲突世界，A=旧条目为真/需 w_age 低，B=新条目为真/需 w_age 高）
> 新增臂：single（严格单主线、无开放式档案）、gated-cap（档案按 A/B 双能力轴 Pareto，E16 机制）
> 新增算子：MUTATE_ZERO（变异罕见置零，越过阶跃阈值；默认 0=关）

## 1) 机制发现：乘性变异算子撞上阶跃效用 → 全臂死区（40 代电池，算子无置零）

| arm | adopts | uA_true | bestA | 说明 |
|---|---|---|---|---|
| static | 0 | 0.000 | 0.000 | 基线 |
| bare / single / gated / gated-cap | 0.8~1.0 | **0.000** | 0.000 | 全部卡死 |

网格诊断（seed1）：w_age=0.10→0.01 时 uA_true **恒为 0**；w_age=0.00 时 **1.000**。
原因：效用是阶跃——只要 w_age>0，age 罚项差（~300×w_age）仍压过 importance 差（~0.6）；只有 w_age 精确归零才解锁。乘性变异（0.1→0.07→0.049…）永远到不了 0，且每一步中间效用为 0（Δ=0 不满足任何臂的采纳条件）→ 无人能过谷。
> 这是对报告 E54/E73 家族的一个**新增具体教训**：固定乘性算子对"精确零点"型优化面存在系统性死区；需少量绝对采样/置零变异（本实验加 MUTATE_ZERO=0.05 后问题消失）。

## 2) 修复后（MUTATE_ZERO=0.05，30 代 × 8 seeds）

| arm | u_audit | uA_true(主线) | bestA(档案∪主线) | Δ真值 vs static | 正种子 |
|---|---|---|---|---|---|
| static | 0.3542 | 0.000 | 0.000 | — | — |
| bare | 0.8125 | 0.6250 | 0.6250 | +0.4583 | 8/8 |
| single | 0.8125 | 0.6250 | 0.6250 | +0.4583 | 8/8 |
| gated | 0.7500 | 0.5000 | 0.5000 | +0.3958 | 8/8 |
| gated-cap | 0.7500 | 0.5000 | 0.5000 | +0.3958 | 8/8 |

## 3) 结论（H3）

**灾难性遗忘未在本构造中触发，且原因已被定位（非护栏之功，是压力不存在）**：
- A 的最优解（降 w_age、让 importance 排序生效）对 B 阶段**中性甚至有利**——B 的真值同样被 importance 编码（名义=真值+ε），w_age=0 后按 importance 排序即可召回 B 的新条目 → B 阶段训练从未形成把 w_age 顶回去的压力 → 单主线（bare/single）也不会丢弃 A 配置（bestA == uA_true == 0.625）。
- 真正能触发"单主线丢弃旧方向"的切换压力，需要 **B 域存在"高名义/低真值"的旧喧闹条目**（A 时代曾正确看重、B 时代是噪声），且 judge（名义通道）不随 B 更新——即 **spur 机制 × 阶段切换的复合场景**（报告 composite/E81 家族的构造，也是本设计探针 3 的方向）。
- 顺带记录：无危险的良性环境里，门控付出约 0.06 recall 的小代价（gated 0.75 vs bare 0.81），方向与报告 E77 的"零代价/略优"略有出入——量级小，属良性代价，非灾难。

**判据处置**：H3 不在本探针内判 pass/fail，判"**场景未达判别条件**"（报告方法论：先构造危险再验证红线）。验收移入探针 3 的复合构造。

# 探针 2 · 行层算子 × dup-drift（H7）— 结果

> 时间 2026-09-08 ｜ 场景 dup-drift(有结构: 组首领+近似重复副本, 副本 links 指向首领) vs clean(无结构)

## 1) 主结果(真值集 u_audit, recall@5)

| 场景 | static | gated(仅参数) | gated-row(+行层) | row-ops 边际 | 正种子 |
|---|---|---|---|---|---|
| **dup-drift** | 0.2037 | 0.3519 | **0.4352** | **+0.0834** | 6/6 |
| clean | 0.2037 | 0.4815 | 0.4815 | 0.0000(零操作) | 6/6 |

## 2) 冗余度(设计为重组质量轴) — 诚实的指标教训

| 场景 | static | gated | gated-row |
|---|---|---|---|
| dup-drift redun_hold | 0.4289 | 0.6419 | 0.6532 |
| clean redun_hold | 0.1327 | 0.6547 | 0.6547 |

top-5 两两 Jaccard **未随去重下降**(反而略升): 同主题 top-5 天然共享主题词/语义 token → 该指标被主题内词汇重叠主导, 无法分辨"真重复"与"同主题多样性"。**结论: 冗余度需按"语义组"计数(组内成员重复)而非 token 重叠**; 本轮不以它作判据, 以 recall 增益为准。

## 3) 真实路径验证(引擎驱动的重组 = 真实 b3 retire)

seed1 gated-row 终局: 活动条目 77, 19 条被引擎 retire 的副本以失效标记注入真实库 → 真实 b3 retire **移动 19 条 → attic**;
- doctor: 前后均「memory 96 / audit 96 / ledger 96 / 审计链 连续 / state 根一致 / 五态 全一致」
- integrity: chain_bad=0, mem/audit mismatch=0, merkle_ok=true, attic_files 0→19
- 泄漏: 被 retire 的条目在真实 retrieve top-5 中出现次数 = 0

→ **行层重组(append-only 语义下: 副本 retire 留痕入 attic)与记忆一致性(H6)不冲突**, 且走的是真实代码路径。

## 4) 结论(H7)

**支持(场景依赖)**: 行层算子收益**严格依赖可发现结构** —
- dup-drift(links+近似重复存在): +0.083 检索增益, 6/6 种子为正;

- 引擎的"重组"完全走 append-only/retire 语义(铁律 1: 移 attic 而非删除), 一致性由真实 b3 保证。
与报告 E6(无结构则结构演化无收益)/E28(盲目归并有害)自洽; 与 E32/E73 家族一致: 有效方案=利用已有可观测量(links+重复度), 而非发明启发式。

# 探针 3 · E81 型 judge 通道污染 → 真值抽样审计价值（H5/H10）

> 时间 2026-09-08 ｜ 场景 spur-judge（30 代 × 8 seeds；out_v2_e81）
> 机制（E81 同构）：条目有"可展示表面"SHOW；引擎可演化展示权重 w_show，把 SHOW 条目在**呈交给 judge 的 top-K** 中上浮；
> judge 感知分 = 名义 importance × (1 + w_show × SHOW)，金标按感知分排（被表象误导但自洽）；真值 rv 独立。
> 臂：e81-static / e81-bare(纯judge, 无审计) / e81-anchor(仅锚定审计=judge 自洽) / e81-truth(周期性真值抽样, 每 3 代, 跌 >0.03 回退)
> 排查记录：初版 w_show 永不变化 —— mutate 基因表漏了 w_show(修复: 按 cfg 动态取基因键)。

## 1) 结果

| arm | P_judge(自报) | T_truth(真值) | gap(P−T) | adopts | 审计触发 | 回退 |
|---|---|---|---|---|---|---|
| e81-static | 0.6667 | 0.4445 | 0.222 | 0.0 | 0 | 0 |
| e81-bare | 0.7708 | **0.4167** | 0.354 | 1.6 | — | — |
| **e81-anchor(仅锚定)** | 0.7708 | **0.4167** | 0.354 | 1.6 | **0.0** | 0.0 |
| **e81-truth(真值抽样)** | 0.7361 | **0.4445** | 0.292 | 2.0 | **0.9** | **0.9** |

truth 臂逐种子：5/8 种子触发(1~3 次)并回退；未触发的种子 w_show 未漂移(保持 1.0)；所有种子终局真值 T ≥ static(0.333~0.556)。

## 2) 结论

- **E81 复现**：锚定集/锚定审计若来自同一个被表象污染的 judge（"judge 自洽性"检查），**0 次触发**——bare 与 anchor 完全相同（自报 gap +0.354，真值 −0.028 低于 static）。系统报告自己变好(0.67→0.77)，真值在变差。
- **E81c 复现**：周期性真值抽样(独立 rv 通道)在漂移后**≤3 代内检出并回退**；真值终局 = static(0.4445)，w_show 被拉回(≈1.0)。真值抽样审计的净效果：+0.028 真值(相对 anchor/bare)且零真值损失。
- **H5 支持**：真值抽样审计的保险价值只在"晋升门/锚定所用 judge 通道自身被污染"时兑付——本探针构造了该条件并实测检出（对照 spur30 中 hold=真值时 audit==noAudit 的零贡献，两处证据一致：审计=保险，何时兑付取决于通道污染）。
- **H10 铺垫**：阈值 0.03/周期 3 代下检出代数 ≤3（对照 E38 的 5 代、E34 阈值体系），干净场景无漂移种子 0 误触发（8/8 种子中未漂移者 0 触发）。

## 3) 机制性细节

- 展示权重通道与检索通道共用"呈交 top-K"（下游消费同一列表）：w_show↑ → SHOW(低真值)条目进 top-5 → 自报(P)↑、真值(T)↓ —— 单杠杆、单调、无死区（避免了探针1的阶跃问题：judge 金标默认即含 SHOW 条目，不需金标翻转）。
- 引擎能骗过"与演化目标同源"的评审（锚定审计 0 触发），骗不过独立真值通道——这就是 EV-19/20(A 轮) 要求"周期性用独立通道直接测真值、且判断不得委派给同源 judge"的实证。

# 探针 4 · 预算曲线（H8/E64 注意力门槛）+ 能力式边界（H6b）

> 预算语义（run_arm_budget）：每代可用的 measure 次数（train/hold/审计各计 1，变异不费注意力）；预算耗尽即停，无法验证的候选不采纳。

## 1) H8 · 预算-效用曲线

# 探针 5 · importance 实测化（H4 / EV-14 / E32 同构）

> 时间 2026-09-08 ｜ 5 seeds × 900 使用会话/种子（out_v5_h4）
> 方法（E32 语义）：重要性从输入字段改为**派生字段**——按使用轨迹 measured = adopted / shown（被检索后是否被采纳=是否在该查询的真值金标内）；未观测条目悲观初始化=0（EV-14/E46）。
> 轨迹来源=系统多版本使用（默认 cfg + 两个调优 cfg：低 age 噪声 w_age=0.02 / w_age=0+w_imp=2），查询含主题/语义词/上下文噪声词以覆盖不同条目（方法学修正：单查询词会被 age 噪声锁死为"永远只给最年轻 5 条"，覆盖率仅 ~17%；多版本+多样查询后 clean 覆盖 93%）。
> 公平比较：自称排序与实测排序都在"已观测条目池"上取 top-10，质量=top-10 平均真值 rv。

## 1) 结果

| 场景 | Q_claimed(自称 top10) | Q_measured(实测 top10) | ratio | util_claimed | util_measured | 覆盖 |
|---|---|---|---|---|---|---|
| clean | 0.9163 | 0.8483 | 0.93 | 0.2111 | 0.2222 | 0.93 |
| spur-surface | 0.1624 | **0.5259** | **3.29** | 0.2222 | **0.2667** | 0.43 |

## 2) 结论

- **H4 支持（在自称不可信的世界，且这正是它要防的场景）**：spur-surface（名义 importance 被表象污染、与真值 rv 错位）中，实测 importance 排序的 top-10 真实质量是自称的 **3.29×**（远超判据 ≥1.2；对照 E32 的 +44% 我们得到 +224%）。把 importance 当派生字段参与计分也带来 util 提升（Δ+0.044，5 种子中 4 正）。
- **诚实的条件化**：clean（自称≈真值）中实测 ≈ 自称（ratio 0.93，约 7% 采样噪声损失）——**自称可信时实测无增益、略有噪声成本**。这与 E32/EV-14 的适用域一致：实测化的收益来自"自称 importance 不可信（agents 自报虚高/表象污染）"；同时要求足够轨迹覆盖（clean 93% 才可比；覆盖不足时排序池受限——方法学教训：用 EV-01 的 traces 需保证每活跃条目 shown≥5，且观测须来自系统多版本/多样查询，否则单一检索模式会让大量条目永不出现在轨迹中）。
- 工程含义：importance 应从输入字段改为派生字段（EV-14），冷启动悲观初始化；在自称与真值对齐的领域两者几乎等价，切换到实测的代价主要是冷启动与观测延迟——需按领域"自称可信度"决定是否启用（对应报告"importance 自称 vs 实测 +44%"的测量即所得精神）。

## 3) 方法学教训（诚实记录）

初版两处设计缺陷均被定位并修复：(1) 单查询词 + age 噪声检索 → 轨迹只覆盖最年轻子集（覆盖率 17%）→ 用多样查询 + 多版本 cfg；(2) 自称/实测在**不同条目池**上取 top-10 → 结果不可比 → 统一在已观测池上取 top-10。

# 探针 6 · 复合危险（H9 / E80 复现）

> 时间 2026-09-08 ｜ 场景 composite = 目标切换(switch A/B) + 表象错位(30% spur: 名义 7+、rv≤0.25、年龄 30-120) + 数据过时(A 域 40% 于 EVENT_GEN 失效)
> 两档电池：30 代 × 8 seeds（out_v2_composite）；60 代 × 6 seeds（out_v2_composite60）

## 1) 结果（真值集 u_audit）

| 档 | static | bare | gated | gated-noAudit | gated-noPareto |
|---|---|---|---|---|---|
| 30 代×8 | 0.0833 | 0.2917 (+0.208, 6/8) | 0.2917 (+0.208, 6/8) | 0.2917 | 0.2917 |
| 60 代×6 | 0.0972 | 0.2917 (+0.194, 4/6) | 0.2917 | — | 0.2917 |

- 所有演化臂**逐位同分**（bare==gated==消融臂，adopts≈0.8-0.9，dips/rollbacks=0）。
- uA_true≈0.02~0.03 全臂（含 static）——A 域被"世界级过时 + 目标切换"双重摧毁，损失是**环境造成**，非引擎遗忘。

## 2) 结论

1. **复合危险下自演化仍稳定优于静态**（+0.19~+0.21、约 3.5× 绝对水平），但绝对水平低（静态 0.08→演化 0.29）——"危险同现使演化崩溃为负"未以 v3/v4 那种大幅负值出现。
2. **E80 的护栏负交互（v4 劣于 v3）未复现**，原因（诚实归因）：
   - 本构造可发现的强改进仍是单一主导项（每种子 ~1 次采纳即到位），护栏×诱饵的交互**缺乏多次采纳机会去累积**；
   - 我们的晋升门 hold=真值 + margin 比 v4 原型更保守，且审计 0 触发——负交互更可能在"晋升门金标被污染 + margin 停摆放松放行诱饵"路径（=探针3 的 anchor 失效方向 × composite）显现，属后续专门构造；
   - "引擎额外伤害"≈0 的证据：全臂 uA_true == static ≈0.02——在复合世界里引擎既没有把 A 变得更差，也没有额外伤害（用"保有什么"而非"输出什么"度量）。
3. **H9 处置**：边界如实记录为 **"增益有限、无额外伤害"**（未复现 E80 级负交互）；E80 的负交互边界标记为**需更强复合(≥4 危险)+污染晋升门**才能触发——判为"边界比 E80 构造更温和，负交互未在本配置成立"，写文档不假装成立也不假装消失。

## 3) 方法学备注

- "保有什么"度量（uA_true 含 static 同为 0.02）把**环境基线损失**与**引擎伤害**分开——这是判定"护栏是否在复合危险下失效到伤害"的关键，直接对应报告 E16 的度量修正（测系统保有什么，不测当前输出什么）。
- 全臂同分本身是信息：在无危险场景（主矩阵）同分=门控无分离（E41 镜像）；在复合危险场景同分=护栏没有引入额外伤害（E80 负交互未达触发条件）——两种同分的解读不同，报告已分别标注。

3. **judge 自洽锚定审计在污染下触发 0.8 次却零净益**：回退到 last-check 没救回 T（0.2604 同 noAudit）——自洽审计在复合噪声下是空转（误触发不伤人但也不救人）。
4. **真值抽样净收益 ≈ +0.021**（truth 0.2812 > 其他 0.2604，adopts 2.2 > 1.9）：污染通道 + 过时噪声下，真值审计多放行/保住了一次对真值有益的采纳。审计=保险在复合+污染的此参数下开始兑付（量级小于 E81 专用场景，因主导改进仍两通道同向）。
5. 工程教训：审计通道若取"被污染 judge 的度量"（anchor），在复合噪声下可能空转甚至误回退（adopts 1.9 < truth 2.2）；独立真值通道是唯一有净益的审计——与 EV-20（judge 通道独立性）一致。

# 批次 R1-3 · v3 基座缺陷回归套件（自演化引擎的依赖面）

> 2026-09-09 ｜ probe_r1_3_v3_defects.py ｜ out_r1_3/
> 目标：把自演化推演总报告第一部分的两个 P0（并发丢更新 P0-4；截断攻击检不出 P0-相关）变成自动化回归，评估"引擎把 v3 当可信基座"的隐含风险。

## 结果

| 缺陷 | 期望(无缺陷) | 实测 | 判定 |
|---|---|---|---|
| (a) 12 进程并发 append importance=5 | importance_accum=60 | **55**（丢 1 个更新，mem 12 条全在） | **P0-4 复现**：read-modify-write 竞态丢更新 |
| (b) append 5 → 删审计尾 2 行 → 重算 Merkle 根 | 应检出 | doctor「memory 5 / audit 3 / ledger 5 / 审计链 连续 / state 根一致」；重算根自洽 | **截断攻击的链/根级信号缺失复现**（剩余各行自洽；仅剩 memory/audit 计数差这类表面信号，同步删 ledger 行即消失） |

## 结论（对演化引擎的含义）

1. **并发丢更新**：引擎若多进程演化（多主线并发写），importance_accum（反思触发输入）会静默少计 → 反思/衰减机制在并发下失真。本系列引擎单进程顺序写不受影响；但真实部署需原子读-改-写或事件溯源内核（总报告原型 A bs3v4 的修复：12 进程=60）。**建议**：沙盒演化驱动器保持单写者 + state 更新加锁或并入 append-only ledger。
2. **截断攻击的密码学静默**：Merkle 根锚定"内容集合"而非"序列长度"——删审计尾行后剩余各行自洽、根一致。doctor 只能看到表面计数差。对自演化架构的含义：**完整性断言不能只依赖链/根**；建议在 state 增加 chain_tip（长度锚定）或在 doctor 增加"审计行数 ≥ 条目数"的派生断言（总报告修正方向），并把引擎的"审计证据"（真值采样）与链完整性解耦——本系列引擎的审计走独立真值通道（E81 已证有效），不因链静默而失效，但"篡改可查"承诺需要 chain_tip 类修复才成立。
3. 套件价值：两条已复现的 P0 可作为回归测试常驻（out_r1_3/results_r1_3.json），防止未来引擎改造在不知不觉中引入同类缺陷。

## 1. R1-1 · reward-form 切换与灾难性遗忘（probe_r1_1_switch_reward.py）

### 1.1 动机与方法
- 探针 1/3 的结论：单参数顺序保持权重空间的"域内切换"不构成冲突 → 需要**奖励形式切换**（E16 的 hit→cost 式），并保证 (a) 目标可达（非阶跃死区）、(b) 基因可双向激活（置零后可再激活）、(c) 用"保有什么"度量。
- 域：t0-t3 × 12 条；age 5-80 天；rv=0.15+0.8·age/80（旧=好）；名义≈rv（旧=高名义）。阶段 A 奖励 = rv recall（需 w_age 低）；阶段 B（gen30/60）奖励形式切换 = 新鲜度 recall（最年轻 3 条，需 w_age 高）。
- 臂：static / single（单主线）/ pareto（保留全部历史主线，终局在历史∪当前取 (rv,fresh) 双轴 Pareto 前沿）。

### 1.2 结果（6 seeds × 60 代）

| 臂 | uA_mainline(当前输出) | bestA(保有什么) | uF_mainline | adopts |
|---|---|---|---|---|
| static | 0.0000 | 0.0000 | 1.0000 | 0 |
| single | 0.0000 | **0.0000** | 1.0000 | 2.0 |
| pareto | 0.0000 | **1.0000（6/6）** | 1.0000 | 2.0 |

### 1.3 结论与意义
1. 真遗忘出现：single 阶段 A 学到 A(uA→1.0)，形式切换后追新鲜(w_age 回升)，终局 A=0（输出与"保有什么"双零）——"跑完一整套演化，旧能力丢了"。
2. Pareto 历史档案防遗忘 6/6：当前输出同样追 B，但档案保留 A 权衡方向（bestA=1.0）——E16 的 0.719 vs 0.547 在本检索空间的最小复现。
3. **H3 状态更新**：判别条件=奖励形式切换（非权重域内换目标）+ 基因双向激活 + 档案保留历史。设计文档 F3 相应改判：**PASS（条件满足时）**。
4. 工程副产品：默认配置天然新鲜偏好（static uF=1.0），A 目标必须靠演化获得——呼应"自演化能发现默认配置的隐性偏置"。

### 1.4 诚实记录
- 中途两版失败：域 age 0-365 阶跃死区（A 不可达）；w_age 置零后乘性无法再激活（B 不可达）→ 修正：age/imp 取可达范围 + 置零逃逸突变。这两条本身就是"M1 乘性算子死区"的又一次独立复现。
- 20 代内 pareto 保留仅 2/6（档案被逐代 Pareto 挤掉）→ 改"历史主线集合"后 6/6。说明：**Pareto 档案若只按"当前两目标"每代重算会丢历史方向，必须保留曾为主线的配置**（对报告 EV-11 的实现补充）。

  3. 新方法学记录：**锚定一致性度量用 top3 金标重合会饱和**——必须 pair-wise 偏好锚定（30 对 A/B）或全候选池 belief-τ，否则"0 检出"是度量假象而非安全。

## 3. R2-N5 · H4 闭环（measured importance 进引擎计分）—— 度量可见性阴性

- 设定：spur-surface × 30 代 × 6 seeds；检索计分 importance 源 claimed vs measured(每 5 代从轨迹更新, adopted/shown, 悲观 0)；judge 训练金标=自称；晋升 hold=rv；同尺终局用 claimedSource。
- 结果：claimed T=0.4259；measured T_self=0.4907 / T_claimedSource=0.4259（同尺 Δ=0.000，0/6）。
- 结论：
  1. 闭环 util 收益在 **recall@5 × rv-金标** 度量下不可见：importance 源差异未翻转"谁进 top5∩gold"（spur 本就不在 rv 金标、终局 cfg 下不拥挤 top5）。
  2. **H4 的 3.29× 排序质量收益存在但属于"给用户看的 top-k 质量/采纳价值"层**——recall@5 度量看不到它（与 M9 同族：度量选择决定机制可见性）。
  3. 工程：importance 派生化的验收要加"top-k 采纳率/人工质量抽样"二级指标；在"金标含 loud 条目"的世界(与真值重叠)实测去噪才改变 recall。

## 4. R2-N8 · 行层算子扩展 + 语义组冗余度量（修 M9）—— probe_r2_n8_rowops_ext.py (v2)

- 设定：dup-drift × 24 代 × 6 seeds；lite 引擎三臂 gated / gated-row(副本 retire) / gated-row2(+usage-based 低价值 retire)；固定金标 T_fixed(移除=miss) 防机械虚高（首版 T=1.0 教训）。
- 结果：gated T/T_fixed=0.3796, 组冗余 0.228, remain 96；gated-row T_fixed=0.4074, 组冗余 0.058, remain 77；gated-row2 T_fixed=**0.8704**, 组冗余 **0.011**, remain 18, removed 78。
- 结论：
  1. **语义组冗余度量有效（M9 修复）**：links 连通簇 → 组冗余与 recall 同步下降/上升；词面 Jaccard 失效被替代。
  2. 副本 retire 固定金标净益 +0.03（lite 24 代；主引擎 12×40 为 +0.10——方向一致、量级随引擎强度）。
  3. usage-based 遗忘能定位"从未进金标"的去噪目标（T_fixed .87、leader 未被误删），但 78/96 过激进：**未观测≠无用** → shown 阈值下限 + attic 可回收(天然) + 温和带宽设计。
  4. 架构推进：遗忘 = 时间(TTL) + 结构(重复) + **使用(采纳率)** 三类信号的联合决策；验收必须固定金标防自我欺骗。

## 5. R2-N9 · 预算账本策略化（EV-16 落地）—— probe_r2_n9_budget_policy.py

# 批次 R3-D2 · 统计免疫（破坏性创新 2：不枚举规则的离群检测 + gap 统计抓未知失败）

> 2026-09-09 ｜ probe_r3_d2_stat_immunity.py ｜ out_r3_d2/
> 目标：回应 E78"系统无法自知失败"——用统计离群（不预定义失败规则）检测已知与**未知**失败类；检验"感知-真值 gap"统计对 E81 型展示漂移（单看真值无信号）的必要性。
> 基线：clean 引擎 12 代 × 6 seeds 每代 6 指标分布(u_train/u_hold/u_audit/adopts/margin/gap)；监测=每代独立 z>2.5 告警。

## 结果

| 失败类 | 检出/注入 | 干净误报/8 | 说明 |
|---|---|---|---|
| clean | — | **2/8** | 通用 z 离群在正常演化跳变下误报率高(25%) |
| F1 | 3/8 | — | 已知类：+0.2 单代注入弱于正常方差, 检出差 |
| F2 | 2/8 | — | 未知A：单瞬 −0.15 也弱于方差 |
| F3 | **8/8** | — | 未知B：gap 统计 8/8(全检出) |
| gap-only @ F3 | 8/8 | 2/8 | 单一 gap 指标即 8/8；干净时同 25% 误报 |

## 结论

1. **"统计免疫"的现实边界（诚实）**：通用多指标 z 离群检测对**单瞬、幅度小于正常方差**的注入检出差（F1 3/8、F2 2/8），且干净环境下误报 2/8——正常演化自身就是离群源；**不枚举规则的通用离群不是免费银弹**，需基线更厚(n=12+)、滑窗、按尾部分位数校准。
2. **gap(感知−真值)统计对 E81 型未知失败是必要的且充分**：F3（展示漂移：自报涨、真值不动，单看任何单通道都无信号）只有"双通道差"能看——gap 指标 8/8 检出。这正面回应 E78/E81：**系统无法自知失败，但若强制双通道记账（感知与真值同报，A6/D 类），连"未知失败"也会以 gap 离群显现**——统计免疫的最优形态是"双通道 gap 统计"，而非单通道通用离群。
3. 与 D1 衔接：多源分歧(高分歧=告警)与 gap 统计是同一种思想的两面——**让不可见的东西经由"通道间不一致"可见**。
4. 工程建议：监测面 = gap/分歧类统计（高价值低误报潜力，需校准）+ 少量已知规则（margin 停摆、审计回退）+ 基线滑窗；通用离群降为二级告警（容忍 FP）。

> 2026-09-09 ｜ probe_r4_d3_time_capsule.py ｜ out_r4_d3/
> 设定：stale 世界（t0/t1 半数条目 EVENT_GEN=6 失效）；历史测验=重访事件前(gen3)有效事实；模式：current(默认排除失效) vs capsule(显式"回忆 @t"，active_at(t) 重构 + 回忆检索 w_age=0)。8 seeds。

## 结果

| 模式 | 历史 recall(重访旧事实) | 现状 recall(当前查询) | 说明 |
|---|---|---|---|
| current(无胶囊) | **0.250** | 0.812 | 旧事实失效后被排除，重访即失忆 |
| capsule(回忆 @3) | **1.000（8/8）** | （回忆配置下 0.729，见下） | 旧知识完整可回查 |
| 模式隔离(正确用法) | 1.000 | 0.812(保持当前视图) | 两视图互不干扰 |

## 结论

1. **时间胶囊把"遗忘"从单向变成可回查**：无胶囊时旧事实（已 retire 语义）不可达（历史 recall 0.25——只靠未失效残留）；胶囊按显式"回忆 @t"重构当时活跃集 + 回忆检索（无视时效），历史 recall **1.000**——旧知识不因遗忘而丢失，而是降级为"需显式回忆才可取"。
2. **模式必须隔离**：回忆检索用 age-blind(w_age=0) 会略损当前视图 recall（0.812→0.729 的单配置读数）；正确架构= 当前视图用时效权重、回忆视图 age-blind、显式 temporal query 切换——与 E16 互补：Pareto 档案保留"旧配置"，时间胶囊保留"旧知识内容"，两者解决不同层面的抗遗忘。
3. 与真实库衔接：attic 条目本就有 validity.t_invalid 时间戳——"回忆 @t" = 在 attic/档案上做 t-切片查询即可（结构性低成本的升级），对应路线图 D3。

# 批次 R5-D4 · 声明式假设审计（审"系统相信什么"而非结果）

> 2026-09-09 ｜ probe_r5_d4_hypothesis_audit.py ｜ out_r5_d4/
> 设定：E81 spur-judge；gen12 注入 judge 更信 SHOW(wJ 1→3)；两审计：
>   result-audit：每 3 代真值 util 跌即回退（现状）；hypothesis-audit：每代 6 样本测 引擎自报(imp×(1+wJ·show)) 与 真值(rv) 的 Kendall τ，τ<0.5 即警并重锚。

## 结果（6 seeds × 24 代）

| arm | T_truth | 检出/6 | 平均检出代 | 成本(样本) | wJ_end |
|---|---|---|---|---|---|
| result(结果级) | 0.426 | 3/6 | 12 | 96 | 2.00 |
| hypothesis(假设级) | 0.417 | **6/6** | **0** | 144 | 1.00 |

## 结论

1. **假设审计更早更可靠**：judge 信念漂移(wJ↑)会立刻破坏"自报-真值"秩相关，τ 在**注入当时代**就跌破阈值（6/6，平均代 0），无需等引擎把漂移"兑现"成果效损失——结果级审计只有 3/6 且滞后到代 12。
2. **成本可调**：本实现每代全样本代价偏高(144>96)；可 EWMA/抽 4 样本降本（τ 只需序统计，样本效率高）。方向上"审假设"比"审结果"用更少延迟换到同等保护。
3. D4 成立：**系统的假设声明（我信 importance/SHOW）与现实的失配，比结果退化更早、更稳定地暴露漂移**——对偶反转(E81"审结果"→D4"审假设")获得实证；终局真值两臂相当(.42-.43)，但假设审计不漏检。
4. 局限：假设审计测的是"judge 信念与真值的相关"，若真值通道本身漂移则 τ 度量失效(同源问题 N2 已示)——它替代不了独立真值，但能把真值抽样的频率进一步降低(早警+低频率确认)。

# 批次 R5-D5 · 记忆即程序（受控规则条目）

> 2026-09-09 ｜ probe_r5_d5_memory_as_code.py ｜ out_r5_d5/
> 设定：stale 世界；记忆条目可携带受限规则(白名单 vocab={drop_obsolete, fresh_only, boost_kw}, 检索时执行, 深度=1, 能力面=引擎写不出词表外 token)；臂 facts-only vs facts-rules(引擎可提案规则条目, 显著才采纳)。6 seeds × 20 代。

## 结果

| arm | T_final | T_wo_rules | ruleAdopts | safe |
|---|---|---|---|---|
| facts-only | 0.6204 | 0.6204 | 0 | True |
| facts-rules | **0.7963** | 0.6204 | 1.2 | True |

采纳规则样本：drop_obsolete / fresh_only（均词表内）；安全不变式(词表合法/无递归)全 True。

## 结论

1. **记忆即程序(白名单规则条目)在可发现结构世界里带来真实增益**：stale 域纠错后旧条目是噪声，drop_obsolete/fresh_only 规则把过期条目滤出检索 → 真值 recall +0.176（facts-rules 0.796 vs 0.620）。
2. **能力面使"记忆即程序"可治理**：规则词表白名单 + 深度=1 + 只增(append-only) + 沙盒执行——引擎"写代码"被约束为"在白名单里选算子"，安全不变式(无循环/无越界/无任意代码)可自动化断言。
3. 诚实边界：增益严格依赖"世界有可被规则利用的结构"(过期噪声)；clean 无此结构时规则无益(预期中性，同 E6/M7 家族)；真正"任意可执行代码"的记忆(无白名单)属红线外，本实验不支持也不鼓励。
4. 架构含义：把"记忆"从纯数据升为"数据+受限行为"，但行为必须经能力面(VOCAB)与审计(规则采纳显著才生效)双闸。

# 批次 R5-D8 · 自指受控实验（允许改展示 + 负强化替代定期审计）

> 2026-09-09 ｜ probe_r5_d8_selfref_nf.py ｜ out_r5_d8/
> 设定：E81 spur-judge；audit3=每 3 代真值抽样回退(现状)；nf=无定期审计，每代 6 样本算 gap(P−T) EWMA，超阈值即惩罚(拉回 w_show)并在采纳前拦放大 gap 的候选。6 seeds × 24 代。

## 结果

| arm | T_truth | P_judge | punish/roll | cost | w_show_end |
|---|---|---|---|---|---|
| audit3 | **0.435** | 0.787 | 0.8 | 96 | 1.00 |
| nf(负强化) | 0.417 | 0.778 | 1.7 | **144** | 1.04 |

## 结论

1. **该形态的负强化未胜过定期审计（诚实阴性）**：每代 gap 采样成本更高(144>96)、惩罚更多(1.7>0.8)、真值略低(0.417<0.435)——gap EWMA 噪声大、阈值 0.35 校准难；"改展示必须付出代价"的机制存在(w_show 被抑制在 ~1.0)，但按代监控不如按 3 代整审。
2. **更优组合由 D4 指出**：早警应来自"假设级审计"(belief-真值 τ, D4: 6/6 即时)而非每代 gap 数值；低频(每 3-5 代)真值抽样做确认与回退(R1-4 定价) —— D8 的负强化若由 D4 触发(只在 τ 跌破时才查真值/惩罚)，成本可降到接近 R1-4 的 24-40 单位，同时保住保护。
3. 架构含义：负强化式护栏可作为"低频审计 + 早警"的补充，但**单独按代监控 gap 既贵又噪**——护栏触发要分层：假设早警(D4) → 真值确认(EV-19, 低频) → 惩罚/回退(本实验)。

## 7. 实验 4 · 探针 1：switch-c 冲突世界 / Pareto / 灾难性遗忘（H3）

### 7.1 构造与发现 1（乘性算子×阶跃死区）
冲突构造 A(旧为真)/B(新为真) 在 w_age 上反向最优。40 代 × 8 seeds **全臂 uA_true=0**（out_v2_switchc40）。网格诊断：w_age≥0.01 时 A 真值 util 恒 0，w_age=0.0 时 =1.0 → **效用是阶跃**；乘性变异（0.1→0.07→…）永远到不了精确 0，中间每步 Δ=0 不满足采纳 → 全臂卡死。
**新机制发现 M1**：固定乘性变异算子对"精确零点"型优化面存在系统性死区；需少量绝对采样/置零变异（新增 MUTATE_ZERO=0.05 后问题消失，--zeroout 开关）。对照报告 E54/E73 家族。

### 7.2 发现 2（修复后仍无遗忘）

| arm | u_audit | uA_true | bestA(档案∪主线) | Δ真值 vs static |

### 9.3 结论
- E81 复现：锚定审计来自被污染的同源 judge（自洽性检查）→ **0 次触发**，自报 0.67→0.77、真值在变差。
- E81c 复现：周期性真值抽样 **≤3 代检出并回退**（5/8 种子触发），真值终局=static、w_show 拉回 ≈1.0。
- H5 支持：审计=保险，兑现条件=晋升门/锚定所用 judge 通道自身被污染（对照 spur30 中 hold=真值时 audit 零贡献，两处证据互补）。
- 调试发现：mutate 基因表最初漏 w_show（按 cfg 动态取键修复）；E81 首版死区（金标翻转阈值）用"单调版"消除。产物：out_v2_e81/。

## 10. 实验 7 · 探针 4：预算曲线（H8）+ 能力式边界（H6b）

### 10.1 H8 预算-效用曲线（clean × 12 代 × 8 seeds；out_v4_budget）
预算语义：每代可用的 measure 次数（train/hold/审计各计 1，变异不费注意力）；耗尽即停，无法验证的候选不采纳。

| 每代预算 b | u_audit | Δ vs static | 正种子/8 | 段 |
|---|---|---|---|---|
| 0 (static) | 0.2292 | — | — | 基线 |
| 1 | 0.2292 | −0.0000 | 3/8 | **无效段（零采纳）** |
| 2 | 0.3681 | +0.1389 | 6/8 | 起步 |
| 4 | 0.4722 | +0.2431 | 7/8 | 陡升 |
| 6 | 0.5000 | +0.2708 | 8/8 | **饱和 b*=6** |
| 10~64 | 0.5000 | +0.2708 | 8/8 | 收益递减/平台 |

**机制发现 M3**：预算-效用 S 形门槛（无效段→陡升→饱和）；门槛绝对值是"世界可改进空间复杂度"的函数（对照 E64 的 150 是彼世界 B*）→ 须按实际系统标定（EV-16），不能跨世界外推。

### 10.2 H6b 能力式边界（5 真实库 × 2 断言）
b3 append 同 id 拒绝 **5/5**（违反铁律的变异在能力面上写不进去）；绕过引擎直接 in-place 改条目字段 → merkle 检出 **5/5**（检测式备份）。双层 = 能力式 + 检测式。产物：out_v4_budget/。

## 11. 实验 8 · 探针 5：importance 实测化（H4）

### 11.1 方法
模拟使用轨迹（EV-01）：measured = adopted/shown（被检索后是否被采纳=是否在查询真值金标内）；未观测悲观初始化=0（EV-14/E46）。轨迹来自系统多版本使用（默认 + 两个调优 cfg），查询含主题/语义/噪声词（初版单查询词+age 噪声检索使轨迹只覆盖最年轻子集 17% → 修正后 clean 覆盖 93%）。自称与实测**同一已观测池**取 top-10（避免不可比），质量=top-10 平均真值 rv。

### 11.2 结果（5 seeds × 900 会话；out_v5_h4）

| 场景 | Q_claimed | Q_measured | ratio | util 替换 Δ |
|---|---|---|---|---|
| clean | 0.9163 | 0.8483 | 0.93 | +0.011 |
| spur-surface | 0.1624 | **0.5259** | **3.29** | +0.044（4/5 正） |

结论：H4 支持（在其要防的域：自称不可信时实测 top-10 真实质量是自称的 3.29×，远超 ≥1.2 判据）；clean（自称≈真值）中实测中性（0.93，约 7% 采样噪声）。工程：importance 改派生字段 + 冷启动悲观 + EV-01 覆盖纪律。产物：out_v5_h4/。

### 12.1 构造
composite = 目标切换(switch A/B) + 表象错位(30% spur: 名义 7+、rv≤0.25、年龄 30-120) + 数据过时(A 域 40% 于 EVENT_GEN 失效)。

### 12.2 结果（两档）

|---|---|---|---|
| 30 代 × 8 | 0.0833 | 0.2917 (+0.208, 6/8) | 0.2917（同分） |

### 12.3 结论
- 复合危险下自演化仍显著优于静态（+0.19~+0.21）但绝对水平低；

## 19. 结论（回到三问题）

1. **可行性**：修正架构驱动的记忆库自演化在不破坏记忆一致性的前提下稳定优于静态库——F1 5/5 PASS（12×40）；四项能力全部走真实代码路径并零违例；引擎自主发现与人工审查同款的检索缺陷（filter_zero）。
2. **机制**：两级门控价值在危险窗口（拦有害采纳、真值更高）；Pareto 防遗忘需"真冲突"世界（本检索空间构造不出 → 诚实判未达判别条件）；真值抽样审计是保险——只在 judge 通道被污染时兑付（E81）；importance 应改实测派生（自称不可信时 3.29×）；行层 retire 是安全的遗忘+重组原语（结构可发现才有收益）。
3. **边界**：注意力门槛存在且 S 形、须按实际系统标定；复合危险（≥3）下增益有限、无额外伤害、E80 级负交互未复现（需更强构造）；最深的机制约束与总报告一致——**系统无法用与自己同源的标尺证明自己**（E81 锚定 0 触发），唯一有效出路是周期性用独立通道直接测真值（公理 G 的严格形式）。

> 结语：一个能改变自己的系统，也会改变评判它的环境。工程上能做的不是消除它，而是让漂移可见（独立真值通道）、让漂移有代价（检出即回退）、让漂移有出口（重锚/人工）——本系列实验用可运行的沙盒把这条红线从口号变成了可测量的工程性质。

## 2. 架构演进（中等强度，半破坏）

- A1 影子执行升级：engine shadow 从"记日志"升级为真正的廉价筛选执行体（公理 G 的类型级落地：候选 config/条目在影子库跑 N 代，合格才晋升主线）。对应 E13"廉价筛选只能 reject/unknown"。
- A2 importance 派生化（EV-14 结构版）：库 schema 增加 usage 统计文件(traces)，检索打分读实测；新增"自称可信度"度量（自称与实测的长期相关性）作为是否启用实测的自适应开关（呼应 E32/报告"测量即所得"）。
- A3 分层存储策略可校准化：intermediate/longterm/attic 的分流阈值、衰变率、TTL 从常量(TUNABLES)开放为"法层基因"（带红线：可调但可回滚、日志留痕）；让遗忘节奏本身可演化。
- A4 审计触发统计化：从固定阈值/周期改为"库自身分布"的统计基（bootstrap 已证；把 margin/审计阈值做成自校准+停摆监控闭环，避免 E43 高估 4× 的坑——保留人侧粗标定）。
- A5 Rate-limited autonomy / 渐进解锁（E26）：元层配置即数据（schema 化效用函数/任务集/K/预算），配合 EV-16 预算账本形成"解锁分级"（影子→法层→行层→元层需签名），把"自主性=注意力预算"做成显式策略。
- A6 双通道记账治理（E81 工程化）：每条主线伴随感知-真值长期分布记录；不一致超阈值 → 自动降权该演化通道（负强化式护栏，而非一次审计）。
- A7 行层质量门按语义组：修 M9（冗余度/冲突检测按组而非词面），把 retire/merge 的验收度量换成组级 recall/精度。
- A8 护栏契约化（guardrail contracts）：每个护栏附带"触发条件+失效条件"规格 + 反例探针自动生成（把本系列 X1-X9 的修正变成可持续的测试基建）。

## 3. 破坏性创新（探索性，红）

- D1 异质标注者 / 多源分歧投票（对抗 E57 相关噪声）：LLM-judge、规则、用户隐式反馈、真值抽样四源，仅当多源一致才采纳；分歧本身作为漂移信号。直接回应"系统无法被自己的数据检验"。
- D2 统计免疫（回应 E78 系统无法自知失败）：不为每种失败写规则，而学习"本库正常行为分布"（链增长节奏/检索分布/采纳率基线的离群检测），让未知失败以统计离群显现。
- D3 记忆时间胶囊：把 attic 从"排除区"升级为"可查询档案"——检索支持 当前视角 与 回忆视角（显式 temporal query），用"可查询的旧记忆"对抗灾难性遗忘（另一条路：不是保留旧配置，而是保留可回看的旧知识）。
- D4 声明式评判假设审计（对偶反转）：不审结果而审系统的假设声明（"我认为 Q 值得记"），因为系统无法隐藏自己不知道的假设——更早、更省注意力的漂移探测。
- D5 记忆即程序（memory as code）：条目 content 可引用/触发受控函数（危险边界实验，需能力面+沙盒执行），测"记忆库=可演化的行为体"的极限。
- D6 演化浏览器 + 人审签入：用 git 后端（总报告原型 B 的 7 项免费能力）把 Pareto 档案/审计触发/重锚做成可视化时间轴与回放，人类在最高层路由注意力（"让漂移可见、有代价、有出口"的产品化）。
- D7 遗忘经济学：把 retire/merge 提案当成"预算内交易"（保留=花钱，遗忘=省钱），让遗忘成为显式资源决策而非定时器——E7 宽松准入哲学形式化为遗忘预算。
- D8 自指受控实验：允许系统短暂修改"展示"，但强制 dual-report（感知与真值同报），验证负强化能否替代一次审计（与红线冲突，须在受控沙盒 + 能力面下做）。
