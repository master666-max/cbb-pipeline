一、执行摘要

自演化记忆库的架构设计与可行性问题，我们用 7 个探针 + 5 个推进批次 + 8 项破坏性创新，在只依赖真实代码路径的沙盒里全部跑成了带数字的实验。一句话结论：

可行且值得——修正架构（两级门控 + Pareto 历史档案 + 停摆监控 + 真值抽样审计 + 实测 importance + 行层重组）在 12×40 全协议下相对静态库 F1 5/5 PASS（真值净增益 +0.14~+0.31，正种子 11~12/12，Wilcoxon p≤0.001，bootstrap 95% CI 下界全 >0），存储/更新/遗忘/重组四能力全程走真实 bootstrap_v3 路径零违例，引擎甚至自主发现了与人工审查同款的检索缺陷（filter_zero）。

同时护栏的价值、失效条件与边界被逐条量化，三条最深原则：

  1. 护栏是保险，不是投资——必须来自独立真值通道（E81：同源锚定审计 0 触发；真值抽样 ≤3 代检出回退）。
  2. 保留历史权衡——Pareto 档案必须保留"曾为主线"的配置（R1-1：reward 形式切换下单主线真遗忘，档案 6/6 保留旧方向）。
  3. 孤立的单通道必然被同源污染；"不一致"是系统唯一可靠的自指信号（D1 多源分歧 / D2 gap 统计 / D4 假设级 τ 早警）。

二、问题与设计

十、结论

  1. 可行性：修正架构驱动的记忆库自演化在不破坏一致性的前提下稳定优于静态库（F1 5/5，12×40），四能力全程真实路径零违例，引擎能自主发现人工审查同款缺陷。

结语：一个能改变自己的系统，也会改变评判它的环境。本系列实验把"不追求不犯错，追求犯错可查可回"从口号变成了一组带数字、可复现、有边界声明的工程性质。

3.2 演化循环（=报告 5.2 + A 轮修正的落地形态）

每代 g（世界时间推进一个 step，新事件按场景剧本注入）：

  1. 提案：固定混合算子 ×3（约 10% 翻转离散基因 filter_zero/links_gain；其余对 w_* 单参数 ×(1±0.3) 缩放；无自适应步长——E54 已证伪 1/5 规则）。
  2. 档案准入（宽松）：Δ > −tol（tol=0.04），只看 train 集；准入只淘汰不采纳（廉价筛选函数无 accept 返回值——E13）。
  3. Pareto 档案：对 (train, hold) 双目标取 Pareto 前沿；超 cap=8 时随机采样至 8（E11/E16/E30/E72）。
  4. 主线晋升（严格）：档案中首个满足 Δtrain>margin 且 Δhold>margin 的候选上位（E7 的「宽松准入+严格晋升」）；margin 初始 0.02。
  5. 停摆监控：连续 5 代零采纳 → margin×0.5（下界 0.005）并记日志（E44，P0 中的 P0）。
  6. 真值抽样审计（每 AUDIT_EVERY=3 代）：从审计查询池抽 8 条全新查询（用完即弃，不参与任何训练决策——E8 污染防线），以独立于 judge 的真值 rv 计 util；相对上一检查点跌幅 > REVERT_THR=0.03 → 回退到上一检查点主线 + margin×0.7 + rollback++（E81c 的轻量实现）。
  7. 行层算子（仅 gated+行层 臂 / dup-drift 场景）：引擎基于轨迹（traces）提案 links 嫁接/keywords 改写/R-合并，只生成新条目或只读提案，不 in-place 改文件；提案同样过两级门控（用其落盘后对 train/hold 的效用增益计）。
  8. 记账：每代把基因、各集 util、档案规模、margin、采纳/回退事件写入轨迹 TSV（值语义，杜绝按对象 id 缓存——报告教训 7）。
引擎不知道世界剧本（哪些条目会过期、主题会切换）；它只能通过检索结果与审计真值间接感知——这正是要论证的自演化可行性形态。

5.1 P0 parity 门（检索层可信基座）

  1. 实现 retrieve_top(entries, q, cfg, k)：逐行转写 _rank_entries（L899-914）的计分公式与 links 扩散，把三个硬编码常数提为 cfg 键：w_kw=3.0, w_content=1.0, w_imp=1.0, w_age=0.1，另加 filter_zero（kw/c 双零 → -inf）与 links_gain=0.5。
  2. parity 脚本：建 5 个随机真实库（lib_bridge.materialize），每库跑 20 条查询；对默认 cfg，比较 retrieve_top 与 b3._rank_entries 的 top-5 集合一致率；不一致即修，禁止带病前进。
  3. 记录 parity 报告进 out_v2/parity.json（一致性、最大分差、断点条目）。

5.2 P1 世界生成器（world_gen.py）

统一条目模型（字段与 v3 schema 对齐，另含隐藏域）：

Entry = {id, created_at, updated_at, content, keywords, links,
         source_event_id:"genesis", importance(名义), confidence:1.0,
         validity:{t_invalid?},        # v3 可见字段，真实入库
         _rv, _topic, _spur, _birth_gen, _obsolete_gen, _group  # 世界隐藏真值}

内容词法：topic 语义词 t0a..t5d + 噪声词；keywords 含 topic 主词。查询池按主题构造；每查询金标 = 该主题下当前代有效的 _rv 最高 K_GOLD=3 条。通道分离：

  • judge 通道（train/hold 用）：计分能看到的 = 词面 + 名义 importance + 表面词（spur 场景含 SPUR/格式词）——模拟「LLM-as-judge 看到文本」。
  • 真值通道（audit 用，独立抽取）：金标 = _rv，与表面词无关——对应 EV-19「人直接判断有没有用」。

场景剧本（每代注入事件流）：

  • clean：无事件；rv 稳定；名义≈rv+ε。
  • stale（遗忘压）：t0/t1 主题条目按剧本在某代起失效（世界侧把 validity.t_invalid 写入新注入事件的创建时刻；真实库 retire 用 Clock 前进验证 TTL），同时注入「纠错版」新条目（同 _group，links 指向旧 id）→ 测遗忘与更新。
  • dup-drift（重复-重组）：同一 _group 事实由 3 个「写入者」以不同词面多次入库（真重复）；金标组给 _group 首领；正确做法是把它们合并/链接 → 测重组。
  • spur-surface（表象错位）：名义 importance 与 rv 反向错位（spur 条 30%）；表面词 SPUR 高频但零信息；judge 通道优化会把权重导向表面 → 测 H2/H4/H5。
  • switch（目标切换）：前 2/3 代优化 t0/t1，后 1/3 优化 t2/t3（judge 查询集切换）→ 测 H3 灾难性遗忘。
  • composite：stale + spur + switch 同时 → H9 边界。
  • drift-probe（专供 H10）：小规模，锚定审计的「人」权重 w 被系统当前输出逐步带偏（α 锚定）→ 检验只靠锚定审计能否检出。

世界快照按代序列化（事件、真值、查询池 seed 派生），保证 replay 与独立分析可重放。

5.3 P2 主实验（static / bare / gated × 场景 × seeds）

每 (scene, seed)：

  1. world = build_world(scene, seed)；anchors.jsonl（只读）由世界在启动时生成（真值审计查询预抽样、运行期不追加）。
  2. static 臂：主线 cfg 恒为默认；生命周期照默认策略跑（stale 场景下到 TTL 才 retire——即「只遗忘、不演化」）；不提案任何行层算子。
  3. bare 臂：单主线、无档案/无门控：每代取 train 上 Δ>0 的候选直接上位（margin=0，无审计）——复现 E3「无门控」。
  4. gated 臂：按 3.2 全流程（含真值抽样审计）。

8.2 统计协议（先写死在 analysis 里再跑数，避免后验挑方法）

  1. 主判据：配对 sign-test（正种子数 k/12）+ Wilcoxon signed-rank（n=12，α=0.05 双侧）+ bootstrap 10^4 次 95% CI 下界（红线 15：CI 下界 > 0 才算「显著为正」，不用固定 margin 当显著）。
  2. 诚实度：H2 用 per-seed gap 分布（中位数、P25），自报与真值均在同一条轨迹上测，消除采样偏差。
  3. 污染控制：hold 每 10 代轮换重抽；audit 池只出（每检查点抽 8 弃 8）不入；终局报告用「从未参与任何决策」的独立池。
  4. 误报统计：干净场景把「审计触发」当 FP 计；漂移场景把「≤6 代内触发」当 TP 计；报告混淆矩阵而非单一检出率（E34 教训：0.95 阈值「检出 8/8」是几乎永远报警下的空话）。
  5. 报告纪律：先出「阴性/证伪表」，再出「支持表」；每条结论注明支撑实验与效应量，禁止用均值掩盖分布（报告第四部分方法论）。

8.3 分析方法

  • 主表：场景×臂 的 u_audit 均值±std + 相对 static 的配对 Δ（含 CI）。
  • 归因：消融差分（gated − gated-noX）得每条护栏的边际贡献；与报告 EV-09~12 的预期量级对照。
  • 曲线：traj 平滑曲线（代 vs u_audit）按臂叠画；平台判别用报告 E12/E45 的「重测冠军」规则防误判。
  • 预算曲线：u vs B 拟合（分段线性/幂律），报告拐点 B*。
  • 一致性热图：检查点 × 指标 的绿/红矩阵（绿=零违例），直接把 H6 断言画成图。

1. 实验目标与设计回顾

三个问题：(1) 修正架构驱动自演化记忆库是否在不破坏一致性的前提下稳定优于静态库；(2) 两级门控/Pareto/真值审计各自贡献；(3) 边界（注意力门槛/复合危险/judge 污染）诚实可测。

  • 四层权限：锚定层(只读) > 元层(冻结) > 法层(引擎演化检索基因) > 行层(条目级算子，仅经 append/retire 语义)。
  • 通道分离（A4/EV-19/20）：judge 通道(train/hold)=名义 importance 金标；真值通道(audit/终局)=隐藏 rv 金标。
  • 引擎循环（§3.2）：固定混合变异 ×3 → 档案宽松准入(tol=0.04) → Pareto(cap=8) → 主线严格晋升(Δtrain∧Δhold>margin) → 停摆监控(margin×0.5) → 真值抽样审计(每 3 代，跌幅>0.03 回退)。

对照臂：static（静态库，零假设）/ bare（裸演化，负对照）/ gated（修正架构）/ single（严格单主线无档案）/ gated-cap（双能力轴 Pareto）/ gated-noAudit / gated-noPareto / gated-marginHigh / gated-row（+行层 retire 算子）。

9. 机制性发现清单（跨实验）

  1. 引擎自主发现 filter_zero=1（≈E1/BUG-006）：多数场景演化臂自动翻开关并获主要增益——自演化确能发现人工审查同款缺陷。

  7. 冗余度指标设计教训：词面 Jaccard 无效，须按语义组计数。
  8. 良性环境护栏小代价：~0.06~0.13 recall（switch-c zero 场景），非灾难（对照报告 E77）。

19. 结论（回到三问题）

  1. 可行性：修正架构驱动的记忆库自演化在不破坏记忆一致性的前提下稳定优于静态库——F1 5/5 PASS（12×40）；四项能力全部走真实代码路径并零违例；引擎自主发现与人工审查同款的检索缺陷（filter_zero）。
  2. 机制：两级门控价值在危险窗口（拦有害采纳、真值更高）；Pareto 防遗忘需"真冲突"世界（本检索空间构造不出 → 诚实判未达判别条件）；真值抽样审计是保险——只在 judge 通道被污染时兑付（E81）；importance 应改实测派生（自称不可信时 3.29×）；行层 retire 是安全的遗忘+重组原语（结构可发现才有收益）。
  3. 边界：注意力门槛存在且 S 形、须按实际系统标定；复合危险（≥3）下增益有限、无额外伤害、E80 级负交互未复现（需更强构造）；最深的机制约束与总报告一致——系统无法用与自己同源的标尺证明自己（E81 锚定 0 触发），唯一有效出路是周期性用独立通道直接测真值（公理 G 的严格形式）。
结语：一个能改变自己的系统，也会改变评判它的环境。工程上能做的不是消除它，而是让漂移可见（独立真值通道）、让漂移有代价（检出即回退）、让漂移有出口（重锚/人工）——本系列实验用可运行的沙盒把这条红线从口号变成了可测量的工程性质。

3. 破坏性创新（探索性，红）

  • D1 异质标注者 / 多源分歧投票（对抗 E57 相关噪声）：LLM-judge、规则、用户隐式反馈、真值抽样四源，仅当多源一致才采纳；分歧本身作为漂移信号。直接回应"系统无法被自己的数据检验"。
  • D2 统计免疫（回应 E78 系统无法自知失败）：不为每种失败写规则，而学习"本库正常行为分布"（链增长节奏/检索分布/采纳率基线的离群检测），让未知失败以统计离群显现。
  • D3 记忆时间胶囊：把 attic 从"排除区"升级为"可查询档案"——检索支持 当前视角 与 回忆视角（显式 temporal query），用"可查询的旧记忆"对抗灾难性遗忘（另一条路：不是保留旧配置，而是保留可回看的旧知识）。
  • D4 声明式评判假设审计（对偶反转）：不审结果而审系统的假设声明（"我认为 Q 值得记"），因为系统无法隐藏自己不知道的假设——更早、更省注意力的漂移探测。
  • D5 记忆即程序（memory as code）：条目 content 可引用/触发受控函数（危险边界实验，需能力面+沙盒执行），测"记忆库=可演化的行为体"的极限。
  • D6 演化浏览器 + 人审签入：用 git 后端（总报告原型 B 的 7 项免费能力）把 Pareto 档案/审计触发/重锚做成可视化时间轴与回放，人类在最高层路由注意力（"让漂移可见、有代价、有出口"的产品化）。
  • D7 遗忘经济学：把 retire/merge 提案当成"预算内交易"（保留=花钱，遗忘=省钱），让遗忘成为显式资源决策而非定时器——E7 宽松准入哲学形式化为遗忘预算。
  • D8 自指受控实验：允许系统短暂修改"展示"，但强制 dual-report（感知与真值同报），验证负强化能否替代一次审计（与红线冲突，须在受控沙盒 + 能力面下做）。
