## 结论

1. **真值保护在本环境几乎处处饱和到 static（T≈0.444）**——审计的收益不是"比 static 更好"而是"不让真值掉到 static 之下"（对照无审计时 bare/anchor 真值 ≈0.417）。
2. **保险定价的边界明确**：密集审计（freq1-2，cost 80-160）带来大量回退（7-8 次）且无额外保护——**审计是保险不是投资**（报告 E25 的 +0.5 vs 成本面在本网格量化）；稀疏真值抽样即足够。
3. **最优前沿**：freq∈[5,10]、sample≥8、thr=0.05 → cost 24-40（约 1.2-2 单位/代），rollbacks 0.5-1.2，T 零损失。样例频过低（freq10×sample4×thr.03）会漏检一次（T=−0.028）。
4. **工程默认值建议**：审计周期 5-10 代、每检查点抽 8 条真值、阈值 0.05；并把审计预算计入 EV-16（约 2 单位/代），不足时宁缺毋滥（配合 H8 预算门）。
