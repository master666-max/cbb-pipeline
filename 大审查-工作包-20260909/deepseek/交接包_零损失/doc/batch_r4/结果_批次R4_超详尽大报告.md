## 1. D3 · 记忆时间胶囊（attic 可查询档案 / 回忆视角）—— probe_r4_d3

- 设定：stale 世界(t0/t1 半数 EVENT_GEN=6 失效)；历史测验=重访事件前(gen3)有效事实；模式 current(排除失效) vs capsule(回忆 @t: active_at 重构+w_age=0)。
- 结果：历史 recall current **0.250** vs capsule **1.000（8/8）**；现状 recall current 0.812（回忆配置下 0.729 → 须模式隔离）。
- 结论：
  1. 遗忘从"单向排除"升级为"显式回忆才可取"——attic 本带 t_invalid 时间戳，"回忆 @t"=t-切片查询即可(结构性低成本)。
  2. 模式必须隔离：单一配置不能既当前时效又回忆 age-blind；架构=显式 temporal query 双视图。
  3. 与 E16/R1-1 互补：Pareto 保留旧配置(参数层)，时间胶囊保留旧知识(内容层)——两层抗遗忘。
- 产物 out_r4_d3/。

## 2. D6 · 演化浏览器（谱系时间轴/回放/人审签入原型）—— probe_r4_d6

- 设定：e81-truth(spur-judge, 含回退) 与 gated(composite) 各 2 seeds；每代快照(cfg+效用+事件)；回放=记录 cfg 重算效用比对。
- 结果：4 谱系 nodes 16-18，**replay_mismatch 全 0**（确定性）；e81 seed1 adopt2/rollback1 可定位漂移-检出-回退三段；产物 lineage.json/timeline.md/ascii 树。
- 结论：浏览器=注意力最高层路由的基座（漂移可见→人冻结/签入/分叉）；真实库版须以 chain(+chain_tip) 为谱系锚；局限=目前用引擎 traj 非真实审计链。

## 4. 方法学记录

- D3 首版胶囊 recall 未提升（回忆检索仍受 age 罚压制旧条目）→ 回忆模式 w_age=0（X14）。
- D6 首版回放误报（traj 4 位小数 vs 1e-6）→ 容差 1e-3；e81 traj 缺 cfg 键 → 用 E81_CFG0+w_show 重建（X15）。
- 样本量：D3 8 seeds、D6 2 seeds ×2 场景（原型级，非全功效）。
