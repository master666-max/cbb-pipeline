## 1. D1 · 异质标注者 / 多源分歧（对抗 E57/同源失效）

- 设定：composite corr=1.0（引擎唯一可见真值=纯声称——N2 中 gated==bare 的极端）；S1 judge 声称 / S2 内容规则 / S3 使用实测；臂 single / consensus(2/3 多数) / truthsampled；24 代 × 6 seeds。
- 结果：T0 single 0.1666 / consensus 0.1945 / truthsampled 0.2083（相对 single +0.028 / +0.042）；static 0.0972。
- 结论：
  1. 异质标注确实降低共享偏差伤害（单调 +）；这是 E57"异质标注者"解药与 E81"同源锚定 0 触发"对称解在本架构的首个实证。
  2. 幅度温和（源只是代理、adopts 低、世界噪声大）；源质量决定增益。
  3. 局限：consensus 中 S1 常赢仍可能带 spur 入金标；**最终仍需至少一个真值源**；多源价值=把"信谁"结构上分散 + 分歧即警报（与 D2 衔接）。
- 产物 out_r3_d1/。

## 2. D2 · 统计免疫（不枚举规则的离群检测 + gap 统计）

- 设定：clean 引擎 12 代 基线 6 seeds 六指标分布；监测=每代 z>2.5；注入 F1 自报通胀 / F2 审计骤降 / F3 展示漂移(仅 gap 有信号) / clean。
- 结果：通用 z：clean FP 2/8；F1 3/8；F2 2/8；F3 8/8；gap-only @ F3 8/8（干净 2/8）。
- 结论：
  1. 通用离群不是免费银弹（正常演化即离群源；单瞬小注入低于方差检出差）。
  2. **双通道 gap 统计是 E81 型未知失败的必要且充分检测**（8/8）——"系统无法自知失败"的工程解 = 强制感知-真值同报，让未知失败以通道间不一致显现（A6/D4 思想的数据支持）。
  3. 监测面建议：gap/分歧类统计为核心 + 已知规则(margin/审计) + 基线滑窗；通用离群降为二级。
- 产物 out_r3_d2/。

## 3. 破坏性创新对架构的增量

| 原则 | 证据 | 落地 |

## 6. 批次终点的一句话

两条破坏性创新把"评审"与"自知"从架构外部移进系统内部：**评审可以是多通道分歧管理（信谁由结构分散）、自知可以是双通道 gap 统计（不可见的失败以不一致显现）**——两者共用同一洞见：孤立的单通道必然被同源污染，而"不一致"是系统唯一可靠的自指信号。
