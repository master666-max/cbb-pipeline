## 结论

1. **异质标注确实降低共享偏差伤害**：在"引擎唯一可见真值=纯声称"的极端世界（N2 corr=1.0 下 gated==bare 的构造），引入 S2/S3 两个与声称不同源的标注后，honest T0 单调上升：single 0.167 → consensus 0.194（+0.028）→ 真值抽样 0.208（+0.042）。方向支持 D1 假设（报告 E57 的"异质标注者"解药；E81"同源锚定 0 触发"的对称解）。
2. 幅度温和：世界噪声大、adopts 低（0.7-1.8），且 S2/S3 只是代理(非完美)；量级敏感于源质量——工程含义：**标注者同源性是连续变量，源的"声称-内容-使用"三角分立每加入一个就恢复一部分信息差**。
3. 局限（诚实）：consensus 2/3 多数在 spur 占比高时仍可能把 spur 带进金标(S1 常赢)；truthsampled 用独立 rv0 代理最好——**最终仍需要一个真值源**，多源的价值是把"谁该被信"从结构上分散，而不是替代真值。
4. 破坏性价值：把"评审"从单通道(judge)变成**多通道分歧管理**——分歧本身可作为漂移/污染信号（分歧高 = 通道不一致 = 警报），与 D2 统计免疫衔接。
